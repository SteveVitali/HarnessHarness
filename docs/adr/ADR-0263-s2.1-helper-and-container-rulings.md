# ADR-0263: S2.1 helper/container rulings — `hh-helper/1` over a short AF_UNIX rendezvous, kernel-minted `commit_proof`, kernel-side `fs_change` diffing, podman for `local_container`, and `tier-c1` for the C1 executor halves

- **Status:** Accepted
- **Date:** 2026-09-18
- **Ticket:** S2.1
- **Requirement ids:** R-2.5.5 · R-2.2.5 · R-2.5.5¹
- **Spec:** §5d.5 (helper/executor) · §5a.5 (environments) · ADR-0050
  (helper layer) · ADR-0062 (containment backend) · ADR-0100…0102
  (dispatch/effect lifecycle) · ADR-0130…0138 (environments/snapshots) ·
  ADR-0182 D8 (removability)
- **Rung (ADR-0024 obligation):** **C0** — MUST-code/MUST-data: the
  `hh-helper` binary + `hh-helper/1` closed verb sum, the attribution-token
  echo, `commit_proof` admission, helper-enforced deadlines, the
  process-group ladder, `local_sandboxed`/`local_container` backends, the
  `fs_tree` snapshot/diff/restore/verify verbs, `derive` modes, per-class
  meters, executor-side dedup + `preserve_until` (C1).

## Context

S2.1 moves execution out of the kernel process per ADR-0050's helper
layer. The spec fixes the *semantics* (kernel authoritative; helper
executes and reports; token echoed verbatim; `fs_change` via baselines)
but left several mechanism choices to the ticket:

1. **Wire substrate.** The helper session needs a channel the kernel can
   *reattach* to after its own restart (`resume_session_id`, the
   unreachable/heal ladder). Stdio cannot be re-opened; a TCP listener
   would widen the surface beyond loopback semantics.
2. **macOS AF_UNIX path limit.** `sockaddr_un.sun_path` is 104 bytes on
   darwin; session sockets under the (deep, content-addressed) store root
   overflow it, and test-time temp dirs nest deeper still.
3. **`commit_proof` construction.** §5d.5 §4 requires a `commit_token`
   the helper can verify locally (the kernel may be unreachable at exec
   time); the helper must never mint authority.
4. **`fs_change` authority.** The spec says `fs_change` is computed "via
   baselines" — it does not say *which side* diffs.
5. **`local_container` runtime.** The Stage-2 gate decision (`34fd5d9`)
   authorized podman on this operator host; image spelling, network/fs
   defaults, and the meters source needed pinning.
6. **C1 removability.** R-2.5.5¹'s executor-side dedup and
   `preserve_until` are C1 — a build without them must *refuse honestly*
   (`removability(0)`), not silently degrade (ADR-0182 D8).

## Decisions

- **D1 — `hh-helper/1` is NDJSON over an AF_UNIX stream socket, served by
  the `hh-helper` binary.** One frame per line, decoded by the shared
  `hh-wire` JSON codec (CC1/CC7 — one canonical codec, no second wire
  format). A socket (not stdio) because the kernel re-connects across its
  own restarts: the driver persists `{session_id, nonce, sock_path}` and
  `resume` re-`hello`s the same endpoint. A helper crash is evidence
  (`unreachable`), never a silent redispatch.
- **D2 — the rendezvous lives under `std::env::temp_dir()` with a
  content-derived short name** (`hh-<idp_id(store_root)>/s-<id>.sock`),
  and the resolved path is *persisted in the store* so `resume` rebinds
  the exact socket. This keeps the path under the 104-byte AF_UNIX limit
  while staying deterministic (CC1 — no ad-hoc randomness; the name is
  derived, the path is data). The kernel retries connect until the
  listener is live rather than polling `exists()` (existence ≠ bound).
- **D3 — `commit_proof = idp_id("commit_token", nonce ∥ effect_id ∥
  attempt_no)`**, minted by the kernel at dispatch from the session nonce
  it holds and the *committed* effect members. The helper recomputes over
  its own nonce copy and refuses `NotCommitted` on mismatch — forged,
  replayed-for-a-different-effect, and absent proofs all fail closed.
  The helper echoes the `attribution_token` verbatim in every journal
  frame; a wrong/absent echo drops the item and appends
  `action.effect.unattributed` (AC-R-2.5.5-10).
- **D4 — the *helper* scans, the *kernel* diffs.** `fs_tree` snapshot
  returns a content-addressed `tree/1` manifest; `fs_change` is the
  kernel's baseline-vs-manifest comparison. Observation stays a kernel
  authority (equal state ⇒ equal `snapshot_ref`, S3); the helper only
  reports bytes and metadata it can see inside its backend.
- **D5 — `local_container` is podman** (`podman create --network none
  --read-only --cap-drop ALL --user <uid> -v <ws>:/work`, `exec`, `kill`,
  `rm`); image refs carry the `docker://` transport prefix. Container
  cpu/mem meters come from `podman stats`; unmeasurable dims report
  `Unavailable` provenance, never `0` (T-LCD honesty). Runtime absent ⇒
  `Unavailable` at provision, fail-closed.
- **D6 — `local_sandboxed` is macOS Seatbelt** (`sandbox-exec` with a
  generated SBPL profile: deny-default, writable roots = the declared
  workspace/scratch only, `(deny network*)`, `sysctl-read` + root read
  for the dynamic loader, exec restricted to the policy's allowed
  prefixes). The profile is generated from the containment policy —
  policy controls the profile, never the reverse.
- **D7 — the deadline ladder is helper-local.** The deadline watcher in
  `hh-helper` SIGTERMs then SIGKILLs the *process group* (children spawn
  as pgrp leaders); the classification is recorded *before* the terminal
  notify so `read` observes `deadline_exceeded`, not a generic exit.
  Detached members (a group that outlives its leader, e.g. a backgrounded
  process holding inherited pipes) are recorded on `detached[]` at reap
  time — the reap does not block on pipe EOF — and are surfaced through
  `list_detached`/`terminate_detached`.
- **D8 — C1 halves ride the `tier-c1` cargo feature on `hh-helper`.**
  Default-on; `--no-default-features` builds without them, and the
  session then returns typed `unsupported` for `preserve_until` and
  `dedup_window` (`removability(0)` honest refusal — `scripts/
  check-removability.sh` proves both halves and re-runs the tier-1
  suite). With `tier-c1`, terminal verdicts bind the `idempotency_key`
  in a windowed `DedupStore`; a replay inside the window returns the
  recorded verdict without re-executing.

## Consequences

- The kernel never forks a workload; every effect crosses the wire, so
  `unreachable`/`heal`/`replace` are *observed* states, not inferred
  ones (AC-R-2.2.5-3).
- Token admission is local to the helper — no kernel round-trip at exec
  time — but the helper can only *check* proofs, never mint them (the
  nonce is kernel-issued at `hello`).
- Socket files outlive the store's lifetime only as long as the helper
  lives; `resume` against a dead endpoint lands `unreachable` cleanly.
- Removability is deterministic and tier-monotonic: tier-0 refuses the
  two C1 members explicitly; every other verb is tier-independent.
- Deferred: the cross-implementation EP2 battery and Stage-3+ containment
  halves stay on their existing DF rows; `share` derivation stays
  `unsupported` (C1+).

## Revisit trigger

A move to a non-darwin/non-podman runtime target (which would add a backend
arm rather than change the wire), a C1+ ticket landing `share` derivation or
a distributed-helper transport (which would revisit D1's AF_UNIX substrate —
the session protocol is transport-independent), or a `hh-helper/2` dialect
bump if a later ticket needs verbs the closed sum does not carry.
