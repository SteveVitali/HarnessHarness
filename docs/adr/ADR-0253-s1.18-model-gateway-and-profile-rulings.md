# ADR-0253: S1.18 model-plane rulings — the `hh-gateway` boundary crate, the two `ModelRef` records, the `select` port seam, the G-2 tri-state reading, and the `model.*` event registrations

- **Status:** Accepted
- **Date:** 2026-09-17
- **Ticket:** S1.18
- **Requirement ids:** R-2.3.1, R-2.3.2 (C0 slice), R-2.3.3⁰, R-2.3.4⁰
- **Spec:** §5b.1–§5b.4 · ADR-0118…0128 · ADR-0039 · ADR-0040
- **Rung (ADR-0024 obligation):** **C0** — MUST-code: the closed
  vocabularies (`StopReason`, `ModelErrorClass` with kernel `retry_class`
  defaults, `RetryClass`, `BlockKind`, `NoticeKind`, `UsageArrival`,
  `Purpose`, `RerouteReason`), `WireDialect/1` (strict codec, complete debt
  on every textual rule, narrowing-only `retry_class_override`),
  `InferenceRequest/1` + `ProviderRequestPlan/1`, the `ModelEvent` grammar
  G1–G7 + `collect` (T1–T7), the R-RT-1…6 attempt driver, `ModelGateway`
  over `Transport`/`CredentialPort`/`EventSink`, `RoutingPolicy` +
  `ModelRoleTable` + `select` (the C0 `static`/`role_table` arms) + the
  closed `RoutingRefusal`, `CacheSemantics` as data + `place_markers` +
  `derive_affinity_key` + `expect_cache_state`, LC-1…LC-9, and the
  `ModelProfile/1` selector machinery in `hh-compiler`. A live `Transport`,
  provider-faithful dialect documents, `probe_profile`, reroute
  orchestration (`model.surface.relowered` emitters) and the K2–K6 stores
  stay at their spec'd stages.

## Context
S1.18 lands the model adapter/gateway and the C0 model-plane slices. The
seams the spec leaves open at C0 needed rulings: where the gateway lives,
how request-side versus charge-side model identity is spelled, how `select`
reaches profiles/budget/health without owning them, what the C0 capability
tri-state makes of `unknown`, and which ledger classes the new payload
builders write against.

## Decision
1. **The gateway is its own crate** (`crates/hh-gateway`), not an extension
   of `hh-compiler` or `hh-ledger`. §5b.1's `home = model_boundary` is a
   distinct component with its own ports (`Transport`, `CredentialPort`,
   `EventSink`); the dependency direction is `hh-gateway → hh-compiler`
   (the gateway consumes `ModelProfile/1` via `SelectorView`) — the
   compiler never depends on the boundary (CC10).
2. **Two `ModelRef` records exist and are not the same type.**
   `hh_gateway::plan::ModelRef{profile_ref, provider_model_id,
   snapshot_id?, serving_route?, effort?}` is the *request-side*
   coordinate — `serving_route`/`snapshot_id` are absent until the route
   resolves. `hh_budget::attribution::ModelRef{…, serving_route` (required)
   `, effort?}` is the *charge-side* record — a charge always knows the
   served route (ADR-0039: priced at `served_model`). The gateway record
   converts via `charge_ref()` (`None` when `serving_route` is unset — a
   charge can't be priced before the route resolves). This is one scheme
   (CC1): the request coordinate and the charge coordinate are different
   concerns; the conversion is explicit, never a re-parse.
3. **`select` is a free function over ports, not a trait object soup.**
   `select(request, profile_env, account, health, policy, table,
   decision_id)` takes `&dyn SelectorView` (the profile enumeration seam),
   `&mut dyn BudgetPort` (the `AccountBudget` adapter wraps
   `hh_budget::Account::reserve` and maps `InsufficientBudget{dimension}`
   onto the refusal member), `&dyn HealthView` (the cooldown projection —
   `NoHealth` is the C0 default; a materialized view, never a store of
   truth), plus the `RoutingPolicy`/`ModelRoleTable` records as data. The
   seam is pure: identical inputs decide identically minus the allocated
   `decision_id`/`reservation_id` (AC-R-2.3.2-11).
4. **G-2's tri-state reads `unknown`, never `unmet`.** The C0 capability
   declaration is tri-state (`declared | probed | unknown`); there is no
   declared-negative. `required_capabilities` axes that are neither
   `declared` nor `probed` — including the measured bounds
   `context_window`/`max_output` when undeclared — collect into
   `CapabilityUnknown{unknown[]}` (the debt-recorded `allow_unknown` rule
   is the only escape). `CapabilityUnmet` stays in the closed
   `RoutingRefusal` sum (CC8) for the C1 arms where a measured bound below
   a required floor is *unmet*; nothing at C0 produces it, and no
   `unknown` is silently coerced to `unmet`.
5. **`stop_reason` maps only through the dialect's declared
   `stop_reason_map` rules.** The kernel does not parse a raw provider
   spelling into the closed `StopReason` on its own authority — an
   unmapped spelling reads `Unknown` with `raw_stop_reason` preserved.
   Even the canonical spellings (`end_turn`, …) are surface aliases until
   the dialect document declares the map (T-LCD-01/T-LCD-05: every textual
   rule carries debt; the codec never guesses).
6. **`error_actions` absent row ⇒ `GiveUp`.** The class → action table is
   data on the `RoutingPolicy` and rides its `content_hash`
   (AC-R-2.3.2-6); a class with no row is the closed default `give_up`,
   which closes `model.call.failed`. The router never pattern-matches
   provider message text.
7. **`model.rerouted` and `model.profile.expired_used` register as
   `model_io`-origin ledger rows.** The payload is route/profile facts —
   coordinates and closed spellings, never message content.
   `model.profile.expired_used` is the G-1 witness: an `expired` profile
   bound under a recorded `intent_ref` appends it; `retired` never binds.
8. **`VersionPattern::Range` is the spec's
   `range(family, lo?, hi?)` record**, not the landed pair — the schema
   codec and matcher were reconciled to the spec spelling (absent bounds
   are unbounded; the pattern's `family` overrides the selector's
   `model_family` when set).

## Consequences
- The `hh-gateway` crate boundary keeps every model-plane concern behind
  ports; a live `Transport`/`CredentialPort` lands in the run-loop ticket
  without touching the codec, grammar, router or cache code.
- `select` never falls back silently: the candidate list is the binding's
  `primary` + `alternates[]` in order, every candidate is verdicted in
  `candidates_considered[]`, and total failure surfaces the shared refusal
  class or `ChainExhausted{attempted[]}`.
- Reroute ordering (`attempt.failed` → optional `context.compaction.*`
  under the old profile → `model.surface.relowered` → `model.rerouted` →
  `attempt.started` under the new `profile_ref`; the old reservation
  released before the new is held) is the caller's discipline — the
  `reroute()` builder records the decision; the Stage-2 turn loop emits it.

## Alternatives considered
- **Extend `hh-compiler` with the gateway** — rejected: the boundary would
  then live inside the definition-plane crate and the compiler would grow
  a transport dependency; `home = model_boundary` is a separate component
  (CC10).
- **One `ModelRef` for both request and charge** — rejected: a required
  `serving_route` can't be written before the route resolves and an
  optional one lets a charge exist without a priced route; two records +
  `charge_ref()` keeps both honest (CC3).
- **Coerce undeclared capability axes to `unmet`** — rejected: at C0 the
  tri-state has no declared-negative; coercing `unknown` fabricates
  evidence (T-LCD-15). `CapabilityUnknown` is the honest refusal.
- **Canonical-spelling pass-through in `stop_reason`** — rejected: the
  codec would be guessing provider semantics the dialect document is
  required to declare (T-LCD-01/T-LCD-05).

## Revisit trigger
Stage 2 lands the live `Transport`/`CredentialPort` and the kernel emitter
call sites; C1 lands the non-static policy arms, the G-3/G-5/G-6 refusal
producers, `probe_profile` and the K2–K6 stores; Stage 3 lands the
executable battery (DF-S1.18-1/-2). Re-open the `Range` spelling only if
the spec's `range(family, lo?, hi?)` grammar itself changes.
