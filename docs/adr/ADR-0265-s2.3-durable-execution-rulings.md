# ADR-0265: S2.3 durable-execution rulings — checkpoint-as-projection restore, scoped-lease liveness probing, terminated-observation foreclosure, woken-drain delivery, resume-by-leaf persistence, and the speculation-policy floor

## Context

S2.3 lands durable execution and recovery: the checkpoint is a
projection over the committed prefix (never a second authoritative
store), `restore` is a phase-resolved procedure, and the C1 surface —
scoped leases, suspension, wakeups, healing, saga compensation,
resume verification, HLC — lands on top. The spec fixes the
invariants; the mechanism choices below were left to the ticket:

1. **How `restore` reconstructs driver state.** The committed prefix
   is the only authority, but a restored leaf must not re-mint
   `turn-1`'s opener — the boundary needs a durable leaf checkpoint.
2. **What a scoped-lease holder identity can prove.** Spec: takeover
   is expiry-gated *unless* same-host liveness proves the holder dead
   (AC-5). The holder string's probeable shape was unspecified.
3. **Whether `observed{not_applied}` can ever be terminal.** The
   effect fold's risk policy keeps `not_applied` retryable — but
   detached reconciliation's `terminated` verdict must foreclose.
4. **Who dedups `Cue.woken` deliveries.** `wakeup_drain` is a pure
   projection over `fired` rows; re-draining re-yields them. The
   dedup key and the crash semantics needed a ruling.
5. **Where the speculation floor is enforced.** `defer_irreversible`
   and `allow_classes` narrowing are HIR-level predicates; the gate's
   call site (definition overrides at `open_session`) was the ticket's.
6. **The `preserve_until` horizon.** Spec fixes `ttl ≥
   writer_lease.ttl + recovery_grace`; the concrete value and its
   home were unspecified.

## Decisions

- **D1 — restore replays the WAL; the leaf checkpoint is a view
   artifact.** `Store::restore` folds the committed prefix into the
   recovery fold (`recovery.rs` — effect phases, retry timers,
   wakeups, leases, suspended state) and returns a `RestoreReport`
   naming per-scope `RestoreAction`s. No second event store exists:
   the checkpoint bytes under `runs/<run_id>/leaf.checkpoint` are a
   *projection snapshot* the driver rehydrates from, invalidated by
   and subordinate to the prefix (`Driver::resume(ctx, checkpoint,
   sink)` — the checkpoint is an input, not an authority). `leaf.arm`
   carries the arm-time config (surfaces + budget maps) the
   checkpoint doesn't. Both writes are atomic tmp+rename — a torn
   write reads as `unavailable`, never a half-checkpoint.
- **D2 — the scoped-lease holder is `host=<hostname>;pid=<pid>;
   start=<start-id>`; probing is three-valued.** `probe_holder`
   (leases.rs) parses the claim and consults the OS *only* when the
   host segment matches this machine: same-host dead pid ⇒ `Dead`
   (takeover allowed before expiry — AC-5), same-host pid with a
   start-id mismatch ⇒ `Dead`, same-host live ⇒ `Alive` (WouldBlock),
   off-host or opaque ⇒ `Unknown` (expiry-gated, always). The writer
   lease itself never liveness-shortens; suspended runs are exempt
   (`lifecycle.run.suspended` suppresses shortening — a suspended run
   is asleep, not dead).
- **D3 — `observed{terminated: true}` is unconditionally terminal.**
   Reconciliation's termination proof forecloses retry even when the
   risk class would allow it (`EffectFold::is_terminal` treats the
   `terminated` member as terminal regardless of `not_applied`
   retryability). The row carries the *committed* attempt's
   `attempt_no` — the observation closes the existing attempt, never
   mints a phantom one. `terminated` is a declared audit member of
   `action.effect.observed`.
- **D4 — `wakeup_drain` is pure; the caller dedups on
   `(subscription_id, occurrence_key)`.** `EmbedService::drive` runs
   `deliver_wakeup` (occurrence synthesis + W-1 claim, crash-safe via
   `occurred`-not-`fired` rediscovery — KP-11) then `wakeup_drain`
   (W-3 `deliver_after` withholding) at every decision point and
   submits one `Cue.woken` per un-delivered pair. The dedup set is
   in-memory session state carried across in-process takeover
   (`CarriedRuntime`) but deliberately *not* persisted: a `fired` row
   that survives a crash re-delivers into the new writer's inbox —
   at-least-once into the cue channel, exactly the AC-7 semantics.
   Inside the loop, react's I4 totality parks a `woken` on
   `effects_settled` while effects are open — delivery never lands
   mid-effect.
- **D5 — `verify_resume` verdicts map onto the open boundary
   honestly.** `Identical` ⇒ continue; add-only ⇒ `Compatible` +
   `lifecycle.definition.changed{change_kind, diff_ref}` durable row;
   `Incompatible` ⇒ `DefinitionChanged{reasons}` with **no** ledger
   mutation — the refused attempt mints no `session.attached` row.
   The removal witness (`DeliveredToolRemoved`) folds the run's own
   `context.artefact.delivered` events through `LedgerView` — a tool
   already delivered to the model can never be removed mid-run.
- **D6 — the speculation floor is enforced twice, once per reach.**
   `SpeculationPolicy::check_override` (hh-hir) is the pure
   predicate: `defer_irreversible = false` refused outright,
   `allow_classes`/bounds may only narrow/tighten, conditioned rules
   need their debt records. `gate_speculation_floor` (hh-embed)
   applies it at `open_session` override evaluation — a widening
   override is refused before any ledger mutation. The floor is a
   floor: it can only be tightened, never widened (CC2).
- **D7 — `PRESERVE_UNTIL_TTL_MS = 86_400_000` (24h) is a named
   constant in `hh-env::driver`** — the one value every `hello`
   `preserve_until` offers, asserted `≥ writer_ttl + grace_ms`
   against the run's own manifest in
   `durable_recovery::ac_2_2_3_14_preserve_until_exceeds_writer_ttl_plus_grace`.
   The same horizon covers the executor-side dedup window
   (`DEDUP_WINDOW_MS`) so a resumed writer still finds its dedup
   records inside the preserved journal.
- **D8 — HLC renders `H<physical-ms-hex>.<logical-hex>.<node>`,
   stamped only on lineage-bearing runs.** Plain runs leave
   `EventEnvelope.hlc` absent (no clock reading that could be
   mistaken for authority); `continued_from`/`forked_from`/
   `parent_run_id` seed the stamp from the lineage anchor's own
   `hlc`, then tick per event (`store.rs` fold + append paths).

## Consequences

- Every C1 surface is `tier-c1`-gated on `hh-ledger`/`hh-env`; the
  removability check builds both crates `--no-default-features` and
  asserts typed refusals (`removability0_c1_ops_refuse_typed`).
- Producer-side subscriptions, `suspend`/`compensate`/`heal` protocol
  entry points, and `healing_policy_ref` resolution are deferred to
  the consumer tickets named in §5a.3's consumed-by list —
  **DF-S2.3-1** records the seam with its compensating control (the
  machinery is AC-tested; only the call sites wait).
- The `woken` delivery set is at-least-once across a restart by
  design; the in-process dedup prevents redundant re-delivery within
  a writer epoch. A `fired`-never-delivered occurrence after a crash
  is a correct re-delivery, not a duplicate fire (the durable claim
  row is the fire; the cue is the delivery).

## Alternatives considered

- **Persisted woken-delivery marks** — rejected: a durable `delivered`
  row would make a fired-never-delivered occurrence *lost* across a
  crash (the opposite of AC-7); at-least-once into the inbox with
  caller-side dedup is the spec's own discipline (`wakeup_drain`'s
  doc: the pair is the delivery dedup key).
- **`not_applied` terminal under a compensator** — rejected: it would
  silently discard a compensable effect the saga must still see; only
  the reconciliation `terminated` proof forecloses, and only on the
  `observed` row it writes.
- **`preserve_until` sized per-run from the manifest** — rejected for
  now: the manifest's writer TTL + grace is always ≤ minutes; a fixed
  24h horizon satisfies the bound for every shipped configuration and
  keeps the helper contract static. The bound is test-asserted so a
  future TTL change fails loudly.

## Revisit trigger

Reopen if a non-same-host liveness channel lands (D2's `Unknown` arm
would gain a real probe), if `suspend`/`compensate`/`heal` acquire
protocol call sites (DF-S2.3-1 — the woken dedup set may then need a
durable home), or if a writer TTL + grace ever approaches 24h (D7's
constant must then become manifest-derived).
