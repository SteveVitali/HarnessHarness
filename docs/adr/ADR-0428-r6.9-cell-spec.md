# ADR-0428: The TB 2.1 cell spec — image WORKDIR, cpu/memory limits, kernel-mediated copy-in (AR-06)

- **Status:** Accepted
- **Date:** 2026-11-07
- **Ticket:** R6.9 (manifest 262)
- **Requirement ids:** REQ-XB-106, REQ-XB-107, REQ-XB-117; aliases REQ-XB-006, REQ-XB-003
- **Spec:** experiments supplement §3.1/§3.3/§10.5 AR-06; design/31 F8
- **Rung (ADR-0024 obligation):** C1 — closed flags and backend verbs on the admitted podman substrate; no schema addition

## Context

The podman cell lacked four things TB 2.1 needs (design/31 F8): the
image's declared WORKDIR (the scratch `task_workdir` repair existed only
in `/tmp` drivers), the task's `cpus`/`memory_mb` applied as container
limits, digest-only task images, and a copy path for `/tests` and
`/solution` that never travels the agent-writable `/work` mount.

## Decision

1. `hh-helper` gains the closed flags `--workdir <path>`,
   `--workdir-from-image` (resolved via `podman image inspect`
   `.Config.WorkingDir`; an absent declaration refuses exit 3), `--cpus
   <n>` and `--memory <MiB>` on a `CellSpec` member of `PodmanBackend`.
   A spec declaring none of them produces the pre-admission `create`
   argv byte-identically; the members land verbatim after `--init`.
2. `PodmanBackend` gains the kernel-mediated verbs `cp_in`/`cp_out`
   (`podman cp` host↔cell — bytes transit the host edge, never `/work`;
   a cell path under `/work` refuses before argv), `exists`, `ls_dir`,
   `rm_glob` (the stale `reward.*` removal) and `terminate_group`
   (TERM→KILL for the deadline lapse). `HH_PODMAN_BIN` is the
   diagnostic/test binary override.
3. `hh-env` gains `cell_spec`: `ext["cell_spec"]` decodes strictly onto
   `EnvHandle.cell_spec` (absent ⇒ `None`, argv byte-identical;
   malformed ⇒ `Unsupported{cell_spec}`) and `start_helper` appends
   `helper_args()` verbatim; `task_image_ref` admits
   `name@sha256:<64-hex>` as `ImageRef::ForeignDigest` recorded with
   platform and the R1 label — a tag-only reference refuses typed.
4. `hh-runner::cell` drives ST1–ST5 over an injected `CellOps`:
   `/tests` (and `/solution`, oracle only) absent until their phase and
   arriving only by `cp_in`; stale `reward.*` removed before each verify
   leg; every phase exec under the declared WORKDIR.

## Consequences

- The legacy argv and every pre-existing caller are byte-identical.
- `/work` aliasing is refused at the backend and at the drive boundary —
  the phase boundary cannot be laundered through the agent-writable
  mount.

## Alternatives considered

- A new `hh-helper/1` protocol verb for copy-in: rejected for this row —
  the helper-protocol surface for the live cell is the egress lane's;
  the stub-driven verb set carries the same argv either way.
- Hardcoding `/app` (the pre-repair posture): rejected — it is the
  declared-workdir defect REQ-XA-127 repairs.

## Revisit trigger

The live helper-protocol cell lane lands (egress/relay tickets): the
`CellOps` podman lowering is re-bound to the protocol verbs then; the
closed flags stay.
