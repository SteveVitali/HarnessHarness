# ADR-0275: S3.1 lab-boundary and bundle rulings

- **Status:** Accepted
- **Date:** 2026-09-21
- **Ticket:** S3.1 (`044_S3.1__lab-embed-groups-and-bundle.md`)
- **Requirement ids:** R-2.11.4 · R-2.11.1 · R-2.11.3⁰ · R-2.9.3⁰
- **Spec:** §7.4 (Groups M/L, `hh-embed/1`) · §7.1 (Lab nouns, CLI) ·
  §5h.3 (R-2.9.3⁰ reproducible bundles) · §7.3 (R-2.11.3⁰ fixture MCP
  server)

## Context

S3.1 crosses the kernel↔Lab boundary: Groups M (`measurement.*`,
`kernel.bundle`, `kernel.check_completeness`, `kernel.reproduce`,
`kernel.import`) and L (`lab.*`) land on `hh-embed/1`, the Lab nouns
ride the same `Boundary` seam as every other CLI noun, bundles record
`ContractIdentity`, and the R-2.11.3⁰ fixture serves a bundle's
`target:mcp` member over stdio. The contracts were fixed upstream; the
mechanism choices below were left to the ticket:

1. **Which bundle kinds `kernel.bundle` assembles.** §5h.3 names run
   bundles; corpus and profile bundles are declared kinds with no
   Stage-3 content model.
2. **How `kernel.*` derivations append rows.** The bundle/export/import
   ops act on runs whose writer session may already be closed — the
   ordinary session-scoped append path is unavailable.
3. **What a compile failure does to `kernel.bundle`.** `compiled_bundle`
   is the R1 gate, but a run without an admissible profile cannot
   compile — refusing the whole export would make un-profiled runs
   unexportable.
4. **How the ledger export's members resolve under `check_completeness`
   S4.** The derived reproducibility basis names `satisfied_by.member`
   refs; a ref that is not a manifest member fails
   `manifest_reference_unresolved`.
5. **The member-ref idp domain.** Member bytes are content-addressed;
   which domain tag and whether `media_type` enters the digest needed
   pinning (the codec and S2 agree or nothing round-trips).
6. **What `lab.serve` returns.** R-2.11.3⁰ is a *fixture* — whether the
   kernel opens a socket, spawns a child, or hands back a descriptor
   was open.
7. **The `stdio_launch` principal and caller trust.** The fixture's
   binding fixes the caller; what `_meta` may influence needed a
   ruling.
8. **How `kernel.import` lifts foreign content.** An imported bundle's
   claims are asserted by a foreign producer — reasserting them under
   kernel authority would fabricate provenance.
9. **`--dry-run` parity on Lab nouns.** §7.1 makes `--dry-run` the
   planning half of `apply`; how the CLI lowers it for boundary ops
   needed a ruling.
10. **How unimplemented Group L ops answer.** The noun table is wider
    than the implemented op set; the CLI must not invent local
    semantics.
11. **How an over-level `reproduce` claim surfaces.** §5h.3 types the
    refusal; whether it rides the transport error channel or the
    `hh-repro/1` result was open.

## Decision

- **R-BUNDLE-1 — `kind = "run"` only.** `kernel.bundle` assembles run
  bundles; any other `kind` answers `Refused{kind_pending:{kind}}`.
  Corpus/profile bundles land with their content models in a later
  stage.
- **R-BUNDLE-2 — session-free derivation appends.** `kernel.bundle`,
  `kernel.import`, and the measurement emission commit through
  `hh-ledger`'s `commit_kernel_row_for`, which rides the run's
  *persisted* writer-lease generation — a closed writer session does
  not block export. Each assembly is a distinct derivation:
  `created_at` differs per call, so repeat calls append a new
  `bundle_assembled` row and mint a new `version_id` (codec
  determinism — AC-R-2.9.3-1 — is over the encoded form, not the
  assembly).
- **Compile failure degrades, never hides.** When `compile` cannot run
  (unresolvable profile, missing artifact) `kernel.bundle` still
  assembles — without a `compiled_bundle` member, with
  `max_supported_level` capped at R0, and with the typed failure
  carried in the result's `compile_error` member. A failure of the
  *assembler* itself still refuses; a failure of one optional input
  does not sink the export.
- **Ledger members are first-class refs.** `ledger_page:{run}:{seq}`
  and `ledger_tree:{run}` are manifest members alongside the section
  roles, so every `satisfied_by.member` the derived basis emits —
  including the traces/tree coordinate — resolves under S4.
- **Member refs mint under `blob`.** `m.ref = idp("blob" ∥ bytes)`;
  `media_type` and `role` are member *fields*, never part of the
  digest. `encode_dir`/`encode_container` and S2
  `present_members_verify` share the rule — a byte that recomputes to
  a different address fails `hash_mismatch`.
- **`lab.serve` is a lowering, not a server.** The op decodes the
  bundle, extracts the `target:mcp` member, lowers the
  `hh-mcp-target/1` document into a deterministic `hh-mcp-artifact/1`,
  and returns `{artifact, binding, launch}`. Serving is delegated to
  the `hh-mcp-serve` fixture binary over newline-delimited JSON-RPC on
  stdio — the kernel never holds a socket for a fixture.
- **Fixed `stdio_launch` binding.** `kind = stdio_launch`,
  `principal = principal:test`. Caller-supplied `_meta` is preserved
  on echo but ignored for authority decisions; `HandleId`s are
  internal to the server and never cross the wire. `tools/list` and
  `server/discover` are deterministic functions of the artifact —
  same bundle, same bytes.
- **Import lifts references, not facts.** `kernel.import` refuses an
  incomplete bundle (`validate` must pass), deposits member bytes into
  the blob pool, opens a new run, and writes the import lineage +
  receipt rows. Lifted content is recorded under `unverified`
  authority as *references* to the foreign bundle — never as
  kernel-asserted facts.
- **`--dry-run` is the planning op.** On Lab nouns the flag lowers the
  command to its planning half (`definition plan` — the same op the
  apply path issues first), so the dry-run result is byte-equivalent
  to apply's planning half by construction, not by a second code path.
- **Pending ops answer `stage_pending`.** Group L ops without a
  landed implementation return `Refused{stage_pending}` typed through
  the boundary; the CLI surfaces the refusal verbatim and never
  fabricates a result — a noun that aborts mid-pipeline (e.g.
  `compare report` after a `stage_pending` `analyze`) issues no
  further calls.
- **`reproduce` refusals are results.** A requested level above
  `max_supported_level` answers a well-formed `hh-repro/1` document
  `{outcome:"refused", refusal:"ReproClaimUnsupported{requested,
  max_supported}"}` — the typed refusal is report data, not a
  transport error, so a caller can diff it. R3's budget gate
  (`UnmatchedBudget`) is likewise a refusal, not a drift row (CC9).

## Consequences

- The Lab runs entirely over Groups S/R/M/L on either binding —
  in-process `EmbedService` for tests or a spawned `hh-kernel serve`
  for the separate-process path — with no CLI-local kernel semantics.
- Bundle identity is stable and checkable: `version_id` is `idp/1`
  over the manifest preimage, member refs are `idp/1` over bytes, and
  a forged coordinate fails `hash_mismatch`/`manifest_reference_unresolved`
  at validate rather than at reproduce time.
- An un-profiled run is still exportable and importable at R0 — the
  R1 gate observes the absent member instead of the export refusing.
- The MCP fixture is pure over `(artifact, binding)`: no ledger, no
  kernel handle — the served tool list cannot drift from the bundle
  the artifact was lowered from.
- Imported runs carry their provenance honestly: `unverified`
  authority + lineage to the source bundle, so a downstream reproduce
  never mistakes a lifted reference for a local observation.

## Alternatives considered

- **Refuse `kernel.bundle` when compile fails.** Rejected — couples
  export to the profile machinery; an un-profiled diagnostic run would
  be unexportable even though every other section is well-formed. The
  `compile_error` member keeps the failure visible instead.
- **Serve MCP in-process inside `lab.serve`.** Rejected — the kernel
  would hold a socket and a tool dispatch loop for a fixture; the
  descriptor + `hh-mcp-serve` split keeps the boundary op total and
  the fixture independently testable over stdio.
- **Reassert imported rows under kernel authority.** Rejected —
  fabricates provenance and poisons the audit trail; lifting as
  `unverified` references preserves the foreign origin and lets
  authority be conferred explicitly later.
- **A separate dry-run code path per noun.** Rejected — two paths can
  diverge; lowering `--dry-run` onto the same planning op the apply
  path issues makes parity definitional.
- **Surface over-level reproduce as a transport error.** Rejected —
  `ReproClaimUnsupported` is a *verdict* about the bundle; a transport
  error says the call was malformed. The `hh-repro/1` refusal member
  is diffable report data.

## Revisit trigger

- Corpus/profile bundle kinds land a content model (retires
  `kind_pending` and R-BUNDLE-1's gate).
- A real MCP transport (socket, remote principal) replaces the
  `stdio_launch` fixture — the binding record is already a member, so
  the artifact path survives.
- Group L op implementations land (retires the `stage_pending`
  answers; the CLI surface is unchanged).
