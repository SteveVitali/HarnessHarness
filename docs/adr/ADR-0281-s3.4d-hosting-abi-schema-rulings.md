# ADR-0281: S3.4d Hosting-ABI schema rulings

- **Status:** Accepted
- **Date:** 2026-09-23
- **Ticket:** S3.4d (`050_S3.4d__hosting-abi-schemas.md`)
- **Requirement ids:** R-2.10.6⁰
- **Spec:** §6.6 (the `hh-hosting/1` Hosting ABI — `HostedEvent`, `proj_ABI`,
  the lift table, `ConformanceRecord`, `AdapterRecord`, adapter zero) ·
  ADR-0164 (the projection's lowering column + the declared loss report) ·
  ADR-0165 (D6 mediation at applicability; D7 `veto.permission_violation`;
  D8 native-only vetoes) · ADR-0166 (record layering; the `hh.hosting/1`
  ext block; the adapter debt record) · ADR-0041/0159 (the `MatchSpec`
  refusal semantics this ticket only *tests*) · CF-390 (removable tier)

## Context

S3.4d lands the schema half of the Hosting ABI (C0/Stage 3 — R-2.10.6⁰):
the `HostedEvent` envelope, `proj_ABI`/`lift`, the registry's
`participant`/`adapter` opaque kinds, `ConformanceRecord`/`hosted_entries`,
adapter zero, and the `requires_capabilities`/`requires_mediation` wiring
on the scorecard path. The service (handshake, verbs, probes, quarantine,
hosted launch) stays at S4.5a. The mechanism choices left to the ticket:

1. **Where the lowering table lives.** `proj_ABI` needs a per-class
   disposition (`typed kind | passthrough | hint | none`). A second class
   list in `hh-hosting` would fork the registry (CC7); the class table in
   `hh-ledger` is the one list.
2. **How the registry stores the new record kinds.** `participant` and
   `adapter` records must be storable without the registry re-owning the
   §6.6 schema (a schema owned twice is a drift source).
3. **The authority ceiling on a hosted row.** The ABI preserves unknown
   kinds verbatim (I-3); what stops an extension row carrying `kernel`
   authority, or a participant claim asserting `mediated`?
4. **Model I/O under an unintercepted session.** Adapter zero is
   intercepted, so its descriptor declares `model_io` — but the lowering
   must state what happens to `model.call.*`/`model.stream.*` rows when
   the session never declared interception. A `hint` row would carry the
   raw model I/O in `ext.source` — observability the session does not
   have.
5. **`ConformanceRecord`'s verdict.** A hosted conformance entry compares
   a declared capability state against an observed one; `unknown`/
   `skipped` values must never coerce into a `drift`/`supported` verdict
   (T-LCD-07).
6. **Participant `version_identity`.** The record names the participant's
   declaration-version coordinate; an authored value that can drift from
   the declaration it names is a lie waiting to happen.
7. **Where `mediation` enters the eval path.** `requires_mediation`
   existed on `MetricDeclaration` since S1 but nothing populated the
   `EvalRun.mediation` set — the scorecard could never produce
   `n/a{mediation}`.
8. **AC-R-2.10.6-6's enforceability check.** The `MatchSpec`
   `budget_enforcement` machinery (`BudgetEnforcement`, the per-dimension
   `enforced` gate) was already landed — the ticket owed the AC's
   executable battery (token matched-cap refusal, interception accept).
9. **The adapter-zero parity claim (AC-R-2.10.6-2).** The parity is over
   the *analysis-side* view of the hosted artefact — the lifted rows —
   measured against the same fold the native run renders.

## Decision

1. **`HOSTED_LOWERING` is a column of the class registry**
   (`hh-ledger::classes`). Every registered class carries a `lowering`
   field populated by `hosted_lowering(class)` at row construction —
   exhaustive by construction (a `classes::tests` sweep refuses a missing
   or duplicate entry: an unlisted class would silently lower to `"none"`,
   the exact failure CC3 forbids). The table is *data* — naming a hosted
   kind creates no dependency edge (CC6; `check-removability.sh` now
   asserts `hosting_edges = []`: no crate depends on `hh-hosting`).
2. **Opaque bodies behind the `kind` tag.** `RegistryRecord::Participant`/
   `Adapter` store the canonical `Json` verbatim — the same layering as
   `EnvironmentRecord`; `hh-hosting` owns the §6.6 schemas
   (`ParticipantRecord`/`AdapterRecord` + the `hh.hosting/1` ext block),
   the registry gates only that the body's `kind` tag matches the record
   kind. `ConformanceReport.hosted_entries` is the typed exception: the
   report schema is registry-owned, so the entries decode in
   `hh-registry` — and `hosted_entries` is legal only on a
   `subject_kind = participant` report (codec gate) whose `subject_ref`
   resolves to a registered participant record (store gate).
3. **I-4 + the mediation admissibility rule.** `validate_event` refuses
   `authority > delegate` unless `origin ∈ {intercept, environment}` *and*
   the kind is closed-schema (a known `hh-hosting/1` kind or a registered
   native class); `mediation = mediated` is admissible only on those same
   kernel-gated origins — a participant claim and the adapter itself can
   never assert `mediated`. Extension kinds are preserved (I-3) but carry
   `unverified`/`delegate` at best.
4. **`model.call.*`/`model.stream.*` are observability-gated in
   `proj_ABI`.** When the hosted session did not declare `model_io`, the
   projection emits no model-I/O row — *including* `hint` rows, whose
   `ext.source` embed would otherwise carry model I/O to a session that
   cannot observe it — and declares each gated class in the
   `LoweringLossReport` (`no_slot`/`info`, detail
   `observability-gated`). `validate_session` enforces the same gate on
   ingress (`ModelIoUndeclared`).
5. **The verdict is derived, never authored.** `ConformanceRecord`
   constructs only through `observed_entry` (`verdict =
   derive_verdict(declared, observed)`: `drift` iff both sides concrete
   and differing; `supported` on agreement; a non-concrete observed value
   projects `unknown`/`skipped`); the codec re-derives and refuses a
   mismatched authored verdict. `is_stale` pins the
   `participant_version_identity` the entry observed — a version change
   re-derives conformance, never inherits it.
6. **`version_identity` is derived at construction and re-derived at
   decode** — `idp("hh.hosting.participant", canonical{declaration,
   participant_version})`; a mismatched authored value refuses
   (`VersionIdentityMismatch`). `ParticipantRecord` additionally enforces
   `class = hosted` (`ClassNotHosted`) and `hosting_mechanism ≠ none`
   (`MechanismNoneOnHosted` — CF-351, `none` is native-only).
7. **`mediation` rides the results-row coordinates.**
   `ResultsRow.coordinates.mediation` (additive member, `MediationChannel`
   spellings, stamped at bind time from `manifest.extra["mediation"]` —
   the Stage-4 producer) projects into `EvalRun.mediation`; `render_cell`
   (and therefore `hh-analysis`'s A1 summarize, which shares the cell —
   CC1) calls `applicability_at`, so `requires_mediation`/`applies_to_
   families`/`requires_capabilities` all take effect on the scorecard
   path. A *native* row's surface is fully mediated (the kernel owns every
   channel — `{effects, egress, model_calls}`); a hosted row carries only
   its declared channels, never defaulted. In the catalogue:
   `veto.permission_violation` gains `requires_mediation =
   mediated(effects)`; `veto.duplicate_effect`/`veto.audit_completeness`
   become `applies_to_classes = {native}` (participant-reported tool
   events never enter the effect lifecycle and a hosted ledger carries no
   audit surface); the seven hosted-specific declarations
   (`hosted_observation_completeness`, `mediation_coverage`,
   `usage_report_agreement`, `conformance_drift_count`,
   `synthesized_terminal_rate`, `observed_duplicate_action_rate`,
   `observed_blast_radius`) land `applies_to_classes = {hosted}` —
   schema-only at C0 (their folds arrive with the service at S4.5a; a
   declared row renders `n/a{class}` on native arms, never a coerced
   value).
8. **AC-R-2.10.6-6 is a test over the landed machinery.** `validate_match`
   already gates `matched_cap`/`matched_total` on per-dimension
   `budget_enforcement`; the ticket adds the AC's executable battery —
   `ac_r_2_10_6_6_tokens_matched_cap_refusal_and_interception_accept`
   (`tokens.output.visible` `unenforceable`/`advisory` → refused
   `IncommensurableMatch{Unenforceable}`; interception-derived `enforced`
   → accepted) alongside the pre-existing `iso_cost` spend-confidence
   gate.
9. **The parity fixture lifts then folds.** AC-R-2.10.6-2's test
   (`hh-hosting/tests/hosting.rs`) projects a native run through adapter
   zero, `lift`s the hosted events back into native-class envelopes, and
   asserts `metric_view` byte-equality on every process metric whose
   `requires_observability ⊆ {events, end_state, model_io}` (the
   intercepted adapter-zero set — the AC's `{events, end_state}` leg is
   contained), and `n/a{observability}` — never 0 — on every
   `ledger`-requiring metric. The loss report is asserted to name exactly
   the `none`/`hint_only` classes the fixture exercises.

## Consequences

- The hosting tier is removable: delete `crates/hh-hosting` and the
  workspace is unchanged (the registry arms are opaque `Json`; the ledger
  column is data); `check-removability.sh` proves `hosting_edges = []`.
- Deferred to S4.5a unchanged: the handshake, the baseline/capability
  verbs, probes P-01…P-16, quarantine, hosted launch, `budget_enforcement`
  derivation, and Adapter A+. The hosted-metric *folds* are likewise
  S4.5a (their declarations are schema now).
- `DF-S1.3-2` stays OPEN: the ABI schemas land here, but the `≤ delegate`
  mint for ABI-*vouched* participant claims needs the vouching service —
  a progress note records the schema landing.

## Alternatives considered

- **`HOSTED_LOWERING` as a `hh-hosting`-owned table.** Rejected: a second
  class list forks the registry (CC7) and `check-removability` would have
  to carve the ledger edge — keeping the column on the class table makes
  exhaustiveness structural and the edge count stays zero.
- **`hh-registry`-owned participant/adapter schemas.** Rejected: §6.6
  schemas owned in two places drift; opaque `Json` bodies behind the
  `kind` tag keep the registry's obligation structural (the same layering
  `EnvironmentRecord` already uses).
- **Emitting `hint` rows for model I/O under an undeclared-interception
  session.** Rejected: the hint's `ext.source` embed carries the raw
  model I/O — observability the session does not have. Gating the class
  (with a declared `observability-gated` loss) preserves I-3's
  nothing-drops accounting without leaking a channel the descriptor
  never declared.
- **Authored conformance verdicts.** Rejected: an authored
  `supported`/`drift` can disagree with the compared values; deriving the
  verdict (and re-deriving at decode) makes drift-by-authorship
  unrepresentable (T-LCD-07).
- **Defaulting hosted rows to the fully-mediated surface.** Rejected: a
  hosted row's mediation is exactly its declared channels; defaulting
  would let `veto.permission_violation` apply where no `mediated`
  channel exists — the `n/a{mediation}` posture is the honest answer.

## Revisit trigger

Reopen when any of: (a) S4.5a lands the hosting service — the handshake
may require `HostedEvent` members the schema slice did not declare, and
the vouched-participant `≤ delegate` mint (DF-S1.3-2) becomes reachable;
(b) a second adapter beyond adapter zero exercises a lowering the
`HOSTED_LOWERING` column cannot express (a per-class cell rather than a
kind would then be needed); (c) the `hh.hosting/1` ext block version
bumps (`hh.hosting/2`) and the codec's closed-member posture must widen;
(d) a mediation channel beyond `{effects, egress, model_calls}` enters
the ontology.
