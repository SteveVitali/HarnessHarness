# ADR-0244: S1.13 secrets-crate rulings — crate shape, the PDP/CDP gate seam, the staged `mediate`, the deny-by-default env projection, the mask-set/redaction split, rotation's CAS+retention batch, and the canary tripwire

- **Status:** Accepted
- **Date:** 2026-09-17
- **Ticket:** S1.13
- **Requirement ids:** R-2.8.3
- **Spec:** §5g.3 (the C0/Stage-1 slice per §5g.3 §9) · §05a B5 · ADR-0057
  D2/D3 · ADR-0058 D2/D3/D4/D5/D6 · ADR-0059 D2/D3 · ADR-0023/0024 ·
  ADR-0026/0029 · ADR-0033/0034/0035 · ADR-0036/0037 · ADR-0051/0052/0053 ·
  ADR-0066 Rule P · ADR-0212 (OQ-132 interim `ResourcePattern`)
- **Rung (ADR-0024 obligation):** **C0** — MUST-code: the kernel-side
  `CredentialBroker` verbs (`register_channel`/`grant`/`bind`/`mediate`/
  `mint`-SPI/`revoke`/`rotate`/`kernel_use`/`fingerprint`), `redact`, the
  `env_apply` projection and `leak_scan` are §5g.3 §3 inside-list items;
  `SecretChannelSpec`s, allow-lists, destination bindings, delivery-mode lists
  and the four `secret_*` veto declarations stay MUST-data.

## Context
S1.13 lands credential mediation & secret isolation's Stage-1 slice — the
"secrets never appear" floor: value-free `SecretRef`/`SecretChannel`, the
kernel-side broker verbs, the deny-by-default environment projection, the
known-value mask set + source redaction, the `leak_scan` test battery, and the
seven `security.credential.*`/`security.secret.*` event classes. The spec fixes
the record shapes, the refusal vocabulary and the SV-1…SV-10 invariants but
leaves these concrete rulings to the slice:

1. **Where the PDP/CDP check lives.** §5g.3 §2 makes `bind`/`mediate` require
   a *recorded* `security.permission.decided{decision = allow}` covering a
   `secret_access` grant (AC-R-2.8.3-13) — but the broker runs without calling
   back into the monitor (the monitor decides; the broker delivers). The
   covering test has to be a pure fold over the run's committed events.
2. **What Stage-1 `mediate` returns.** §5g.3 §9 assigns the wire-side
   `mediate` (carrier-slot fill at R-2.8.4's egress mediator) to Stage 2 —
   yet AC-R-2.8.3-13 is a Stage-1 criterion exercised *through* `mediate`, and
   §2's refusal order is normative. The verb must exist now without pretending
   the wire machinery exists.
3. **The environment contract.** §5g.3 §1/§05a B5 require deny-by-default
   inheritance, placeholder-only bound values, and a value-free snapshot —
   including the case where a *credential-shaped* name is explicitly
   allow-listed (the allow-list must not amplify).
4. **Where redaction sits.** ADR-0057 D3's `redact` runs "at source"; the
   leak battery's `leak_scan` must not become a live interceptor that pretends
   to guarantee absence (it is a verifier over committed surfaces).
5. **Rotation's failure shape.** §2 makes `rotate` compare-and-swap with the
   old value retained in the mask set — a rotation that cannot retain the
   outgoing value would silently break SV-1 ("every revision stays masked"),
   so retention failure must refuse, not degrade.
6. **The canary.** ADR-0059 D3's canary is the encoding-independent tripwire:
   "the broker never injects it" needs a refusal code (`canary`) *and* a
   durable `leak_detected` row — and a live-boundary location the
   `ScanTarget` sum did not previously name.

## Decision
- **§1 — one persistent crate `crates/hh-secrets`** (deps
  `hh-wire`/`hh-identity`/`hh-provenance`/`hh-ontology`/`hh-hir`/`hh-ledger`/
  `hh-monitor`/`hh-containment` only — no `Text` leaf authored, no model call
  on any path). `types.rs` carries `SecretRef{channel_id, description}`,
  `ProvidedSecret{provided}`, `SecretFingerprint` (keyed, truncated —
  irreversible), `Placeholder` (`mh_secret:v1:<channel>:r<rev>:<nonce>` — the
  nonce an `idp/1`-framed digest over `run_id ∥ binding_id`, SV-10),
  `BindingState`, `KernelPurpose`, `AccessClass`, `SecretUnavailable`.
  `channel.rs` carries the §5g.3 §3 sums verbatim: `CredentialKind`,
  `SecretSource{operator_vault|os_keyring|launch_env|external_binding}`,
  `DestinationBinding{scheme, host_pattern, port?, path_prefix?,
  auth_carrier}`, `AuthCarrier{header{name,prefix?}|basic|query_forbidden}`,
  `SenderConstraint{dpop|audience|none}`, `SecretChannelSpec` (incl.
  `canary`, `bindable`, `delivery_modes_allowed`, `max_lifetime`,
  `allowed_env_names`) — strict canonical codecs (`BadMember`/`BadValue`,
  CC4). `BindingMode` **is** `hh_monitor::assess::SecretTransport` (CC1/CC7 —
  no second mode vocabulary).
- **§2 — the PDP/CDP gate is a recorded-input fold.** `decisions.rs` folds
  the run's committed `security.permission.{granted,decided,revoked}` events
  into a `DecisionView`; `covering_secret_access(view, holder, channel_id,
  decision_ref)` requires `decision = allow` **and** a live handle granting
  `secret_access` over `secret:<channel_id>` for the same holder (a revoked
  handle uncovers — `mediate` re-checks at delivery). `bind` and `mediate`
  refuse `DecisionMissing` when uncovered; the broker never mints, infers or
  widens a decision (the monitor's payloads are value-free by construction —
  AC-R-2.8.3-13).
- **§3 — Stage-1 `mediate` is a staged `Delivery`, not a wire rewrite.** The
  verb enforces §5's normative refusal order (`revoked → expired →
  out_of_scope → ambiguous_path → canary → decision_missing →
  broker_unavailable`), resolves the source (fail closed — never an env-value
  fallback, AC-R-2.8.3-10), appends `security.credential.used` durably
  **before** returning (SV-5), and yields `MediationOutcome::Staged(Delivery)`
  whose `claim_id` names a kernel-held value slot the Stage-2 mediator drains
  (DF-S1.12-1/DF-S1.13-1). `mint` is the failure-typed SPI —
  `Deferred{stage: 2}` — never a panic, never a silent no-op.
- **§4 — `env_apply` is deny-by-default three ways.** Only `EnvSpec.allowlist`
  names may appear; `KERNEL_NONINHERitable` names and credential-shaped
  suffixes (`_API_KEY`/`_TOKEN`/`_SECRET`/`_SECRET_KEY`/`_PASSWORD`/
  `_CREDENTIALS`/`_PRIVATE_KEY`) are withheld *even when allow-listed* (the
  allow-list masks, it does not amplify); bound channels project only their
  `Placeholder`; a known secret value inside an ordinary allowed variable is
  masked at projection. `dump()`/`proc_env()`/`snapshot()` are the same
  projected map — no second form can carry a value (SV-4).
- **§5 — redact at source; leak-scan as verifier.** `redact` replaces hits
  with content-free `REDACTED[<detector>:<fingerprint|label>]` tombstones
  (known-value hits fingerprint, never echo). `leak_scan` over `ScanTarget{
  event|blob|request_view|definition|sink_delivery|mediation}` is the
  test-battery entry — `leak_scan(run) = ∅` is LT-01's verdict — and is never
  wired into a live path as a runtime interceptor. The mask set **fails
  closed**: an unresolvable source makes `mask_set()` `BrokerUnavailable`
  rather than emit an incomplete set (SV-1 completeness is a precondition).
- **§6 — `rotate` is CAS + retain + revoke, one durable batch.** A stale
  `expected_revision` is `Conflict{current}`; the outgoing value is resolved
  and retained in the mask set *before* the swap (an unresolvable old value ⇒
  `BrokerUnavailable` — the rotation refuses rather than lose mask coverage);
  `security.credential.rotated` + the implicit `security.credential.revoked`
  for every live binding commit in one atomic batch before the new revision is
  visible.
- **§7 — the canary refuses at the live boundary.** `bind`/`kernel_use`/
  `mediate` on a `canary` channel append `security.secret.leak_detected{
  location = "mediation:<verb>:<channel>", detector = canary}` durably, then
  refuse `Refused{canary}` — `ScanTarget::Mediation` is the live-path location
  the row names (ADR-0059 D3).
- **§8 — the refusal vocabulary is the spec's closed sum.** `RefusedCode` is
  `{no_grant, not_bindable, decision_missing, mode_not_allowed,
  environment_not_isolated, expired, revoked, out_of_scope, ambiguous_path,
  sender_constraint_unmet, canary, broker_unavailable, audit_unavailable}` —
  `denied` rows carry the tag; `SecretUnavailable{channel, reason}` is the
  terminal model-facing observation (a closed tag, never prose, never a
  value).

## Consequences
- The `security.credential.{bound,used,denied,revoked,rotated}` +
  `security.secret.{redacted,leak_detected}` classes are registered in
  `hh-ledger`'s `CLASS_TABLE` (durable, events-observable, audit-grade,
  kernel-origin, provenance-mandatory); `hh-hir` gained
  `HirError::SecretValueInDefinition` (+ the `hh-assembly` diagnostic mirror)
  and `HirDocument::text_leaves()`/`HirDiff::canonical_bytes()` so the
  definition/diff scans cover in-memory text bodies as well as the canonical
  form (AC-R-2.8.3-8); `hh-identity` gained `RecordKind::SecretChannel` +
  `RecordKind::CredentialBinding`; `hh-monitor`'s `SecretTransport` gained
  `as_str`/`parse`/`Ord`/`Hash` for the delivery-mode allow-list.
- **Deferred (in DEFERRALS.md):** the Stage-2 wire half (`Injected{carrier}`
  at the egress mediator, `mint`ed token delivery, sender-constraint
  verification, `credential_supply`) → DF-S1.13-1; snapshot/fork placeholder
  rebinding → DF-S1.13-2; the Stage-3 executable battery (LT-03/11 vetoes,
  suite canaries, the utility `ComparisonReport`) → DF-S1.13-3; the C1 halves
  (encoded-variant detectors + LT-12 + miss-rate emission, `wrapped_long_lived`
  destination revocation, LT-07) → DF-S1.13-4.
- The `rotate` verb and `mediate`'s refusal path land ahead of §9's Stage-2
  label deliberately: AC-R-2.8.3-13 is a Stage-1 criterion exercised through
  `mediate`, and the kernel-side verb surface is the same record the Stage-2
  mediator will consume — landing it now is additive, not a re-decision
  (CC8).
- OQ-149 (whether `SecretRef` becomes a HIR leaf kind) stays open with WS-A3 —
  the model-facing form is a record projection (`channel_id` + description),
  so the Stage-1 leaf-scan battery is unaffected. OQ-151's fingerprint scheme
  is the interim `idp/1`-framed keyed SHA-256 (truncated to 32 hex) — stable
  within a broker lifetime; the ratified scheme lands at Stage 2.

## Alternatives considered
- **Broker calls `hh_monitor::authorize` directly.** Rejected — the monitor's
  decision function is pure over recorded inputs; a callback would make the
  delivery point a second PDP and couple the crates circularly (the monitor
  owns the `secret_access` Π rows already).
- **`mediate` returns the raw value to the caller at Stage 1.** Rejected —
  the caller-visible surface stays value-free; the staged `Delivery` keeps the
  wire half additive at S2.4 without weakening SV-2/SV-5.
- **A second `BindingMode` enum in hh-secrets.** Rejected — CC7/CC1: the
  spec's mode spellings are the monitor's `SecretTransport` spellings
  (`proxy_injected`/`minted_scoped`/`wrapped_long_lived`).
- **`leak_scan` as a live egress interceptor.** Rejected — a scanner that
  promises absence becomes the thing a leak bypasses; it is a verifier over
  committed surfaces (the veto is a fold, not a filter).

## Revisit trigger
S2.4 lands the egress mediator consuming `Delivery` claims — revisit the
staged-claim shape and the `credential_supply` declaration then; the C1 ticket
landing `known_value_encoded` detectors revisits the detector set's closed
