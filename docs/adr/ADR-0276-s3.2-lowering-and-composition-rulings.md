# ADR-0276: S3.2 lowering and composition rulings

- **Status:** Accepted
- **Date:** 2026-09-21
- **Ticket:** S3.2 (`045_S3.2__compiler-full.md`)
- **Requirement ids:** R-2.1.2 · R-2.1.3 · R-2.1.4 · R-2.1.4¹ᵃ
- **Spec:** §3.2 (the compiler chain — stages 3–4, `lift`, `relower`,
  E4–E6, `opacity`, `ablate`) · §3.3.4 (`compose`/`space`/`enumerate`)
  · §3.3.13 (the Stage-3 op set)

## Context

S3.2 lands the two halves of the compiled-artefact chain §3.2 stages at
Stage 3 — profile lowering (`lower_profile` → `ModelSurface`), target
lowering (provider tool-API + MCP) with typed loss reports, `lift`,
`relower`, and the executable half of the E1–E7 equivalence battery —
plus the §3.3.13 composition ops (`compose` over `layers[]`,
`space`/`enumerate` with the ADR-0025 override grammar, the bundle
opacity ratio, and `validate_assembly` stage 6a). The owning ADRs
(ADR-0015…0025, ADR-0090…0092, ADR-0124…0126, ADR-0021 D5, ADR-0118
D6) fix the contracts; the mechanism choices below were left to the
ticket:

1. **The `tool_shape` rule's param shape.** CF-199 fixes "the family is
   named by id, never inline"; whether the rule maps `capability_class →
   SurfaceFamilyRef` or carries a flat `{capability, variant_id}` needed
   pinning (link validates the map form — every member must be a
   family ref).
2. **The two minimal profiles' differing surface.** ADR-0020 requires a
   pair differing over an owned-field diff, not just a name; which
   capability and which variant pair was open.
3. **Where the E4 suite lives and what world it runs.** §3.2.6 makes E4
   an *executable* differential at Stage 3; the suite carrier, the
   closed world set, and the grammar interpreter were mechanism.
4. **The provider artefact's strict-subset keyword set.** §3.2.5 names
   "the provider's strict subset" — the C0 membership needed fixing.
5. **What the MCP artefact carries of the plan.** `_meta` admits the
   minimum carried set; which members ride it and which are declared
   `no_slot` losses needed a ruling.
6. **How `enumerate` marks unfilled budgets.** AC-CC-08 requires
   per-arm `search_budget`/`eval_budget` — declared, never silently
   absent.
7. **How a group override (`class_id=variant_id`) retargets a slot.**
   The retarget's effect on the resolved pinning and the materialised
   `native.slots` mirror needed a ruling.
8. **The stage-6a check shape.** R-2.1.4¹ᵃ names declaration-level
   compatibility; which members it compares was open.
9. **What `ablate` does to dependents.** Removing a node leaves
   incident refs; the refusal shape needed a ruling.
10. **How the profile-pair diff is checked.** AC-CP-02's "diff ⊆ owned
    fields" needs a surface-diff function and a path convention aligned
    with `owned_fields`.

## Decision

- **R-SHAPE-1 — `tool_shape` params are the CF-199 map.**
  `{capability_class → {family_id, variant_id, param?, grammar_ref?}}`;
  the map key scopes the rule (a key matching the capability's name or
  semantic id applies it). The flat `{capability: …}` spelling is not a
  rule param — link validates every member as a `SurfaceFamilyRef` and
  a missing `family_id` fails closed.
- **R-PROF-1 — the minimal pair differs over `edit_file`.**
  `minimal-patch` (prefix naming, `patch` variant — a `patch` text arg
  `parse(grammar_ref)`'d into `edits`) vs `minimal-string-replace`
  (suffix naming, `string_replace` — `old_string`/`new_string` project
  into `edits[0]`). Owned fields: `tools/*/name`,
  `tools/edit_file/{arg_map,schema}`. The diff is exactly the owned
  union (AC-CP-02).
- **R-E4-1 — the suite is profile-carried data.** `tests.e4_suites[]`
  on the `ModelProfile` (merged across the chain). The C0 world set is
  closed — `fs_map`, a string-map filesystem whose apply is `edits[]`
  string replacement; the transform interpreter admits
  `identity | rename | const | project | parse(grammar_ref)` and
  typed-refuses `coerce`/`unescape`/`resolve_name`. `parse` grammars
  are suite data (`grammars{ref → grammar}`); the interpreter is the
  closed `hh-line-patch/1` line-block grammar
  (`{grammar, open, mid, close}`). Open-world capabilities report
  `n/a{open-world}` (T-LCD-15); the named closed-world primitives
  (`edit_file`, `execute`, `read_file`) require `pass` — a missing
  suite is a `fail`, never an `n/a` (§3.2.6 rule i).
- **R-PROV-1 — the provider subset is the declared keyword list.**
  `PROVIDER_STRICT_KEYWORDS` in `hh-compiler/src/target.rs` fixes the
  C0 membership; keywords outside it are `narrowed` loss entries under
  `prefer` and `UnexpressibleSurface` under `require` (the
  `schema_dialect` rule's `strict` member carries the knob). ADR-0021
  D5 stands — no lift; the T1–T7 `name_to_semantic_id` normalisation
  record is carried as data so the artefact is self-describing
  (ADR-0118 D6).
- **R-MCP-1 — the `_meta` minimum carried set.** `_meta
  ["dev.cognition/hir"]` carries `{semantic_id, surface_id, effects,
  permission_class, budget_ref, provenance{authority, origin}}`;
  `bundle_id` is deliberately absent — the artefact is
  bundle-identity-free so `bundle_id` stays a pure function of outputs
  (§3.2.4). Declared `no_slot`/`hint_only` losses cover what the
  dialect cannot carry (budgets, permission enforcement, validators);
  `annotations` project the effect-hint booleans. `lift` recovers every
  carried member and reports `declared_unverified` for `_meta`-less
  tools (`origin = import`, `authority = unverified`; unknown `_meta`
  keys preserved verbatim — CC3).
- **R-ENUM-1 — budget placeholders are declared `None`.**
  `EnumeratedPoint{document, overrides[], search_budget: None,
  eval_budget: None}` — the slots exist and are empty until the sweep
  engine fills them; a point validates before any budget is spent
  (AC-CC-08's pre-spend gate) and a rejected point carries the full
  `ValidationReport`.
- **R-GROUP-1 — a group override unpins the slot.** `class_id=variant_id`
  retargets the slot's `ComponentVariantRef` to `version = Selector("*")`
  (a sweep point is an authored candidate — `resolve` re-pins it before
  seal), clears the assembly's `resolved` member (no stale pinning), and
  mirrors into the root process's `native.slots` so the desired-state
  record and the materialised view never disagree (`C-COMP-2` owns a
  disagreement).
- **R-6A-1 — stage 6a compares declaration to declaration.** A pinned
  `profile_binding` consults the bound `ProfileView`: each variant's
  `capability_declaration` must be `declared`/`probed` on the named
  profile — else `C-PROF-1 ProfileIncompatible`. An unbound binding is
  vacuous; stage 6b remains `n/a{not_run}` (C1).
- **R-ABL-1 — ablation of a depended-on node refuses.** `ablate` returns
  `UnresolvedRef` naming each dangling ref rather than leaving one; a
  clean ablation drops the node + incident edges and stamps a
  `DerivedFrom` lineage edge (`authority = kernel`) — the removal is a
  recorded derivation, never an erasure (CC2/CC3).
- **R-DIFF-1 — `surface_diff` emits `owned_fields`-convention paths.**
  `tools/<capability>/<member>`, `layout/<section_id>`,
  `params/<member>`, `dialects/<role>`, `transcript/stale_signature`;
  the `profile` member is excluded — it is the *cause* of the diff, not
  a field the check owns. The AC-CP-02 check is `diff ⊆ ⋃ owned_fields`
  under single-segment `*` globs.
- **R-ERR-1 — override application errors are typed.**
  `apply_override`/`apply_to_assembly` return `OverrideError`
  (`Unapplied` for a path outside the declared space) — the
  `enumerate` caller routes the point to `rejected` with a `C-PARAM-*`
  diagnostic, never a silent skip.

## Consequences

- E4 is executable over the declared suite only; a capability outside
  the closed world honestly reports `n/a{open-world}` — the check set
  widens only when new closed worlds land (never by guessing).
- `relower` re-runs stages 3–5 under the new chain and refuses any
  `RuntimePlan` change — profile-independent semantics cannot move
  under a relowering (the refusal is typed; the migration record names
  dropped/rewritten transcript items).
- The bundle's `opacity_report` is the `validate_assembly` 7-O value
  verbatim (CF-050 — one producer, `hh_hir::ops::opacity`); AC-CP-12
  compares them equal.

## Revisit trigger

- A second closed world or grammar family lands (E4's `E4_WORLDS` /
  `hh-line-patch/1` are closed sets — a new member is an ADR, not a
  fallback).
- A provider schema dialect widens or narrows its keyword set —
  `PROVIDER_STRICT_KEYWORDS` is the single C0 list; an upstream change
  re-opens the membership question.
- Stage 5 lands: 6b `C-PROF-2` (observation-level compatibility)
  replaces stage 6a's declaration-level check's n/a remainder.
- The runtime ticket lands: AC-CP-09's mid-run `model.surface.relowered`
  emission consumes `TranscriptMigration`/`relowered_event`.
