## Context

S5.3 lands the comparison & analysis engine's C2 depth:
A7 `fit_surface` with `factorial_glmm` /
`curve_on_ordered_axis`, A14 strata views over the five
axes, judged realized-benefit stages, A10 designed-ablation
→ `attribution_report/1`, the classified-diff retirement
gate (AC-R-2.10.3-13), publication `verifiable_by` and
the `reproduced` public tier, and the hosted interception
(Adapter B) and container-installed (Adapter C) lifecycles
with hosted bundle export members. Seven spellings needed
owned rulings — each a seam the spec leaves to the
implementation, each now with exactly one spelling
(CC1/CC7):

1. **What an unavailable hosted observation looks like in
   a fitted surface.** A hosted run on a component-level
   axis cannot join the fit — the host never observed the
   component. Coercing it into a native-looking row
   fabricates evidence (CC3); the honest encoding needed
   one shape.
2. **How the minimum-design shortfall reads.** A design
   below the model's minimum (e.g. `factorial_glmm`
   needing ≥2 levels per factor with replication) must not
   silently fit a thin surface.
3. **Which `MatchSpec`s may share one surface.** C2 joins
   rows across arms; two rows fitted together must have
   been compared under the same matching discipline.
4. **How unannotated pooling reads in `strata_view`.**
   ADR-0012 D6 forbids silent pooling — the
   `filters.aggregate = pooled` request needed a typed
   refusal, the same name the scorecard side raises.
5. **What counts as an admissible retirement diff.**
   AC-R-2.10.3-13 requires the classification to refuse a
   diff that is not a single-rule removal — the deltas the
   classifier reports and the exception it honours needed
   one grammar.
6. **How `verifiable_by` is computed per reader set.**
   §6.5 §2.4 requires the publication to name each
   reader's verification ceiling — the level derivation
   (digest-only vs admitted minimum) needed one rule.
7. **How hosted lifecycle endpoints report.** Adapter B
   intercepts the model boundary; Adapter C runs a
   container image. A hook-reported call the proxy never
   intercepted, and a container close with no terminal
   event, both needed honest — never fabricated —
   encodings.

## Decision

**D1 — Hosted coordinates are typed `n/a{class}`, never
coerced.** A component-level axis makes the surface
native-only: hosted runs are listed `n/a{class}` in the
report, never fitted. On a configuration-level axis a
hosted run joins only where its `supported|partial`
conditionality admits the coordinate; where two hosted
rows disagree on the varied coordinate the cell reads
`unknown{hosted_rows_disagree}` — never averaged, never
picked.

**D2 — Below-minimum designs report `insufficient`, and
unknown cells are named, not zeroed.** A design below the
form's minimum produces a report whose status is
`insufficient` with the deficit named — the fit still
emits a durable record (the debt record below) rather
than refusing outright, so the shortfall is auditable.

**D3 — One `MatchSpec` per surface.** `fit_surface`
refuses `IncommensurableMatchSpec` when the joined rows
carry differing match specs — a surface is only ever a
comparison under one matching discipline.

**D4 — Expiry is wired to the debt record.** The report
carries `status ∈ {active, expiring, expired}` from
`SurfaceExpiry{fitted_at, now_ms, max_age_ms}`; a fitted
surface mints an `AssumptionDebtRecord` whose
`evidence_refs` bind the report id and whose
`removal_tests` carry the new `refit{min_design}` kind
(`RemovalTestKind::Refit` — the re-fit re-runs the
declared design template; a `match_spec` is not mandatory
because the re-fit owns its own design minimum declared
in `criteria`).

**D5 — `strata_view` covers the five axes and refuses
silent pooling.** `StrataAxis ∈ {contamination_stratum,
capability_vector, cost_confidence, suite_validity,
mediation}`; hosted strata key by `capability_vector` /
`mediation` / cost `confidence` per §2.5.
`filters.aggregate = pooled` raises
`StrataPooledUnannotated` — the same refusal name
`hh_eval::scorecard` raises (ADR-0012 D6).

**D6 — Judged realized-benefit stages join the
decomposition as a fourth stage.** `realized_stages`
emits `hh-realized-stages/1` over the deterministic
headline plus the judged `activated`/`followed`
detectors — a judged observation that the host cannot
see stays `n/a{class}`, never a zero.

**D7 — Attribution is a first-class section.** A10's
`designed_ablation` output lands as
`attribution_report/1` carrying the M1 members; hosted
attribution limitations stay named in the report.

**D8 — The retirement classifier refuses non-removal
diffs.** `RetirementDiffView{authority_delta,
budget_delta, semantic_ops, candidate_bound}`; the
Lab/experiment/embed layers refuse a classified diff
that is not a single-rule removal unless
`candidate_bound` holds — `Refused`, never a warning.
The resolver is `RetirementDiffResolver`, a type alias
over the closure contract (the same alias discipline in
`hh-lab` and `hh-experiment`).

**D9 — `verifiable_by` derives the reader's ceiling
from the cut.** A reader whose cut withholds payload
(`payload_protection = restricted_store`, or a
`content_classes` list omitting `content`) sees a
digest-only index → `R0`; else the level is the admitted
entries' minimum resolved `claimed_level` — an entry
with no resolved level contributes `R0`, never a
fabricated claim. `LeaderboardDefinition::public()` sets
`min_status = Reproduced` (independent reproduction per
ADR-0140); `PublicationPolicy::public()` is the matching
per-suite default (`readers = [public]`,
`restricted_store` protection, `content` withheld) with
every withheld member landing in the loss report (CC3 —
never silently dropped).

**D10 — Adapter B records what it could not intercept.**
`hh.adapter.b` lifts the interception proxy's `model_io`
as `mediated` on the `proxy` channel; participant hooks
arrive `observed` on the `hook` channel; a hook-reported
call the proxy did not intercept is reconstructed from
transcript rows and tagged `unobserved` — never
`mediated`. `set_coordinate{model}` lands on the proxy's
upstream (never the participant's config), and the
`GenParamPolicy{forward[], default{}}` is a declared
adapter parameter whose debt record the `AdapterRecord`
carries (T-LCD-05 reflexive) — anything else the
participant asks for is stripped and logged, never
silently applied.

**D11 — Adapter C synthesizes an honest terminal.** The
container path lifts `install`/`run`/`kill`/`snapshot`
lifecycle events; `close_and_reconstruct` emits a
synthesized terminal observation tagged as reconstructed
when the container produced no terminal row — the run's
end state is never left unrecorded and never claimed as
mediated. Hosted bundle export adds
`descriptor_version` claims (from the attach row's
`abi_version`/`mediation`/`placement`/
`hosting_mechanism`, `environment` authority),
`adapter_version` claims (from the `hosting_adapter`
bound-component row), and a `hosted_native_records`
member carrying the raw `lifecycle.hosted.native_record`
leaves — classified `content` so a withholding policy
lists them in the loss report.

## Consequences

- A7/A14/A6/A10 are records-in/records-out and
  deterministic — every rule above is exercised by the
  `s5_3` suites (11 analysis + 4 hosting + 2 bundle +
  1 results + 7 retirement tests).
- Hosted comparisons are honest by construction: a
  reader of a fitted surface sees exactly which cells a
  hosted row could not join, and why.
- The `reproduced` public tier gives the spec's
  publication floor an executable shape; withheld
  members are always accounted in the loss report.
- Adapters B and C extend the hosted registry without
  widening participant authority — every lifted row
  carries `mediated`/`observed`/`unobserved`/`reconstructed`
  provenance.

## Alternatives considered

- **Coerce hosted rows into the fit with an `n=0`
  weight.** Rejected — a zero-weight row is still a row;
  the reader cannot tell absence from observation
  (CC3 violation).
- **Refuse `fit_surface` outright when any hosted row is
  present.** Rejected — a configuration-level axis is a
  legitimate cross-participant comparison; refusing
  throws away exactly the comparison C2 exists to make.
- **Warn on non-removal retirement diffs.** Rejected —
  AC-R-2.10.3-13 is a gate, not an advisory; a warning
  can be ignored, a typed refusal cannot.
- **A `verifiable_by` fixed per-tier table.** Rejected —
  the ceiling is a function of the *cut* (what the
  reader's policy withholds), not just the tier name; a
  static table lies when a policy withholds `content`
  under a higher tier.

## Revisit trigger

Reopen if a C3 surface kind or a new hosting mechanism
adds an observation channel these provenance tags cannot
express (e.g. a channel that is neither `mediated`,
`observed`, `unobserved` nor `reconstructed`), or if the
spec changes the `reproduced` admission rule or the
retirement-diff grammar — the ruling is the grammar, not
the refusal.
