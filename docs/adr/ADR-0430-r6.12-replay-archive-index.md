# ADR-0430: Proxy record/replay, `hh-l1-canon` reuse, and `hh-receipt-index/1` (AR-20)

- **Status:** Accepted
- **Date:** 2026-11-07
- **Ticket:** R6.12 (manifest 265)
- **Requirement ids:** REQ-XC-122 (absorbs REQ-XD-108), REQ-XC-125, REQ-XF-124, REQ-XH-101
- **Spec:** experiments supplement §4.9/§4.10; design/33 F15; design/36 §1.3, §1.6 P1–P9
- **Rung (ADR-0024 obligation):** C1 — new boundary modules beside the frozen receipt and
  canonicalization contracts; no amendment of `hh.model_io/1` or `hh-l1-canon/1` rules

## Context

R6.12 owes two pieces from the §4.9/§4.10 machinery: deterministic
record/replay over the proxy (so L1-gate replays and offline parity
have one recording format) and the first archive-index/condenser leg
(so a pass's receipts, store segments, and derived files are
enumerated and recomputable without committing archive bytes). The
ambiguities the ticket names: which bytes a match compares, what
"strict" does, how streaming requests replay, where the index lives.

## Decision

1. **One recording format, `hh.model_proxy.recording/1`** — per call
   `k`: the downstream request bytes (capture point 1), the
   upstream-bound body after lane transforms (capture point 2 — the
   match key, since it is what the model conditions on), the verbatim
   upstream exchange `{status, headers, body, chunk_stamps}`, the
   released downstream bytes, the §4.3 disposition, and the recorded
   latency. `provenance ∈ recorded | synthetic`; the codec is closed
   (unknown members refuse). `record` mode captures into the slot's
   in-memory buffer; `seal_recording` deposits the manifest blob
   (leak-scanned like every blob) and lands
   `model.proxy.recording.sealed` (new class-table row,
   `O::ModelIo` origin, hosted lowering `none` — the proxy is the
   sole writer).
2. **`replay` allocates no budget state** — no root pool, no slot
   slice, no reservation: "no budget charge" is structural (zero
   `control.budget.*`/`measurement.cost.attributed` rows), not a
   zero-price reservation. `configure` still requires the
   authorization (it is recorded on the manifest), and the catalog
   probe is skipped (no upstream port).
3. **`RequestCanonicalizer` + three built-ins** — `identity` (byte
   equality), `json_canonical` (`parse_provider` →
   `Json::to_canonical_string`; CC1 — the same canonicalizer, never a
   second), `hh-l1-canon` (the existing `L1Canon` view; `hh-wire`'s
   private `first_diff` is exposed as `first_diff_path` rather than
   duplicated). `match_requests` returns
   `exact | canonical_equal | diverged{first_diff_path}`; a
   canonicalizer refusal degrades to `diverged{canon_error:…}`, never
   an identity fallback.
4. **Sequence positions = slot call ordinal** — `sequence` keying
   serves the smallest unserved index; `sequence_then_hash` first
   scans outstanding calls for a canonical-hash match (design/33
   F15's interleaved repair). A slot-bound request that refuses
   locally still consumes one index (`verdict: refused_local`), so a
   record-mode trajectory containing refusals replays aligned.
   Strict stops with typed 409 `replay_diverged` and ends the slot;
   lenient serves and records — never gate evidence. Sequence end is
   a typed 409 `replay_exhausted`.
5. **Streaming replay re-chunks deterministically** — the recorded
   `chunk_stamps` lengths drive the segmentation (P7's declared
   rule); a non-streaming serve is byte-identical to the recorded
   release. `latency: recorded` sleeps the recorded call latency
   (default `immediate`).
6. **`RecordedTransport`** in `hh-gateway` serves the same recording
   rows to native runs, decoding through
   `HttpModelTransport::raw_frames`' extracted helper
   `decode_exchange_frames` — no second decoder. A `send` past the
   sequence is a typed `replay_exhausted` refusal; `with_matcher`
   records per-call verdicts and refuses `replay_diverged` when
   strict.
7. **`hh-receipt-index/1` + condenser in `hh-runner`** — the index is
   the committed record (not a store): `dataset{repo, revision,
   visibility}`, per-attempt `files[]` over the closed role set
   `{raw_receipts, transcript, atif, egress_log, native_log,
   store_segment}`, pass `artifacts[]` over `{layer_export, bundle,
   binary_set}` with `upload ∈ archived | digest_only` (digest_only
   carries no uploaded path), `scans{}`, `supersedes[]`, `tombstone`.
   `packet_fold` recomputes `{consumed_micros, calls, receipts,
   dispositions}` from durable events. `condense` writes
   `transcript.jsonl` deterministically (trial header, positional
   message dedup, one `call` line per receipt) through the
   `hharness-secrets` `redact` hook — the R6.23 scan's tombstone
   point; raw archive bytes stay out of git.
8. **Offline checker** — `scripts/check-proxy-offline.sh` fails when
   a proxy test names a non-loopback endpoint literal without
   `#[ignore]` + ADR-0363; CI runs it (`mode != 'fast'`).

## Consequences

- Replay and record are additive beside `live`: the R6.10/R6.11
  receipt shape and ordering are unchanged (the `mode` member is the
  only new field, and `proxy.replay` is `null` for live/record).
- The slot call-ordinal keying means record-mode refusals are part
  of the sequence; a synthetic sequence that omits them diverges on
  replay — declared, testable.
- `hh-runner` gains a `hharness-secrets` dependency (the tombstone
  hook) — a downward edge, checked by `check-runner-edges.sh`.
- R6.23's upload/supersession machinery and the cell-environment
  leg (DF-R6.7-1 → R6.16) remain open; this ticket lands the codec,
  condenser, and replay substrate only.

## Alternatives considered

- **Serve `upstream_response` rather than `released`** — rejected:
  `released` is what the socket read (error bodies, in-stream
  failures); byte-identity demands it, with `upstream_response` as
  fallback for calls that never released.
- **A second match-key on downstream bytes** — rejected: downstream
  equality is diagnostic; the model conditions on upstream-bound
  bytes (capture point 2).
- **Index/condenser in `hh-ledger` or `hh-hosting`** — rejected: the
  runner owns archive orchestration (R6.23's consumer); the modules
  stay below `hh-embed` per K-2/AR-04.

## Revisit trigger

The L1 gate (R6.21+) needing cross-connection hash keying beyond
`sequence_then_hash`, multi-slot trajectory bundling, or
canonicalizer rulesets past `hh-l1-canon/1` — each is a new
declaration, not an edit to this record.
