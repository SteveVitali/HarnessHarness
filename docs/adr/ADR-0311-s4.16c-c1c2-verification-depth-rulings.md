# ADR-0311: S4.16c C1/C2 verification depth rulings

- **Status:** Accepted
- **Date:** 2026-09-30
- **Ticket:** S4.16c
- **Requirement ids:** R-2.7.1² (judged validators + hosted
  `end_state`), R-2.7.2b (belief-state reconciler class +
  judged divergence detectors), R-2.7.3 (independent
  critics/evaluators + `execution_alignment` + `probe`)
- **Spec:** §5f.1 (verification fabric, validators, hosted
  verdict surface); §5f.3 (belief-state reconciler, D1/D4/
  D7–D10 divergence classes, n/a surface); §5f.4 (critic
  component class, calibration/independence, probe mode);
  ADR-0111/0112 (verification fabric + C2 staging),
  ADR-0114 (metric declarations, the C2 variant as a
  matched-budget Lab factor), ADR-0115–0117 (judged
  emission), ADR-0047(c) (calibration gate, judged
  independence), CC1/CC2/CC7/CC8/CC9.

## Context

S4.16c lands the §5f C1/C2 depth over the C0/S4.15/S4.16b
seams. Nine spellings needed owned rulings — each a seam the
spec leaves to the implementation, each now with exactly one
spelling (CC1/CC7):

1. **How a judged validator runs under `offline-only`.** A
   `validator{kind = judge}` cannot call a model from inside
   the kernel — yet its verdict still must satisfy the same
   declaration contract as a deterministic one.
2. **Which observability leg gates the judged surface.** The
   §5f.3 n/a map names `model_io` for judged classes; the
   hosted `end_state` leg observes the same participant — the
   admission rule could not silently equate them.
3. **What a hosted `end_state` gate verdict reports.** Floor
   9 says a hosted run's gate still runs; the end-state
   assertion set is a spelling the adapter reports —
   met/unmet/unread each needed one honest outcome, never a
   guessed pass.
4. **How judged records coexist with the completion gate.**
   A `verification.claim.reconciled` row emitted by a judged
   detector carries `delegate` authority — it may annotate,
   never independently hold or veto `stop`.
5. **What the C2 divergences fold over.** D1/D4/D7–D10
   operate on projected belief state; the projection's
   authority rule for kernel-emitted rows (driver writes
   without a `provenance` record) had to be owned, or D7
   (`censored_evidence`) never fires.
6. **What `probe` mode may touch.** A probe critic reads —
   its capability surface, the bundle immutability and the
   prohibited domain set each needed one closed rule.
7. **How comparative judges and panels reduce.** Pairwise
   order effects, majority-with-withholding and the
   calibration expiry boundary each needed one
   deterministic reduction.
8. **What quarantine does to a critic's verdicts.** A
   tainted critic cannot silently participate — the
   raise-only rule and the taint surface needed owning.
9. **What the critic gate and feedback notice record.** The
   `control.critic.gated` audit row and the
   `context.artefact.delivered{kind = kernel_notice}`
   feedback needed exactly one ledger spelling each.

## Decision

1. **A judged validator is a declaration + a deterministic
   adapter over caller-supplied judge output.**
   `ValidatorDeclaration::validate` enforces the judged
   contract — `judge ⇒ ¬deterministic`, `judge ⇒` a
   `profile_ref` and an assumption-debt record, judged
   surface ⇒ `required_inputs` declares `ModelIo`
   observability, `side_effects` read-only — while
   `check_judged` and `admit_hosted` run offline: the
   caller supplies the judge's `Verdict` (delegate
   authority) and the runtime validates it against the
   declaration. Verdict authority is detector-bound at
   admission: deterministic ⇒ `kernel`, judged ⇒
   `delegate`, human ⇒ `principal`. `Verdict` gains the
   additive judged members `bundle_id`,
   `calibration_ref`, `independence_summary`,
   `uncited_findings` (CC8; old verdict bodies decode with
   the members absent).
2. **The judged `n/a` surface requires `ModelIo` exactly;
   `EndState` is a distinct observability leg.** The C2
   `na_classes` map renders every judged detector class
   (D1 `phantom_observation`, D4 `stale_belief`, D7
   `censored_evidence`, D8 `progress_regression`, D9
   `evidence_inversion`, D10 `no_progress_loop`) typed
   `n/a{class}` unless `ModelIo` is in the participant's
   declared observability set — an `end_state`-only host
   cannot support judged detectors and must not be
   counted as if it could.
3. **`evaluate_gate_hosted` runs the floor-9 gate over
   `end_state` assertions with three honest outcomes.**
   Met assertions satisfy the gate; unmet assertions
   hold/refuse per the declaration; an end-state record
   the adapter did not report (`unread`/absent) is an
   honest failure — the gate never guesses a pass over
   unobserved state.
4. **Judged reconciler records annotate; only
   `hold_admissible` records gate completion.**
   `reconcile_c2` emits deterministic C2 records
   (detector `deterministic`, `charged_to = instrument`,
   `mode = ledger_only`, sorted/deduplicated evidence
   refs, no calibration/independence members) beside the
   C0 base record. The driver's hold/veto decision reads
   `hold_admissible()` — judged records carry findings,
   never an independent `hold`.
5. **The projection confers `kernel` authority on
   driver-emitted kernel rows; other unprovenanced rows
   stay `unverified`.** `EventEnvelope.provenance` absent
   plus `producer.component_class = kernel` mints
   `kernel` authority in the `ReconcileContext`
   projection — the D7 `censored_evidence` detector's
   refused-effect rows are kernel facts. Any other
   unprovenanced row is `unverified`, never coerced.
6. **`probe` mode admits a closed, read-only,
   closed-world capability set; bundle payloads are
   immutable.** `ProbeCapability` is a closed sum;
   `admit_probe` refuses undeclared capabilities, any
   capability outside the read-only set, and the
   prohibited-domain list outright. Evidence-bundle
   payloads a probe reads are bytes-immutable — a probe
   never writes.
7. **Comparative judges run both orderings; panels reduce
   majority-with-withholding; calibration has a hard
   expiry.** A comparative critic consumes the pair in
   both orders and the result records the ordering pair;
   a panel reduces to a verdict only at the declared
   majority, withholding otherwise; a `CalibrationRecord`
   past expiry refuses admission — calibration is a gate
   input, not an annotation.
8. **Quarantine taints; a tainted critic's participation
   raises, never silently participates.** A quarantined
   critic's verdicts carry the taint and the runtime
   raises on any use — quarantine is raise-only
   (findings preserved for audit, never silently
   dropped, never silently admitted).
9. **The critic gate records `control.critic.gated`;
   reconciler notices emit
   `context.artefact.delivered{kind = kernel_notice}`.**
   `control.critic.gated` is a registered ledger class
   (`led`, events-observable, audited) carrying the gate
   declaration + payload; the reconciler-enabled driver
   feeds divergence findings back to the context plane
   as `kernel_notice` deliveries — additive event kinds,
   the C0 event set is unchanged (CC8).

## Consequences

- Judged verification runs fully offline: the kernel
  never calls a model; judged inputs arrive as
  caller-supplied `Verdict`/`CriticVerdict` data validated
  against the declaration — the `offline-only` budget is
  preserved without weakening the judged contract.
- `na_classes` requires `ModelIo` for every judged class:
  hosted runs whose surface is `end_state`-only get honest
  `n/a{class}` rows, never a divergence verdict the
  observability cannot support.
- `hold_admissible()` is now the single read path the
  completion gate uses — deterministic records can hold a
  `stop{completed}`; judged records annotate the same run
  for audit and feed-back without vetoing.
- The `kernel`-authority projection rule is the only
  legitimate mint for unprovenanced rows: driver/kernel
  rows are kernel facts; everything else is `unverified`.
- Critic evaluation depth (comparative, panel, expiry,
  taint, probe admission) is executable now over
  caller-supplied judge output; `CriticDeclaration{kind =
  judge}` bound on live judge calls at `link` stays owed
  (DF-S1.21-3 progress) — the offline budget keeps the
  judge itself outside the kernel.
- CC8 additive verdict/record members keep every C0 body
  decodable; the new ledger/event kinds are additive
  registrations.

## Alternatives considered

- **Treat `EndState` as sufficient observability for the
  judged classes.** Rejected: `end_state` reports the
  terminal assertion set — it cannot carry the model-I/O
  surface a judged detector reads; folding them would
  emit `diverge`/`ok` verdicts an `end_state`-only host
  cannot support.
- **Let judged records hold the gate like deterministic
  ones.** Rejected: a `delegate`-authority finding cannot
  independently veto a kernel decision — the judged row
  annotates and feeds back; the hold authority stays with
  deterministic records (spec §5f.3 gate composition).
- **Mint `unverified` for every unprovenanced event row.**
  Rejected: the driver's own kernel-produced rows (e.g.
  refused-effect observations) would fall below the D7
  authority floor and `censored_evidence` could never
  fire — the kernel-producer mint is the honest rule.
- **Probe capabilities as an open string set.** Rejected:
  a probe's read surface must be closed-world and
  read-only by construction (CC1); an open set makes the
  prohibited-domain check meaningless.

## Revisit trigger

Reopen when (a) the Stage-5 hosting/online budget lands a
kernel-reachable judge gateway — `check_judged`/`admit_probe`
move from caller-supplied to gateway-called, or (b) the
critic-variant tickets bind `CriticDeclaration{kind =
judge}` at `link` on live runs and the calibration/
independence members need to ride the binding surface rather
than the verdict.
