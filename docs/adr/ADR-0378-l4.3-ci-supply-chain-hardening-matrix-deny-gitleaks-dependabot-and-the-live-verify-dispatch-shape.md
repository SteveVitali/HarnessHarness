# ADR-0378: L4.3 CI supply-chain hardening — matrix, cargo-deny, gitleaks, dependabot, the live-verify dispatch shape, and the ADR-0365 RustSec pin bumps

- **Status:** Accepted
- **Date:** 2026-10-22
- **Ticket:** L4.3
- **Requirement ids:** R-2.12.4 (supply-chain half) · the 2026-10-20
  live-CI ruling ("Local + manual workflow") · BL-31 (live CI seam) ·
  ADR-0362 contract D-D (the R4.2a D6-fallback deliverable 5)
- **Spec:** none — CI/tooling policy, not a contract change
- **Rung (ADR-0024 obligation):** non-contract — CI and repository
  posture; no runtime surface.

## Context

L4.3 hardens CI for a public repo: an ubuntu + macOS build/test matrix
(the helper's seatbelt backend is macOS-native), `cargo-deny`, gitleaks
over history, dependabot, SHA-pinned actions, a `cargo doc -D warnings`
gate, and the operator's "Local + manual workflow" ruling as a
dispatch-only `live-verify` workflow bound to a protected Environment.
During implementation `cargo deny check` surfaced two live advisories
inside the ADR-0365 admission set — the trigger ADR-0365 names ("a
RUSTSEC advisory lands against the D1 set — the pin bumps by sibling
ADR, never a silent `cargo update`").

## Decision

1. **RustSec remediation (ADR-0365 sibling).** `rustls-webpki`
   `=0.103.15` → `=0.103.16` (RUSTSEC-2026-0382 — distrusted emSign
   intermediates in path validation) and `webpki-roots` `=1.0.9` →
   `=1.0.10` (the sibling fix — the same roots dropped). Same crates,
   same closed scope, patch-level pins only; `Cargo.lock` and
   `THIRD_PARTY_NOTICES.md` regenerated. `rustls` `=0.23.46` is
   unaffected and stays.
2. **Matrix.** `build-test-drift` runs `{ubuntu-latest, macos-latest}`
   with `fail-fast: false`; each leg runs the fast-path decision and
   uploads its own `$RUNNER_OS` anchor (the naming was already in the
   anchor contract). Node 22 + Python 3.13 are provisioned so the E2/E3
   foreign legs execute on both legs.
3. **Supply-chain jobs.** `cargo-deny` and `gitleaks` are separate
   jobs declared before `build-test-drift` — the step-mode lint
   requires the anchor pair to be the file's last two steps. They run
   on every head: gitleaks scans docs/ history (a docs reader is never
   gated); cargo-deny audits the lockfile. `actions: read` stays in
   `permissions`.
4. **Tool acquisition.** `cargo-deny` installs via
   `taiki-e/install-action` `tool: cargo-deny@0.20.2` (the action
   SHA-pinned). `gitleaks` installs from the release tarball pinned by
   version + sha256 — `gitleaks-action` cannot express
   `--log-opts=--all` against the committed `.gitleaks.toml` cleanly
   and carries an organisation-license term this repo does not need.
   Every `uses:` in both workflows is pinned by commit SHA with a
   `# v…` version comment; dependabot tracks those.
5. **dependabot.** `github-actions` weekly; `cargo` with
   `open-pull-requests-limit: 0` — security updates only, consistent
   with the hermetic-modulo-ADR posture.
6. **live-verify.yml.** `on: workflow_dispatch` only, `environment:
   live-verify`, secrets materialised as NAME=value lines in a
   `umask 077` env file (never echoed), legs chosen by input,
   run-produced evidence uploaded as an artifact (committing stays the
   local runner's job). `check-live-verify-workflow.sh` lint-enforces
   the dispatch guard in CI: no `pull_request*` token outside comments,
   `workflow_dispatch` present, the environment bound, and no
   `secrets.` reference in any PR-triggered workflow.
7. **deny.toml policy.** `licenses.allow` = the MIT/Apache/ISC/MPL
   family plus BSD-3-Clause (`subtle`) and CDLA-Permissive-2.0
   (`webpki-roots` packaging; MPL-2.0 covers the embedded root data).
   `sources` denies unknown registries/git (crates.io only).
   `multiple-versions` and `wildcards` are `warn`, not `deny`: the
   admitted transitive duplicates (getrandom, windows-sys) and the
   workspace's version-less path deps would otherwise fail on
   semantics they were never meant to gate — they report in every run
   instead.
8. **The rustdoc sweep.** `RUSTDOCFLAGS="-D warnings" cargo doc
   --workspace --no-deps` surfaced ~55 pre-existing intra-doc-link
   failures across ~25 crates (links drifted as items were renamed,
   made private, or gained same-name siblings — the build never
   checked them). The ticket's AC requires the step green, so this
   ticket fixes every one — doc comments only, zero semantic change:
   unqualified links gain their `crate::`/`hh_*::` path, ambiguous
   function/module names get `mod@`/`()` disambiguation, links to
   private items or nonexistent names de-link to code font, and
   literal `<x>` text escapes to `&lt;x&gt;`.

## Consequences

- The ADR-0365 admission set is advisory-clean again; the next RustSec
  finding against it is red in every CI run until fixed or explicitly
  allowed with a reason.
- macOS coverage exercises the seatbelt-native helper paths in hosted
  CI for the first time; PR runtime roughly doubles on the gated path.
- A docs-only head still runs the two supply-chain jobs (≈1 job-minute
  each) — the fast path gates only `build-test-drift`'s steps by
  design.
- The live-verify workflow is dormant-safe: it cannot trigger until
  the operator creates the `live-verify` Environment and provisions
  its secrets (HUMAN-H6).
- Doc-comment edits in ~25 crates ride this PR — required by the
  ticket's own `cargo doc -D warnings` AC (the only way to land the
  gate green is to fix what it surfaces). Nothing outside doc comments
  changed; `cargo fmt`/`build`/`test` re-verify.

## Alternatives considered

- **`gitleaks-action`** — cannot express `--log-opts=--all` + the
  committed config cleanly and needs an org license path; rejected.
- **Steps inside `build-test-drift`** — matrix fan-out would double
  the cost and `fetch-depth: 0` would penalise both legs; rejected.
- **`wildcards`/`multiple-versions = "deny"` + skip lists** — produces
  `unnecessary-skip` noise or false findings for path deps; `warn`
  keeps the finding visible honestly; chosen.
- **Upgrading actions to v7 majors** — out of this ticket's scope;
  dependabot proposes those bumps on its own cadence; rejected.

## Revisit trigger

Reopen when: a RustSec advisory lands against the ADR-0365 set again
(the pin bumps by sibling ADR, never a silent `cargo update`); a new
dependency, registry, git source, or license family needs admission
(always an ADR first); the `ubuntu-latest` → Ubuntu 26 or macOS image
migration changes runner semantics; the `live-verify` Environment's
protection shape changes; or cargo-deny/gitleaks releases move the
pinned behaviour.
