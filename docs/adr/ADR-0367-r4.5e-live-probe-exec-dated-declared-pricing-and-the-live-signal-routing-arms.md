  `routing_policy` arms beyond `fail_fast`/`route` now select) ·

## Context

DF-S1.18-1's residual after R4.5d named two halves: `probe_profile`/
`ProbeSpec` *executed* against the three admitted families (the R2.7
machinery minted declared probe rows only), and the live-signal
`RoutingPolicy` arms ADR-0338 D4 left answering typed refusals
(`learned`, live health, price discovery) — each must select under its
declared guard set from live probe results and recorded outcomes, never
defaulting to healthy/zero/available. Seven decisions are this ticket's
to own: how a transport answers a probe, where probe execution lives in
the open path, what "price discovery" honestly is when no provider
serves a price API, what the `learned` arm's replayable signal is, how
probe verdicts reach health, what a `model.profile.probed` row carries
for replay, and the ticket's measured size.

## Decision

- **D1 — the `Transport` probe surface is credential-bearing; the
  claim-shaping capabilities ride one measured call.**
  `Transport::discover`/`probe_capability` take the `CredentialHandle`
  exactly as `send` does — the hosted listing and the probe calls auth
  through the same coordinate-only handle (the value resolves inside
  the call and drops, ADR-0366 D4). `HttpModelTransport` answers three
  probe primitives: `cap.model_listing` rides `discover` (`GET
  {endpoint}/models` — the listing member the dialect names);
  `cap.count_tokens` rides the Messages family's `count_tokens`
  primitive where the dialect declares one (a family without the member
  answers `UnsupportedFeature` — the conformance row records `skipped`,
  never a fabricated value); `cap.streaming` /
  `cap.snapshot_id_exposed` / `cap.cache_state_visible` read a single
  cached tiny probe call (`stream:true`, one-token reserve) whose raw
  documents are scanned *before* normalization — `system_fingerprint`,
  `cache_*_tokens` and the usage object's members are observed as the
  wire carried them. A capability with no primitive is
  `UnsupportedFeature`; a probe *failure* is the dialect's typed
  `ModelError`, never a silent row.

- **D2 — `probe_exec[]` lanes execute at `open` through the arm;
  measured usage rides the probed row.** The `router` slot's
  `probe_exec[]` member declares each live lane `{profile_ref, dialect,
  endpoint, credential_ref?, provider_model_id, pinned{}, canaries[],
  dependency_capabilities[], status_declared}` (`endpoint`/
  `provider_model_id` resolve `env:NAME`; `credential_ref` keeps the
  coordinate spelling — T-LCD-01 admits `provider_model_id`, never
  `model`). `exec_probe_decl` binds the credential, reads the
  authenticated listing, folds `served_model.<id>` plus every declared
  capability row through `run_transport_probes`, and hands the arm the
  rows to mint — `model.profile.probed{profile_ref, probe_run_id,
  records[], observed.usage}` lands durable before the first
  `model.call.requested`; a `dependency_capabilities` verdict of
  `DRIFT`/`UNSUPPORTED` mints `model.profile.status.changed{trigger:
  probe_failure}`. The `probe_run_id` is idp/1 over the record
  spellings (the same observed outcome replays to the same id); the
  measured probe-call usage rides `observed.usage` — instrumentation
  metering on the row, never an estimate and never an unmetered call.
  A resume re-folds the durable rows — it never re-executes live
  probes.

- **D3 — price discovery is the dated declared view; stale is
  `NoPrice`.** No admitted provider serves a machine-readable price
  API, so the arm selects over the dated declared table —
  `DeclaredPricing` decodes the `router` slot's `pricing` member
  `{table_ref, source, retrieved, max_age_days, models{id →
  prompt/completion per-1k-μUSD}}`: provenance is mandatory (a view
  that cannot name its date is no declared view), and past
  `retrieved + max_age` every read answers `None` — the candidate
  verdicts `NoPrice`, never a stale price, a zero cost, or an invented
  row. `PricingView::estimate_call_cost` carries `now_ms` so the
  freshness bound verdicts per read. *Recorded deviation:* the spec's
  "price discovery" is discharged by the declared view + staleness
  bound — whether the requirement's verdict reads MET-DIFFERENTLY is
  surfaced at GATE-G6 per the ticket's own note, not self-ruled here.

- **D4 — `learned` replays declared recorded outcomes; an unscored
  candidate is `policy_excluded`.** The arm's evidence binding gains
  `params.evolution.scores{model_ref-spelling → score}` — the
  evolution pipeline's recorded outcomes, replayed verbatim (declared,
  durable-readable, deterministic). A missing `scores` table is the
  same `PolicyInvalid` as every other missing evidence member; a
  candidate with no recorded outcome is `policy_excluded`; admitted
  candidates rank by recorded score, binding order breaking ties —
  `inputs_read` records `recorded_outcomes`. No in-router learner, no
  invented score.

- **D5 — probe verdicts fold into health; `health_aware` never
  defaults healthy.** `project_health` gains the
  `profile_ref → target` join (`probe_targets`, derived from the role
  table's bound candidates): a probed row's `SUPPORTED` records count
  success observations, `DRIFT`/`UNSUPPORTED` count failures, every
  other verdict observes nothing — probe outcomes feed health exactly
  as attempt rows do (CC1, one fold over the durable prefix). A
  `health_aware` arm whose admitted set carries no observation at all
  refuses `PolicyInvalid`; an unobserved candidate sorts below every
  observed score — a candidate the signal has not seen never outranks
  a measured one.

- **D6 — the executor is open-path only and refuses whole.**
  `exec_probe_decl` runs inside `arm_routing_lane` on the open path
  (`execute_probe_execs=true`); resume passes `false`. An unadmitted
  dialect coordinate, an unbindable credential, or a probe leg's typed
  transport refusal fails the *open* with the reason — no partial rows
  mint and no lane silently degrades to declared-only.

- **D7 — size deviation recorded, not hidden.** ≈2,320 changed lines
  code+tests+scripts vs the ticket's 800-line budget (≈2.9×): the
  credential-bearing probe surface, the per-family probe primitives,
  the three live-signal arms' signal plumbing, the hermetic arm cells,
  and the three-family live leg are one atomic feature — a per-arm
  split would strand the probe executor from the health fold that
  proves it. The R4.5b/R4.5d live-track pattern continues; carried to
  GATE-G7's systematic under-pricing account.

## Consequences

- `probe_profile` executes against all three admitted families live:
  the authenticated model listing folds `served_model.<id>` against the
  pins, the capability walk emits derived-verdict `ConformanceRecord`s
  (`ObservedIn::Probe`), and a dependency-set contradiction flips
  status — `docs/build/reports/live/2026-10-21-routing-probe.json`
  (`live-executed`, measured spend $0.000033 — two development-attempt
  legs carry declared-budget debits of $5 each in SPEND.jsonl, the
  framework's conservative un-measured rule, total recorded $15.0006 of
  the USD 5 allocation; the provider-console authority reconciles per
  ADR-0363 D4).
- Every live-signal arm has hermetic cells over recorded rows:
  `learned` ranks by declared scores + refuses `PolicyInvalid`/
  `policy_excluded` on missing signal; `health_aware` refuses
  `PolicyInvalid` on zero observations and never sorts unobserved
  ahead; `DeclaredPricing` refuses `NoPrice` stale/unprovenanced;
  `project_health` folds probe verdicts — `model_plane.rs` 60/60.
- **DF-S1.18-1 is discharged** — dated evidence: the `routing-probe`
  record + transcript above and this ADR.
- ADR-0284 trigger (b) and ADR-0338 triggers (a)+(b) are fired-answered
  (dated notes appended on both records).
- `BL-31` keeps OPEN — its residual is the real
  Embedder/Summarizer/ProviderCompaction adapters and ADR-0346's
  live-sink leg, not this row's cells.

## Alternatives considered

- **Probe execution as a boundary op** (`probe_profile` RPC driving the
  transport directly): rejected — the rows must land under the run's
  fenced writer ordered before the first visible drive; an op-side
  mint could not place them inside the open's arm, and the declared
  lane is where §5b.3 puts probe evidence.
- **Minting `model.call.*` rows for the measured probe call** (the
  `Purpose::Probe` call path): rejected for the claim-shaping walk —
  the §5b.3 probe is a conformance observation, not a session call;
  the usage is honestly metered on the probed row's `observed.usage`
  member the leg's spend record reads, and the fingerprint-probe
  (`Purpose::Probe`) path stays the call-shaped probe for its own
  contract.
- **A provider price API probe:** no admitted provider serves one —
  the dated declared table + staleness bound is the honest reading of
  "price discovery"; inventing an endpoint would fabricate signal
  (recorded as the D3 deviation for GATE-G6's verdict accounting).
- **`scores` read from the registry instead of params:** rejected for
  this rung — the params member keeps the recorded outcomes inside the
  sealed slot declaration (replayable byte-identically); a
  registry-read variant is a later surface, not a second signal
  source.

## Revisit trigger

- A provider serves a machine-readable price API the declared view could
  be replaced by → re-open D3's recorded deviation and re-rule the
  price-discovery arm against the live primitive.
- An admitted family declares a capability whose observation does not
  fold through `run_transport_probes`'s raw-member scan → extend the
  transport probe primitive set under this ADR's D1.
- `evolution.scores` gains a registry-durable home → re-rule D4's
  params-declared surface as the sealed spelling.
