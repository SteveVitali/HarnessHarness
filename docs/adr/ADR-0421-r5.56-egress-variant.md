# ADR-0421: R5.56 admits the scoped `bridge`-network cell profile as a first-class `PodmanBackend` variant

- **Status:** Accepted
- **Date:** 2026-11-06
- **Ticket:** R5.56 (egress variant — S4-completion extension, manifest
  row 247)
- **Requirement ids:** contributing-only `R-2.8.4` (the
  containment/egress policy enforcement surface this variant honours);
  no primary ownership — the S4 cohort predicates (`REQ-D-101/102/103`,
  `REQ-E-011`) stay owed to R5.58/R5.59
- **Spec:** `spec/CANONICAL_SPEC.md` §5d.5 (the helper/executor
  boundary); §5g.4 `net.mode ∈ {none, mediated, public}` (ADR-0061 D1)
  and `residual_channels[{kind, statement, owner, closer}]` incl.
  `host_bridge` (N4 — `mode = public` requires authority ≥ principal and
  a declared residual, `PolicyError::PublicWithoutResidual`);
  `docs/tickets/247_R5.56__egress-variant.md`;
  `docs/build/runs/S4-EGRESS.md` + `docs/build/reports/2026-11-05-s4-egress-cohort.json`
  (`hh-s4-egress-supplement/1` — the sanctioned field spellings; both
  land via PR #283)
- **Rung (ADR-0024 obligation):** implementation landing record — a
  scoped executor variant admission; no RPC, no schema source, no new
  dependency, no new event class or `RecordKind`, no store/dispatch
  authority, no spend

## Context

The S4 egress supplement ran its `declared_deps` cells on a scratch
helper binary — `/tmp/s4-helper-egress`, `hh_helper.rs` verbatim plus a
`--network <none|bridge>` / `S4_HELPER_NETWORK` knob — because the stock
helper hardcoded `network: false` and produced `--network none`
unconditionally. The supplement was a *named, bounded* admission:
egress-declared tasks ran their podman cells on `--network bridge`
(outbound NAT through the VM's slirp4netns) under an honest policy —
`net.mode = public` with a declared `residual_channels[host_bridge]`
entry — and every slot row recorded `egress_profile: declared_deps`,
`cell_network: bridge`, `policy_net_mode: public`, `helper_bin`
verbatim. Its first smoke run panicked on exactly the N4 check
(`PublicWithoutResidual`), which is the honesty the sanctioned form
must preserve.

Scratch machinery cannot serve an admitted run: the binary lived in
`/tmp`, the knob had no contract, and R5.58's GCE re-execution of the
50 inconclusive cohort slots requires the variant as first-class,
regression-pinned machinery. The admission is deliberately scoped:
`declared_deps`-only, `none` stays the default posture for untrusted
participants, and no other network mode or residual kind is admitted.

## Decision

1. **The flag is the sanctioned surface.** `hh-helper` admits
   `--network <none|bridge>` (default `none`) with the
   `S4_HELPER_NETWORK` env fallback — `HelperClient::spawn` passes a
   fixed argv, so the env is the channel a spawn-side admission
   travels; an explicit flag always wins. An unknown flag *or* env
   value is a usage failure (exit 2), never coerced. `PodmanBackend`
   gains no new field — `network` drives the existing
   `--network bridge|none` spelling; `create()`'s argv is extracted to
   `create_args()` so the mapping is observable without a live podman.
   The scratch `/tmp/s4-helper-egress` variant is **superseded** — its
   provenance stands in `runs/S4-EGRESS.md`, never erased.
2. **The attached policy drives the cell network.**
   `EnvDriver::start_helper` builds the helper's podman argv through
   `hharness_env::egress_profile::podman_helper_args` — `net.mode =
   public` on the *attached* containment policy appends `--network
   bridge`; `none`/`mediated` leave the flag absent, so an unadmitted
   cell's argv is byte-identical to the pre-variant posture. `mediated`
   is its own declared posture — never silently widened to bridge.
3. **The `declared_deps` admission is transactional and honest.**
   `egress_profile::admit_declared_deps(record, policy, decl, at)`
   refuses typed (`Unsupported{egress_profile.declared_deps}`) when the
   task declares no runtime egress deps, when the residual's
   owner/closer is empty, or when the record is not a `local_container`
   cell. On admission it mutates a policy *candidate* to `net.mode =
   public` + `residual_channels[{kind: host_bridge, statement, owner,
   closer}]` (the statement names the deps verbatim; kernel provenance
   satisfies N4's ≥-principal leg), runs `validate()`, and only then
   commits the policy and stamps `record.ext` with the supplement's
   field spellings — `egress_profile`, `cell_network`,
   `policy_net_mode`, `declared_deps` verbatim. A refused admission
   changes nothing; `PublicWithoutResidual` and
   `PublicBelowPrincipal` still fire because the validator is
   consulted, never bypassed. A bridge cell can never be labelled
   `none`/`mediated`: the record stamps exist only after the honest
   policy does.
4. **The supplement's vocabulary is the record vocabulary.** The
   machinery answers `egress_profile`, `cell_network`,
   `policy_net_mode` verbatim so R5.58's slot rows read identically to
   `hh-s4-egress-supplement/1`; `helper_bin` becomes unnecessary — the
   stock binary *is* the admitted variant.
5. **Scope is the recorded bound.** Only `declared_deps` cells get the
   bridge; fs/proc boundaries are untouched (pids limit,
   `no-new-privileges`, `/work` mount, `--init` stay exactly as
   `create()` declares); no mediator/proxy change, no other residual
   kind, no relaxation of N4.

## Consequences

- The variant is first-class: `cargo test -p hharness-helper` spawns
  the real binary against a `podman` stub and pins the argv
  (`--network bridge` on flag/env; `--network none` byte-identical on
  absent flag; usage(2) on unknown values), and
  `hharness-env/tests/r5_56.rs` pins the policy-driven selection, the
  transactional admission, and the N4 refusals.
- Default posture is provably unchanged: absent the flag the helper
  emits the same `podman create` argv it always did.
- The admission composes with the existing machinery: `attach`'s
  fail-closed `validate()` and the meet's authority rules apply to the
  `public` layer exactly as to any other — the profile widens nothing
  beyond the declared `host_bridge` residual, which names its owner
  and closer.
- `S4_HELPER_NETWORK` is admitted machinery, not a side channel: it
  exists because the spawn argv is fixed; it is documented on the
  binary's contract header and gated by the same closed sum as the
  flag. A process env that lies produces a usage refusal or the same
  honest bridge — never an undeclared mode.
- R5.58 can run egress-declared cells on the admitted variant without
  scratch machinery; the per-slot record fields are stable.

## Alternatives considered

- **Keep the scratch variant:** rejected — an uncommitted `/tmp` binary
  cannot serve an admitted cohort run, and its knob had no contract or
  regression battery; this ADR sanctions the semantics, not the file.
- **Generic `--network <name>` passthrough:** rejected — an open
  podman-network vocabulary admits arbitrary network topology under an
  unscoped flag; the closed `none|bridge` sum is the admitted scope,
  and anything else refuses at usage.
- **Drive the flag off a record `ext` member:** rejected — `ext` is
  surface, never identity-bearing; the *attached policy* is the
  authoritative declared boundary, so a bridge cell sourced from an
  unvalidated member could disagree with the record and relabel the
  cell `none`. Policy-driven selection makes the honest label
  structural.
- **A new `EnvironmentClass` or record member for the profile:**
  rejected — a schema/record change is beyond this scoped admission;
  `ext` already carries the verbatim field spellings the supplement
  defined.
- **Widen `mediated` to bridge:** rejected — `mediated` declares
  boundary enforcement the bridge does not provide; silently widening
  it would label a public posture as a contained one.

## Revisit trigger

- A second admitted network posture (a real `mediated`/proxy cell, a
  different podman network name, or a non-`host_bridge` residual kind)
  lands: re-scope the closed `--network` sum and the validator leg.
- `HelperClient::spawn` gains per-cell argv plumbing: re-rule whether
  `S4_HELPER_NETWORK` stays admitted or the flag becomes the only
  channel.
- The GCE backend's network spelling differs from local podman's
  `bridge` (R5.58's live leg): re-derive the mode↔spelling map rather
  than widening the sum silently.
- `net.mode` gains a fourth member or `ResidualKind` a second
  bridge-class kind: the admission's closed mapping and the N4 leg get
  re-justified.
