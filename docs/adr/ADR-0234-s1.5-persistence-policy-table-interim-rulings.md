# ADR-0234: S1.5 persistence-policy class table — the C0/Stage-1 registered set and its interim rulings (audit-grade subset, kernel-origin, provenance-mandatory `security.permission.*`, ephemeral member stripping, scope open/close, interim Rule-C cap)

- **Status:** Accepted
- **Date:** 2026-09-15
- **Ticket:** S1.5
- **Requirement ids:** R-2.2.1
- **Spec:** §5a.1 §3 (event taxonomy, persistence-policy table), §5a.1 §6 (audit rules) ·
  ADR-0026 §3/Phase-2-log, ADR-0035 §4, ADR-0066 Rules C/P/O, ADR-0102 §8

## Context
§5a.1 §3 requires *one declared table* (never producer-local code) stating per class:
`durability`, inline offload threshold, minimum `observability_level`, producers,
audit-grade flag, and Hosting-ABI lowering. The C0/Stage-1 build-stage slice names
"lifecycle + model + action (incl. effect phases) + `security.permission.*` classes".
Several rulings in the surrounding text are under-specified for a Stage-1 table or
belong to subsystems that have not landed, so the ticket had to fix interim values
without contradicting the staged spec:

- The §5a.1 §6 audit list names `lifecycle.lease.*`, `lifecycle.ledger.{redacted,gc}`,
  `lifecycle.run.*`, `lifecycle.head.moved` as audit-grade; the wider taxonomy names
  classes whose audit status is decided elsewhere (§05a.2 makes every `action.effect.*`
  phase audit-grade with a content-free envelope; §05b.1 does the same for
  `model.call.{requested,completed,failed}`).
- ADR-0035 §4's mandatory-provenance table (as re-keyed by its Phase-4 log) covers
  `security.permission.granted` and `security.label.*`; whether the whole
  `security.permission.*` request/decision chain is provenance-mandatory is a
  §8.1/§5a.1 spelling reconciliation.
- ADR-0066 Rule C ("audit-grade classes carry content-free envelopes") defers the
  per-class `audit_fields` whitelists to the §05g audit catalogue — not landed.
- `security.permission.requested` is `ledger` with an ephemeral `rendering` member —
  the only Stage-1 class needing per-*member* persistence.
- `effect_id`/`child_run_id`/`branch_id` scopes have no Stage-1 openers
  (`control.subagent.spawned` is Stage 4; `lifecycle.branch.*`/`navigate` is Stage 2),
  and several `action.tool.*` classes are unregistered under ADR-0212's OQ-235 deferral.

## Decision
- **One `pub const CLASS_TABLE`** in `hh-ledger::classes` is the registry (CC7):
  `class, durability, offload_threshold, min_observability, audit_grade,
  kernel_origin, requires_provenance, ephemeral_fields, opens_scope, closes_scope,
  lowering`. Unknown classes are refused `SchemaViolation`, never admitted.
- **Audit-grade rulings (interim, cited):** the §5a.1 §6 list verbatim, **plus**
  `lifecycle.run.suspended` (it sits in §05a.3's audit list), every `action.effect.*`
  phase (§05a.2 §6), and `model.call.{requested,completed,failed}` (§05b.1).
  `lifecycle.run.resumed` is audit-grade per the §5a.1 §6 enumeration.
- **Kernel-origin rulings:** every `lifecycle.*` row and every `action.environment.*` /
  `action.world_state.*` row requires `producer.component_class = "kernel"` **and**
  `provenance.origin = kernel` (§5a.1 §6); both fire `AuditProducerInvalid` /
  `KernelOriginRequired`.
- **Provenance-mandatory ruling (interim):** the *entire* `security.permission.*` set
  and `security.label.*` carry `requires_provenance` — the request/decision/grant/revoke
  chain is one fact class, and under-declaring would silently drop the mandatory record
  on the non-`granted` members. Marked interim pending the §8.1/§5a.1 spelling
  reconciliation; a test cross-checks the declared set against `hh-provenance`'s
  §8.1-table coverage so the interim never drifts *below* the spec table.
- **Interim Rule C:** until the §05g per-class `audit_fields` whitelists exist,
  audit-grade payloads are capped at `AUDIT_PAYLOAD_MAX_BYTES` = 4 KiB canonical
  (`AuditFieldsTooLarge`) — a size bound stands in for the whitelist.
- **Ephemeral members:** `security.permission.requested` is `ledger` with
  `ephemeral_fields = ["rendering"]` — the durable form strips `rendering` and
  subscribers receive it as an `Ephemeral` fragment carrying `durable_event_seq`.
  `model.stream.delta`, `action.tool.output_chunk`, `action.tool.progress` are
  `ephemeral` classes; `security.permission.pending` is `ledger` (ADR-0026 Phase 2 log).
- **Scope rulings:** `turn_id` opens at `lifecycle.turn.started`, `model_call_id` at
  `model.call.requested`, `tool_call_id` at `action.tool.proposed`, `effect_id` at
  `action.effect.intended`; terminals close them. `child_run_id`/`branch_id` have no
  Stage-1 opener and may only appear *absent* — a set-but-unopened value is
  `ScopeNotOpen`. ADR-0212/OQ-235-unregistered `action.tool.*` spellings are absent.
- **Lowering** is `"none"` on every row (R-2.10.6/ADR-0164 owns hosted lowering);
  **blob ceiling** is an interim 1 GiB (`DEFAULT_BLOB_MAX_BYTES`) pending the Stage-2
  retention policy.

## Consequences
- Good: AC-12's "one declared table" is literally one `const`; every append-time rule
  the gating ACs need is a table lookup, and the test suite cross-checks the table
  against the ontology prefix rule and the §8.1 mandatory set so silent drift fails CI.
- Cost: interim flags may over-declare (`security.permission.{requested,pending,
  decided,revoked}` provenance-mandatory) — over-declaration is safe (never drops a
  required record) but may tighten to the §8.1 spelling later; the 4 KiB Rule-C cap is
  coarser than per-field whitelists and may refuse a legitimately-small-but-correct
  audit payload shaped differently than expected.

## Alternatives considered
- **Only `security.permission.granted` provenance-mandatory** (the literal §8.1-table
  spelling) — rejected: under-declares the same fact class's other members; the interim
  over-declares and a future ADR can relax, never retro-fill.
- **Implement Rule C whitelists now** — rejected: the field lists are the §05g audit
  catalogue's data (not landed); inventing them here would be a second schema source.
- **Register the full §5a.1 §3 taxonomy** — rejected: `control.*`/`measurement.*`/
  wildcard classes have no Stage-1 producers; declaring dead rows would let callers
  mint events no producer owns.

## Revisit trigger
Reopen when the §05g audit catalogue lands (replace the size cap with per-class
`audit_fields`), when the §8.1 mandatory-provenance spelling is reconciled (relax the
`security.permission.*` interim), when R-2.10.6 lands hosted lowering, or when a
Stage-2+ ticket registers the deferred families.
