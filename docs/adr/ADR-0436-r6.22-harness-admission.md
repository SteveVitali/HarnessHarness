## Context

Experiments spec §5.1–§5.3 requires every hosted harness to enter a
slot through one admission: an `hh-harness-admission/1` record a
validator checks before any slot (AG1–AG9 per role, pinned versions and
digests, the Q-X26 terms for Claude Code), a `container_installed`
declaration with its `HostingExt`, and the §5.2 two-stage install — a
once-built content-addressed bundle (a) plus a per-(harness × task
image) layer (b) — whose run-side ST2 setup is verify-only. No build
executes in this row: W1 (R6.32) builds; R6.23 carries and exports.

The alternatives were weighed at design time (design/34 §1.2): a
runtime install breaks the offline agent cell (Q-X30) and pin
reproducibility; a bind-mounted bundle alone misses the system packages
Harbor's `ensure_system_dependencies` installs (F2) and is the
disk-bound fallback only (C4 OQ-4). The two-stage layered image is
faithful, offline at run, and byte-identical between O and H with
`skip_install` (F4).

## Decision

- **`hh-harness-admission/1` is one runner-crate record** (CC1) over
  `hharness-wire` canonical JSON, homed in `hharness-runner` beside
  `hh-experiment-slot/1` — never an `hh-embed/1` member (CC7). Its
  member set is the §5.1 list: `harness` (name, role, harbor_agent,
  version, version_source, freeze_at, legal), `install` (recipe_ref
  with attribution and deviations, bundle, system_deps, layers,
  install_tree_paths, version_probe), `runtime`, `config` (renderer id
  and version, template hash, effort mechanism and value, limits ref,
  disable switches, instruction passing, model selector, surface,
  base_url_suffix, rendered_paths), `egress` (`expected_denied`,
  `must_reach: [model_relay]`), `client` (timeout and retry where
  known, `unknown` otherwise — REQ-XC-322), `completion`, `artifacts`,
  `gates` (AG1–AG9 → result and evidence), `posture` (placement,
  residuals), the C3 attributes A1–A7, `admission_timing:
  outcome_blind`, and `verification` (fixture class until W1 measures).
- **One pure validator** refuses: a missing AG1–AG9 gate per role (AG9
  only where the harness is O-vs-H eligible — a `harbor_agent` adapter
  at the pinned commit on the same image, REQ-XC-214); a floating,
  `@latest`, `stable`, prerelease or unlocked version (REQ-XD-081,
  REQ-XB-014's alias); a missing lock or resolution cutoff; a missing
  bundle or layer digest; a missing config template hash,
  `expected_denied` list, legal-posture record, A1–A7 attribute,
  effort-pin mechanism or configuration-limit set. mini-swe-agent is
  exactly 2.4.6; LiteLLM is pinned; a post-freeze version change is a
  new participant identity (`admission_id` re-derives over
  `{name, version, freeze_at, role, bundle.digest}`). Proprietary or
  source-available harnesses carry quoted terms, a terms-source ref and
  a recorded operator acknowledgement with `branding: name_only`
  (REQ-XC-202); Claude Code carries the five Q-X26 terms verbatim —
  unmodified pinned binary, no Claude account, black-box arm only,
  name without logo, the not-supported disclosure — plus the binary
  sha256 the ST2/ST4 probes check (REQ-XC-327 contributing).
- **Placement is declared, not admitted.** Adapter C's
  `placement_supported` gains `lab_host` now (REQ-XC-301); the
  declaration fixture validates `HostingExt{model_io_intercept:
  base_url, process_placement}` and `model_io` is earned only from
  proxy receipts — a native-log lift never sets `mediation: mediated`.
  A `lab_host` *slot* refuses typed until AR-19 (ticket Notes resolve).
- **The two-stage build is a recorded host act.** The bundle recipe is
  HH-owned text derived from the pinned Harbor commit's `install()`
  with attribution and listed deviations (REQ-XC-303); the layer
  Containerfile is `FROM` the task image digest, replays the adapter's
  system-dependency step and places the bundle at the adapter's
  expected paths (REQ-XC-304). The build sub-command runs `podman
  build` with an `--iidfile` digest capture and a package-delta
  manifest; cells reference layers by digest only — a tag ref refuses.
  A layer builds at most once per pass: a rebuild is a new admission
  (REQ-XC-330 contributing). A bundle or layer containing a
  proprietary harness is a `digest_only` index member — its bytes stay
  on the operator controller (REQ-XC-330 contributing).
- **ST2 is verify-only and never opens a network** (REQ-XC-305): the
  version probe output, the bundle tree hash and the rendered-config
  hash (plus the Q-X26 binary sha256 where declared) are compared
  against the admission; a mismatch is
  `withheld{admission:harness_layer_mismatch}` through R6.8's closed
  set — never a second vocabulary (X-04). A failed build step is
  `n/a{install:<step>}` (§5.8); a fixed recipe is a new admission.
- **The results site carries no third-party logo without a recorded
  permission** (REQ-XC-202): the `logos` leg extends R6.6's
  `check-site.sh` — the same checker, never a second one (CC1) — and
  fails any `logo`-shaped mark or raster image not named in the
  declared permission set.
- **The $0 build leg is registered and stubbed:** `admission-build` in
  `scripts/live-verify.sh` is `skipped(executes-in-W1-under-R6.32)`
  until W1; the matching `#[ignore = "live — ADR-0363: …"]` test is the
  stub (REQ-XC-329, AC-5.7-4 contribution).

## Consequences

- R6.23 consumes the layers map, the digest-only upload class and the
  build record; R6.24 consumes `config.rendered_paths` and the Q-X26
  members; R6.25 consumes `client` for SM-slow; R6.26 consumes
  `gates.AG9` and the O-surface `skip_install` pairing; R6.27 consumes
  the admission ref for the request fingerprint.
- The record's `verification.class` is `fixture-verified` until W1
  measures bundle digests, smoke evidence and client behaviour — no
  member asserts a live value (X-08).
- No real build, pull, VM or spend runs under this decision; the live
  leg is an honest `skipped(...)` until R6.32 wires it.

## Alternatives considered

- **Runtime install (Harbor's behaviour)** — requires network at
  setup, breaks Q-X30's offline cell and resolves per trial; rejected
  (design/34 §1.2).
- **Bind-mounted bundle only** — misses `ensure_system_dependencies`;
  the disk-bound fallback (C4 OQ-4) only; rejected as the default.
- **A validator inside the slot worker** — admission is a pre-slot
  host act over the record, not a per-attempt re-check; the worker
  keeps consuming `withheld{admission:<r>}` facts (CC1); rejected.
- **A second site checker for logos** — CC1; rejected. The leg extends
  `check-site.sh`.

## Revisit trigger

Revisit when W1's measured bundle/layer digests land (fixture members
flip from `fixture-verified` to measured), when a fourth harness is
admitted (later pass), when AR-19 admits a `lab_host` slot, or when
the Claude Code binary sha256 is first measured on the VM.
