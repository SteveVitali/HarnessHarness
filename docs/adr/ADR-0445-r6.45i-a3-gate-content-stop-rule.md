# ADR-0445: PROV readout content — the re-scope ladder and the prediction-track table; the post-Wc9 stop rule (§10.5 amendment row A3)

- **Status:** Accepted — operator ruling R-8, interactive 2026-11-15 (LEDGER `## GATE DECISIONS` `intervention-2026-11-15` row, verbatim)
- **Date:** 2026-11-16
- **Ticket:** R6.45i (manifest 309i — records); applied by GATE-G28i/GATE-G28j's readouts and every later repair/re-proof PROV; GATE-G30's readout template carries a dated note
- **Amendment register item:** A3 (experiments spec §10.5, "First-pass intervention amendments")
- **Requirement ids:** REQ-XH-004 (readout terms), REQ-XH-116 (the seeded replacement order under `re-scope{exclude-and-replace}`), FP-7
- **Spec:** experiments spec §10.3 (gate content), §10.1.4, §10.5 row A3; insert spec §6 (the ladder) and §7 (the early-inspection checkpoint)
- **Rung (ADR-0024 obligation):** an explicit non-contract note — this ADR governs the experiments-program first pass, not the canonical kernel contract ladder.

## Context

Each repair-window readout offered only `run | not_run`, and each predicted success — "the last confirmed blocker is repaired" — seven times running (Wc2 through Wc8; diagnosis §1.4). A two-option gate that always predicts success gives the operator no honest middle path between another blind window and stopping the pass.

## Decision

R-8 (verbatim in the GATE DECISIONS row):

1. **Every PROV readout for a repair or re-proof window lists the re-scope ladder** besides `run`/`not_run`:
   - `re-scope{harden-again}` — another R6.45k-style insert plus a new smoke envelope, for a newly named defect class;
   - `re-scope{exclude-and-replace}` — only where A5 makes an exclusion legitimate (a named denied host / O-fail), replacement from the seeded order per FP-7/REQ-XH-116;
   - `re-scope{end-first-pass-early}` — record the re-proof outcome as the first-pass result and skip W4, naming the claims withheld.
2. **Every such readout carries the prediction-track table** — each prior window's readout-predicted outcome vs the actual outcome.
3. **Wc9 carries the early-inspection checkpoint** (operator-preauthorized as the GATE-G28j readout records it): once the first H-allow cells of ≥ 4 distinct members complete, their cell reports are harvested; a machinery signature (`verifier_unavailable:*`, a mediator 5xx, a tunnel `close_cause` ≠ `eof`) stops the leg, tears down and records `incomplete{early_stop:machinery_signature}`; otherwise the window runs to completion.
4. **Post-Wc9 stop rule:** if Wc9 leaves any member with a `machinery{…}` discordance or a `verifier_unavailable:*` classification, **no Wc10 is drafted** — `blockedOn` plus a scope-decision readout carrying options 2–5 of the ladder.

## Consequences

GATE-G28i's readout carries the ladder and the track table (a smoke-envelope presentation, not an evidence PROV — the amended content rule is met regardless). GATE-G28j's readout pre-registers all eight required contents including the A2 budget table and the track table (Wc→Wc8). GATE-G30's readout template gains the same elements by dated note. The prediction-track table makes each readout's forecasting record auditable — the operator can weigh a ninth prediction against the seven recorded ones.

## Alternatives considered

- **Keep `run | not_run` only** — the recorded failure mode: binary gates plus overconfident predictions produce serial window spend. Rejected.
- **An automatic stop after N failures** — a mechanical rule reads outcome-shaped state; the ruling keeps the decision at the operator with better information instead. Rejected.

## Revisit trigger

Revisit if the ladder's options need a sixth member, if Wc9 completes clean (the stop rule discharges — record it), or if a prediction-track pattern emerges that warrants an automatic rule (propose it as a new amendment, never apply silently).
