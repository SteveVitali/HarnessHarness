# AR-05 — `allowlist_mediated`: the paid-cell egress profile (R6.15)

## Status

Accepted 2026-05-02 — lands with manifest 268 (R6.15). Absorbs ADR-C2-C's
mediation requirements (REQ-XB-008 → REQ-XB-113; REQ-XC-102's mediation
vocabulary and residual declarations). `declared_deps` (ADR-0421) remains
admitted byte-identically and is never substituted silently.

## Context

Experiments-spec §3.5 defines one paid-cell network posture (ticket
EGRESS a+b, absorbing C2 EGRESS): `--network none` for the cell's whole
life, `net.mode = mediated`, exactly the two bind-mounted unix sockets
`{model, egress}`, a statically linked `hh-cell-relay` as the cell's main
process, per-phase policy via the sealed `set_phase` schedule, and a
Q-X55 first-pass allowlist (apt ∪ PyPI ∪ npm ∪ crates; no `github.com`
in the agent phase). The alternative — three profiles — was rejected
Q1 in the ticket; a second profile widens the paid attack surface.

## Decision

- **`hh-env::egress_allowlist`** owns the profile: `admit_allowlist_mediated`
  is a transactional admission (mutate a candidate → `validate()` →
  commit; a refusal leaves record+policy byte-identical), deriving the
  closed socket grants, permanent deny rules (answer-key hosts +
  declared mirrors), the sealed `phase_schedule` ext member (setup →
  agent → verify `policy_rule` layers at `principal` authority), the six
  declared residuals, the env routing hints, and the honest record
  stamps (`egress_profile`, `cell_network=none`,
  `policy_net_mode=mediated`, `per_phase_network_policy=supported`,
  `mediated_cell`, `allowlist{protocol_id, epoch, digest}`).
- **`hh-cell-relay`** lives in `hh-helper` (std-only → a
  `x86_64-unknown-linux-musl` static binary; the target is admitted in
  `rust-toolchain.toml`): `--pair <model|egress>=<port>=<sock>` binds
  loopback and bridges to the bind-mounted socket; pairs are the closed
  set. It runs as the cell's main process under `--init` (catatonit
  forwards a PID-1 signal — REQ-XB-129's kill fact reads the same);
  podman argv mounts sockets + the binary ro, replaces the `sleep
  infinity` tail.
- **`hh-egress-mediator`** lives in `hh-env`: sole writer of its store
  root, serves the egress socket, re-reads the policy file per
  connection (a phase swap is a file write). `EgressMediator::forward`
  shares its pre-decided legs with the new `forward_tunnel` (`pre_wire`)
  so CONNECT follows the identical `requested → decided{allow|deny}`
  ordering before any upstream byte; `security.egress.tunnel.closed` is
  registered in the class table for the closing byte fold.
- **`hh-egress-allowlist-freeze/1`** records `{protocol_id, epoch, list,
  digest}` before the first paid slot; an unchanged `protocol_id`+epoch
  with a different digest refuses `allowlist_changed`; a task needing an
  ungranted agent host excludes `runner_infeasible:allowlist_gap{host}`.
- The cell env carries routing hints only (`http(s)_proxy` at the relay
  port, mandatory `no_proxy`, proxy base URLs, slot token) — never a
  kernel attribution token; `validate_cell_env` refuses a missing
  `no_proxy` or a token-named member. The backend's recorded
  `proxy_env_is_not_mediation` lowering loss is preserved.
- The slot identity gains `identity.infrastructure` (`runner|helper|
  relay|model_proxy|egress_mediator` × `binary_sha256`, strict decode)
  — REQ-XC-330's set, relay digest admitted now; the full population is
  R6.23's.

## Consequences

- The TB 2.1 paid lane is the admitted profile only; nothing ambient
  widens it (the record stamps, the sealed schedule, and the freeze are
  what an un-admitted cell lacks).
- `set_phase` is the sole phase-transition path — the container is never
  re-networked; a swap is a host-side policy write + one sealed layer.
- `DF-R6.7-1` stays OPEN to R6.16 (the runner cell-environment leg);
  `protocol_id` is verbatim until R6.18 mints `comparative_protocol/1`;
  the oracle/verifier feed is R6.16/R6.17's; per-socket/phase attribution
  detail is R6.23's (the side_channel residual declares the shape now).
- Live reachability (`--network none` cell reaches only the two sockets)
  is ADR-0363 live evidence — the deterministic legs assert argv,
  refusal, classification, and freeze behavior; the musl link leg is a
  real skip where the target's linker is unavailable.

## Revisit triggers

- If `hh-cell-relay` gains a third pair name, this ADR and the closed-set
  checks in `hh-env`, `hh-helper` and `hh_cell_relay` move together.
- If `comparative_protocol/1` (R6.18) lands, the freeze record's
  `protocol_id` becomes a typed ref — amend by a dated note.
- If the model route stops being unix-socket-only, the `side_channel`/
  `unix_socket` residual set and this profile's grant shape reopen.
