- **Status:** Accepted
- **Date:** 2026-11-03
- **Ticket:** R5.25 (Recompute frozen analysis through the native

- **Requirement ids:** REQ-A-103, REQ-C-003, REQ-F-005, REQ-F-007,
  REQ-F-203 (contributing only — no primary targets; the
  full-target predicates stay owed per the coverage register)
- **Spec:** docs/evidence-and-adoption-spec.md §6.3 (Recompute card
  + comparison rules; "no new `hh recompute`"), §6.1 (all-planned
  closure); docs/tickets/195_R5.25__recompute.md; scoped review
  docs/build/planning/2026-11-03_R5.25-split-review.md (AMEND)
- **Rung (ADR-0024 obligation):** implementation landing record —

## Context

§6.3's Recompute card requires: verify inputs; reconstruct frozen
grade selection; reconcile planned slots; rerun pinned analysis;
compare counts/membership/weights/unknown bounds/raw and joint veto
outcomes/estimates/intervals/refusals/full families and prices —
under exact identity/order/count/verdict rules and the frozen
portable scalar tolerance `abs(new−reference) ≤ 1e−10 ×
max(1,abs(reference))`, full precision before formatting. Before
this ticket no owner procedure existed: `analyze_and_record` is the
producer path — a recorded report is served, never silently
recomputed — and `kernel.reproduce` covers bundle R-levels, not the
analysis procedure.

## Decision

1. **One owner-bound interface** `recompute_analysis(&RecomputePlan,
   &AnalysisInput) → Result<RecomputeReport, AnalysisError>` inside
   `hh-analysis` — records-in/records-out like `assemble_receipt`;
   §6.3 forbids inventing `hh recompute` (the recipe/CLI owner is
   R5.28; outside review is R5.52).
2. **Legs are the §6.3 row verbatim:** `verify_inputs` (declared
   `spec_ref`/`prices`/`method`/`weights`/`seed`/`draws` member-wise
   against the frozen reference and the rebuilt input — `Withheld`,
   `NonFinite`, `WrongPin`; `generated_from` and `report_id`
   recomputed exactly) → `population` (the landed
   `assemble_receipt` over runs/tasks/pins folded from the same
   rebuilt input — never a second run set; a non-`closed` verdict
   is `SelectionNotClosed`, a verify-first refusal, not a compare
   drift) → `rerun` (`analyze`; kernel refusals propagate
   verbatim — one vocabulary) → `compare` (recursive body walk
   with the closed drift-kind set `identity`/`order`/`count`/
   `verdict`/`threshold`/`scalar`).
3. **The comparison rule is frozen, not parameterized:** exact for
   identities/membership/order/counts/categorical verdicts and the
   closed exact-member set (pins/counts/ordinals/levels —
   `seed`, `draws`, `level_ppm`, `tol_ppm`, cell `c`/`n`, `*_count`,
   `*_size`); the `1e−10` tolerance applies only to estimate
   scalars and is a module constant — never a parameter, never a
   recipe-side fork. A threshold/verdict change fails even inside
   tolerance; nonfinite pins refuse.
4. **`RecomputeError` rides `AnalysisError::Recompute`** — the one
   typed refusal vocabulary the boundary renders verbatim (CC9);
   no second codec, no new class.
5. **`reproduced` confers arithmetic agreement only** — never a
   hidden-history/oracle/R-level claim (§6.3); the
   `analysis-recompute/1` record is derived evidence about a
   procedure, in the `closure-report/1` family.

## Consequences

- A recipient can verify the declared pins, reconcile the frozen
  selection/population, rerun the pinned analysis and obtain an
  exact-or-tolerance verdict — all through the native owner.
- AMEND ruling `f2dd2fac`: 1,468 changed source/test lines vs ≤700
  — recorded Deviation accepted (one owner interface; no
  documented seam; each leg alone dead or unverifiable; ~2.1× in
  the accepted band).
- DF-R5.17-1 unchanged: the fixture exercises the registered
  `beta{1,1}` arm only; the mislabelled `beta{2,2}` arm stays owed
  to R5.40 — the comparator reproduces what the pinned
  implementation computes, never repairs semantics.

## Alternatives

- **Boundary/CLI surface in this ticket** — rejected: §6.3 forbids
  inventing `hh recompute`; recipe forwarding is R5.28's scope.
- **Tolerance parameter or recipe-side formula fork** — rejected by
  §6.3 verbatim (frozen before execution, never widened after
  mismatch).
- **Split the interface across legs to fit the trigger** — rejected
  per the scoped review: each leg alone is dead or unverifiable,
  and a source-vs-battery cut separates behavior from its
  fails-without coverage.

## Revisit triggers

- If a later kind's persisted body lacks `metadata`/`weights`
  members, the declared method/weights pins have no frozen
  counterpart — `Withheld` is the admitted honest refusal; admitting
  another kind needs its frozen member map named.
- If the admitted wire encoding gains a non-integer numeric member,
  revisit `within_tolerance`'s `i64` surface — the frozen rule
  itself is unchanged.
- If DF-R5.17-1's parameterized-prior repair lands (R5.40), the
  recompute reproduces the repaired math unchanged — no edit.
