# ADR-0264: S2.2 variant-host rulings — `hh-varhost` over `hh-helper`, claims-lowered-at-spawn, seatbelt unix-socket regex emission, resolved-path profiles, blocking accepted streams, and the two-lane test split

- **Status:** Accepted
- **Date:** 2026-09-18
- **Ticket:** S2.2
- **Requirement ids:** R-2.12.2 (AC-R-2.12.2-{3–7,13}) · DF-S1.9-1
- **Spec:** §8.4 (plugin_abi/1 — V1–V6, placements, callbacks, guards) ·
  §5d.2/§5d.5 (containment + helper) · §5e · ADR-0180 (requests/sealing) ·
  ADR-0181 (variant-host boundary) · ADR-0182 (X1–X6, removability)
- **Rung (ADR-0024 obligation):** **C0** — MUST-code/MUST-data: the
  `subprocess_confined` launch path, `lower_requests`, the closed
  callback set, the screen/stamp halves, `GuardVerdict` meet inputs, the
  packaged `compaction_strategy` variant, the protocol + isolation
  suites.

## Context

S2.2 lands the §8.4 Stage-2 variant host: a plugin runs as a helper-
spawned subprocess whose only reach is an allow-listed AF_UNIX ABI
channel. The spec fixes the invariants (V1–V6, closed callback set, no
`allow` verdict) but left mechanism choices to the ticket:

1. **Which side of the helper boundary owns lowering.** `requests` are
   claims; something must turn them into the `Permission` +
   `ContainmentPolicy` before the process exists.
2. **Seatbelt's unix-socket filter spelling.** `net.mode = none` must
   still admit exactly one socket — the host channel — but SBPL's
   `remote unix-socket` literal forms silently never match on current
   macOS.
3. **Path identity under seatbelt.** macOS resolves `/var/…` to
   `/private/var/…` before matching — rules written against the
   unresolved spelling never fire.
4. **Accepted-socket blocking.** The host binds a listener
   non-blocking to poll for the variant's connect; on macOS/BSD the
   accepted stream inherits `O_NONBLOCK`, so reads return `WouldBlock`
   instead of waiting.
5. **Test topology.** The protocol suite needs determinism and speed;
   the isolation suite needs a real sandbox. One lane cannot serve both.
6. **Fixture crash semantics.** An in-process fixture cannot
   `exit(3)` without killing the test harness.

## Decisions

- **D1 — `lower_requests` runs at `spawn`, inside the host.** The
  manifest's `requests` ∩ the sealing principal's `cap` produce the
  `PermissionRecord` (issuer = principal, `delegable: false`) and the
  `ContainmentPolicy` (`fs.read = allow_only{package_root ∪ fs_roots}`,
  `fs.exec = {contribution binaries}`, `net.mode = none`, the channel
  socket as the sole `unix_sockets.allow`, cleared env + declared
  `env_keys` projection). The helper enforces the policy; the session
  keeps the grant set for callback grant-checks. `requests.egress`
  cannot lower onto the seatbelt lane — every entry lands in `losses`,
  recorded never silently dropped.
- **D2 — seatbelt emits `(remote unix-socket (regex #"<escaped>"))` per
  allowed socket.** Empirically (the isolation suite's allow-list probe):
  `literal`, `path-literal`, and `subpath` inside `remote unix-socket`
  never match an AF_UNIX connect on current macOS; the regex form both
  admits the listed socket and denies a sibling. Deny-default stands.
- **D3 — every absolute path emitted into an SBPL profile is
  canonicalized first** (`resolve`: `fs::canonicalize`, falling back to
  the normalized spelling for paths that do not yet exist). Applies to
  read/write/exec extents and `unix_sockets.allow` alike — the /var→
  /private/var mismatch was the first live seatbelt failure this run.
- **D4 — `SocketIo::new` forces the accepted stream blocking.**
  Deadlines are applied per-read via `set_read_timeout`; inheriting the
  listener's `O_NONBLOCK` made every post-handshake read an instant
  `WouldBlock` → `InvocationTimeout`.
- **D5 — two lanes, one screening path.** `attach` (in-memory `MemIo`
  pair) runs the *identical* codec/screen/handshake as `spawn`
  (listener → helper exec → `SocketIo`) — the protocol suite's 29 tests
  run in-process, the isolation suite's 11 run real helper+seatbelt
  launches. `MemIo`'s `Drop` closes the pipe so a dead fixture thread is
  `PluginCrashed`, never a hang.
- **D6 — the fixture crashes by thread-death in-process, `exit(3)`
  out-of-process.** `Mode::Crash` panics when no `--socket` was passed
  (mem lane) — the `MemIo` drop closes the channel; under a real spawn
  it exits. The host sees the same EOF either way.
- **D7 — the packaged variant's committed manifest is the unsealed
  template** (`code_pointer` zero-digest). `seal()` computes the real
  pin at pack time over the built binary; `load()` refuses
  `PinMismatch` on any drift. A changed artifact is a new package — the
  host never re-seals (AC-13).
- **D8 — the helper's policy-hello upgrades the backend to seatbelt**
  (existing `hh-helper` semantics S2.2 relies on): `spawn` always
  attaches the lowered policy, so `backend = "direct"` test specs still
  run sandboxed where `sandbox-exec` exists — the isolation suite's
  assertions are real confinement, not plumbing theater.

## Consequences

- A plugin cannot gain a fs/exec/net/env capability its manifest did not
  declare *and* the sealer did not cap — verified live under seatbelt
  (exec/spawn/net/fs/helper-socket/peer-root probes all deny).
- The ABI channel is the plugin's only unix reach; sibling sockets are
  EPERM (the helper socket probe).
- `MemIo` lanes make the whole protocol suite deterministic and fast;
  divergence between lanes is bounded by sharing `AbiChannel`,
  `screen_inbound`, and `expect_hello`.
- The removability gate now proves the extension tier is edge-free into
  the base (`check-removability.sh` extension section).
- Deferred knowingly: egress mediation (DF-S1.12-1 stays S2.4's),
  `budget_share` metering on the seatbelt lane (recorded loss),
  `component_model` placement (vocabulary-held).

## Alternatives considered

- **Per-socket literal filters** — rejected empirically (D2): they
  compile but never match on macOS; a rule that can't fire is a false
  containment claim.
- **Emitting both resolved and unresolved path spellings** — rejected:
  doubles rule count for a case canonicalization covers completely.
- **One lane (spawn only) for all tests** — rejected: the protocol
  suite's hostile probes need sub-second determinism; helper+seatbelt
  launches make every protocol test a spawn test, slowing the suite
  ~100× for no additional protocol coverage.
- **Checked-in sealed manifest** — rejected: the pin must cover the
  built binary, which changes per build; sealing is a pack-time act by
  definition.

## Revisit trigger

Reopen if a non-macOS confinement backend lands (D2/D3 are
seatbelt-specific — the container lane re-derives its own emission), if
SBPL's unix-socket literal filters begin matching (a probe test will
flip), or if the `MemIo` lane ever diverges from `SocketIo` in
observable host behavior (then the lanes must share a differential
test).
