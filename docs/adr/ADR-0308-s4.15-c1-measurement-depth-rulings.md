# ADR-0308: S4.15 C1 measurement depth — adapter declaration, validity gating, foreign interchange and judge-oracle rulings

- **Status:** Accepted
- **Date:** 2026-09-29
- **Ticket:** S4.15
- **Requirement ids:** R-2.9.4 C1 (AC-R-2.9.4-{9,10}),
  R-2.9.1¹ (AC-R-2.9.1-9), R-2.12.1¹ (AC-R-2.12.1-6),
  R-2.9.2² (AC-R-2.9.2-14)
- **Spec:** §5h.4 (the C1 measurement row — adapter contract,
  strata B/G, foreign export/import, hosted participants);
  §5h.1 (`R-2.9.1¹` — M12 run-tree rollup, M18 hosted

## Context

S4.15 lands the C1 measurement depth. Six seams needed owned
rulings — each is a spelling the spec leaves to the
implementation and each now has exactly one spelling
(CC1/CC7):

1. **What `declare()` returns and who supplies the facts.**
   §5h.4 §2.1 requires the declaration to name version
   identity, suite family, submission kind, verifier
   isolation, export formats, hosting surfaces and the parity
   reference. The adapter contract needed one record shape
   and one rule for where the facts come from — declaration
   is a claim the harness may check against, never an
   inference over fixture content.
2. **What `parity = none` admits.** ADR-0142 D3's I-5 rule:
   an adapter with no parity reference may run hosted
   participants, but only at product-level granularity — the
   absence of a parity report is itself a contract fact, not
   a missing field to default upward.
3. **When stratum B counts toward the headline.** B enters
   the corpus only "once its `SuiteValidityRecord` exists" —
   the gate needed one executable check at load time, not a
   review-time convention.
4. **What a foreign export is.** `harbor_trial_dir` export
   and Harness-Bench result import are lossy by construction;
   the ruling needed one lowering record so that nothing is
   silently dropped and no foreign fact is silently adopted
   (CC3).
5. **How a judge oracle is admitted and where its values may
   land.** R-2.9.2²'s judge rows need calibration and
   independence evidence at admission, and a hard boundary
   keeping judged values out of deterministic headlines.
6. **How `capability_vector` strata parse.** Hosted rows
   carry a capability vector; a malformed member must refuse
   typed, and a capability the suite cannot support must land
   `n/a{reason}` — never a zero-fill and never a silent skip.

## Decision

- **D1 — `AdapterDeclaration` is a declared-facts record with
  a default `declare()`.** `crates/hh-bench/src/adapter.rs`
  adds `adapter_declaration/1`: adapter id, version identity,
  suite family, `families_supported[]`, `submission_kind`,
  `verifier_isolations[]`, `export_formats[]`,
  `hosting_surfaces_supported[]`, optional `parity_ref`, and
  provenance. The trait gains a default `declare()` built
  from the adapter's own fact table (`FixtureAdapter::
  decl_facts()` keyed by adapter id) — implementations supply
  facts, never derive them from task content. Undeclared
  hosting surfaces refuse `HostingSurfaceUnsupported`;
  undeclared export formats refuse `ExportFormatUnsupported`;
  hosted runs are refused rather than downgraded to `native`.
- **D2 — `parity = none` ⇒ product-only admission.**
  `parity_ref: None` is the contract spelling of
  `parity = none`; `AdapterDeclaration::admits_granularity`
  refuses any granularity finer than `product`
  (`GranularityRefused{granularity}`) — never a silent
  scope-down. Adapter G (`suite.harbor_index`) declares no
  parity reference and serves `native` hosting only.
- **D3 — `SuiteValidityRecord::l2_check` is the load-time
  headline gate.** `SuiteManifest::validate()` requires
  `epoch_seeded = true` and a non-empty `dispatch_ref` before
  the stratum may contribute headline measurements
  (`crates/hh-bench/src/benchset.rs`); a missing or failing
  validity record refuses typed. Flawed tasks stay in the
  corpus as *marked* members (retired-for-headline state,
  reasons, audit refs, split assignments and split hashes
  preserved) — never silently dropped. The corpus is now six
  strata (`a` tb2, `b` swe_fresh, `c` swebench, `d` taubench,
  `e` agentdojo, `g` harbor_index); `benchset.json` is the
  single benchset record (CC7).
- **D4 — Foreign interchange is explicit lowering with a
  loss report.** `crates/hh-bench/src/foreign.rs`:
  `export(format)` writes the adapter-native set (lossless)
  or lowers to `harbor_trial_dir` with a
  `LoweringLossReport`/`LossEntry` naming every dropped
  member (audit fields, provenance, cost, typed-`n/a`
  values); Harness-Bench `import_result` lifts under
  `unverified`/foreign provenance and reports members with no
  foreign slot in the same report. Foreign artifacts carry
  canonical `idp` identity; `ExportFormatUnsupported`
  refuses undeclared formats. This is the same
  loss-report discipline as `hh-bundle`'s
  `interchange_trajectory` export (whose `unit_conversion`
  entries declare cost-view lowering loss — CC3 end-to-end).
- **D5 — Judge oracles admit on calibration + independence
  and never land judged values on deterministic metrics.**
  `crates/hh-eval/src/judge.rs`: `admit_judge` requires a
  `CalibrationStatus` and the `JudgeContext`'s declared
  `CriticUse`; a judge sharing the beneficiary's context or
  snapshot, an overclaimed declared family, or
  model-claim-only evidence refuses at admission.
  `emit_judged` emits `*_judged`-family rows beside (never
  into) the deterministic metric — an uncalibrated judge
  emits `exploratory` rows only; a calibrated one may gate.
  `execution_alignment_failure_rate{,_judged}` are distinct
  catalogue families (`crates/hh-eval/src/catalogue.rs`), so
  detector verdicts never alias headline metrics. The
  deterministic declaration pins `requires_observability =
  {ledger}` over *both* participant classes — hosted rows
  render `n/a{observability}` (the §5f.2-prescribed reason);
  the spec's class-conditional `end_state`-hosted/D5-only
  split is not expressible in a single set and lands with the
  C2 `execution_alignment` variant.
- **D6 — `capability_vector` parses strict, refuses typed,
  degrades to `n/a`.** `crates/hh-analysis/src/project.rs`
  reads `capability_vector` from `manifest.extra`: a stamped
  vector projects verbatim, a supported capability admits the
  stratum cell, an absent/`unsupported` capability lands the
  typed `n/a{reason}` cell, and an unknown spelling or
  malformed member is a typed `AnalysisError` — never a
  zero-fill, never a skip (T-LCD-07).

## Consequences

- Hosted and native participants now run the identical
  adapter lifecycle (`materialize → expose → collect →
  grade`) — the hosting surface is a declaration checked at
  the contract boundary, not an inferred capability
  (AC-R-2.9.4-9/-10).
- The corpus carries a smoke stratum (`g`) that can never
  inflate a headline — `parity = none` binds at the
  declaration, so product-only admission is structural.
- Stratum B can be loaded, audited and reported the moment
  its `SuiteValidityRecord` passes `l2_check`; until then it
  refuses headline use without shadow state.
- Every foreign export/import is accountable: the loss
  report is part of the artifact, so downstream consumers can
  distinguish native lossless records from lowered foreign
  ones without trusting file layout.
- Judge verdicts can gate only after calibration is
  admitted; exploratory emission keeps uncalibrated signal
  visible but fenced.
- Cost rollup, hosted ingestion and interchange loss now
  have executable C1 halves (DF-S1.14-3 closes); the
  convention-shaped sink fixtures and remaining DF-S1.14-2
  cells stay open on their own rows.

## Alternatives considered

- **Infer declaration facts from the served fixtures.**
  Rejected: declaration is a claim the harness checks — a
  fixture-derived declaration would make the check circular
  and would hide a mismatched adapter (CC2/CC3).
- **Treat absent `parity_ref` as "parity pending" and admit
  all granularities.** Rejected by I-5: the absence is the
  contract; admitting finer granularity would let
  product-only evidence read as per-phase parity.
- **Filter flawed tasks out of the corpus at load.** Rejected
  by CC3: a removed task is unaccounted history; marking with
  retirement reasons + audit refs preserves the record while
  gating the headline.
- **Emit foreign exports without a loss report (layout
  implies the loss).** Rejected: the loss report is the
  auditability (CC3); a consumer reading only the foreign
  layout cannot reconstruct what was dropped.
- **Let judged values merge into deterministic metrics behind
  a flag.** Rejected by §5h.2: judged and deterministic
  families stay disjoint catalogue entries; a flag would be a
  silent downgrade path.

## Revisit trigger

Reopen if (a) a foreign format needs partial-fidelity slots
that `LossEntry` cannot name (extend the report shape, don't
drop the entry); (b) a parity-bearing adapter for stratum G
lands and `product`-only must widen — widen at the
declaration, never at the admission check; or (c) judge
calibration evidence gains a richer status than the landed
`CalibrationStatus` sum (the admission seam is typed and
additive — extend it rather than loosening `emit_judged`).
