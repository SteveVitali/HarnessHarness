- **Spec:** docs/evidence-and-adoption-spec.md §5 (s5 O1–O8 cells, counts

- **Rung (ADR-0024 obligation):** implementation landing record — the

  O2/O8 evidence folds; no RPC, no schema, no new dependency, no new
  event class, no store/dispatch authority

## Context

§5.2/D3-F3 requires the O-cell trials to run against a **confined
observer apparatus**: an independently surviving supervisor that watches
a real dispatch, a durable marker sink standing in for the external
world the runtime cannot roll back, and a denied/read-only sentinel —
plus the declared Kp4 commit→injected-termination-before-executor-entry
injection over the R5.8 Dispatcher durability bridge. The contract binds
instrument to trials ("existence alone cannot pass"): the apparatus is
meaningless without the fold that reads its records, and the O8 seeded-
duplicate detector only proves sensitivity if the sink cannot silently
deduplicate. Kp4 proves *classification, not completion* — the crash
path must retain `unknown{worker_lost}` and a probe obligation, and no
apparatus-internal verdict may launder an unresolved effect into a pass
or authorize a retry/settle from an external sink-zero read. Before this
ticket hh-env had the kill-point seam (`inject_kill_point`,
`KillPoint::Kp4` at post-committed/pre-executor) and the probe contract
(`ProbeVerdict`) but no observer/sink/sentinel instrument and no fold
vocabulary for the O1/O2/O8 cells.

## Decision

1. **`crates/hh-env/src/ops.rs` (`pub mod ops`) is the confined
   apparatus — read-only by definition.** It observes, appends to its
   own files and folds evidence; it never appends to the run `Store`,
   never dispatches, and never authorizes a retry or settlement.
2. **`TrialMarker`/`MarkerSink` model the external world.** One fixed
   non-idempotent `append` lands one durable line (flush + fsync); there
   is deliberately no `append_once` — deduplication inside the sink
   would hide the O8 defect. `markers()`/`count_for`/`duplicates()`/
   `digest()` re-read the file from disk — the world's own read, never
   runtime memory. `marker_id` derives `<trial>/<effect>/<ordinal>`; a
   defecting executor's second append carries `ordinal = 1`.
3. **`Sentinel` is detection, not prevention.** `create` writes
   `sentinel.bin`, pins its digest and drops write permission;
   `intact()` re-reads and digest-compares — a mutated or missing file
   reads `false`. The digest is the detection surface; the mode bit is
   not load-bearing.
4. **`OpsObserver` survives the subject by file fact.** Its append-only
   `observer.jsonl` lives on its own path outside the run `Store`;
   `open` on an existing directory retains every prior row (survival is
   a file fact, not a process fact). `note(entry|bytes|termination)` and
   `snapshot(before_launch|at_boundary|after_quiescence, sink, sentinel)`
   durably record the three required intervals; `rows()` replays the
   parsed record.
5. **Probe authority is a closed vocabulary with one refusal surface.**
   `ProbeSource::{Instrument, ExternalSinkZero}` / `RecordedProbe` /
   `probe_authorization`: only an instrument `ProbeVerdict` is
   admissible; absent probe, `undeterminable`, or an external sink-zero
   claim maps to terminal `Refused("no_valid_probe"|"undeterminable"|
   "external_zero")`. An external zero authorizes nothing — the
   apparatus records admissibility for a later owner's decision and
   never redispatches itself.
6. **The O-cell folds are pure, honestly-labelled verdicts.**
   `o1_outcome` (allowed control: complete supervisor record + sentinel
   + observed + exactly one marker + recorded digest = recomputed),
   `o8_outcome` (seeded-duplicate detector: `DefectDetected` is the
   expected label — a miss is `DetectorMiss`, never a pass), and
   `kp4_outcome` (reached fault, zero boundary sink delta, new fence,
   `unknown{worker_lost}` classification, scheduled probe obligation,
   repeated restoration adds nothing) fold explicit evidence structs
   into `CellVerdict`/`Kp4Outcome`. `Kp4Outcome` retains
   `UnknownUnprobed`/`UnknownUndeterminable`/`Resolved*` — never `pass`.
   The closed `TrialFailure` set (missing_observer, missing_marker,
   digest_mismatch, unobserved, unreached_fault, sink_delta,
   sentinel_mutation, stale_fence, duplicate_restoration,
   missing_unknown, missing_probe_obligation, detector_miss) names every
   AC-2 negative; none can be laundered into a pass.
7. **The battery drives real seams, not mocks.** `tests/r5_32.rs` runs
   the real `Store`/WAL, the real Π `Monitor` allow rows, the real
   `Dispatcher` and the R5.8 `inject_kill_point` seam — `MarkerExecutor`
   appends one marker per effect; `DuplicateExecutor` appends twice
   despite an `Ok` terminal (the seeded O8 defect); probe variants cover
   applied / not_applied / undeterminable / unsupported. Predecessor
   contracts (R5.8 dispatch durability, R5.19 reservation/deadline,
   R5.23 projection assembly) are consumed unchanged.

## Consequences

- The O1/O2/O8 cells have a single confined instrument whose records
  outlive the subject under test; the three-interval observation and
  the digest/sentinel checks are file facts a crash cannot rewrite.
- A duplicate restoration or blind redispatch is detectable at the
  sink (non-idempotent append) and at the fold (`duplicate_restoration`,
  `extra_commits`/`extra_dispatches`); neither can pass silently.
- `defect_detected` is a first-class distinct label — the O8 detector's
  sensitivity is recorded as detection, never as an invariant pass.
- Settlement/retry authority stays with the probe contract's owner:
  the apparatus can only ever *refuse* (`ProbeAuthorization::Refused`)
  or record admissible evidence; an external sink-zero read confers
  nothing.
- `pub mod ops` is an internal instrument surface in hh-env — not a
  public RPC, schema, dependency or event-class admission. Actual
  backend/live trials remain gated to R5.44.

## Alternatives considered

- **Dedup inside `MarkerSink` (idempotent `append_once`)** — rejected:
  it would hide the very defect O8 must detect; the sink is the world
  and the world keeps every append.
- **Process-lifetime observer state (in-memory rows drained after the
  run)** — rejected: survival must be demonstrable after the subject
  `Store` drops; only a file on its own path proves independence.
- **Letting the apparatus settle or retry on `not_applied` probes** —
  rejected: authority stays with the named owner path; the instrument
  records admissibility, it does not act on it.
- **An external sink-zero read as probe evidence** — rejected: it is
  inadmissible by construction (`Refused("external_zero")`); a zero in
  the world confers neither settlement nor retry authority.
- **Splitting the apparatus from its battery (the ruled-on proposal)** —
  rejected by the 2026-11-03 scoped review (`planning/
  2026-11-03_R5.32-split-review.md`): ops.rs contains no `#[cfg(test)]`
  seam, the claimed leg-(a) unit battery was unwritten, and §5.2/D3-F3
  weld instrument to trials — leg (a) would land a dead instrument.

## Revisit triggers

- If R5.44 (or a later owner) consumes `ops` for live/backend trials,
  re-read the fixture-bound surface — `MarkerSink`/`OpsObserver` path
  binding and the probe vocabulary are built for the confined O-cell
  slice, and a live trial may bind them differently.
- If `ops` ever gains write/dispatch authority (a `Store` append, a
  redispatch, a settle), re-read the read-only confinement — the
  verdicts' honesty rests on the apparatus never acting.
- If `MarkerSink` acquires dedup/`append_once` or `markers()` stops
  re-reading disk, re-read the O8 detector contract — detection depends
  on the world keeping every append.
- If `observer.jsonl` becomes an authoritative store (a projection
  folds it into run state), re-read durable-before-visible — it is a
  supervisor record, never run truth.
- If `TrialFailure` grows members or `ObservationPoint` gains an
  interval, re-read the AC-2 negative matrix — the closed set and the
  battery must move together.
