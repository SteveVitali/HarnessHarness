# ADR-0261: S1.26 attended-CLI rulings — `hh-cli` as a thin generated-client/renderer, the invocation provenance row, sealed-run lease releases, parked-detach reporting, and the escalate-on-exhaustion carve-out

- **Status:** Accepted
- **Date:** 2026-09-18
- **Ticket:** S1.26
- **Requirement ids:** R-2.11.1⁰ᵇ
- **Spec:** §7.1 · §7.4 · ADR-0167/0168/0169 · ADR-0184 D2 · readiness ADR-0210…0216
- **Rung (ADR-0024 obligation):** **C0** — MUST-code: attended terminal mode
  with per-effect approvals, `approval *`, `run resume/fork/cancel/inspect/
  status/events/amend/submit`, the attendance declaration, I-1, exhaustion
  `escalate`/`stop`, the full §7.1 §2.5 exit-class table, `json`/`jsonl`,
  typed stdin, `InvocationRecord` + idempotency. The non-`budget` `amend`
  targets and the parked-detach exit surface stay at their spec'd stages
  (DF-S1.26-1/-2).

## Context

§7.1 (`R-2.11.1⁰ᵇ`) defines the attended CLI slice over the `hh-embed/1`
boundary landed at S1.25. The hard constraint is that `hh-cli` must be a
thin generated-client/renderer: it translates argv into typed boundary
records, performs one boundary-operation sequence per command, and renders
results/prompts/ledger projections — it must never decide kernel
semantics, widen authority, recompute identity, or keep independent state.
At this ticket's start the boundary could drive a run end-to-end
(`open_session{new} → submit → read → close`), but several contract and
kernel seams the CLI depends on were missing or wrong:

- `amend`/`fork` were declared `experimental`/unimplemented; `amend` had
  no `invocation` member; there was no `AuthorityWideningRequiresHuman`
  refusal kind for the I-1 widening case the CLI must surface pre-ledger.
- `open_session` idempotent replay returned the recorded *session id*
  verbatim — replaying a `new` whose session was since closed handed back
  a dead handle; a replayed `attach`/`resume` likewise returned a stale
  session id.
- `close{…}` released the writer lease unconditionally — on a finished
  run `lifecycle.lease.released` minted *after* `lifecycle.run.finished`,
  so the `run events --from 0` export carried a post-terminal row the
  live stream never showed, breaking AC-R-2.11.1-3's byte-identity.
- `read{from_seq > head}` refused rather than answering an empty page,
  diverging from `stream_events`' sync-first semantics.
- `hh-hir`'s budget-diff classifier ignored scalar-leaf edits, so a
  `hard`/`soft` ceiling change produced no `budget_dir` classification
  and the embed `amend` path could not tell loosening from tightening.
- `hh-control`'s exhaustion path had no escalate-aware semantics: a
  budget-exhaustion *escalation* proposal re-tripped the same exhaustion
  guard forever; `stop{…}` refused to carry a structured `StopReason`;
  and a `cancelled` stop on an admitted cancel raced the guards.
- `security.permission.requested` upcall payloads did not propagate the
  §5g.7 explanation members (`explanation{rule_id, risk_factors,
  what_would_auto_approve, model_justification}`) through the boundary,
  so the CLI had nothing to render for AC-R-2.11.1-12.

## Decision

1. **`hh-cli` is one `Boundary` trait over the generated client, two
   bindings, zero kernel semantics.** `crates/hh-cli/src/boundary.rs`
   defines `Boundary` (`call`, `poll_frame`, `poll_upcall`, `hello_result`,
   `drain`); `ServiceBoundary` wraps `EmbedService` (binding a, the test
   binding) and `ProcessBoundary` spawns `hh-kernel serve` over piped
   stdio (binding b — `crates/hh-cli/src/boundary.rs::ProcessBoundary`).
   `--kernel-cmd`/`HH_KERNEL_CMD` select the binary (whitespace-split —
   documented limitation: no shell quoting); a spawn or `hello` failure is
   `infrastructure_failure`/`refused_by_kernel`, never a silent fallback.
   Every command is one boundary-op sequence; the CLI never opens the
   store, never mints, never recomputes an identity.
2. **The CLI mints exactly one provenance row per command —
   `lifecycle.surface.invoked` — through the boundary's `invocation`
   param.** `crates/hh-cli/src/invocation.rs` builds the typed
   `InvocationRecord` (argv, cwd, env allow-list, attendance, idempotency
   key, format) and threads it into `open_session`/`amend`/`fork`. This is
   the AC-R-2.11.1-2 "explicitly documented invocation/provenance row"
   carve-out: the CLI's ledger effect is byte-identical to the raw
   boundary sequence *modulo* that one row and its mechanical consequences
   (seq/event-id/parent/hash/prev-hash shifts, derived checkpoint and
   containment refs, provenance timestamps) — asserted by
   `ac2_cli_ledger_range_byte_identical_to_the_boundary_sequence`, which
   drops the invocation row and diffs the rest field-by-field.
3. **Idempotency keys are per-invocation, per-step** —
   `step_key(invocation, "submit"|"amend"|"fork"|…)` derives each step's
   key from the invocation record, so a *re-run* of a command replays
   `open_session` (same run) while a *fresh* invocation never replays a
   stale `resume`/`amend` onto a closed session. `open_session` replay on
   the service side is honest about session lifetime: a live session
   replays verbatim; a replayed `new`/`attach` whose session is gone mints
   a fresh attach handle onto the same run rather than returning a dead
   id (`crates/hh-embed/src/open.rs`).
4. **The writer session is never closed mid-run.** The run loop reads
   durable events (`read` pages from watermark 0), polls
   `upcall.request_permission` notifications, and only calls
   `close{done}` at a terminal. `close{interrupt}` on a live run mints
   `lifecycle.session.detached` + `lifecycle.lease.released` and submits
   the `Interrupt` cue — the honest cancelled-by-principal close. When a
   prompt hits EOF (pipe ends, `--park`) the CLI detaches *honestly* — the
   ask stays `pending`, the session detaches, the run stays live and
   resumable.
5. **Sealed runs release the writer lease without a run-plane row**
   (`crates/hh-ledger/src/store.rs::release_silent`). A run's event stream
   seals at `lifecycle.run.finished`; a `lease.released` row appended
   after it would be a post-terminal row no live stream can carry —
   breaking AC-R-2.11.1-3 (`run start --jsonl` ≡ `run events --from 0`,
   now executable: `ac3_jsonl_stream_minus_result_equals_run_events`).
   `close{…}` re-checks `finished` *after* the interrupt drive (the drive
   itself can mint `run.finished`) and releases silently whenever the run
   is sealed; the lease file still records `Released`. Mid-run releases
   (parked detach, takeover fencing) still mint `lease.released` — they
   are pre-terminal audit rows.
6. **`read{from_seq = head + 1}` answers an empty page**, not a refusal —
   aligned with `stream_events`' sync-first rule (a cursor at the head is
   not an error; it is the quiescent state). This is what lets the CLI
   poll quiescent runs without special-casing EOF.
7. **Exhaustion `escalate`/`stop` per ADR-0168(e) with the escalate
   carve-out.** `hh-control` gained escalate-aware exhaustion:
   `react` marks the run `escalate_on_exhaustion` when the manifest
   allows amendments; a budget-exhaustion *escalation proposal* does not
   re-trip the exhaustion guard (the carve-out — otherwise escalating
   loops forever); `stop{…}` carries a structured `StopReason`;
   `lifecycle.budget.exceeded` is the durable exhaustion row; a
   `cancelled` stop is admitted through the guards. The CLI surfaces
   `escalate` → attended `amend{budget}` (I-1: loosening requires
   `interactive` attendance or a caller attestation — the
   `AuthorityWideningRequiresHuman` refusal is `invocation_error` by the
   §2.5 table's own row) and `stop` → `budget_exhausted`.
8. **Approval rendering carries the full §5g.7 explanation through the
   boundary.** `security.permission.requested` upcall payloads now
   propagate `rendering.explanation{rule_id, risk_factors,
   what_would_auto_approve, model_justification}` plus
   `options_presented`; `render_ask` (`crates/hh-cli/src/cli.rs`) prints
   the permission id, proposal, rendering text, rule id, risk factors,
   the auto-approve hint, and the model justification *labelled as
   delegate-authority content* — never as a fact — and never invents
   options (the offered set comes from the upcall). Unattended resolves
   asks `decider: policy, reason: unattended` (ADR-0071 D4).
9. **The `detached:"parked"` result member is an interim reporting
   surface** — a parked-detach is not a run terminal and has no §2.5
   row, so the result record answers `ok` + `detached:"parked"` rather
   than claiming `finished` or inventing a class (DF-S1.26-2 — the
   Stage-2 R-2.11.1 slice owns the detach/park lifecycle surface).
10. **`amend` landed as an `experimental` op with `budget` the only
    implemented target**; other targets answer `Refused{stage_pending}`
    (ADR-0178 D4 / ADR-0168(e) — DF-S1.26-1). `AmendParams` gained the
    `invocation` member; `AuthorityWideningRequiresHuman` (1306) joined
    the closed `EmbedError` sum for the I-1 widening refusal; the
    `amend`/`fork` ops flipped `implemented: true` at `experimental`
    tier in the same schema source (CC7 — regenerated artifacts are
    drift-checked).
11. **Schema-invisible literal overrides are `AuthorityViolation`, not
    silent no-ops** (`crates/hh-embed/src/overrides.rs`): a literal
    override pointer that produces no schema-visible change previously
    slipped a hidden permission mutation past the I-1 widening check;
    it is now refused.
12. **Interim numeral band `64–73` is cited, not re-decided** —
    ADR-0210/OQ-384 leaves the exit-code band unsettled upstream; the
    authoritative channel is `result.exit_class` (the string). The full
    §2.5 class sum is landed (`crates/hh-cli/src/exit_class.rs`) with the
    total `outcome_class × StopReason` derivation plus the pre-ledger and
    refusal rows.

## Revisit trigger

- **DF-S1.26-1 closes** when the C1/Stage-2 amendment machinery lands
  (non-`budget` targets: `approval_mode`, `attendance`, …) — `amend` then
  implements the full declared target set.
- **DF-S1.26-2 closes** when the Stage-2 run-lifecycle slice defines the
  parked/detached surface — `detached:"parked"` either becomes a declared
  result member or the §2.5 table gains a detach row.
- The interim numeral band is superseded when OQ-384 settles
  (ADR-0210's owned decision); `result.exit_class` stays authoritative.
- `release_silent` is superseded if the ledger ever gains a post-terminal
  audit plane; the invariant to preserve is AC-3's stream ≡ export
  byte-identity.
