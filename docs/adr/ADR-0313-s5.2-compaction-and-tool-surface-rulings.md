## Context

S5.2 lands the Stage-5 compaction family, the
split/composite tool-surface family, the context-policy
family, similarity reranking and the procedure-target
residual. Nine spellings needed owned rulings — each a
seam the spec leaves to the implementation, each now with
exactly one spelling (CC1/CC7):

1. **How conditioned compaction rules resolve.** The
   compaction family admits profile-conditioned rules —
   which conditions are admissible, what inputs the rule
   may read, and how the debt record gates resolution
   needed one rule (AC-R-2.4.2-6).
2. **How `compaction_reminder` reaches the model.** The
   notice is profile-owned content; its decode grammar,
   placement and accounting needed one spelling.
3. **How a model-owned compaction call is admitted.** The
   model may propose compaction; which grammar the call
   parses through and which invariants the proposal faces
   needed one rule (AC-R-2.4.2-10).
4. **How `Restructure`/`ProviderCompact` execute.** The
   closed `CompactionOp` sum gains two legs — the
   deterministic checkpoint port and the provider port —
   plus the accounting rule for a provider that cannot
   report its forgotten set (§5c.2's `all_prior` row).
5. **How demotion routes.** Authority-inadmissible
   candidates need a declared destination that is never a
   silent drop and never an upward move (AC-R-2.4.1-11).
6. **How `similarity_rerank` binds its embedder.** A
   non-deterministic ranker must pin its instrument —
   which identity binds, how the refusal reads, and how
   calls are accounted needed one rule (AC-R-2.4.3-10).
7. **What `PlanMap` steps are checkable.** The
   static-composite mode needs a closed step grammar and
   a total verdict for the uncheckable members
   (AC-R-2.5.2-3).
8. **How the S1–S4 synthesis gates are ordered.** The
   synthesized-surface pipeline's four checks and their
   fail-closed admission needed one enumeration
   (AC-R-2.5.2-8).
9. **How `freeform`/`code_mode`/`shim` spell their
   surfaces.** Each mode's binding shape, catalogue
   membership, sandbox declaration and metering class
   needed one rule (AC-R-2.5.2-9/-10).

## Decision

1. **Conditioned compaction rules resolve by declared
   profile or runtime-compliance conditions only — never
   model identity.** `check_variant_declaration` requires
   every variant's declared inputs to be a subset of
   `{ModelProfile, ResourceAccount}`; a rule conditioned
   on `model_identity` refuses at declaration. A
   conditioned rule without a complete
   `AssumptionDebtRecord` is inadmissible (ADR-0189's
   gate, applied at registration). Resolution walks the
   canonical rule order — declared profile match, then
   runtime-compliance conditions — and never reorders
   (the order is the contract).
2. **`compaction_reminder` is a profile-owned notice, not
   a kernel injection.** The profile rule's params decode
   through `decode_compaction_reminder` into a
   `CompactionReminder{placement, text_ref}`; assembly
   mints a `reminder_candidate` at the declared placement
   and counts it in the plan. Absent the rule, no
   reminder exists — the kernel never fabricates one.
3. **Model-owned compaction faces the identical kernel
   invariants.** `model_owned_ops` parses a
   `ModelCompactCall` through a closed grammar into the
   same `CompactionOp` sum; `compact_model_owned` submits
   the proposal to `check_proposal` — I-REQ, I-NOWIDEN,
   I-CUT, I-RECLAIM apply unchanged (no privileged model
   path). The proposal records `summarizer_profile`,
   `max_summary_tokens`, `input_reduction`,
   `instructions_ref`, `restructure`; the call meters as
   `model_call` under the declared role.
4. **`Restructure` executes only through a deterministic
   `CheckpointExtractor` port; `ProviderCompact` only
   through a bound `ProviderCompaction` port.** The
   extractor is a typed seam (structured checkpoint in,
   `PlannedItem`s out — `structured_checkpoint`/
   `world_state_refresh`/`summarize_rolling`/
   `offload_then_summarize`/`fresh_window_with_notes` are
   the declared variants). The provider op names a
   capability; the returned summary lands only in a slot
   whose `min_authority ≤ delegate`. When the provider
   cannot enumerate its forgotten set, the record
   carries `forgotten = {range: "all_prior"}`: the
   submitted blocks are forgotten at minimum, plus every
   non-`required` view item before `insert_at` — I-REQ
   keeps `required` items delivered inside the range and
   the marker still records the unreported loss (CC3; the
   semantic loss is recorded independently of local token
   reclaim).
5. **Demotion routes to `external` — never inward, never
   upward, never a silent drop.** A `DemotionWrapper`
   names `wrapper_id`/`target_slot`; the assembly outcome
   carries a `Demotion{candidate_id, wrapper_id,
   target_slot, text_ref}` per demoted candidate. The
   wrapper's target must be a slot the candidate's
   authority is admissible into — `external` is the only
   destination a demotion may select; any inward or
   upward routing is a `PolicyViolation`.
6. **`similarity_rerank` binds a pinned `Embedder`; the
   request's `embedder_ref` must equal the bound
   identity.** A mismatch or unpinned request refuses —
   never a substituted embedder. `cosine_ppm` is
   integer-only (ppm arithmetic over `i64` vectors, an
   integer square root — identical on every host). Every
   query/item embedding increments
   `RetrievalReport.embedder_calls`; the report marks the
   result non-deterministic (model/instrument
   conditioned), and the deterministic filter order is
   preserved upstream of the rerank.
7. **`PlanMap` admits exactly `Branch`/`Invoke`/`Verify`.**
   `Loop`/`Delegate`/`Opaque`/`Instruction` are
   `UncheckableSurface` — a plan containing one is
   code-mode by definition, never silently checkable.
   Every `Invoke` must name a member of
   `allowed_capabilities` (S1 inclusion —
   `AuthorityWidening` otherwise); `check_plan_map_evidence`
   runs E1–E7 per branch against the capability node.
   `VariantSelector` is a closed grammar —
   `TaskClass`/`Environment`/`TurnField{declared}`/`Any`/
   `All`/`Not`/`Always` — with no model-identity member; an
   undeclared turn field reads `false`, never a peek. A
   `SurfaceFamily`'s `reference_variant` must be a
   primitive/split rendering (the native_fc fallback);
   `split` expands one capability into N surfaces at lower
   time — each mints its own `surface_id`, binds its const
   arg (`const{value}`) and drops its dropped args (E7:
   a split rename changes the surface coordinate only).
   The canonical `str_replace_editor`/`unified_exec`
   `PlanMap` fixtures ship in `hh-compiler::family`.
8. **The synthesis pipeline is S1→S4, fail-closed, gate
   named.** `check_safety` produces `SafetyEvidence`
   (S1 no authority widening: `effects_bound ⊆
   capability_effects` ∧ every invoke ⊆
   `allowed_capabilities`; S2 composite ⇒ per-step nested
   mediation; S3 synthesized text labelled and placed at
   `≤ delegate` and at-or-above the target slot floor; S4
   fail closed — any uncheckable member is a refusal, not
   a pass). `synthesize_surface` admits only a
   `SafetyEvidence` of all-pass/n-a carrying a *complete*
   `AssumptionDebtRecord`; the refusal names its gate
   (`debt`/`s1`/`s2`/`s3`/`s4`). `retire_surface` removes
   the admitted rule; the residual rule list is the arm
   the retirement experiment reads.
9. **`freeform` is one `parse{grammar_ref}` entry;
   `code_mode` mints child effects under the parent;
   `shim` is an exact table.** `freeform_map` produces the
   single `surface_arg → parse{grammar_ref}` map. A
   code-mode nested call is its own `Effect` under
   `parent_effect_id`; `code_mode_catalogue` admits only
   bindings whose `admitted_modes ∋ code_mode` — tools
   lacking the hint are absent, never error entries;
   `CodeModeSandbox` cannot express `holds_credentials`/
   `ambient_authority` as `true` (structural S2 — a `true`
   member is `AuthorityWidening`). `shim_resolve` consults
   the declared name table only — a miss is
   `UnknownSurface`, never a best-effort match; the call
   runs at `delegate`; `shim_metering` meters the
   interpreter call as `model_call` under the *calling*
   role's token role (`harness_overhead.shim_interpreter`
   attribution — never a fourth bucket).

## Consequences

- The compaction family is executable end-to-end offline:
  variant declarations gate on the declared-input set,
  conditioned rules carry debt or refuse, the
  `Restructure`/`ProviderCompact` legs run through typed
  ports, and an unreported provider loss still lands its
  `all_prior` marker — nothing the op consumed survives
  unrecorded.
- Model-owned and variant-owned proposals share one
  invariant gate — there is no model-privileged
  compaction path and no second kernel.
- The policy family's five variants and demotion wrappers
  route by rule, with the demotion record durable on the
  assembly outcome.
- Similarity reranking cannot substitute an instrument:
  the embedder identity is a pin member, calls are
  counted, and the result is honestly marked
  non-deterministic.
- The surface family is checkable where it claims to be:
  static composites carry per-branch E1–E7 evidence; the
  uncheckable members name themselves code-mode; split
  surfaces mint real identities; synthesized surfaces
  must pass all four gates with a complete debt record.
- Every new member/variant is additive (CC8): new
  `CompactionOp` legs, `PolicyKind` variants, exposure
  modes and selector members extend closed sums; C0
  fixtures decode and run unchanged (the workspace suite
  is byte-identical green).

## Alternatives considered

- **Record `all_prior` but let the provider result fall
  through to the deterministic fallback when local reclaim
  is zero.** Rejected: the fallback rewrites the record —
  the provider's declared loss marker would be erased
  silently (CC3). The submitted blocks are forgotten at
  minimum (the provider consumed them), so a valid
  delegated compaction always reclaims its inputs.
- **Give the model-owned path a separate, lighter check.**
  Rejected: a second gate is a second invariant surface
  (CC1) and a privilege channel — the model proposes ops,
  the same kernel disposes.
- **Admit `Loop`/`Delegate` steps into `PlanMap` with a
  bounded-iteration check.** Rejected: boundedness over a
  dynamic step is undecidable at compile; the honest
  verdict is `UncheckableSurface` — the plan is code-mode
  and faces code-mode's gates instead (S2 mediation per
  call).
- **Resolve `shim` calls by fuzzy/prefix match.**
  Rejected: S4 fails closed — a near-miss is a different
  surface, and a best-effort binding is silent widening
  (CC2); `UnknownSurface` is the only honest answer.
- **Let `compaction_reminder` mint unconditionally at a
  threshold.** Rejected: the notice is profile-owned
  policy content — the kernel emitting one without the
  rule would pre-decide a profile decision (CC10) and
  fabricate an undeclared context item (CC3).

## Revisit trigger

Reopen when (a) a spec revision admits further
`VariantSelector` members or `PlanMap` step kinds — the
closed grammars extend by sum member, never by wildcard;
or (b) a provider compaction API reports structured
forgotten ranges — the `all_prior` marker narrows to the
reported set verbatim; or (c) the hosted/online budget
lands a real `Embedder`/`Summarizer`/`ProviderCompaction`
adapter — the port signatures and refusal spellings
stay, the stub leaves the tree.
