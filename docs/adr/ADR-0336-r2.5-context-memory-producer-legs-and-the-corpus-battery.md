# ADR-0336: R2.5 context/memory producer legs — the driver-owned port seams, the pending-effect lifecycle, the shared-subdomain differential corpus, and the recorded size deviation

- **Status:** Accepted
- **Date:** 2026-10-06
- **Ticket:** R2.5
- **Requirement ids:** DF-S2.8-1 · DF-S1.19-1 · DF-S1.19-2 · BL-15 ·
  R-2.4.1 · R-2.4.2 · R-2.4.3 · R-2.4.4 · R-2.4.5
- **Spec:** §5c (context/memory — assemble, retrieve, compaction,
  `mark_scope_ended`, `resume_set`, procedure artefacts) · §5a.2 (the
  effect lifecycle — `intended → authorized → prepared → committed →
  terminal`, fencing tokens) · §5f (`verification.artefact.followed`
  detector members) · ADR-0075/0146 (the `evict_oldest` C0 variant) ·
  ADR-0273 D3 (the driver's compaction routing) · ADR-0330 D2 (the
  `AssemblerPort` seam this ticket consumes)
- **Rung (ADR-0024 obligation):** C0 — every landed member is a
  deterministic producer leg over the landed C0 machinery; no C1+ sum
  member is claimed (the `judged`/`human` corpus legs emit typed `n/a`,
  never fabricated verdicts).

## Context

R2.5 owns the producer-side residual cluster (DF-S2.8-1 members a/b/e/f,
DF-S1.19-1's real-run emitter call sites, DF-S1.19-2's corpus legs): the
§5c machinery landed in Round 1 emitted rows only from unit call sites —
nothing sequenced `assemble`/`retrieve`/`compact`/`mark_scope_ended` on a
real run, nothing consumed `resume_set`, the `judged`/`human` artefact
detectors had no call site, and the packaged `hh-compact-evict-oldest`
variant had no differential witness against the kernel rung.

Three forces shaped the mechanism choices: (i) CC3 durable-before-visible
— producer rows must land under the run's writer lease, never inside a
port; (ii) the first real `hh-embed` drive over the new seams exposed a
latent gap in the effect path — a host effect the strategy intended but
the host had not yet settled was minted as an illegal
`intended → unknown{awaiting_host}` transition and tripped INV-2's
dangling-intent check; (iii) the OOP variant's wire contract
(`{items:[{seq,tokens}]}`) and the kernel rung's `CompactInput` (priority
classes, indivisible groups, legal cut points, net-of-omission reclaim)
are the same *strategy* over different view languages, so a naive
byte-differential either silently shapes the corpus or fails on a
documented semantic difference.

## Decision

**D1 — the driver owns sequencing and appends; ports return rows.**
`MemoryPort` (`crates/hh-control/src/driver.rs`) carries the four
producer legs — `retrieve`, `trigger_retrieve`, `resume_set_read`,
`mark_scope_ended` — each returning `(class, payload)` rows in emit
order; the driver appends them under the writer lease. `resume_set`
consumption is a one-shot drain ahead of the first `decide` from
`DriverConfig.resume_set_heads`; an armed set with no bound port is
`UnbackedPort{kind:"resume_set"}`, never silently skipped.
`CompactionDone.emitted` carries the port's side events so compaction
machinery rows land durable in the same order the kernel produced them.
The `hh-embed` side wires one shared `Rc<RefCell<KernelContext>>` into
`KernelAssembler`/`KernelMemory`/`KernelCompaction`, so the store the
assembler selects over is the store the reader reads (CC1 — no shadow
memory plane).

**D2 — pending host effects stay open; the loop parks `wait`.** The
effect path now mints the full §5a.2 chain — `action.effect.intended`
(with `effective_risk_class` sourced from the surface's declared
`SurfaceSpec.risk_class`) → `security.permission.decided` →
`action.effect.authorized` → `action.effect.prepared` →
`action.effect.committed` (sink-stamped `fencing_token` on every
post-prepared row) → the settled terminal — only when the host actually
settles. A host effect still `awaiting_host` is never rendered
`unknown{awaiting_host}` (an illegal transition); a batch whose effects
are all pending leaves the intents open and ends the step in `wait`,
which is the honest INV-2-clean state. Quarantine/invariant rows land
*before* `lifecycle.turn.finished` (the checkpoint scope stays open for
its own evidence).

**D3 — the differential corpus compares verdicts on the declared shared
subdomain, and reports the divergence band as typed `n/a`.**
`hh-compact-evict-oldest` is now a thin `main.rs` over `src/lib.rs`'s
`compact` module, so the corpus (`tests/r2_5_differential.rs`) runs the
*same* code the packaged variant serves — never a second spelling (CC1).
Each `benchset.stage3.v1` task's recorded `model_io` projects to a
`context_view` (canonical 4-bytes/token estimator, declared in the
battery header). On the shared subdomain (all-optional, unpaired,
single-priority items; every cut boundary legal — where the kernel's
richer ordering provably reduces to oldest-first) the battery asserts
byte-identical evicted-seq verdicts: 23/23 members, 23/23 non-empty
evictions. Members whose `occupancy − cap` lands inside
`[0, OMISSION_ITEM_TOKENS)` are typed `n/a{omission_placeholder_band}` —
the kernel reserves one `kernel_omission` placeholder per contiguous
forgotten range, a member the wire contract does not model; the corpus
is never edited to dodge the band.

**D4 — judged/human detector legs execute at driver level; the corpus
legs emit typed `n/a`.** `verify{subject: artefact_activation |
artefact_followed}` mints `detector: judged` rows carrying the verdict's
`confidence_ppm`/`evidence_ref` (never `1_000_000` — judged evidence
keeps its grade and never launders into a deterministic `followed`), and
`Cue::HumanInput::ArtefactMark` mints the `human` activation
(`hh-control/tests/r2_5.rs`). `benchset.stage3.v1` records `model_io`
surface calls — no judge verdicts, no human marks — so the corpus legs
emit one typed `n/a` row per member per leg naming the driver-level
battery (`hh-bench/tests/r2_5_corpus.rs`), the AC's prescribed honesty
shape for a member that cannot run hermetically.

**D5 — DF-S1.19-2's corpus legs run the real `MemoryStore`/retrieval
pipeline per member** (`hh-bench/tests/r2_5_corpus.rs`, dev-only edge on
`hh-context`): labelled corpora (the authority floor partitions the 23
members — served at `unverified`, withheld at `principal`), `resume_set`
runs (every member's head resolves `by_name` through the same scope-walk
`KernelMemory::resume_set_read` uses), `environment_epoch` providers
(every member expires `dependency_changed` on the republished epoch),
and judged-conflict fixtures (23 `ConflictSet`s mint `detector:
deterministic`; the `judged` member is a typed `n/a` — staged C2).

**D6 — the size deviation is owned here, not hidden.** The ticket's 1400
changed-line budget assumed the corpus battery was the bulk of the work;
in fact the effect-lifecycle legality repair (D2) and the shared-fold
wiring (D1) were inseparable from the producer legs — the first real
drive surfaced both, and splitting mid-run would have left a
non-compiling stacked base. The ticket's own escape hatch names
`R2.5a`/`R2.5b` as the split seam *before* work starts; since the
landed diff is one coupled change, the overage is recorded as a
deviation for operator review rather than retro-fitted into a split.

## Consequences

- A real run's ledger now carries the full context producer sequence —
  `context.assembled` → `context.retrieval.completed` /
  `context.memory.read` → `context.compaction.*` →
  `context.memory.invalidated{fired_stamp: scope_ended}` — minted by the
  driver, durable under the writer lease.
- `resume_set`-armed runs refuse `UnbackedPort` rather than silently
  dropping carried heads.
- Pending host effects no longer quarantine honest runs; INV-2 fires
  only on genuinely dangling intents.
- The variant crate's library surface is now the canonical contract
  implementation; the binary is a `plugin_abi/1` adapter over it (the
  thin-binary rule).
- The differential battery pins the two `evict_oldest` spellings to the
  same verdicts — a future divergence in either is a loud corpus
  failure, not a drift.
- DF-S2.8-1's residual is exactly the `deliver_wakeup` steer arm
  (OQ-316, R2.6); DF-S1.19-1/-2 keep dated residuals (non-`default`
  `ContextPolicy` wiring, consolidation watermarks, non-`lexical`
  indexes, golden-plan/stress fixtures).

## Alternatives considered

- **Ports that append directly.** Rejected — a second durable writer
  breaks CC3's single-writer-lease discipline; returning rows keeps the
  driver the only appender and makes ordering testable.
- **Rendering pending host effects as `unknown{awaiting_host}`.** What
  the first real drive did; rejected — it mints an illegal lifecycle
  transition and falsely trips INV-2 on a run that is simply parked.
- **Subprocess-driving the packaged binary for the differential.** The
  `hh-varhost` end-to-end test already proves the sealed package works;
  for the *corpus* the in-process library call is hermetic
  (no `hh-helper`/socket dependency) while still executing the identical
  contract code — the honest fixture ceiling.
- **Shaping the corpus to skip the omission-placeholder band.** Rejected
  — the band is a real semantic difference (net-reclaim vs the wire
  contract's gross accounting); typed `n/a` rows report it instead of
  hiding it.
- **Splitting into R2.5a/R2.5b mid-run.** Rejected — the producer legs
  and the effect-lifecycle repair are one coupled change over the same
  driver path; the deviation is owned by D6 instead.

## Revisit trigger

- R2.6 lands `deliver_wakeup`'s steer arm — DF-S2.8-1's residual flips
  with it.
- A `judged`/`human` detector corpus source exists (recorded judge
  verdicts or human-mark fixtures) — the `n/a` rows in
  `r2_5_corpus.rs` become executable members.
- The wire contract gains an omission-placeholder member (a contract
  bump) — the `omission_placeholder_band` n/a class empties and the
  band members join the compared set.
- The operator judges the D6 overage warrants a retro-split — the
  ticket's named seam (`driver call sites` vs `corpus batteries`) is
  preserved in the file layout for exactly that move.
