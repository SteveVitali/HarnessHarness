# ADR-0246: S1.14 measurement-convention rulings — the closed point table, monotonic durations and skew detection, `TokenVector` normalization, and provenance-preserving cost

- **Status:** Accepted
- **Date:** 2026-09-17
- **Ticket:** S1.14
- **Requirement ids:** R-2.9.1
- **Spec:** §5h.1 §2.5/§2.6/§3 · ADR-0043 D1–D7 · ADR-0039 (resource
  taxonomy, `Money`, `CostProvenance`) · ADR-0029 (canonical form)
- **Rung (ADR-0024 obligation):** **C0** — MUST-code: `normalize_usage`,
  `registry_check`, `ts_ms`/`skewed`, and the views' duration/cost folds are
  §5h.1 §2 inside-list items; `MEASUREMENT_POINTS`, `TokenVector`,
  `MeasuredAt`, `Timing`, `CostProvenance`/`confidence` handling and
  `ResourceVector` rollup stay MUST-data.

## Context
The spec fixes the *conventions* (integer `*_ms` from monotonic clocks,
`measured_at`, `clock_tolerance_ms`, `clock_skew_flag`, `hh-inclusive/1`
tokens, `Money{micro_units}` never summed across currencies) and the closed
measurement-point list — but leaves these concrete rulings to the slice:

1. **How the closed table is represented.** §2.5's M1–M19 + M-ENV-1…3 table
   is normative and *closed* ("adding a point is a spec change"). The code
   must make the table inspectable and exhaustively checked, not scattered
   through match arms.
2. **What a duration *is*.** `ts` is wall-clock ordering metadata on the
   envelope; §2.6 says `ts` orders nothing and payload durations come from
   the measuring component's monotonic clock. `trace_view` must therefore
   *prefer* payload-measured durations and flag disagreement, never infer
   durations from `ts` arithmetic.
3. **How provider usage shapes converge.** §2.6 fixes `hh-inclusive/1` and
   the invariant `input_total = input_uncached + cache_read + cache_write`,
   `output_total ⊇ output_reasoning`; the AC fixture names four provider
   shapes (inclusive-cached, exclusive-cached, details-nested, flat).
   `cache_hit_rate` must never report a fake zero on a 0/0 denominator.
4. **Whether cost types are redefined.** `Money`, `CostProvenance`,
   `Confidence`, `Attribution`, `ResourceVector` and `SpendRow` already
   exist in `hh-budget` (S1.6, ADR-0039's taxonomy). §5h.1 §3 says the
   taxonomy is *owned by §08* — telemetry fixes measurement points only.
5. **What `metric_view` renders when the run cannot see a metric's inputs.**
   §2.1 and the T-LCD statement: `n/a{reason}`, never 0 — and DF-S1.5-2 is
   owed the registry check that resolves `requires_observability` against
   `ClassSpec::min_observability`.

## Decision
- **§1 — `MEASUREMENT_POINTS` is one declarative table**
  (`scope.rs`): every row `{id, scope, opens, closes, duration_source,
  measured, producer, stage}` verbatim from §2.5, including points whose
  emitter classes do not exist yet (M5/M6/M13/M14/M15 → C0/S2, M12 rollup →
  C1/S4, M16–M18/M-ENV point gauges → declared, `scope: None`). A unit test
  asserts the table is closed and unique and that M1–M12's Stage-1 rows are
  wired to real `CLASS_TABLE` classes — a spec change to the table is a
  code change here, satisfying ADR-0043 D1 mechanically.
- **§2 — durations are payload data; `ts` is never a clock.** `Span.
  duration_ms` reads the payload's measured field (`latency_ms`,
  `Timing.last_byte_ms − request_sent_ms`, `assembly_ms`, `compaction_ms`,
  …) stamped with `measured_at`; the `ts` span is computed only to set
  `clock_skew_flag` when `|payload_ms − ts_span_ms| >
  clock_tolerance_ms` (default `DEFAULT_CLOCK_TOLERANCE_MS = 5`, the
  manifest constant). Malformed `ts` yields `None`, never a guessed span.
  `SpanStatus` is `{ok, error{class}, open, cancelled, rolled_back}` per
  §3; a scope without a terminal event is `open` (ADR-0042 D5's
  `open_scopes` audit hook).
- **§3 — `TokenVector` is strict and invariant-checked.** The strict codec
  (unknown member ⇒ `BadMember`, float ⇒ `FloatRejected` via `hh-wire`)
  enforces nonnegative counters, the inclusive-input invariant, the
  reasoning-subset bound, the optional `output_text ⊆ output_total` bound,
  `convention = "hh-inclusive/1"` and mandatory `normalizer_ref`.
  `normalize_usage` converges the four AC shapes — inclusive-cached,
  exclusive-cached, details-nested (`input_details{cache_read,
  cache_write}`/`output_details{reasoning}`), and flat
  `prompt_tokens`/`completion_tokens` — onto the one canonical vector;
  `cache_hit_rate_ppm()` returns `None` on a 0/0 denominator (a rate, not a
  fabricated zero — the T-LCD `n/a`-never-`0` rule applied to ratios).
- **§4 — cost reuses `hh-budget`, period (CC1/CC7).** `cost_view` folds
  `measurement.cost.attributed` rows through `SpendRow::from_json` and
  aggregates `Money`/`CostProvenance`/`Confidence`/`Attribution`/
  `ResourceVector` — the §08 types, not telemetry-local redefinitions.
  `provenance_mix` is a `map<CostProvenance, share>` and `confidence` is the
  minimum (never averaged); mixed currencies refuse `MixedCurrency` rather
  than converting. `by_scope` keys on the scope coordinate the spend names;
  `harness_overhead` buckets {compaction, verification, routing, retries,
  retrieval, consolidation} populate when the corresponding classes exist.
- **§5 — `metric_view` and the registry check close DF-S1.5-2.**
  `catalogue.rs` declares the §8 process-metric names as
  `ProcessMetric{name, requires_observability, applies_to_classes,
  computed_from_classes, unit}` rows; `registry_check` resolves each row's
  `computed_from` classes against `hh_ledger::classes::CLASS_TABLE`'s
  `min_observability` and fails any metric whose `requires_observability`
  under-declares (a metric reading a `model_io` class must require at least
  `model_io`). `metric_view` renders `MetricValue{value | n/a{reason}}` —
  a metric whose `requires_observability ⊄ run.observability_level` or
  whose class applicability fails renders `n/a{observability}` with the
  `computed_from` `EventRef`s attached, never 0.

## Consequences
- Adding a measurement point without updating the checked table fails the
  closed-table test — the spec-change gate is mechanical.
- Clock skew is observable (`clock_skew_flag`) instead of silently wrong;
  a stepped wall clock yields correct monotonic durations (AC-R-2.9.1-13).
- Provider-usage drift converges at one normalization boundary; every
  downstream consumer reads one convention.
- Cost provenance survives projection — `estimated_from_pricing` can never
  be pooled into `provider_reported`.
- Deferred: `turn_phase_profile` (M2's phase partition — C0/S2, with the
  gateway emitters), `audit_view` (S1.15, §05g.6's attestation), the
  catalogue's Stage-3 distribution computation, and `search_budget`/
  `eval_budget` arm attribution (DF-S1.14-2).

## Revisit trigger
S1.15's `audit_view` consumes `sink_deliveries` and the open-scope deadline
machinery — revisit `SpanStatus`'s deadline handling when §05g.6's
`AuditCompleteness` lands; the Stage-3 catalogue-distribution ticket revisits
`ProcessMetric` rows for per-configuration computation (additive — thresholds
and targets stay out of scope per §8).
