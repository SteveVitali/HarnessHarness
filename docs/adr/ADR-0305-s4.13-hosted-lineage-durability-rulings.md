- **Spec:** §5a.3 (goal continuation, wakeups, inbox runs),

- **Rung (ADR-0024 obligation):** **C1** — the hosted-lineage/durability slice — the C1 rung (C0/C2 members named).

## Context

S4.13 lands the hosted/subagent durability slices across five
surfaces: derived-index reads and the 10⁵-event latency criterion,
intra-run branches with promote/discard, goal continuation with
inbox runs and the `schedule`/`external`/`peer_message` wakeup
family, the three provider environment classes with suspend/
resume/detach/share, and the hosted lift table (status mapping,
`session.resumed`, unknown-kind preservation). Four rulings the
slice needed:

1. **Which projections are incremental vs rebuilt** — OQ-388's
   measurement half. ADR-0214's interim rule: the bound is
   proportional to result size, not run length; the per-projection
   maintenance policy was open.
2. **The hosted `session.resumed` lift target.** AC-R-2.2.3-13's
   table maps a hosted `session/resume{replayFrom}` to
   `lifecycle.run.resumed{cause: wakeup|operator}`. A participant-
   origin row must never mint a kernel lifecycle transition the
   participant cannot assert (CC2 — the participant is not the
   run's writer; only the kernel resumes a run).
3. **`discard` at the embed boundary.** `discard` terminates
   branch effects per the §5a.4 table; the compensable arm needs
   a compensator the boundary does not hold (the saga coordinator
   is the orchestrator's, CC10).
4. **`external` leaving the fleet-only boundary.** ADR-0131's
   Stage-4 extension admits `external` through registered ingress
   adapters; the kernel gate must therefore key on run kind only
   for `manual` (fleet-bound), not `external`.

## Decision

- **D1 — Derived indexes are maintained incrementally at
  append and rebuild identically; `read(filter)` is
  result-proportional (OQ-388 measured).** `by_event_id`,
  `by_class` and `ir_index` are posting lists updated inside the
  same batch commit as the events they index
  (`crates/hh-ledger/src/store.rs`); a filter naming an indexed
  dimension intersects postings and re-checks candidates against
  the full predicate, so indexed and linear scans are
  byte-identical in result. Every other projection stays a
  shared-fold rebuild — no second fold exists (CC1). The
  executable criterion (`hh-ledger/tests/s4_13.rs`
  `ac_r_2_2_1_16_latency_1e5_fixture`): a 10⁵-event run answers a
  class+ir_ref filtered read of 100 results in ~15 ms while a
  class-only full scan stays linear — the measured bound is
  proportional to `|result| + |candidates|`, confirming the
  interim rule. OQ-388's remaining half — WS-B1/K2 ratifying the
  bound value and the maintenance policy per projection — is
  DF-S4.13-1; this ADR fixes the *implemented* policy the
  measurement covered.
- **D2 — Hosted `session.resumed` lifts to
  `lifecycle.session.resumed`, never `lifecycle.run.resumed`.**
  The hosted event is the participant's *report* that a resume
  happened — authority `participant`, observational. Minting
  `lifecycle.run.resumed` under participant origin would let a
  hosted stream assert a kernel-owned lifecycle transition the
  kernel never performed (CC2 — content never confers
  authority). The new class is registered
  (`crates/hh-ledger/src/classes.rs`; `hosted_lowering` pairs it
  with `session.resumed`), payload verbatim
  (`resume_event_ref`/`carried` opaque), so the resume point is
  reconstructible without synthesising kernel state. A kernel
  resume still mints `lifecycle.run.resumed` itself.
- **D3 — At the embed boundary, `discard` records
  `compensation_failed{boundary: no_dispatch}` for the
  compensable arm.** The op passes a `no_compensator_at_boundary`
  closure into `Store::discard_branch`; the durable row then
  carries the honest `compensation_failed` record per effect —
  nothing is silently dropped or marked compensated that was not
  (CC3). Orchestrator-side discard supplies the real saga
  compensator and reaches `compensated`; the boundary path is the
  declared `n/a`, not a silent substitute.
- **D4 — `external` is admissible on every run kind; `manual`
  stays fleet-bound; `environment_ready` keeps its typed
  refusal.** The `wakeup_subscribe_owned` admissibility gate
  (`crates/hh-ledger/src/wakeup.rs`) checks the durable manifest
  for `run_kind = fleet` before refusing `manual`, and admits
  `external`/`schedule`/`peer_message` uniformly. Unattended
  (`schedule`/`external`) subscriptions on an
  `attendance = interactive` run refuse unless the policy names a
  reachable principal (`WakeupPolicyUnsupported`) — a wakeup that
  would park on an unanswered TTY is a typed refusal, never a
  parked fire.

## Consequences

- Indexed reads and linear scans are provably equivalent — the
  index is a posting accelerator, not a semantic fork; rebuild
  produces byte-identical postings (`ac_r_2_2_1_16_index_
  survives_rebuild_identically`).
- Hosted resume records are fully preserved without widening
  participant authority; consumers that fold on
  `lifecycle.run.resumed` (recovery metrics, resume counts) see
  only kernel-performed resumes — a hosted resume reports
  `n/a`, never a phantom 0 (T-LCD-15).
- The embed boundary's `discard` is honest but weaker than the
  orchestrator path: a run needing real compensator dispatch must
  discard through the saga surface. The capability asymmetry is
  recorded on the row, so no audit reads a boundary discard as
  fully compensated.
- Fleet agents on `external` triggers now compose with the
  shared ingress path; `manual` remains the attended fleet
  surface only.

## Alternatives considered

- **Lift `session.resumed` onto `lifecycle.run.resumed` with an
  origin marker** — rejected: the marker would be content-derived
  authority (CC2), and every consumer folding on
  `run.resumed` would have to re-derive the distinction the
  class name already encodes (CC1).
- **Rebuild-all index policy** — rejected: the 10⁵-event bound
  cannot be met with O(N) rebuild per filtered read; incremental
  postings with rebuild-identical verification give the bound
  and keep the fold single-sourced.
- **Pretend-dispatch `compensable` at the boundary** — rejected:
  recording `compensated` without dispatch fabricates evidence;
  `compensation_failed{boundary: no_dispatch}` is the honest
  residue.

## Revisit trigger

Reopen when (a) WS-B1/K2 ratify an OQ-388 bound different from
the measured result-proportional shape (the index policy then
needs re-review), (b) the hosted ABI grows a negotiated
resume-acknowledgement verb that needs `lifecycle.run.resumed`
semantics from the participant side (a new class or an
attestation field, not D2's passthrough), (c) the embed boundary
acquires a compensator (D3's `no_dispatch` marker then becomes
unreachable and should be deleted), or (d) `external` wakeups on
inbox runs need per-goal admission distinct from per-run.
