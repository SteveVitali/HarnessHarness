## Context

Each window's harvest committed a raw run tree — trials, cell artifacts, journals — large enough that six dated baseline classes (`wc-journald-size-1`, `wc4/wc6/wc7-runroot-size-1`, …) exist just to explain the bytes to the validator. The evidentiary value of the raw tree is preserved by the private archive upload (REQ-XH-102's verified `archive_verified` index); what the repo needs is the summary, the digests and the excerpts a verdict cites.

## Decision

R-9 (verbatim in the GATE DECISIONS row): from Wc9 on, commits carry **harvest summaries, digests and the small evidence excerpts a verdict cites** — including R-11's per-cell first-error excerpt (`run-root/verifier-first-errors.txt`) so identical signatures tally. **Raw run trees stay on the controller** (`~/hh-retained/<window>`) **and in the private archive upload** — the `archive_verified` index remains the retention guarantee.

**Conflict caveat (recorded, per the ruling):** if REQ-XB-220 or any committed requirement mandates in-repo raw trees, current behavior keeps and the conflict is surfaced — never silently resolved. REQ-XB-220's text requires harvesting the run root *under a verified sha256 manifest*; it does not name the repo as the manifest's home — read so, digests-plus-excerpts satisfies the letter while the archive carries the bytes. The caveat stands regardless: a contradictory reading anywhere keeps current behavior and surfaces.

## Consequences

Wc8 already exercised the shape early (the R-9 row records it): git carries `MANIFEST.sha256` + `wc8-window-record.json` + `verifier-first-errors.txt`; the raw tree rode the prescanned `wc8/run-root-tree.json` bundle and `digest_only` artifacts to the private archive. R6.45l's smokes and R6.45m's Wc9 commit `docs/build/reports/smoke|compute/…` summaries + cited excerpts + digests; raw trees stay in `~/hh-retained/` and the archive. Reviewability improves: a verdict's evidence is a cited excerpt with a digest, re-checkable against the archived tree.

## Alternatives considered

- **Keep committing raw trees** — the recorded validator friction and repo growth for bytes the archive already keeps under an `archive_verified` index. Rejected.
- **Digests only, no excerpts** — a verdict could not quote its evidence; the excerpt set is bounded to what a verdict cites. Rejected.

## Revisit trigger

Revisit immediately if any committed requirement is found to mandate in-repo raw trees (the caveat: keep current behavior and surface), if the private archive's `archive_verified` index is ever unavailable for a window (the raw tree then has no retention guarantee — stop and record), or at CAP6.2's retention review (REQ-XH-106).
