# ADR-0284: S3.7 model-plane evaluation rulings

- **Status:** Accepted
- **Date:** 2026-09-24
- **Ticket:** S3.7 (`053_S3.7__model-plane-eval.md`)
- **Requirement ids:** R-2.3.1, R-2.3.2⁰, R-2.3.3⁰, R-2.3.4⁰ (S3 slices)
- **Spec:** §5b.1–§5b.4 (the Stage-3 executable battery: substitution and
  drift fixtures, accounting completeness, reroute ordering, deviation
  posture, `fail_fast` outage, the profile test gate, cache accounting,
  export loss, the second dialect) · owning ADRs ADR-0118…0129 ·
  ADR-0156 D1 · ADR-0126 D5 (removal verdict) · ADR-0129 d.2 (K5)

## Context

S3.7 lands the Stage-3 model-plane executables: the drift/substitution
fixtures run against the landed ports, the accounting projection checks a
run's `model.*` rows, the comparison layer gains the deviation/outage
postures, the profile compiler's V1–V9 test battery gates linking, the K5
response cache executes, and the GenAI export names its losses. The ticket
owned these rulings:

1. **Where the accounting completeness check lives.** The AC-R-2.3.1-14 /
   AC-R-2.3.2-3 obligations ("exactly one `model_calls` charge per
   terminal; one attempt span per attempt; probes charge `instrument`;
   the charge's `model_ref` equals the route decision's") are checks *over
   a run's durable rows* — they belong in the evaluation crate, not the
   gateway that emitted them.
2. **What a disallowed substitution is.** A provider serving a different
   model than requested under `substitution_allowed = false` must never
   complete silently — but a refused substitution still consumed attempts,
   so it needs a terminal row, not an exception above the sequence.
3. **How hosted normalization surfaces.** AC-R-2.3.1-15 requires the
   hosted path's canonical event sequence to equal the native one with
   `participant_class` carried — the stamp has to cover the *stream* rows,
   not just request/terminal.
4. **Where the deviation postures live.** AC-R-2.3.2-8/-9's pooling
   policy and `fail_fast` posture are pre-registration members — they are
   `Design` fields, and the comparison layer enforces them.
5. **Whether `stratify` produces a pooled estimate.** Mixing deviated and
   clean rows under `pool_with_flag` is declared-acceptable; `stratify`
   exists for designs that refuse pooling outright.
6. **What the removal verdict is.** AC-R-2.3.3-8 needs a deterministic
   `pass | fail | inconclusive{reason}` over the retirement comparison —
   "the mean improves" must not rescue a reliably regressed subset.
7. **What a K5 arm may declare.** ADR-0129 d.2 admits exactly one
   response-cache kind at C0; the lab registration must refuse the
   invalid arm shapes (K5 outside `reproduction` without a `cache`
   factor; `natural` cache policy on a cache-invisible dialect without a
   stratification declaration; retirement arms in the wrong match shape).
8. **What the GenAI export may drop.** AC-R-2.3.4-13 requires the cache
   fields to carry and every non-representable member to land as a named
   loss — nothing silently absent.

## Decision

1. **Accounting is a typed-violation fold in `hh-eval`.**
   `facts.rs` projects the durable rows into typed `LedgerFacts`
   (attempts, terminals, route decisions, cache resolutions, charge/spend
   rows, event references, timing state); `accounting.rs`'s
   `model_accounting` returns `Vec<AccountingViolation>` — a closed sum of
   violation kinds, never warnings. A cache-served terminal must show
   `model.cache.resolved` naming the call, a zero-amount `model_calls`
   charge with `cache_hit = true`, and `timing = n/a{not_run}`; avoided
   estimates carry `provenance = estimated_from_pricing`.
2. **Disallowed substitution is a terminal `failed` row.** The gateway
   emits `model.call.failed{error_class = served_model_mismatch}` with the
   attempt history intact — the sequence stays canonical, the refusal is
   data. An *allowed* substitution completes with `served_model` /
   `substitution` stamps, and `charge_model` keys the charge at the
   served coordinate (the `profile_ref` is the request's own — a binding
   never changes mid-call).
3. **Hosted normalization is a stamp on every emitted row.**
   `stamp_participant` folds `participant_class` into each `model.call.*`
   payload including the interleaved attempt/delta stream; `None` /
   `"native"` leaves bytes untouched. The canonical sequence is identical
   by construction — the same emitters run.
4. **`Design` gains three additive members.** `routing_policy`
   (`fail_fast` default; `route{policy_ref}` binds named fallback
   chains), `deviation_policy ∈ {exclude_deviated, stratify,
   pool_with_flag}` (absent = pooling refuses), `cache_na_stratified`
   (admits a `natural` cache-policy arm on a `cache_state_visible =
   unsupported` dialect). All decode with defaults — CC8-clean.
5. **`stratify` yields no pooled estimate.** The `CompareOutcome` carries
   a `DeviationReport` (declared policy, per-arm deviated/total counts,
   excluded run ids, per-stratum outcomes); under `stratify` the pooled
   `reports` are empty and each deviation stratum carries its own
   comparison — a stratum one arm does not contribute to is recorded with
   `outcome = None`, never dropped. `exclude_deviated` lists the excluded
   runs beside the estimate.
6. **Two hard refusals guard the report.** A run with
   `replayed_trajectory` never enters a `ComparisonReport`
   (`ReplayedTrajectory`); a `routing.deviation` row under
   `routing_policy = fail_fast` contradicts the pre-registration
   (`DeviationUnderFailFast`). Outcome counts are stratified per arm —
   the `infrastructure_failure` rows are a `fail_fast` design's outage
   counts.
7. **The removal verdict is conjunctive and honest.**
   `removal_verdict` (ADR-0126 D5) requires *both* the paired interval's
   regression-side bound within the pre-registered `margin_ppm` on every
   compared metric *and* the reliably-regressed task share ≤
   `regressed_share_bound_ppm`; a metric with no defined point/interval
   renders `inconclusive{reason}` — never a pass. `retire_rule` produces
   the `P − R` profile; lab registration refuses retirement arms that are
   not `{mode: matched_cap, cache_policy: cold_start}` or not a
   single-rule removal diff (`NotARetirementMatch`).
8. **`ArmSpec.response_cache` is a closed sum with registration gates.**
   `k5` is the only C0 member. Registration refuses: a K5 arm on a
   non-`reproduction` spec without `cache` declared as a factor
   (`PreRegistrationInvalid`); a `natural` cache policy on a dialect the
   context resolver reports `cache_state_visible = unsupported` unless
   the design declares `cache_na_stratified`; a retirement spec failing
   the match-shape/single-rule-diff checks.
9. **Every representable GenAI field is carried; the rest are named
   losses.** `hh-telemetry::genai` maps cache usage to
   `gen_ai.usage.cache_read.input_tokens` /
   `cache_write.input_tokens`; `model.cache.resolved` and any
   nonrepresentable member (`miss_reason`, `avoided.spend`, …) emit
   explicit loss entries. Nothing is consumed without a projection or a
   named loss.
10. **The link gate enforces the profile test battery.** A bound non-null
    profile without a `ProfileTestReport` refuses `ProfileUntested`; a
    failing validity section refuses `ProfileInvalid`; a rule depending on
    a capability with a `DRIFT`/`UNSUPPORTED` conformance record and no
    recorded intent refuses `CapabilityDrift`. The kernel `null` profile
    is exempt — compiling under it is the compiler's own removal test.
    `CompiledBundle.profile_test_report_ref` carries the report ref;
    `fallback_used` records the escape-hatch binding.

## Consequences

- The AC set is executable: AC-R-2.3.1-{9,10,12,14,15},
  AC-R-2.3.2-{3,4,8,9,13}, AC-R-2.3.3-{2–6,8,10,12–14},
  AC-R-2.3.4-{6,7,10,11,13,14} all have failing-if-removed tests.
- **DF-S1.18-2 is discharged** — the Stage-3 executable battery exists
  and runs green over the landed records/ports.
- DF-S1.18-1 stays OPEN — the *emitter call sites* on a real run (the
  turn-loop driver) remain the Stage-2/C1 boundary decision, not a code
  gap.
- `hh-gateway` gains an `hh-registry` dependency (conformance records)
  — the direction stays plane-legal (gateway → registry read view).

## Alternatives considered

- **Accounting checks in `hh-gateway`:** rejected — the gateway emits
  rows; auditing them is the evaluation plane's job (CC10). A fold in
  `hh-eval` also checks recorded runs the gateway never sees again.
- **Warnings instead of typed violations:** rejected — CC3 requires
  unaccounted spend to be a violation, not noise; every violation kind is
  a closed-sum member the test battery enumerates.
- **A separate hosted event sequence:** rejected — two sequences would
  need a parity proof forever; stamping `participant_class` on the one
  canonical sequence is the honesty-preserving reading of AC-R-2.3.1-15.
- **`stratify` emitting a pooled estimate beside the strata:** rejected —
  that is `pool_with_flag`'s meaning; conflating them removes the
  design's ability to forbid pooling.
- **`removal_verdict` treating a missing interval as `fail`:** rejected —
  `inconclusive` is the three-valued honest answer; a failed run and an
  unmeasurable one are different verdicts.

## Revisit trigger

Reopen if (a) a second response-cache kind is admitted at C0
(`ResponseCacheDecl` is a closed sum — extending it is a spec change),
(b) a `routing_policy` arm beyond `fail_fast`/`route` is needed (the
non-`static`/`role_table` arms are C1 per DF-S1.18-1), or (c) the GenAI
semantic conventions gain cache-member spellings that make today's named
losses representable.
