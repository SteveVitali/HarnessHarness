## Context

REQ-D-301/302/303/308/D-004 bind §4.4/§4.5: authentic admission
compares the **same participant/configuration** under HH (H) and
the original runner (O) — pinned task/split/stratum/model/
environment/oracle, preassigned first attempts inside
`(task, repeat, pair_id)`, matched budgets/cache, original/replay
evidence, the signed pre-data
dimension→metric/estimand/population/range/unit/margin/
applicability/evidence map and equal `T`/`R`/weights, with adapter
≥3 and S3 ≥5 attempts-per-task floors. Empty maps, wrapper
reports, supplied model-I/O fixtures and oracle transport equality
alone fail; missing required replay is unmatched; a dropped
required endpoint blocks the whole conjunction; typed
inapplicability records its reason and never counts as passed.
Native first-wave efficacy needs adapter admission applicable to
**both** actual policies or preregistered identical-bridge reuse —
baseline-only parity cannot silently admit the changed policy
(`b_A = −.10`, `b_B = .10` alone can fake a +.20 effect), and no
mixed Bayesian/frequentist certificate is admitted. Before this
ticket `hh-eval` had no admission validator and `IntervalMethod`
had no spelling to declare the admission check; the s3_12b corpus
fixture (recorded model I/O, empty equal snapshot maps, no
equivalence margin) remains useful fixture evidence and nothing
more.

## Decision

1. **`parity_admission` is records-in, validator-only.** The
   `AdmissionEvidence` union names exactly one admissible shape —
   `authentic_first_attempt` manifest — plus the five
   known-inadequate shapes (`recorded_model_io`,
   `artifact_benefit_wrapper`, `model_snapshot_maps`,
   `oracle_transport_equality`, `seed_presence`) and an `Other`
   spelling, each refused `InauthenticEvidence{shape}`. The module
   never manufactures authentic runs; it validates supplied
   records and emits `admitted` only when every check holds.
2. **The manifest binds actual identities, not outcomes.** Each
   pair carries `(task_id, repeat, pair_id, subject, phase,
   stratum, policy)`, actual `h_run_ref`/`o_run_ref`/
   `h_verdict_ref`/`o_verdict_ref`, a required `replay_ref`
   (absent ⇒ the pair is unmatched, `MissingReplay`, never a
   pass), `attempt = 1`, and recorded
   `seed_requested`/`seed_honoured` — counted on the report while
   honoured-seed coupling/CRN spellings refuse
   `UnsupportedDependence` (the grouping exception grants no CRN,
   honoured-seed or R2 claim). Equal `T·R` coverage, distinct
   subjects, declared phase/stratum/policy and both floors are
   checked before any map validation.
3. **The map is signed and pre-data.** `signature_ref` is required;
   `map_seq < first_outcome_seq` is the declared pre-data ordering
   (`LateMap` otherwise). The seven contract dimensions are a
   closed vocabulary; `required` drives coverage — a required
   dimension absent from `entries` is `MissingDimension`, typed
   `inapplicable` records its reason (`RequiredInapplicable` when
   required), and `pass^k`/`conditional_eligible` estimands stay
   `UnavailableMethod` — unavailable, never silently dropped.
   Margins bind only through `benefits::registered_margins`
   (pre-registration authority, never the caller), with the
   absolute/relative kind checked against the estimand.
4. **Applicability is both-policy or predeclared bridge.**
   `BothPolicies` requires an evidence binding per declared
   policy; `IdenticalBridge` requires `bridge_seq <
   first_outcome_seq`; `BaselineOnly` and any uncovered declared
   policy refuse `PolicyScope`. Every non-`"none"` transfer claim
   fails typed — `MixedUncertainty` (Bayesian lower endpoint +
   frequentist calibration), `BaselineOnlyTransfer` (`b_A` alone),
   `TransferBudget` (`|b_A|+|b_B| > κ`), else
   `UnsupportedTransfer` — original-runner transfer is a
   separately admitted design.
5. **The routed kind persists the admission report.** The
   `parity_admission` kind arm decodes `query.filters`
   (records-in), resolves margins from `PreRegistration` only, and
   appends the report as an `analysis_report_body/1` section;
   `IntervalMethod::ParityAdmission` is a manifest-level
   declaration (scorecard cells report `n/a{estimator_undefined}`,
   a method/kind mismatch is `MetadataOnly` — the R5.16/R5.38
   rule). The admitted pair ids are the records
   `directional_kl_equivalence` consumes unchanged.
- Authentic H/O execution (R5.47 under GATE-G13), the numerical
  review (R5.40), the central protocol (R5.41) and the study
  report (R5.49) keep their owners — this ticket discharges
  engineered D/E only.

## Alternatives considered

- **Admission inside `directional_kl_equivalence`** — rejected:
  M-E owns the estimator, M-F owns admission; fusing them would
  let synthetic declarations silently re-enter as "authentic" and
  recreate the fixture-efficacy mistake I-05 forbids.
- **Seed presence as a required pair member** — rejected: the
  amendment preserves requested/honoured seeds but grants no
  honoured-seed coupling; requiring them would smuggle a
  coupling claim into admission (counts are reported instead).
- **Admitting a well-formed joint transfer certificate** —
  rejected: original-runner transfer is a separately admitted
  design (spec §4.5); this module's contract is refusal with
  typed failure shapes.
- **A new report store or event class** — rejected: additive
  `analysis_report_body/1` member reuses the existing route.

## Revisit triggers

- If the admitted evidence-shape vocabulary grows (a second
  admissible manifest form), re-read the `InauthenticEvidence`
  legs.
- If Packet E pair binding lands a durable capture path
  (R5.47/GATE-G13), re-read the records-in manifest shape —
  authentic capture supersedes declared fixtures, never a second
  input path.
- If a transfer design is separately admitted, re-read the
  `UnsupportedTransfer` legs — the registered claim spelling
  changes with that admission.
- If `IntervalMethod`, the margin authority or the dimension set
  changes, re-read the kind arm's method gate, margin binding and
  `DIMENSIONS`.
