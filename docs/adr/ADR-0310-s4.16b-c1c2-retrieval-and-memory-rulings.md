# ADR-0310: S4.16b C1/C2 retrieval and memory depth rulings

- **Status:** Accepted
- **Date:** 2026-09-29
- **Ticket:** S4.16b
- **Requirement ids:** R-2.4.3 (retrieval/memory hierarchy),
  R-2.4.4 (lifecycle semantics), R-2.4.5¹
  (AC-R-2.4.5-8 — `subagent_task`), R-2.4.2²
  (AC-R-2.4.2-{11,12} — hosted compaction lift, boundary
  companion, judged fidelity)
- **Spec:** §5c (retrieval, memory lifecycle, consolidation,
  adoption epochs, summarization, `subagent_task`); §5c.2
  (compaction ops + summarizer); §5c.5 (procedure targets);
  ADR-0075…0086 (the memory/retrieval family this ticket
  lands C1/C2 under); ADR-0077 (boundary companion + judged
  fidelity), ADR-0115…0117 (judged-detector emission),
  ADR-0047(c)(ii) (calibration gate), CC1/CC2/CC3/CC7/CC8/CC9.
- **Rung (ADR-0024 obligation):** **C1/C2** — the retrieval/memory depth — the C1/C2 rungs.

## Context

S4.16b lands the C1/C2 retrieval and memory depth. Nine
spellings needed owned rulings — each a seam the spec leaves
to the implementation, each now with exactly one spelling
(CC1/CC7):

1. **Where the `subagent_task` lowering product lives.**
   `lower_procedure` under `CompilationTarget::SubagentTask`
   must produce a `DelegateSpec`; the spec's schema already
   had one owner (`hh-subagent::SubagentSpec`) and the
   compiler needed one shape to carry it.
2. **How `select_target` admits `subagent_task` at Stage 4**
   without breaking the four-refusal C0 battery
   (AC-R-2.4.5-5).
3. **What a ranker "family" is as data.** `report.
   deterministic` could not stay a hard-coded variant list —
   declarations had to drive it (CC1), including the
   declared-but-unbound `similarity` member.
4. **Where model calls inside `Summarize` may come from.** The
   compaction engine runs inside the kernel; the only
   honest seam is the caller's gateway.
5. **What the `memory_store` plugin boundary carries.** A
   stored `MemoryVersion` legitimately contains
   `label.authority = kernel` and `label`-class members —
   the V1 inbound screen reads those as forged plugin
   envelope authority claims. The wire shape had to keep
   stored records as data without weakening the screen.
6. **What consolidation is cadenced on, and what it charges.**
   The cadence set, the guard order and the watermark basis
   each needed one rule.
7. **How `adopt` reports incremental lowering.** The loss
   report, the permission-coverage recompute and the epoch
   fold each needed a surface that stays additive (CC8).
8. **How a hosted `compact_boundary` becomes the canonical
   pair.** Two spellings (Inspect `CompactionEvent`,
   Claude-Code `compact_boundary`) with different member
   names and unreported member sets.
9. **What the boundary companion compares.** A paired arm
   whose budgets differ is not a comparison (CC9) — the
   refusal had to precede any fork.

## Decision

1. **`DelegateSpec` is the `RuntimePlan/1` `delegate` node;
   the spec schema stays in hh-subagent.** `lower_procedure`'s
   `subagent_task` product is
   `DelegateNode{spec, budget, permission}`; `spec` is the
   canonical `SubagentSpec` JSON document the kernel `spawn`
   consumes (`SubagentSpec::{to,from}_json`, CC7). The
   constructor `hh_subagent::task::spec_for_procedure` builds
   the typed spec — `Goal = P` + bound parameters, grants over
   `allowed_capabilities`, ceiling `delegate`, fresh context —
   and the compiler carries it as data (the same shape a
   declared `ProcedureStep::Delegate{spec}` carries). The
   compiler never re-declares the schema (CC10).
2. **`select_target` rule (iii) admits `SubagentTask` under
   `I(P)` ∧ `subagents_bound` ∧ `profile_declares_subagents`;
   the override leg demands the same conjunction.** Every
   other demand for the subagent path refuses
   `DelegationUnavailable` — the honest typed error when
   delegation is required but cannot bind; the AC-R-2.4.5-5
   refusal set is unchanged. `workflow_node`'s legs (i)/(ii)
   are likewise executable (rule (i) refuses
   `UnexpressibleAsWorkflow{step, reason}` when B(P) fails
   under the override). `subagent_task` carries
   `expected_evidence` through `risk_floor` like every target
   (AC-R-2.4.5-8).
3. **`RankerDeclaration` is data per variant; the feature
   vocabulary is closed.** The kernel registers
   `deterministic_default`, `structural_pagerank`,
   `lexical_weighted`, `recency_importance` (all
   `deterministic = true`) plus `similarity_rerank`
   (`deterministic = false`, `required_inputs` =
   `{ModelProfile(pinned embedder), ResourceAccount}`) —
   declared, and `EmbedderUnpinned` until the embedder inputs
   are pinned. `report.deterministic` reads the declaration's
   `deterministic` member, never a table keyed by variant id.
4. **`Summarizer` is a caller-supplied port; the model call
   rides the caller's gateway (I-BUDGET).** `Summarize`
   execution is gated on a declared `summarizer_profile` in
   the proposal plus a bound `Summarizer` — absent either
   the refusal is `UnresolvedSummarizer`; an op outside the
   declared set is `UnsupportedOp`. `input_reduction` applies
   once on `SummarizerOverflow` and is recorded
   `input_reduction_applied` — the declared reduction is a
   fact on the row, then success or the deterministic
   fallback. The emitted record carries `derived_from`,
   `insert_at` and `summariser_usage` overhead
   (`harness_overhead.compaction`); `relower_summarize` and
   `fold_on_return` are `CompactionTrigger` variants of the
   same path.
5. **`memory_store` binds the `MemoryStorePort` surface over
   `plugin_abi/1`; record payloads cross the wire as canonical
   JSON strings under `{result: "…"}`.** The contract op set
   is the 23-member port surface (`put, bind, revoke, resolve,
   manifest, enumerate, stale_candidates, reads_of,
   writes_by, record_read, set_stamp, set_validator_verdict,
   mark_scope_ended, publish_replacement, version,
   version_order, edges, revocations, conflicts, applied_seq,
   drain_events, take_lease, lease`) — the same surface
   `retrieve`/`lifecycle`/`consolidate` read. Codecs are
   strict canonical JSON with typed `CodecError`s; domain
   refusals are output *data*
   (`{ok: false, refusal: {code, detail}}`), never ABI or
   channel failures. Record outputs are wrapped as canonical
   JSON strings under a result envelope — stored records are
   data, so the V1 inbound screen cannot mistake a record's
   own `label.authority = kernel` member for a forged plugin
   envelope claim (the pre-wrap failure mode was an
   `AuthorityCrossing` drop presenting as an invocation
   timeout). `MemoryStorePort` is satisfied identically by the
   in-process `MemoryStore`, the kernel-side `RemoteStore`
   over a `StoreChannel`, and the spawned `hh-memory-store`
   plugin — one conformance battery runs all three.
6. **Consolidation cadences are `{session_start, idle,
   rate_limit}`; the gate runs lease → cadence → guards →
   watermark diff.** A closed gate skips without a record.
   The driver diffs `{input_watermark,
   last_success_watermark}` (content-addressed — a watermark
   is the hash of the inputs it covers) and charges
   `harness_overhead.consolidation`; dedupe rebinds names to
   the live replacement, the conflict guard and
   `max_versions` bound refuse before any write, and the
   lease fences a stale holder (a revoked lease's writes
   refuse, never commit).
7. **`adopt_with` takes `AdoptInputs{loss_report?, coverage}`;
   `adopt` delegates with the empty context.** The caller
   supplies the incremental lifter's `LoweringLossReport` and
   a coverage oracle over the run's grant set — adopted
   entries recompute `permission_coverage` (typically
   `uncovered` until a grant exists). The results row's
   `lineage` section gains the additive members
   `configuration_drift` and `catalog_epochs[]` (folded from
   `action.tool.catalog.epoch` rows) — `hh-results-row/1`
   members, never a shape change (CC8).
8. **`normalize_compaction` maps both spellings onto the
   canonical `compaction.observed` record; absent members
   stay absent or are honestly stamped.** `applied_ops`
   reports verbatim when the record names them, else the
   format default `[{kind: summarize}]` with
   `applied_ops_source = "format"` — the inference rides its
   own member, never disguised as reported data.
   `tokens_before`/`tokens_after` lift the spelling's names
   (incl. nested `compact_metadata`) and stay absent when
   unreported; component metrics emit the typed
   `n/a{class}` the host cannot observe. The envelope keeps
   `origin = participant`, `authority = unverified` (CC2 —
   a participant-reported compaction is never kernel-stamped).
   The lift emits `context.compaction.started` and
   `context.compaction.completed` in order.
9. **`lab/compaction-boundary-v1` forks `fork_by_reference`
   at each `context.compaction.started` event ref; unequal
   arm budgets refuse `UnmatchedBudget` before any fork.**
   The pair (`applied`/`withheld`) is keyed by the shared
   `forked_from`, derives `environment_derivation =
   fork_snapshot`, and continues a fixed `eval_budget` of
   `turns = 5` — matched-budget-or-refuse (CC9), never an
   uneven comparison. `grounding.summary_fidelity_judged` is
   the companion's declared optional C1 metric:
   `detector = judged`, `oracle = judge`, `charged_to =
   instrument`, `headline = false`, native-only
   `applies_to_classes` (hosted rows render `n/a{class}`) —
   emitted through `emit_judged`, the deterministic
   predicate over caller-supplied judge verdicts (the judge
   critic itself is §05f/S4.16c).

## Consequences

- The `memory_store` ABI is canonical and additive: a v1
  plugin and the kernel-side remote agree on one op set and
  one codec; future ops are new members, never rewrites.
- The `{result: canonical-json}` envelope is the ruled
  answer wherever a port's output type contains members the
  V1 screen scans — the pattern any later class boundary
  should reuse before loosening the screen.
- `similarity` stays declared-but-unbound: pinning an
  embedder profile is the S5.x decision that lands it, and
  until then every similarity request refuses typed
  (`EmbedderUnpinned`).
- The judge critic, hosted `end_state` verdict depth and
  the remaining §05f surface are S4.16c's; the judged
  fidelity declaration + emission path landed here so the
  boundary companion can name its optional metric.

## Revisit trigger

Reopen if (a) the `memory_store` contract version needs to
carry a member the V1 screen cannot pass — extend the ABI
with a new contract version rather than weakening the
screen or the `{result: canonical-json}` wrap; (b) an
embedder profile lands pinned — `similarity_rerank` binds
under its declared `required_inputs` then, never by
relaxing `EmbedderUnpinned`; (c) §05f lands a judge critic
whose verdict shape is richer than a `MetricValueKind` —
extend the `emit_judged` emission additively rather than
forking the judged detector; or (d) the boundary
companion's continuation budget changes by ADR — the
`turns = 5` `eval_budget` is a declaration member, not a
code constant to drift.
