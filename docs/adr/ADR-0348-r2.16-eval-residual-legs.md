## Context

R2.16 discharges the §5h.2 residual — DF-S1.22-1's last open members
and DF-S1.22-2's last four battery cells. Five design rulings were
the ticket's to make:

1. **Where `search_budget = unknown` is admissible.** The
   declaration-level rule (a hosted arm's limits are reported, not
   measured — §6.3 C1) landed earlier; the *match*-level question was
   open: may a commensurability check ever treat an unknown search
   budget as a zero, or silently widen? T-LCD-07 forbids the silent
   zero; the granularity at which the comparison runs decides what
   `unknown` can mean.
2. **Where `declare_arm`'s engine precondition bites.** The record
   schemas and `Arm::validate` declaration checks were landed; the
   *engine* precondition — the sealed configuration's `budget_vector`
   must be the arm's declared `eval_budget` (CF-099) — had no
   enforcement site.
3. **How a judge context is derived at run time.** The
   `JudgeContext` schema and the register-time independence checks
   (S4.15) existed; deriving the context from an actual `EvalRun` —
   and re-checking it at the consume side — was owed
   (ADR-0047(c)).
4. **Whether the HAL fault vocabulary is first-class.** The fault
   taxonomy's provider-side failure modes (`timeout`,
   `error_response`, `partial_failure`, `rate_limit`,
   `network_error`, `invalid_response`, `empty_response`) had
   spellings in the spec's fault-injection table but no `FaultType`
   variants — profiles could not name them.
5. **What a foreign import binds.** OQ-377 asks whether an imported
   experiment should mint an `experiment_run` with
   `provenance = imported`; the interim rule needed ratifying in a
   fail-if-removed test.

## Decision

- **D1 — `unknown` binds at product granularity only, never coerced.**
  `hh_budget::matchspec::validate_match` delegates to
  `validate_match_at(arms, Granularity)`. At `ProductLevel` an arm may
  carry `search_budget = unknown`; cap/metering cross-checks skip the
  unknown-search arm (it is *not* folded into a zero — T-LCD-07) while
  the enforcement checks still bind it. At `ConfigurationLevel`
  (the default everywhere — the configuration is the comparand's
  identity there) the unknown refuses `UnbudgetedArm`, and M3
  `matched_total` refuses it at any granularity: a total-budget
  match cannot waive what it cannot see. `CompareInput` carries the
  granularity; `BudgetMatch.search_unknown` records the flag
  (serialized only when `true`, decoded defaulting `false` — old
  reports decode unchanged). At the spec layer `check_arms` admits an
  absent `search_budget` only on an arm assigning a `hosted`-class
  level, and `check_match` picks the group's granularity by the same
  predicate; the `lab.eval.compare` boundary decodes `granularity`
  (default `configuration_level`) and promotes `native: false` arms
  to hosted enforcement with `search_budget = unknown`.
- **D2 — `budget_ref` is the configuration's declared budget
  binding.** `ArmConfiguration` gains the additive member
  `budget_ref: Option<String>` — the sealed configuration's
  `budget_vector` semantic id, as produced by the assemble → resolve →
  seal chain. `expand` refuses
  `ExperimentRefusal::BudgetMismatchWithinArm{arm,
  configuration_budget, eval_budget}` when it differs from
  `arm.eval_budget` — `declare_arm`'s CF-099 precondition enforced at
  the engine, never a dropped cell. `None` defers to the
  record-level `Arm::validate` gate (the resolver carries only ids).
  The member is additive on the `lab.experiment.expand` params —
  older callers decode unchanged.
- **D3 — judge context derives from the run, never from trust.**
  `hh_eval::judge::judge_context_for(run, independence)` derives the
  `JudgeContext` from an `EvalRun` plus its declared
  `IndependenceVector` — the snapshot axis folds from the run's own
  facts — and refuses `JudgeError::UnboundJudge` when no declared
  judge binds. `recheck_judged` is the consume-side re-admission: the
  judged verdict is re-checked against the run's facts where it is
  consumed. Calibration expiry folds deterministically (the same
  expiry rule as the register-time declaration check, replayed over
  run facts — no wall-clock, no live judge).
- **D4 — the seven HAL failure modes are `FaultType` variants.**
  `HalTimeout`/`HalErrorResponse`/`HalPartialFailure`/`HalRateLimit`/
  `HalNetworkError`/`HalInvalidResponse`/`HalEmptyResponse` spell the
  spec's `timeout`/`error_response`/`partial_failure`/`rate_limit`/
  `network_error`/`invalid_response`/`empty_response` rows;
  `stage3_fault_profiles()` gains the `f/hal-*-pNN` profiles bound at
  `at: "provider_call"`. A HAL fault is an environment-factor level —
  the same injection surface as every other fault profile.
- **D5 — OQ-377's interim rule: no binding is minted.** A foreign
  lift (`hh_bundle::import::lift_foreign`) mints `hh-import/1` with
  `participant_class: hosted`, `claimed_level: R0`,
  `authority: unverified` and an **empty** `subject.experiment` map —
  the import never fabricates an experiment binding. Rows lifted from
  it stay unbound and the leaderboard's `require_experiment` L6 gate
  reads them `undisclosed` (AC-R-2.10.5-8). The question stays OPEN —
  minting `provenance = imported` experiment runs is a later-ticket
  call; the interim rule is now pinned by
  `hh-bundle/tests/s4_2.rs::foreign_import_mints_no_experiment_binding`.

## Consequences

- `unknown` is a first-class value, not a silent zero (CC9/T-LCD-07):
  a comparison that cannot see an arm's search spend reports
  `search_unknown: true` on the budget match rather than pretending
  commensurability.
- `BudgetMismatchWithinArm` joins the closed `ExperimentRefusal` sum
  (refusal code `"BudgetMismatchWithinArm"`); a mis-bound
  configuration fails at `expand` before any cell is planned.
- The judge's runtime checks are machine-achieved end to end: derive
  (context from run + independence vector), consume (`recheck_judged`
  at the read site), expire (the deterministic calibration fold).
  Nothing trusts a judgement the record does not carry.
- The fault battery's last cells execute over the recorded corpus:
  the combined infrastructure-failure + budget-exhaustion +
  verifier-crash fixture derives `oracle_failure`; `LeakedSplit`
  refuses a held-out label inside an `adaptive_search` design; the
  HAL levels bind as environment-factor levels.
- DF-S1.22-1 and DF-S1.22-2 are discharged; the OQ-377 import rule is
  the ratified interim (the question itself stays open).
- Owned vocabulary is additive (CC8): `budget_ref` on
  `arm_configs`, `granularity` on `lab.eval.compare`,
  `search_unknown` on `BudgetMatch`, the seven `FaultType` spellings.

## Alternatives considered

- **Coercing `unknown` to a zero cap.** Rejected: T-LCD-07 — an
  unmeasured search spend is not a measured zero; the flag on the
  budget match is the honest report.
- **Enforcing the `budget_vector` binding at `register`.** Rejected:
  the sealed configuration does not exist at register — the arm is
  declared, the configuration is produced by the assembly chain and
  consumed at `expand`; the check binds where the artifact it names
  exists.
- **A live `JudgeContext` lookup service.** Rejected: under
  `offline-only` there is no live judge; deriving the context from
  the run's own facts is the honest ceiling (the same shape
  `RecordedJudge` took at R2.15, ADR-0347 D3).
- **HAL faults as free-form `ext` tags.** Rejected: a spelling that
  is not a `FaultType` variant cannot bind as an environment-factor
  level through the catalogue — the fault battery cell requires the
  first-class vocabulary.
- **Minting an `experiment_run` at import (the OQ-377
  `imported`-provenance answer).** Deferred, not rejected: the
  question stays OPEN — minting a binding at import would claim an
  experiment the foreign record never ran; the empty binding + the
  `undisclosed` gate is the honest interim.

## Revisit trigger

Reopen D1 if a third granularity lands (`search_unknown` becomes a
per-granularity table rather than the product-level predicate).
Reopen D3 when a live judge binding is admissible (the
`offline-only` ceiling lifts — R2.21): `judge_context_for` then
composes with a live `JudgePort`, never replaces it. Reopen D5 when
OQ-377 resolves: if imports mint `provenance = imported` experiment
runs, `lift_foreign` gains the binding and the leaderboard gate's
`undisclosed` half shrinks accordingly.
