# ADR-0317: S5.6 fleet-adapter rulings

- **Status:** Accepted
- **Date:** 2026-10-02
- **Ticket:** S5.6
- **Requirement ids:** R-2.12.6 (C4/Stage-5
  halves; AC-R-2.12.6-{9,10,11}); CC1/CC2/CC3/
  CC6/CC7/CC8/CC10.
- **Spec:** §5i.1 (R-2.12.6 — adapters, fleet
  view, metrics, ceiling), §7.1/§7.2
  (FleetView); owning rulings ADR-0205
  D4–D6, ADR-0206 RC-1…8, ADR-0207 D4/D5,
  ADR-0180/0181 (L5 plugin placement),
  ADR-0209 D2.
- **Rung (ADR-0024 obligation):** **C4** — the fleet adapter — the C4 organizational rung.

## Context

S5.6 lands the C4 Stage-5 slice of the fleet
layer: the generic signed-webhook ingress with
capability probes, the out-of-process tracker
adapter over the L5 plugin boundary, `FleetView`
on both first-party surfaces with the
approval-inbox join, the fourteen fleet metric
declarations plus `unowned_dispatch_count`, and
the optional `ext.effects.external_irreversible`
ceiling. **HUMAN-H2 — a provisioned real
issue-tracker + signed webhook — was not
provisioned at build time**, so the ticket's own
fallback rule applied: run the Stage-4 fixture
adapter as the proxy and record the deferral.
The run had to rule on the points below.

## Decision

- **D1 — The fixture adapter is the declared
  proxy, never a fabricated real.** With
  HUMAN-H2 unprovisioned, `hh-tracker-fixture`
  runs the whole `work_source_adapter` class
  contract (`capabilities`, `occurrences`,
  `suspended`, `activate_run`, `list`, `get`)
  out-of-process through `hh-varhost` at
  `subprocess_confined` — a genuinely spawned
  child process, not an in-process stand-in.
  DF-S5.6-1 records the real-tracker leg as
  owed; no test or document claims a live
  tracker was exercised.
- **D2 — The webhook secret is a boundary
  parameter, verified never stored.**
  `fleet.webhook_ingress` takes
  `{delivery, signature, key}`: `key` is the
  broker-resolved value for the policy's
  `key_ref` (the caller side of the H3 broker
  resolves `key_ref → bytes`; the embed service
  holds no key table). The signature verifies
  `hmac-sha256:<hex>` over the canonical
  payload; the key bytes ride the request only
  — no ledger row, reply record, view member or
  log line carries them (the acceptance test
  asserts the occurrence row's payload lacks the
  key). When the H3 mediator surfaces a
  broker-side `key_ref → bytes` verb the param
  migrates to `key_ref` alone — the codec is
  additive-compatible (CC8).
- **D3 — Adapters are `&mut` at the call site;
  authoritative state stays ledger-derived.**
  `WorkSourceAdapter`'s verbs take `&mut self`
  (a poll can consume a delivery queue, a probe
  can latch a fault). Engine calls
  (`observe`, `reconcile`, `dispatch`) receive
  the adapter mutably; anything durable still
  lands as a ledger row and rebuilds identically
  from events alone — adapter process state is
  call-local, never load-bearing (CC3; INV-9).
- **D4 — The irreversibility ceiling reserves
  at the owner pool, not the dispatch slice.**
  `on.external_irreversible` under a bounded
  `ext.effects.external_irreversible` pool
  dimension reserves one unit at the root pool
  *before* dispatch; carrying the dimension
  into the per-dispatch slice instead produced
  a false `BudgetExceedsParent` (the child
  limit could exceed the parent's remaining).
  Exhaustion refuses the dispatch, appends the
  durable `blocked{irreversibility_ceiling}`
  row and escalates; an absent/unset dimension
  is a strict no-op (AC-R-2.12.6-11).
- **D5 — Probing resolves `unknown` only.**
  The capability probe tri-state
  (`unknown`/`declared`/`probed`/`probed_absent`)
  never downgrades: probing a `declared` or
  already-probed capability leaves it
  untouched (T-LCD-07); unknown names and
  invalid states fail closed. A re-delivered
  webhook's `push_delivery_id` evidence probes
  that capability from `unknown` when the
  adapter didn't declare it.
- **D6 — `FleetView.metrics` is the catalogue
  verbatim.** `fleet.fleet_view` carries the
  fifteen fleet-level `MetricDeclaration`s
  (fourteen §5i.1 rows + `unowned_dispatch_count`
  — the `veto: true` trace predicate) in §5h.1
  declaration form; fold status is declared per
  row and hosted activations render
  `n/a{observability}` on ledger-only fields,
  never a fabricated zero (V-3/T-LCD-15;
  AC-R-2.12.6-10).
- **D7 — The approval-inbox join is a
  projection, not a row.** The V10 supervision
  view joins durable `security.permission.pending`
  payloads onto `FleetView.items[].approvals` by
  `work_item_id` and renders the full pending
  set under `approval_inbox`; nothing is minted
  for the join — it rebuilds under the same
  watermark (ADR-0207 D4 V-1…V-5).

## Consequences

- Every Stage-5 adapter seam is executable
  end-to-end today — signed ingress, probing,
  the read minimum, OOP placement — while the
  *real-tracker* leg waits on operator
  provisioning (DF-S5.6-1, gate-scoped P row).
- `key` as an op parameter means the boundary
  request carries secret material in transit;
  the design keeps it out of every durable and
  rendered surface, and the migration path to a
  pure `key_ref` op is recorded above.
- A faulted source is a first-class report
  member (`fleet_report.source_unavailable`) —
  liveness claims read the fault, never infer
  health from silence.

## Alternatives considered

- **Blocking S5.6 until HUMAN-H2 provisions.**
  Rejected by the ticket note itself — the
  fixture is the sanctioned proxy and the
  deferral ledger is the honest carrier; a gate
  is a pause, not a block.
- **Resolving `key_ref` inside `EmbedService`
  via `CredentialBroker`.** Rejected for this
  slice: the broker's channel/binding/grant
  machinery is run-scoped secret mediation, not
  a service-side lookup table; minting a
  broker-internal resolution path here would
  pre-decide the H3 surface another ticket owns
  (CC10). The param shape keeps the broker-held
  property (the kernel never persists it).
- **Carrying the ceiling dimension in the
  dispatch slice.** Rejected — it produced the
  false parent/slice mismatch; the root
  reservation is the accounting the AC names
  ("refused at `reserve`").
- **Downgrading `declared` on probe.** Rejected
  — T-LCD-07 keeps the declaration truthful;
  a probe that rewrites declared state makes
  `declared` meaningless.

## Revisit trigger

Reopen when **HUMAN-H2 provisions** (the real
tracker adapter's variant manifest replaces the
fixture in the AC-9 legs and DF-S5.6-1 closes),
when the H3 mediator lands a broker-side
`key_ref → bytes` resolution verb (D2's param
migrates), or when a second adapter variant
needs a capability or fault vocabulary
`WorkSourceAdapter` does not express.
