## Context

S5.5 lands the C3 orchestration depth that needed
Stage-4 data: T3 recursive orchestration with
`depth_cap ≥ 2` and `share`-mode children, the
scheduler binding `code`-owned delegate decisions
under profile-conditioned rules, the `bandit` /
`surface_prior` prior families with `PriorCell`
persistence and `prior_reset`, `voi_weighted`
allocation inside `adaptive_search`, `explain[]` in
the trace viewer, `lab/coordination-topology-v1`,
`three_way_text{ast}`, and `belief_divergence`
probes as profile rules. The two interrupted
workers left the bulk implemented (commits
`4f2e560`, `dfec1ff`); this run audited the
residue, closed the remaining legs, and had to
rule on the points below.

## Decision

- **The `voi_weighted` inclusion table is a ledger
  row, not a view.** Each allocation round appends
  `measurement.experiment.inclusion_probabilities`
  (`{record_id, strategy, estimator, round,
  per_plan, picked}`) to the experiment run
  *before* the pick is dispatched, registered as a
  durable, provenance-mandatory class (`Led`,
  `O::Events`) beside the rest of the run family.
  `charged_to = instrument` — the allocation draw
  is the harness measuring itself, never a billed
  arm observation (CC3; the pick is
  replay-sensitive, so the published table is the
  rebuild's source of truth).
- **`voi_weighted` stays confined to
  `adaptive_search`.** Any other design kind —
  including a held-out-touching spec — refuses
  `AdaptiveOutsideSearch` at registration; the
  confirmatory full-set order is untouched.
- **Cold starts are honest markers, not silent
  defaults.** `bandit`/`surface_prior` with an
  empty prior cell fall back to `rules` and stamp
  `bandit.cold_start` /
  `surface_prior.cold_start` in `rules_fired`;
  the trace-view `explains[]` row projects
  `fallback: true` from that marker, so a reader
  sees the degradation, never a fabricated score.
- **`prior_reset` is a ledgered boundary.**
  Provider drift / profile supersession appends
  `control.compute.prior_reset` (`O::Ledger`,
  provenance-mandatory) carrying
  `trigger_event_ref`/`trigger_class`; the
  subsequent bind reads unknown/empty priors and
  falls back to `rules` (AC-R-2.6.4-9).
- **Searched arms are `matched_total` or refuse.**
  `lab/value-of-compute-v1` gains a `bandit`
  policy level whose arms register only under the
  `matched_total` comparand group — an arm whose
  search budget the match cannot see is
  `IncommensurableMatch` under `matched_cap`
  (CC9). An *unfunded* `bandit` arm is not a
  searched arm: it cold-starts through
  `bandit.cold_start` and stays comparable under
  `matched_cap`. Learned variants keep a complete
  `search_budget` record, and claims stay
  conditional on `budget_match.status =
  matched`.
- **`belief_divergence` is provisional on the row,
  not just the render.** Every
  `BeliefProbeRecord` encodes `provisional: true`
  (decoding an absent flag yields `true` — the
  label is constitutive); the metric declares
  `requires_observability = model_io` and renders
  `n/a{observability}` without it; the judged and
  deterministic detector strata stay separate
  members of the fold and never average
  (AC-R-2.7.2b-6).
- **`verification.belief.probe` is durable +
  provenance-mandatory.** The class registers in
  the class table with a `hint` hosted lowering —
  the same treatment as the other verification
  rows — even though the runtime emitter is the
  `belief_probe` `ProfileRule` firing (the
  telemetry fold consumes the class today).
- **Depth is a typed gauge, not a runtime
  check.** `T3Recursive{depth}` binds child
  `delegation_depth` capacity at `plan` — a child
  whose cap cannot carry the declared depth
  refuses `SpawnRefused::Depth{depth, cap}` (an
  under-capped child is a typed refusal, never a
  mid-run surprise); `share`-mode children run
  under the K-2 mandatory HLC and carry
  `reserved_keys`, `topology_ref`, and the
  `code`-owned spawn label in their
  `control.subagent.spawned` rows.
- **`three_way_text{ast}` joins the merge-policy
  arm.** `TAGGED_CST_GRAMMAR` parses tagged-CST
  spellings; a three-way merge that cannot join
  two sides degrades through the typed merge
  error channel, never a silent pick.

## Consequences

- The allocation audit trail is complete: any
  experiment run under `voi_weighted` can be
  replayed to the same pick from the ledger alone
  (INV-9 rebuild equality is asserted by test).
- A profile/provider change can never leave stale
  priors silently steering decisions — the reset
  row is on the ledger plane (`O::Ledger`) so the
  provenance chain names the trigger event.
- The recipe's comparand discipline means the
  `bandit` contrast can never claim a search
  result it did not fund; the cost is a narrower
  claim set (H3 holds only under
  `matched_total`).
- `belief_divergence` numbers are single-origin
  by construction — downstream consumers must not
  treat them as corroborated counts (ADR-0047 D6
  precedent).
- New owned vocabulary — the two event classes,
  `bandit.cold_start`/`surface_prior.cold_start`,
  `fallback` in `explains[]`, `matched_total`
  group naming, `SpawnRefused::Depth` — is
  additive (CC8) and stamped in the catalogue /
  class table / schema.

## Alternatives considered

- **Projecting inclusion probabilities in the
  experiment view instead of a ledger row.**
  Rejected: the pick must be reconstructable from
  the event stream alone (INV-9); a view-only
  projection leaves the draw unaccounted (CC3).
- **Averaging judged + deterministic probe
  strata into one divergence count.** Rejected:
  the strata have different provenance grades;
  merging them fabricates precision the detectors
  do not share (the AC's "never merge" clause).
- **Emitting `provisional` only at render.**
  Rejected: a consumer folding raw rows would
  lose the label — constitutive encoding keeps
  the guarantee under any view.
- **Funding the `bandit` arm under
  `matched_cap`.** Rejected: a searched arm's
  warm-up spend is invisible to the configuration-
  level match — exactly the incommensurable-budget
  hole `matched_total` exists to refuse (CC9).
- **Runtime depth checks at `spawn`.** Rejected:
  an under-capped child would fail mid-run after
  parent rows are committed; binding the gauge at
  `plan` keeps the refusal before any effect
  (CC2/CC10).

## Revisit trigger

Reopen when the belief-probe runtime emitter and
the reconciler land (the `verification.belief.
probe` class row's flags should be re-checked
against the emitted shape, and `provisional`
should lift only under a corroborating stratum —
ADR-0047 D6's condition), and when a sixth
topology or a second adaptive strategy needs
`depth`/`round` parameters the current gauges do
not express.
