# ADR-0266: S2.4 egress-mediation rulings — resolve-only attribution tokens, anti-laundering destination coverage, charge-before-wire, durable ordering, ask/endorsement amendment leases, retained-rotation masks, revocation-intent-as-egress, and fork placeholder virtualisation

- **Status:** Accepted
- **Date:** 2026-09-19
- **Ticket:** S2.4
- **Requirement ids:** R-2.8.3 · R-2.8.4
  (AC-R-2.8.3-{2,4–6,9} · AC-R-2.8.4-{2,4,6–7}; LT-02/04/05/06/09)
- **Spec:** §5g.3 (credential mediation, rotation, snapshot
  virtualisation) · §5g.4 (the egress mediator, `decide_egress`,
  `security.egress.*`, `network.calls`) · ADR-0057…0062 (the owning
  rulings) · ADR-0026…0029 (events/ids) · ADR-0058 (credential rows)
- **Rung (ADR-0024 obligation):** **C0** — the mediator, the broker
  mediation ops, and the durable `security.egress.*`/`security.credential.*`
  surfaces are Stage-2/C0 machinery; nothing tier-gated is added
  (`tier-c1` rows like `hh-ledger` ops already carry their own gates).

## Context

S2.4 lands the egress mediator (PDP in `hh-containment`, CDP/runtime in
`hh-env`) and the credential broker's mediation surface (`mediate`,
`minted_scoped`, `rotate`, `virtualize_for_fork`, revocation intents).
The spec fixes the normative decision order and the fail-closed
invariants; the mechanism choices below were left to the ticket:

1. **What an attribution token *is*.** §5g.4 requires every mediated
   call to resolve to a resolvable `effect_id` + environment handle
   (AC-R-2.8.4-6) but does not fix the token's carrier or authority.
2. **Which sentinels may be substituted on an allow.** An allow rule
   declares `credential_bindings` candidates; whether the rule's
   declaration alone authorizes substitution (a laundering channel) was
   unspecified at mechanism level.
3. **When `network.calls` is charged.** The budget must equal allowed
   decisions per effect (AC-R-2.8.4-6), but charging after the wire
   leaves a delivered-but-uncharged window.
4. **The durable ordering of `requested`/`decided`/credential rows.**
   Spec requires the rows; the crash-position semantics were the
   ticket's.
5. **How an ask-endorsement changes policy.** A `lease` endorsement
   must amend containment for the run without exceeding the amendment
   ceiling (§5g.4 + the Stage-1 amendment floor).
6. **How rotation and destination revocation are plumbed.** CAS
   semantics, mask retention, and whether revocation rides a side
   channel or the mediated path.
7. **TLS.** `tls.terminate` is `false` at this stage; the transport's
   honest posture needed a ruling.
8. **Fork placeholder virtualisation.** DF-S1.13-2's close criteria:
   fresh `(child_run, binding)` spellings, old spellings resolve to
   nothing, `leak_scan` empty.

## Decisions

- **D1 — the attribution token is a resolve-only proxy handle, never
  authority.** `TokenMinter` (kernel-side) mints opaque spellings bound
  to `(run_id, env_handle_id, effect_id, expires_at)`;
  `EgressMediator::tokens` is a `TokenResolver` — resolve-only.
  `ResolveOutcome::{Resolved, Unknown}`; expired or
  env/effect-mismatched tokens collapse to `Unknown` ⇒
  `deny{source: unattributed}` durable, refused fail-closed
  (`lt09_unattributed_request_denied_fail_closed`). The token confers
  *attribution*, never permission (CC2): all authority still flows from
  the policy decision.
- **D2 — anti-laundering by destination coverage, not rule
  declaration.** The allow rule's `credential_bindings` are *candidates*
  (`credential_binding_candidates` on the decision). The mediator
  substitutes a sentinel only when the sentinel's own
  `DestinationBinding` covers the normalized host (and the request's
  env handle is the binding's). An unbound destination ⇒
  `Refused{out_of_scope}` with `security.credential.denied`; a path the
  binding does not cover ⇒ `ambiguous_path` (`lt02_*`). The sentinel
  therefore never appears on the wire except substituted for a host in
  *that* credential's binding (AC-R-2.8.4-2's egress half).
- **D3 — `network.calls` is charged before the wire, attributed to the
  decided row.** Forwarding pre-gates budget availability; the durable
  `control.budget.consumed{key: network.calls}` row names the decided
  event. A budget refusal ⇒ no byte reaches the wire
  (`network_calls_exhaustion_gates_before_wire` — the transport log is
  empty). Never delivered-but-uncharged (CC9 matched-budget).
- **D4 — durable ordering is fixed: requested → decided → credential
  → wire.** `security.egress.requested` (with `sentinel_refs`) commits
  before `decide_egress` runs; `security.egress.decided` commits before
  the refusal or the forward is visible; the broker's
  `security.credential.used`/`denied` rows are durable before carrier
  substitution. A ledger, broker, resolver, or budget failure refuses
  closed — a crash anywhere leaves the true durable prefix, never a
  delivered call with no row (AC-R-2.8.3-10's mediator half).
- **D5 — endorsement is a runtime resume; `lease` mints a bounded
  amendment.** `default_unmatched = ask` parks a permission ask
  (charged to `approvals.requested`; exhaustion converts the ask to
  `deny{approvals_exhausted}` — AC-R-2.8.4-7's budget arm).
  `endorse{allow_once}` forwards once with no cache insert;
  `endorse{deny}` refuses durably; `endorse{lease}` mints a
  narrowing-only `security.containment.amended` row under the
  amendment ceiling and forwards — the amendment *is* the "amended
  replicate annotated" record. The approval cache (`ApprovalCache`) is
  narrowing-only, `idp_id`-keyed over `(host, port, protocol, method,
  scope)`, version-pinned to `policy.version_id`, and only consulted
  when `amendment.session_cache` opts in — a hit emits
  `source: approval_cache`; it can never widen a deny to an allow.
- **D6 — rotation retains every historical mask; revocation rides the
  mediated path.** `CredentialBroker::rotate` CAS-checks
  `expected_revision` (stale ⇒ `Conflict`, LT-06), registers the new
  value out-of-place, and retains *every* prior value in the mask set
  so a rotated-out value still trips `leak_scan`/`leak_detected`.
  `RevokeIntent{binding_id, channel_id, host_pattern,
  revocation_path}` is dispatched as an ordinary mediated egress call
  to the binding's declared `revocation_path` — the destination-side
  revocation flows through the same decide/charge/durable path, never
  a privileged side channel (`lt05_revoke_fences_replay_minted_and_destination`).
- **D7 — TLS termination is deferred honestly.** `LocalHttpTransport`
  is plain HTTP/1.1 over `TcpStream` to the *resolved, re-checked*
  address; `tls.terminate` is always `false` this stage and the
  mediator never claims TLS inspection. Row **DF-S2.4-1** records the
  TLS-terminating transport as owed work.
- **D8 — fork virtualisation re-mints `(child_run, binding)`-scoped
  placeholders.** `CredentialBroker::virtualize_for_fork` mints a fresh
  placeholder per bound binding for the child run; snapshots persist
  placeholder spellings only; `EnvDriver::rebind_credentials_for_fork`
  installs the child-side bindings. The parent's spellings resolve to
  nothing in the child; `leak_scan(forked_run) = ∅`
  (`lt09_snapshot_placeholders_only_fork_virtualizes`) — closing
  **DF-S1.13-2**.
- **D9 — the token rides the request object, not an event channel.**
  `EgressRequest.token` carries the handle; the mediator resolves it
  against the kernel mint table at request time. No credential or
  token material is ever read from event payloads (CC2/CC5).
- **Schema additions (additive, CC8):** `security.containment.amended`
  registered as an audit class (emitted by D5's lease arm);
  `security.egress.requested` gains the `sentinel_refs` audit member
  (placeholder spellings — refs, never values; SV-5).

## Consequences

- A denied or unattributed request performs zero credential work and
  zero wire work — every refusal path is durable-first and fail-closed.
- Fresh DNS resolution happens *after* the policy check and is
  re-checked against the non-public/deny guards — a name that resolves
  to a private address is denied on the answer, not the spelling
  (DNS-rebinding/SSRF pivot closed).
- The hermetic lane is real: `LocalHttpTransport` dials loopback over
  `TcpStream`; the LT-02 positive test observes the substituted carrier
  on a real socket (the 158e56e gate authorized local fixtures).
- `tls.terminate = false` means mediated traffic is plain HTTP at this
  stage — acceptable for the loopback lane, explicitly owed (DF-S2.4-1)
  before any non-loopback deployment.

## Alternatives considered

- **Bearer-authority tokens** (the token *is* the effect's authority)
  — rejected: it would conflate attribution with permission (CC2) and
  make token replay an authority replay; resolve-only handles keep the
  policy decision as the sole authority.
- **Charge-after-wire accounting** — rejected: a post-wire charge
  failure leaves a delivered call with no budget row; pre-gating is
  the only fail-closed order (CC9).
- **A dedicated revocation side-channel** — rejected: it would bypass
  `decide_egress`, `network.calls`, and the durable `security.egress.*`
  rows; revocation is egress and must be mediated like egress.
- **Rule-declared substitution authority** (any sentinel may
  substitute once the rule names the binding) — rejected: that is the
  laundering channel AC-R-2.8.4-2 forbids; coverage must come from the
  credential's own binding.

## Revisit trigger

Reopen when a TLS-terminating transport lands (DF-S2.4-1 — D7's plain
HTTP posture must not survive contact with non-loopback egress), when
the protocol-level `fork` op lands (S2.9 — D8's
`rebind_credentials_for_fork` gains its real call site), or if the
approval-cache scope set ever grows beyond `{session, run}` (D5's
narrowing-only invariant must be re-argued for any wider scope).
