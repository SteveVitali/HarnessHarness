## Goal

Close G2 and G21/G1 (spec §7.3): prompt templates compile under the std-only `hh-tmpl/1` subset with environment-dependent slots filled at run time from a ledgered in-cell probe (REQ-XE-112, REQ-XE-113); and, when a session is armed with a compiled `ModelSurface`, the model port renders the request from that surface — layout sections with declared provider roles including `system` — through **one** renderer, while an unarmed session renders byte-identically to today (REQ-XE-103, REQ-XE-104). This row owns that renderer; R6.36 and R6.37 extend it and never re-implement it (CC1).

## In scope — deliverables

**Stage 1 — E2-T3 (`hh-tmpl/1`; own commit).**
1. A std-only `hh-tmpl/1` engine in the home AR-23 fixes: `{{ ident(.ident)* }}` substitution, `==`-literal conditionals (`if`/`elif`/`else`/`endif`), Jinja whitespace control, strict undefined; any construct outside the subset fails compile as `UnexpressibleSurface`. No new dependency. *(REQ-XE-112)*
2. A subset-parse test of the pinned `mini.yaml` system and instance templates that lists their variables; if a pinned template needs a construct beyond the subset, extend the grammar under AR-23 (amend the ADR by dated note) before this stage lands. *(REQ-XE-112)*
3. Run-time slot fill: `task` and the `uname.{system, release, version, machine}` slots are filled at run time from a ledgered, read-only, setup-phase in-cell probe, never at compile time; an unfilled slot at run time is a typed refusal before any model call. *(REQ-XE-113)*

**Stage 2 — E2-T2 (a) (the single renderer; own commit).**
4. Arm `GatewayModel` with the session's compiled `ModelSurface` and renderer spec, compiled at arm from the sealed definition and bound profile through `hharness_compiler::compile`; with a surface armed, the request (layout sections, transcript) is rendered from it; with none armed, the pre-change path renders byte-identically. *(REQ-XE-103)*
5. `prompt_layout.section_templates{slot_id → Text leaf}` in `lower_layout`, placing specific `Text` leaves into specific sections with declared provider roles, including `system`. *(REQ-XE-104)*
6. Regression battery (e.g. `crates/hh-compiler/tests/r6_35.rs` + `crates/hh-embed/tests/r6_35.rs`).
