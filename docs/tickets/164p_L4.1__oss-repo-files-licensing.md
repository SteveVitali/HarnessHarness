## In scope — deliverables

1. `LICENSE-MIT`, `LICENSE-APACHE` (standard texts; copyright line naming the operator as the repo owner); workspace +
   every crate/plugin manifest `license = "MIT OR Apache-2.0"` (scripted edit; `cargo metadata` shows no crate without it).
2. `THIRD_PARTY_NOTICES.md` — `ring` (its ISC/OpenSSL-derived terms), the rustls graph, `webpki-roots` (MPL-2.0 data —
   state it), `tempfile` dev-dep; generated from `Cargo.lock` by a committed script so it cannot drift.

   (build/test commands, the build-memory workflow, DCO-or-not stated, dual-license contribution clause),
   `CODE_OF_CONDUCT.md` (Contributor Covenant 2.1), `CHANGELOG.md` (Keep-a-Changelog; `0.1.0` unreleased section).

5. Living-doc scrub — personal paths replaced by repo-relative or `<skills>`-style placeholders in the living set only;
