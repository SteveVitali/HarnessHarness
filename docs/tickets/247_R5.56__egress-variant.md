## Goal

The S4 egress supplement ran its `declared_deps` cells on a scratch helper binary (`/tmp/s4-helper-egress` — `crates/hh-helper/src/bin/hh_helper.rs` verbatim plus a `--network <none|bridge>` / `S4_HELPER_NETWORK` knob) because the stock helper hardcodes `network: false` at `crates/hh-helper/src/bin/hh_helper.rs:92`. This ticket sanctions that profile as a first-class variant: a *declared* `declared_deps` egress admission drives `cell_network: bridge` on the podman cell and `policy_net_mode: public` on the attached containment policy, with the N4-honest `residual_channels[host_bridge]` declaration recorded (kind, statement, owner, closer). Only slots whose tasks declare runtime egress deps may run this profile; `none` stays the default posture — a cell spec that does not declare the profile produces argv byte-identical to today's hardcoded `--network none`.

## In scope — deliverables

1. **`hh-helper` first-class flag** — `--network <none|bridge>` on the binary (default `none`), plumbed to `PodmanBackend.network`. Absent flag = the hardcoded posture byte-identically (no behavior change for any existing caller); an unknown value is a usage failure, never coerced.
2. **Policy-driven cell network** — `EnvDriver::start_helper` derives the podman network from the attached containment policy: `net.mode = public` ⇒ `--network bridge` in the helper extra_args; `none`/`mediated` postures unchanged (`mediated` stays its own declared posture — it is not silently widened to bridge).
3. **The `declared_deps` profile machinery** — the declared admission that produces the honest policy for an egress-declared task: `policy_net_mode: public` + `residual_channels[{kind: host_bridge, owner, closer, statement}]` recorded verbatim on the cell spec (`egress_profile: declared_deps` + `cell_network: bridge` echo the supplement's field spellings). Reuse the `hh-containment` decls (CC1 — one policy codec); `PublicWithoutResidual` still fires when a public mode lacks a declared residual.
4. **ADR** — admits the scoped `bridge`-network cell profile as a first-class variant: provenance (the sanctioned scratch variant, superseded), the `declared_deps`-only scope, the N4 residual declaration, `none` as the preserved default, and the honesty bound (bridge declares `public` — never labelled `none`/`mediated`).
5. **`crates/hh-env/tests/r5_56.rs` (or owning battery) + helper tests** — the regression battery below.
