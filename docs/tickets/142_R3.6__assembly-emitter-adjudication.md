## In scope — deliverables
1. Per-code adjudication of all eleven: for each, either (a) land the producer — the code mints
   from a real document/stage path with a fixture moved to `F` — or (b) rule it permanently
   external/unemittable with the sharpened reason recorded in the INDEX row (and an ADR where
   the ruling is a design decision, e.g. "this code can only be minted by a component class not
   in the grammar").
2. The adjudication is honest in both directions: no fixture is forced through a path that
   cannot emit the code for real, and no `U`/`X` row keeps a vague reason — each ruled row's
   reason states the precondition that would re-open it.
3. The INDEX↔`Code::all()`↔`kern_code` drift discipline extended so a `U`/`X`→`F` promotion or a
   new permanent-external class cannot drift silently.
4. DF-S1.9-2 discharged `DONE` with dated evidence; BL-10 closable; R-2.1.4's residual verdict
   re-stated.
