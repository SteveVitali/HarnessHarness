## In scope — deliverables

1. The pass's `sweep-registry` record (new exploration identity, R6.43's schema + validator reused): every Tier-1 level declared (factor, typed paths, baseline/level values, tier, exercising condition, activation metric, forecast source, cost prior, dependency tickets, upstream locator or "HH-only"); Tier-2 recorded with reasons; frozen with its hash for R7.2's pre-registration. *(consumes REQ-XD-201/202 machinery; REQ-XD-225 admission check)*
2. Seal the remaining Tier-1 levels plus the effort-lane and compaction-composite levels through enumerate→seal, each with its declared-delta/liveness check. *(machinery is R6.43's; this row lands the levels)*
3. Tier-2 admission check: a candidate enters only a later exploration identity, after its dependency lands and its forecast activation meets the floor. *(REQ-XD-225)*
4. Effort lane: a declared lane parameter of the level document (or an AR-26 factor kind), proxy-pinned, requested and applied values per call; any call whose applied value differs from the declaration makes the level ineligible for selection. *(REQ-XD-204)*
5. The W-rule derivation: compute the token-record distribution F over committed **non-outcome** baseline records; select W ≥ 32 768 targeting F(W) ≥ 0.5; withhold if F(32 768) < 0.25; each compaction level is the declared composite of strategy S and `window_cap` W applied identically to every task and replicate; task-conditioned caps and input padding refuse. Emit the derivation record (F, the chosen W, the refusal fixtures). *(REQ-XD-205 + REQ-XE-127)*
6. The §4.2-generic activation fold computing per-level activation incl. exact counterfactual activation for deterministic renderer/executor knobs; `hh-activation/1` unchanged. *(REQ-XD-208)*
7. The inert forecast: before X1 spend, a forecast from non-outcome baseline records withholds levels below the activation floor (proposed 0.25) as `withheld{inert_predicted}`, retained in the registry with the forecast; the input manifest refuses outcome fields. *(REQ-XD-209)*
8. Regression batteries (e.g. `crates/hh-lab/tests/r7_1.rs`).
