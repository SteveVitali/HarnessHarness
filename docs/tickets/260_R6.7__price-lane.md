# R6.7 — Integer-µ$ pricing unit and the Ollama lane (raw forward, auth from `auth_kinds`)

## Goal

Make the spend unit and the upstream lane that every paid consumer reads exist before the proxy is built. PRICE: `PricingTable` carries `rate_unit`, prices a call as one exact sum rounded once to the µ$, itemizes roles with a `rounding` role, refuses non-integral rates as `NoPrice{unrepresentable_rate}`, and carries the glm-5.3-flash row (AR-09; REQ-XC-116). LANE: Ollama same-dialect lanes over a new raw forward primitive on the gateway HTTP transport, with the auth header derived from the lane's declared `auth_kinds` (Bearer on every Ollama surface) and the credential confined to the forwarding process (AR-11; REQ-XC-104).

## In scope — deliverables

**Stage 1 — PRICE** (commit checkpoint `R6.7 stage 1/2: PRICE` before Stage 2).
1. `PricingTable.rate_unit ∈ {micro_per_token, micro_per_1k_tokens}` (default the former), exact per-call sum, one rounding (ceil to µ$), roles itemized by floor plus a `rounding` role; a non-integral rate refuses `NoPrice{unrepresentable_rate}`. [REQ-XC-116, REQ-XC-008]
2. The glm-5.3-flash row at 150 / 30 / 500 µ$ per 1k tokens (input / cached input / output) with `valid_from` and source cited (§4.1). [REQ-XC-116]
3. `DeclaredPricing` either derived from `PricingTable` or declared out of scope for paid studies in AR-09; no second pricing representation (CC1). [REQ-XC-116]
4. The r4_5d µ$ comment correction (design F11), only if it is a comment; no test semantics change.
5. ADR for AR-09.

**Stage 2 — LANE.**
6. Ollama lane dialects for OpenAI chat and Anthropic Messages (Responses is conditional and not built in Round 6, C-32), declared alongside the hosted dialects. [REQ-XC-104]
7. A raw forward primitive on the gateway HTTP transport (same dial, TLS and `hh-wire` codec) that sends request bytes verbatim and captures the raw response (JSON and SSE); additive `hh-wire` pieces it needs (design 33 §4 hint 2). [REQ-XC-104]
8. The auth header derived from the lane's `auth_kinds`, not the wire family: `Authorization: Bearer` on every Ollama surface, Messages included; existing dialects keep their current auth bytes. [REQ-XC-104, REQ-XC-001]
9. The credential reaches only the forwarding process through the existing credential port; no returned capture, record or error carries it. [REQ-XC-104, REQ-XC-001]
10. ADR for AR-11.
11. Regression batteries in the owning crates (e.g. `crates/hh-budget/tests/r6_7.rs`, `crates/hh-gateway/tests/r6_7.rs`).
