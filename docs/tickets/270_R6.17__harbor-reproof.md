Make the O surface a pinned, recorded, read-only external tool and build — but not run — the $0 oracle re-proof: one program-wide Harbor pin chosen by the Q-X41 rule at dispatch and held in AR-04's tool-admission record with its `uv.lock` host venv; a runner-written, committed job config (`-r 0`, never `--upload`, `skip_install` with the layer digest when the pin has it); identical image bytes on both surfaces with drift withheld; read-only ingest into `hh-harbor-ingest/1` / `hh-harbor-trial/1`; and the observe → freeze → prove driver over O, H-pub and H-allow with its admit rule, discordance register, packet label and a registered `reproof` live-verify leg, all proven on fixtures so W1 (R6.32) only executes it.
