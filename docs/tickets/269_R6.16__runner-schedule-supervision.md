## Goal

Complete `hharness-runner` so that it can run a window unattended and honestly: it packs slots first-fit in the engine's recorded order under the C rule, supports the two declared schedule kinds and their composition, applies each protocol's declared reattempt policy through the engine (never its own counter), stops admitting at the dead-man cut-off while harvesting incrementally, sweeps only its own labelled containers — and it supervises the model proxy and the egress mediator as separate sole-writer processes over the Json control channel, minting and revoking per-slot tokens, granting each cell exactly its sockets, and carrying the proxy root pool forward from harvested ledgers.
