## Goal

Extend R6.35's single compiled-surface renderer (never a second one, CC1) so that `tools[]` carry the compiled description and the capability `input_schema` verbatim (G3), the completion surface appears only when declared or required by the `stop_rule`, and `tool_choice` is sent only when declared (G4) — REQ-XE-105, REQ-XE-106. Then add the pure typed renderers AR-23 admits: `json_head_tail@1` / `text_head_tail@1` result renderers with typed-parameter constants (G8, REQ-XE-110) and typed `error_format` failure classes (G9, REQ-XE-111). Wiring the result renderer into the live observation path is R6.37.

## In scope — deliverables

**Stage 1 — E2-T2 (b) (extends R6.35's renderer; own commit).**
1. `tools[]` render from `ModelSurface.tools`: the compiled description and the capability `input_schema` carried verbatim, including member descriptions, with no re-derivation from `ParamSpec`. *(REQ-XE-105)*
2. The completion surface (`hh.submit`) is armed only when the definition declares it or its `stop_rule` requires it; `tool_choice` is rendered only when the `model_port` slot declares it (R6.34's member); the legacy default is unchanged. *(REQ-XE-106)*

**Stage 2 — E2-T4 (a) (pure renderers; own commit).**
3. `ResultRenderSpec` members `json_head_tail@1{threshold, head, tail, unit ∈ {chars, utf8_bytes}, fields, json_style}` and `text_head_tail@1`, with typed-parameter constants (sweepable, never string edits). *(REQ-XE-110)*
4. `error_format` typed format-failure classes rendered from `Text` leaves with slots: `no_tool_calls`, `args_unparseable{error}`, `unknown_tool{name}`, `missing_param{name}`, `output_truncated{finish_reason}`; batch-scope failure declarable. *(REQ-XE-111)*
5. Regression battery (e.g. `crates/hh-compiler/tests/r6_36.rs`, `crates/hh-embed/tests/r6_36.rs`).
