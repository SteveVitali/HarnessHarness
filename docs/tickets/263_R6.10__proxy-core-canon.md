## Goal

Build the model proxy of [§4.1–§4.3](../experiments-spec.md#s4):
- `hharness-hosting::proxy` plus an `hh-model-proxy` binary, depending only downward and controlled by the runner over a Json channel;
- a per-slot token gate and the §4.2 route table;
- same-dialect pass-through that applies only declared, recorded mutations;
- the declared field policy and a path-qualified `GenParamPolicy` (AR-10);
- `hh.model_io/1` receipts with the additive `proxy` member, deposited in the §4.3 ledger order through the phase proxy run's fenced writer. Bytes reach the cell only after the terminal row is durable, and each receipt is `leak_scan`ned first (AR-08).

Stage 2 adds K1: the versioned canonicalization allowlist `hh-l1-canon/1` (C01–C07, [§7.4](../experiments-spec.md#s7)) as a `hharness-wire` module over `Json::to_canonical_string`, with golden and mutation tests.

## In scope — deliverables

**Stage 1 — PROXY-CORE-a** (commit checkpoint `R6.10 stage 1/2: proxy core` before Stage 2).
1. The `hharness-hosting::proxy` module and `hh-model-proxy` bin. Edges go only to gateway, budget, ledger, secrets, wire and tls (internal, within REQ-XC-101's list; no external dependency). The removability hosting leg is reconciled by a recorded facade carve-out or a dated DF/BL row, with where the script runs recorded; the leg then passes. [REQ-XC-101]
2. The Json control channel the runner launches and drives (configure the phase run and slots, register and revoke slot tokens, stop), with an integration test. Runner-side supervision is R6.16's. [REQ-XC-101]
3. A per-slot token gate (Bearer, or `x-api-key` on Messages, in; the lane's Bearer key out). Token helpers live in one lower-layer home with no hosting → embed edge (design 33 ADR-C2-A; CC1).
4. Routes per §4.2: chat completions and Messages (streaming and non-streaming; a streaming request gets the typed `Unsupported{release_mode: buffered_heartbeat}` refusal until R6.11, Notes), `GET /v1/models` forwarded, `count_tokens` as a typed Anthropic-shape 404, and Responses not built (C-32). Every other route is 404, receipted `refused_route`. The closed header forward allowlist applies, and auth headers are never recorded. [REQ-XC-105, REQ-XC-206]
5. Same-dialect pass-through over R6.7's raw forward leg, applying only declared mutations, each recorded with its JSON path and requested/applied values. [REQ-XC-103]
6. Field policy per §4.2, declared in the lane document: strip-with-notice versus a surface-shaped 400. [REQ-XC-106, REQ-XC-012, REQ-XC-209]
7. `GenParamPolicy` with path-qualified `pin` and per-surface `params_scope` (AR-10). The program lane pins `model` and the effort path to the slot level, forwards harness sampling parameters, injects no defaults, and records requested and applied effort per call. [REQ-XC-107, REQ-XC-002, REQ-XC-213]
8. The receipt:
   - an `hh.model_io/1` blob with the additive `proxy` member `hh.model_proxy.receipt/1` (§4.3 members);
   - reasoning kept separate from visible content, and the raw tool-call form beside the parsed form;
   - raw downstream and upstream bytes as separate content-addressed blobs.
   Deposits follow §4.3 ledger steps 1–7 through the phase proxy run's fenced writer, and bytes are released only after step 6. The two AR-08 measurement classes are registered once in `classes.rs` (CC10). [REQ-XC-108, REQ-XC-013]
9. `leak_scan` before every deposit, against a mask set of the Ollama key and all slot tokens. An Ollama-key hit refuses the write and stops the phase; a slot-token hit is recorded and permitted in the raw receipt. [REQ-XC-109]
10. A per-call cost derivation label, priced with R6.7's table. With a provider cached count it is `estimated_from_pricing` with the actual split. Without one it is an upper-bound `estimate` with `cache_read` unavailable, never 0. [REQ-XC-007]
11. Rewrite versioning: every transformation is versioned and enters the participant identity hash; conformance fixtures pin each rewrite. [REQ-XC-208]
12. ADRs for AR-08 (recording S-9 as INTERP; an amendment is raised to the operator, never adopted silently) and AR-10.

**Stage 2 — K1.**
