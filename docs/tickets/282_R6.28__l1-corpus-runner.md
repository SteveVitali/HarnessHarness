## In scope — deliverables

**Stage 1 — K2 + K3** (own AC block, tests and commit):

1. Recorded-response driver: drives each original unmodified against a recorded-response endpoint through its own base-URL setting; for mini-swe-agent the endpoint is reachable from the cell only under the declared egress profile (REQ-XE-004).
2. Observation-replay executor: an exec-seam double serving recorded raw observations `(output, returncode, exception_info)` per step, with the declared, golden-tested inverse of the mini.yaml observation template as the fallback; refuses on a sequence overrun (design 36 §1.2).
3. Synthetic branch fixtures BM1–BM19 covering §7.4's branch list, in a recorded-format schema carrying `provenance` (contributes REQ-XD-107).
4. Turn-1 census generator over a manifest (generator only; the census executes in W1 (a)).

**Stage 2 — K4:**

5. L1 runner: L1.0 (O twice against REPLAY(S) in fresh cells; defines s(S)), L1.1 (H with REPLAY(S) responses and the observation-replay executor; whole trajectory; gate), L1.2 (H with REPLAY(S) and live execution in a fresh HH cell; gated on requests 1…s(S)); first divergence fails (REQ-XD-103).
6. Equality: byte equality of `hh-l1-canon`-canonicalized upstream-bound requests captured inside the proxy after the lane's transforms, per request; equal parsed actions per step, request count, termination class and submission; no extra request; downstream equality reported as a diagnostic only (REQ-XD-104).
7. `hh-l1-diff/1` durable record per divergence; `hh-l1-conformance/1` with the coverage table, stable-prefix histogram and an L1 pass id bound to the exact H version/digest; a missing BM branch or census entry makes the gate refuse (REQ-XD-109; contributes REQ-XD-102, REQ-XD-107).
8. Stage-tagged tests (`r6_28.rs` in the runner's home), a toy O/H harness pair for fixture verification, run ledger, PR body.
