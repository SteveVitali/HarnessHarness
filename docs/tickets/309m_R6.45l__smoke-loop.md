   - The declaration (`hh-compute-decl/1` `mode: full`, the recipe verbatim) + quote appended to the GATE-G28i readout as minted, before that window's PROV; PROV authorization-match checked before any create.

2. **In-window iteration (A1):** on a failure, diagnose from the cell report, verifier streams and mediator store; patch on the smoke branch, rebuild only the affected binary, re-run only the affected cell, inside D. **Every in-window patch must, before Wc9:** land as a commit with a hermetic regression that fails without it (this row's PR or a follow-up insert), and be added to the conformance leg where real-client-shaped.
3. **SMOKE-PASS check** (all of): every smoke member's H-allow cell classified *decided* (no `verifier_unavailable:*`), reward 1; the mediator store shows zero 5xx replies and no tunnel with `close_cause` other than `eof`; `denied_hosts` empty or exactly the hosts epoch policy denies by design; `query-optimize` H-pub decided, reward 1; per-member H-allow verify walls recorded (they feed Wc9's D sizing).
4. **Records:** `docs/build/reports/smoke/<date>-smokeN.json` (summary + cited excerpts + digests) and a run ledger per window; PHASE_SPEND compute-estimate rows `window: smokeN`; settlement per the window pattern; every artifact labelled per A1; raw run trees stay in `~/hh-retained/smokeN` uncommitted (A7).

- SMOKE-PASS → tear down → settle → records → the next row (GATE-G28j).
- Not passed and smokes remain → next smoke; each smoke starts with what the previous one learned, written down first.
- Not passed after smoke 3 → `blockedOn: H-allow smoke envelope exhausted` + a §6-options diagnosis readout; no further spend.
