## Cells, binds and the executed packet

Per subject (one cell each, fresh store/workspace/marker/sink per §5.2):

1. **provision+attach** — `EnvDriver::provision(LocalContainer, alpine:3.20 unpinned-tag)` + `attach(Ep2Model, FailClosed)` spawns the real podman cell (`hh-env-<env_handle_id>`, unique per call); `OpsObserver` opens `before_launch` + `Sentinel` + `MarkerSink` on the cell's ops dir.
2. **task work** — one mediated `Dispatcher` dispatch (Π `Monitor` authorize → `HelperExecutor` → container exec) writes the instruction-declared submission bytes to `/work/submission.json` inside the cell — the `fs.write` surface's real act; `at_boundary` snapshot after dispatch; the instrument `probe()` verb is exercised on the same executor and recorded verbatim (ENOENT ⇒ withheld).
3. **seal** — `seal_workspace` lands `submission_seal` (end-state pin + participant-access revocation + `meters_sampled`) on the subject run; `after_quiescence` snapshot.
4. **collect+grade** — the artifact bytes read host-side (digest recorded); a `SealedSubmission` (digest-pinned `Submission`) graded through `OracleRunner` on a separate instrument run — `verification.oracle.invoked` durable **before** execution, the spawned `hh-bench-adapter` `grade` op executes the unchanged oracle over the sealed bytes (digest-pinned binary), `verification.oracle.verdict` retains the mapped outcome (`Decided{reward_ppm}` | `OracleFailure`).
5. **controls** (instrument-side, same real oracle path — they control the grade chain's divergence): sanctioned correct output → `Decided 1e6`; plausible wrong contents with an existing file → `Decided 0` (valid zero, never oracle_failure); broken oracle (the real adapter invocation refuses — exit 2 error envelope) → `OracleFailure`. All three must differ; a failed negative control blocks acceptance.
6. **evidence join** — subject seal/detach/meters refs + instrument invoked/verdict refs + artifact digest ↔ `submission_ref` + `charged_to: instrument` attribution all resolve on the durable streams.
7. **retries** — ≤1 diagnostic setup retry per cell (helper spawn/container create/provision-class failures only — never a retried task act), each a new identity, every attempt recorded verbatim; a second setup failure leaves the cell `inconclusive{setup_failed}`, never silently replaced.

Packet: executed `hh-s1-useful/1` record → `docs/build/reports/2026-11-04-r5.43-s1-useful-*.json` — closed leg vocabulary `subject_a | subject_b | oracle_chain | controls | observer_probe | evidence_join | worksheet`; typed `verified | failed{} | inconclusive{} | refused{}` leg verdicts; disposition `executed | failed | inconclusive`; `useful_acceptance: marked` iff ≥1 subject artifact independently grades `Decided 1e6` else `withheld{no_independent_correct_artifact}` (a held acceptance, recorded — never fabricated); `carried_predicates` names the probe-verb gap verbatim; `attempts[]` retains every cell/setup/oracle attempt; `admission: bounded_s1_execution` — never S4/study/R2/R3/scientific efficacy.

Stops: any pin mismatch, podman/backend inconclusive-at-bind (no substitution — the cell goes `inconclusive{backend_unavailable}` honestly), mediation deny, sentinel violation, missing observer interval, artifact absent (a scored failure, retained), oracle-chain pin/digest mismatch, or worksheet blocker ⇒ typed verdict on that leg; integrity/confinement/unexpected destination/resource breach stops the run immediately; USD $0.00 always.
