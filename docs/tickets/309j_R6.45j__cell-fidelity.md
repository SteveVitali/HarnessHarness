## Scope (one line)

## In scope — deliverables

1. **D15 deadlines.**
   - Agent and verifier deadlines come from each task's `task.toml` (`[agent].timeout_sec`, `[verifier].timeout_sec`) in the pinned checkout, using the **same semantics as the pinned Harbor version** — read Harbor's code at the pin: timeout multipliers, the default when the value is absent, whether the agent deadline covers setup; record the exact source lines in the ADR.
   - `cfg.{agent,verify}_deadline_ms` become fallbacks only.
   - `cell-report.json` records `deadline_ms` and `deadline_source: task_toml|cfg_default` per phase.
2. **D17 kill on lapse.**
   - `exec`'s timeout path currently kills the host-side `podman exec` client and calls `terminate_group("agent")` for **every** phase. Replace that with termination of the **lapsed exec's own in-cell process tree**, whatever the phase — each phase exec runs as a process-group/session leader in-cell and the group is killed, or it is tagged with a unique per-exec marker walked for; no dependence on a cmdline pattern the phase's processes may not carry.
   - **Confirm death** by a `/proc` walk before `rm_glob`, the next attempt or copy-out.
   - Keep the stdout/stderr captured up to the lapse rather than returning empty vectors — a timed-out verifier still lands its streams as evidence.
   - Attempts never overlap; collected files belong to exactly one attempt and record the attempt number.
   - Re-check the agent phase under the same change: its `"agent"` pattern must still terminate the oracle/agent tree.
   - Confirm `max_grade_attempts` against the governing REQ and Harbor's behavior at the pin; change it only if the spec says so, otherwise record the observation.
3. **D18 audit.** Record HH cell cpu/memory limits against each re-proof member's `task.toml` `cpus`/`memory_mb`. If HH grants less than a task declares, raise the cell limit to at least the declared value (Harbor semantics) and re-check the packing/C rule; otherwise record parity.
4. **D19 / A5 classifier.**
   - Member roll-up and `reproof` classification: `allowlist_gap{host}` only with a named denied host; H-allow < R/R with `denied_hosts: []` becomes `machinery{h_allow}`.
   - Re-fold the Wc4–Wc8 records' member verdicts under the amended rule **as an appended, dated re-classification record** — the register is append-only and never rewritten.
