**Stage 2 — RUNNER-CHECK** (commit checkpoint)
4. O-surface routing: R6.17's job-config writer extended (CC1), one Harbor job per O slot, per-slot token and slice, model calls through a host relay to the HH proxy, never Ollama directly; no key in any Harbor environment (REQ-XC-326).
5. R-replay comparator: configuration equality (argv with secrets elided, env-name set and non-secret values, config-file sha256s, image digest, detected version) and canonical downstream request-sequence equality modulo declared masks via R6.12's canonicalizer, with a declared-divergence register; honours REQ-XC-306's "not image-identical" label (REQ-XC-325).

7. Phase-3 O participant composition: the frozen original mini-swe-agent layer under the phase-2 hosting path (same proxy, VM, verifier channel as H), and a records check that refuses unless the original's R-replay record exists and precedes the G-L1 readout (REQ-XH-031).
8. An `#[ignore = "live — ADR-0363: …"]` $0 R-replay test (`harbor run -a <agent> --ak skip_install=true` against the HH cell on the same layer and recording), executed only in W1.
