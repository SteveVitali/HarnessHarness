## In scope — deliverables

1. **The conformance harness + red baseline (first).** `scripts/egress-conformance/`:
   - **Topology:** one Linux container from `ubuntu:noble` (the task images' family) containing the chain-tip `hh-egress-mediator` + `hh-cell-relay` built for that arch; the mediator started exactly as `hh-w1 h-run` starts it (same argv shape; same policy **bytes** rendered from the current freeze by the same code path — expose a small `hh-w1 render-policy` subcommand if needed rather than re-deriving it); the relay on `127.0.0.1:3128`; `http_proxy`/`https_proxy`/`HTTP(S)_PROXY`/`NO_PROXY` exactly as `crates/hh-runner/src/render.rs` sets them. No podman-in-podman.
   - **Shapes** derived **mechanically** from the committed `tests/test.sh` of the 14 re-proof members and their pre-re-proofed successors (a script extracts the unique bootstrap lines so the list cannot drift), run verbatim with the pytest leg replaced by `pytest --version` or an import check: **S1** apt update → `apt-get install -y curl` → the astral uv installer → `uvx -p 3.13 -w pytest==8.4.1 -w pytest-json-ctrf==0.3.5 pytest --version`; **S2** the pytorch-index shape (`--index https://download.pytorch.org/whl/cpu`, torch 2.7.1 / torchvision 0.22.1 / numpy / opencv) → `python -c "import torch"` — expected typed 403 deny naming `download.pytorch.org` under epoch-3, success under epoch-4; **S3** the pip shapes (`pip install … --break-system-packages`); **S4** the heavier apt sets (`ffmpeg libsm6 libxext6`, `gcc`, `python3-pillow`, `vim`).
   - **Assertions per shape:** exit 0 (except the expected S2 deny under epoch-3); every `security.egress.requested` row has a `decided` row; zero mediator 5xx replies; every tunnel's `close_cause ∈ {eof}` with true byte counts; per-step wall times and the peak number of concurrent mediator connections recorded (the D8 proof).
   - **Registration:** a `scripts/live-verify.sh` leg named `egress-real-clients` (ADR-0363 pattern), budget $0, no secrets, evidence record per the leg convention — **not** part of per-PR CI.
2. **Fixes (each with a hermetic loopback regression that fails pre-fix):**
   - **D8 concurrency.** Each accepted connection served on its own thread, bounded (e.g. 64 in flight; excess waits in backlog). The ledger `Store` and lease shared behind a `Mutex`, held only for `pre_wire` (requested → decide → decided, durable before the wire) and the close/charge phase — **never during byte pumping or the upstream exchange**. Ordering contract preserved (requested durable before decision; decided durable before the wire; `tunnel.closed` after the pump). Policy loaded once per connection as now, or once with a reload check — never per request inside the lock.
   - **D9 tunnel pump.** No idle read timeout on established tunnel legs, or a declared idle timeout ≥ 300 s, recorded. On one direction's EOF, `shutdown(Write)` the peer (the relay's pattern); join both directions. Record real byte counts and a true `close_cause` (`eof|idle_timeout|error:<kind>`) — never `unwrap_or(0)`.
   - **D10 response hygiene.** Strip hop-by-hop **response** headers (`Connection`, `Keep-Alive`, `Transfer-Encoding`, `Content-Length` (re-framed), `Proxy-*`, `Trailer`, `Upgrade`, plus any header named in `Connection:`); emit exactly one framing header and `Connection: close` (the mediator serves one request per connection).
   - **D11 bodiless responses.** The codec decides body presence from the request method and the status (HEAD, 1xx, 204, 304 carry no body); thread the method through without breaking the model proxy's callers — the `hharness-wire` and model-proxy batteries run.
   - **D12 timeouts.** Declared constants: connect ≤ 10 s; first byte / read ≥ 60 s; a lapse answers a typed **504** (not 502), recorded on the decided/closed row.
   - **D13 streaming (preferred).** In the mediator binary path, stream the upstream body to the client as it arrives (re-framed chunked, or passthrough length after D10 hygiene) with bounded resident memory; the in-process buffered `forward` API kept for existing callers. If streaming does not fit the size budget, keep the 128 MiB bound, record a DEFERRALS row and say so in the PR — never silently skipped.
   - **D14 Host.** Omit the default port from the `Host` header.
   - **D16 scan check.** Run `scan_hosts_in_text` over every re-proof member's and successor's `tests/*` bytes and diff against the epoch-3 verify set. **If** a scanned host is missing (expected: `download.pytorch.org`), find why (derivation input set / scan bug), fix it with a regression, and mint **epoch-4** under `protocol_id fp-w1-q-x55` — a new epoch (REQ-XB-116) with verify-phase additions only, never agent-phase (X-06), recorded with the amendment-document pattern used for epoch-2/3. **Else** record the result; the member's `allowlist_gap{download.pytorch.org}` exclusion then stands (S-3).
