## Goal

Fix the kernel contract the capstone surfaced: `replay{driver_mode: deterministic}` answers `invalid{replay_diverged}`
on every effect-dispatching live run (reproduced 3/3 on the anthropic lane). Runs without a dispatch replay
byte-identically on every lane. The recorded mechanism (L4.6's capstone report §SURFACED BLOCKER): `mc-N`/`tc-N`/`ef-N`/
`d-N`/`e-N` share one monotone allocator (`hh-control` Driver `next_id`); the live drive mints the dispatch ceremony —
`security.permission.decided`, `action.effect.authorized`, `action.effect.prepared`, the `verification.claim/completion`
chain — that the ReplayGate does not re-mint, so the re-drive's next model call allocates a different id than the record
holds (~4-id skew) and the port honestly reports divergence. Make deterministic replay of an effect-dispatching run
byte-identical, with an ADR recording which contract leg moved.

## In scope — deliverables

1. **Diagnose and pin the contract leg that moves.** Two candidate mechanisms the capstone named: (a) the deterministic
   re-drive re-mints the dispatch ceremony events so the shared allocator stays in step (the record and the re-drive
   interleave identically); (b) the recorded-terminal ports (model/tool/effect) match calls positionally/by-content rather
   than by minted id. Choose the one the spec's replay contract + the honest-refusal rules support — the choice is an
   owned decision recorded in a new ADR with the rejected alternative named. The fix must keep the divergence report
   honest: a real divergence still answers `invalid{replay_diverged}` — never a silent pass.
2. **Implement** the chosen leg in `hh-control`/`hh-embed` (and `hh-ledger` if the ceremony rows' re-mint lives there):
   deterministic replay of a run carrying `action.effect.*`/`security.permission.decided`/`verification.*` ceremony rows
   re-drives byte-identically on every binding the record permits.
3. **A regression test that fails if removed:** a recorded fixture run whose ledger carries the 13-row dispatch ceremony
   (build it from the committed capstone anthropic record or a synthetic equivalent) asserts `replay{deterministic}` =
   byte-identical; a mutation test asserting a real divergence still fails loudly.
4. **The spec conform:** if the spec's replay section pins the minted-id mechanism the fix changes, amend via the protocol
   (section edit + `spec/CANONICAL_SPEC.md` mirror + version/delta bump + `00_MANIFEST.md` `## Spec amendments applied`
   line + grep-verified byte-identical mirror); if the spec is silent on the mechanism, the ADR records that and no spec
   text moves.
5. **Live re-verification:** re-run the diverged arm via `scripts/live-verify.sh` — `capstone-run-anthropic`'s
   hh-cli-attach replay (or the focused equivalent re-running the recorded ledger's replay, costing USD 0 — prefer the
   zero-cost re-drive of the committed record first; a fresh live leg only if the contract requires new evidence) →
   a `live-executed` `hh-live-evidence/1` record + SPEND.jsonl debit, honestly `skipped(<reason>)` if the name is
   `provided: no` (STOP-and-ask per the standing live clauses).
6. **The ADR** recording the mechanism choice, the rejected alternative, the spec-disposition, and the revisit trigger;
   `docs/adr/README.md` + `REVISIT_TRIGGERS.md` regenerated by script.
7. **Records:** L4.6's `blockedOn` discharged — a dated append-only note on `runs/L4.6.md` + the capstone report's finding
   block pointing at this ticket's fix commit; `BLOCKED`/`PAUSED` resolution recorded.
