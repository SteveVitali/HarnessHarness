## Goal

Make spec §5.3 and §5.4 true for the three first-pass hosted harnesses (Q-X48): each has a pure configuration renderer (admission × slot → argv, env, files) that mirrors its Harbor adapter at the program pin, projects the closed hosted-cell environment with the slot token as the only credential, sets the native effort mechanism to the pinned `high` (Q-X22) beside the proxy pin, reproduces instruction passing byte for byte with a deterministic hazard pre-check, and, for original mini-swe-agent 2.4.6, encodes the phase-3 reference configuration and the frozen LiteLLM identity (§7.1, §7.5). Claude Code's renderer and record realize the five Q-X26 terms. Later-pass harnesses (Hermes, OpenHands, Kimi Code, OpenCode) and Terminus-2 are not rendered here.

## In scope — deliverables

**Stage 1 — ADAPT-CHAT-PY + ADAPT-CHAT-NODE** (commit checkpoint at the end of the stage)
1. The renderer interface (admission × slot → `{argv, env, files}`) and the rendered-config hash with secrets elided, carried in the slot record (REQ-XC-307).
2. Original mini-swe-agent 2.4.6 renderer mirroring Harbor's `mini-swe-agent` adapter at the pin: builtin `mini.yaml` digest, Harbor's flags (`--cost-limit 0`, `--yolo`, `--exit-immediately`, `model_kwargs.timeout=3600`), declared agent wall timeout and proxy budget ceiling, every override a declared deviation (REQ-XE-001, REQ-XC-307).
3. Pi renderer mirroring Harbor's `pi` adapter at the pin (REQ-XC-307).
4. Closed env projection: base-URL and key variables with the slot token as sole credential, egress routing hints, mandatory `no_proxy=127.0.0.1,localhost`, declared disable switches, image `HOME`/user; `/logs/agent` and `/installed-agent` present, `/tests` and `/solution` absent (REQ-XC-308).
5. Native effort mechanism set to the pinned level on both surfaces; requested/applied recorded per call by the proxy (REQ-XC-309, REQ-XD-082).
6. `LITELLM_LOCAL_MODEL_COST_MAP=True` for every LiteLLM-based harness (first pass: mini-swe-agent), recorded as declared configuration (REQ-XC-310).
7. Byte-exact instruction passing per adapter and a pure pre-check over instruction bytes flagging harness hazards (Pi's leading `-`) before selection freezes (REQ-XC-320).
8. Reference identity: one O image built once with all resolved Python dependency versions (LiteLLM included) recorded and frozen; the participant identity and the slot record carry `litellm_version` read from the installed environment (REQ-XD-121).

**Stage 2 — ADAPT-MESSAGES** (commit checkpoint)
9. Claude Code renderer realizing Q-X26: exact version with binary sha256 checked at ST2 and ST4; `ANTHROPIC_API_KEY=""`, `CLAUDE_CODE_OAUTH_TOKEN=""`, slot token as `ANTHROPIC_AUTH_TOKEN` only; every alias model variable set to the participant model; non-essential traffic and web tools disabled; black-box arm only (refuses any HIR-target use); plain-text name; the "not supported for non-Claude models" statement disclosed (REQ-XC-327).
