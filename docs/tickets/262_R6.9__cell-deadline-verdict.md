## Goal

Give the runner's slot lifecycle (R6.8) the cell, deadline and verdict machinery TB 2.1 needs, per [§3.3](../experiments-spec.md#s3), §3.6 and §3.4.

- **CELL-SPEC (AR-06).** Helper cells run in the image WORKDIR, apply and record the task's cpu/memory limits, take `/tests` and `/solution` only through kernel-mediated copy-in at their phase, and pull images by digest only.
- **DEADLINE (AR-07).** A separate admitted path enforces task-declared agent and verifier deadlines above 900 s. The legacy path stays byte-identical. A lapsed agent deadline ends in verification with `end_cause: agent_timeout`.
- **VERDICT.** `harbor_reward_file/1` with the §3.4 parse rules and bootstrap classifier, the same-cell regrade bound, and `tb10_pytest_log/1` confined to the TB 1.0 pin. The scratch ANSI-strip and declared-workdir repairs become committed code with regression tests (REQ-XA-127).

## In scope — deliverables

**Stage 1 — CELL-SPEC** (commit checkpoint `R6.9 stage 1/3: cell spec`).
1. Helper and driver flags for the image WORKDIR and `cpus`/`memory_mb` container limits, recorded per slot. A cell spec that does not declare them produces argv byte-identical to today's. [REQ-XB-107]
2. Kernel-mediated copy-in/out. `/tests` (and `/solution`, except for the oracle participant) is absent until its phase and never travels through `/work`; `/work` aliasing refuses. Stale reward files are removed before verification. [REQ-XB-106, REQ-XB-006]
3. Digest-only task images recorded as `ForeignDigest` with platform and labelled R1; a tag-only reference refuses. [REQ-XB-117, REQ-XB-003]
4. ADR for AR-06.

**Stage 2 — DEADLINE** (commit checkpoint `R6.9 stage 2/3: deadlines`).
5. A separate admitted path for task-declared agent and verifier deadlines × declared multipliers (canonical 1.0; a setup multiplier other than 1.0 declared per run). Values above the protocol ceiling and malformed declarations refuse. Slot records carry declared and enforced values. The legacy `min(declared, 900 s)` path stays byte-identical. [REQ-XB-118, REQ-XB-009]
6. When the agent deadline lapses, the agent process group is terminated and the slot proceeds to verification with `end_cause: agent_timeout`. [REQ-XB-119]
7. ADR for AR-07.

**Stage 3 — VERDICT.**
8. `harbor_reward_file/1` as an `OracleExecutor` through `OracleRunner` with `shared` isolation (`tamper: n/a{no_detector}`), reusing `grade`/`parse_typed_reward` unchanged. It applies the §3.4 parse rules 1–6 and keeps the reward bytes verbatim. [REQ-XB-109]
9. The bootstrap classifier, a pure function of the recorded bytes and the mediator rows (taken as fixture rows in the declared shape; the mediator lands in R6.15), per the §3.4 table. [REQ-XB-110, REQ-XB-007]
10. Same-cell regrade of a verifier-unavailable slot up to the frozen `max_attempts` (proposed 2); the participant is never re-run. [REQ-XB-111]
11. `tb10_pytest_log/1` (the committed `strip_ansi` set plus a short-summary parse equivalent to tb's `PytestParser`, under the image WORKDIR), selectable only for the `terminal-bench-core==0.1.1` pin; any TB 2.1 slot refuses. [REQ-XB-112]
12. ANSI-strip and declared-workdir regression tests that fail without the repairs; `driver_commit` in every packet; packets reusable by the `hh-surface-xcheck/1` checker. This row builds the $0 targeted-probe driver for `grid-pattern-transform` and `swe-bench-langcodes` with a fixture run; the probe is executed in W1 by R6.32's fleshing, where the two tasks' images and verifier fetches exist (Notes). [REQ-XA-127, REQ-XA-009]
