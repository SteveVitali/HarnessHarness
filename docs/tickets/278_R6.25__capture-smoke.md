## Goal

Make spec §5.6, §5.7 (smoke half) and §5.8 true as offline machinery for the three first-pass hosted harnesses: proxy receipts stay the transcript of record, `/logs/agent` is copied out and hashed at ST4 with a post-agent version probe and install-tree hash, ATIF is converted post hoc and never gates, harness logs reconcile against receipts, and every hosting failure maps to its §5.8 disposition through one pure classifier. The §5.7 admission smoke battery (SM-pos, SM-429, SM-402, SM-slow, SM-hang over `hh-smoke/write-file`) is committed as task, scripted recordings and an offline records-in checker; it executes at $0 on the phase backend only in W1 (R6.32), where its records become the AG3/AG5/AG6/AG8 evidence.

## In scope — deliverables

**Stage 1 — CAPTURE** (commit checkpoint at the end of the stage)
1. `/logs/agent` copy-out by kernel-mediated container-path download after agent end and before verification, refusing `/work` aliasing, hashed into the slot record (REQ-XC-317).
2. Post-hoc ATIF conversion for H slots through Harbor's converter at the pin over the collected logs, schema version recorded; absence is a reported attribute; the publication-check input is the receipt-index transcript (REQ-XC-318).
3. Integrity-input bundle with a manifest whose digests recompute (REQ-XC-317).
4. Receipt reconciliation between harness native logs and proxy receipts (subagent, background, title and compaction calls included); an unreceipted call → `inconclusive{infra:unreceipted_call}`, never scored (REQ-XC-207).
5. ST4: re-run the adapter's version command and hash the install tree; any change flags `harness_self_modified` (REQ-XC-328).

**Stage 2 — SMOKE-BATTERY** (commit checkpoint)
6. The HH-authored smoke task `hh-smoke/write-file` (never a TB task) and one scripted recording per first-pass harness in its own tool schema and streaming mode, in R6.12's recording format, with `keying: sequence`, `on_divergence: serve_recorded` (REQ-XC-324).
7. Variant drivers SM-pos, SM-429, SM-402, SM-slow, SM-hang and a committed offline checker computing every §5.7 assertion records-in over slot records, reusing R6.24's Claude Code assertion (REQ-XC-324, REQ-XC-312, REQ-XC-311, REQ-XC-321).
8. Admission egress probe and the AG5 rule: disable switches and `expected_denied` listed; every agent-phase non-model attempt a logged residual; a harness that cannot complete with non-model egress denied fails AG5 and is granted no host (REQ-XC-311).
9. Endpoint admission: a working custom base URL on a proxied format is required; Google-format-only or vendor-hosted harnesses are excluded `n/a{endpoint}` (REQ-XC-203).
10. Completion: harness process exit with exit code recorded, native terminal status parsed descriptively; only the task deadline and a budget refusal stop a harness (REQ-XC-321).
11. Pure hosting-failure classifier implementing the §5.8 table over recorded facts, incl. `inconclusive{infra:model_route:<disposition>}` after a model-route failure (REQ-XC-323).
12. Live $0 smoke and build legs as `#[ignore = "live — ADR-0363: …"]` tests; all other hosting acceptance offline (REQ-XC-329).
