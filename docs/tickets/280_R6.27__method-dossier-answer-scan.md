**Stage 2 — D1-c:**

6. `answer-scan/1` over the per-slot integrity-input bundle (receipts, egress rows, seal, native artifacts, terminal transcript) with the §6.9 signal set; a received match or tamper hit on a pass is an observed veto unless cleared by a recorded human review; requested-only fetches reported, not scored; a missing scan is unresolved; confirmed leaks score as failures with the scan recorded; detection works from receipts alone; detector version recorded; phase 4 reuses it unchanged (REQ-XD-070 with the literal predicates of REQ-XB-016, REQ-XC-319, REQ-XD-223).

8. Flagged-pass review-record schema: `{confirmed, cleared}`, reason, excerpt hash, harness identity masked where feasible; report fields for flagged/confirmed/cleared counts, detector version, coverage and "the confirmed count is a minimum" (contributes REQ-XD-071; HUMAN-H16 executes).
9. Stage-tagged tests (`crates/hh-eval/tests/r6_27.rs` or the scanner's home), run ledger, PR body.
