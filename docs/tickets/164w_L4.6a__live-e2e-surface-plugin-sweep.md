## In scope — deliverables

1. Legs added to `scripts/live-capstone.sh` (each independently re-runnable via `live-verify.sh`; crate names post-L4.4,
   directories per L4.4's ADR):
   - **(a) ACP:** the official Agent Client Protocol SDK client (S0.3b precedent — python `agent-client-protocol` or node
     `@zed-industries/agent-client-protocol`, installed into a temp dir outside the repo: no workspace/repo dependency)
     drives a live run through `hh-acp` over its real stdio transport to a spawned kernel: session open → prompt → a
     permission round → completion; ledger verify + offline replay. **Planning expectation: the third-party SDK client.**
     Only if it cannot be installed or no longer speaks hh-acp's protocol version, `hh-acp`'s in-tree `client` over the same
     real transport is acceptable — the evidence record states which client ran and why.
   - **(b) MCP-lab:** the official MCP SDK client (python `mcp` / node `@modelcontextprotocol/sdk`, temp dir) connects to
     `hh-mcp-lab` and runs Lab ops as tools live — at least one experiment op over a live-run-backed arm plus results /
     resource reads; the surface-session ledger verifies.
   - **(c) SDK/embed (binding (a) via the library API):** a minimal consumer program outside the workspace (temp-dir crate
     with `path` deps on L4.5's `hharness` facade — no new deps) drives a live run in process through the public
     `EmbedService` API and asserts the same ledger-verify / replay invariants — distinct from L4.6's `hh`-driven legs.
   - **(d) Plugins out of process:** during a live run, `hh-memory-store` (`memory_store`), `hh-compact-evict-oldest`
     (`compaction_strategy`) and `hh-tracker-fixture` (`work_source_adapter`, on the fleet path) execute out of process
     through `hh-varhost` + `hh-helper` over `plugin_abi/1`; the evidence asserts the out-of-process invocation (the
     varhost/helper rows in the run ledger), never an in-process fallback.
2. A dated `docs/build/reports/<date -u>-live-e2e-surfaces.md` (one row per leg: surface, client used, evidence record,
   cost, result) linked from L4.6's capstone report; OPERATIONAL_READINESS rows for `hh-acp`, `hh-mcp-lab`, the SDK/embed
   surface and each plugin updated to `live-executed` only where a record proves it.
