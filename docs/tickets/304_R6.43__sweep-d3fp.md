## In scope — deliverables

**Stage 1 — E2-T10 (own commit).**
1. The first production consumer of `enumerate`: each OFAT perturbation is one override spelling; each point passes `validate_assembly` (failures route to `rejected`, never silently), is resolved and sealed, and its `version_id` is `LevelSpec.ref_`; override spellings are kept for attribution only; no runtime override interpreter. *(REQ-XE-124)*
2. The declared-delta and liveness check before any paid sweep slot: exactly one registered slot differs from the frozen baseline; the L1.1 request diff against the baseline is confined to declared paths and non-empty on the factor's exercising branch; executor-level knobs additionally pass an executed scripted-model liveness leg at $0 model spend; otherwise `inert`. A swept variant carries no parity claim. *(REQ-XE-125; aliases REQ-XD-125, REQ-XD-203)*

**Stage 2 — D3-FP (own commit).**
3. `sweep-registry/1` record and validator: every level declares its factor, typed paths, baseline and level values, tier, exercising condition, activation metric, forecast source, cost prior, dependency tickets and the upstream locator or "HH-only" (non-upstream constants marked); Tier 1 = V1–V9, Tier 2 recorded with reasons; frozen with its hash. *(REQ-XD-201, REQ-XD-202; alias REQ-XE-014)*
4. The V5 `rsn-drop` level sealed through Stage 1, with a refusal test when it is not equal to R6.33's declaration. *(REQ-XD-201; contributes REQ-XH-115)*
5. The V5 arm bound into W4's seeded interleaved schedule (R6.16's schedule kinds; lowest priority per R6.29), each slot naming its document via `participant.hir.level_assignment`; the runner refuses V5 slots without a matching L1 pass id for the exact H swept, and any H change starts a new phase-4 cohort. *(REQ-XD-220; contributes REQ-XH-115)*
6. Regression batteries (e.g. `crates/hh-lab/tests/r6_43.rs`, the runner crate's `tests/r6_43.rs`).
