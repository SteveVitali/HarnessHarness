### 6.1 The IR entity/edge catalogue (ADR-0015, ADR-0016, ADR-0017, ADR-0018)
- A HIR document is a DAG of nodes `{version_id, semantic_id, kind, home_plane, dialect, version, provenance, semantic, surface?, ext}` and edges `{kind, from, to, provenance, fields}`. Kernel sums are closed per dialect; `ext` is open but registered (reverse-DNS prefixes, reserved `hir/`), preserved byte-for-byte, and **never decides authority, budget or validity**.
- **Entities (13):** `Goal, Observation, ContextItem, Memory, Procedure, ToolCapability, Permission, Effect (record) with EffectClass = {domain, attributes}, Artifact, Validator, AgentProcess {native | hosted = OpaqueProcess}, Budget, HarnessRule`; **leaves (2):** `Text{content, owner, authority, provenance}`, `CompiledPayload{format_tag, bytes_hash, declared_interface, owner, provenance}`; **edges (7):** `depends-on, supersedes, authorizes, produced-by, validates, delegated-to, derived-from`. `compensates`/`reverts`/`parent-of` are ledger relations.
- `EffectDomain = {fs_read, fs_write, exec, net_egress, secret_access, spend, message_human, spawn_process, memory_write, permission_request, model_call}`; `EffectAttributes = {mutability, repeat_safety, world, reversibility}`; MCP hints are a projection.
- `AgentProcess.native{harness_def, profile, slots: map<class_id, SlotBinding | [SlotBinding]>, control_boundary: ControlBoundary{assignments, guards}, budget, permissions, environment}`; `DecisionPoint = {plan, act, retrieve, compact, verify, delegate, authorize, retry, stop, escalate}`; `hosted = OpaqueProcess{participant_ref, declared_capabilities (tri-state), observability_levels, version_identity, hosting_mechanism, supplies, budget, permissions}` with no component sub-entities.
- Kernel invariants enforced by `validate`: V-EFF coverage by domain + scope; delegation attenuates; Budget monotone containment (`≤ parent.remaining at allocation`); `Permission.issuer.authority ≠ model_claim`; Observation authority never exceeds its source and `model_claim` never satisfies a Validator alone; Memory revocation = new version + `supersedes`; every Goal/AgentProcess references a Budget; conditioned `HarnessRule` ⇒ complete assumption-debt record; `Loop` bounded; every opaque body has a declared interface. Errors, never warnings: `UnexpressibleSurface`, `OpaqueWithoutInterface`, `EffectUncovered`, `AuthorityWidening`, `ConditionedRuleIncomplete`, `UnclassifiedKind`, `MissingProvenance`, `AuthorityExceedsOrigin`, `TextAboveExternal`, `TaintedAboveExternal`, `IllegitimateEndorsement`, `ScopeCeilingExceeded`.
- Identity: `version_id = H(canonical(node))`; `semantic_id = H(canonical(kind ∥ semantic ∥ refs-by-semantic_id))` excluding surface, provenance, ext and version; rename ⇒ `semantic_id` unchanged. `HirDiff` (identity-keyed, invertible, classified `{semantic_ops, surface_ops, provenance_only_ops, ext_ops, authority_delta, budget_delta}`) is the unit of edit; all-surface diffs are profile versions.
- Every string-shaped construct in a Phase 2 dossier is a `Text` or `CompiledPayload` leaf or it is typed; every new pluggable behaviour is a registered component class with an operation-shaped contract that receives `(ModelProfile, ResourceAccount)`.

### 6.2 The authority/label scheme (ADR-0033, ADR-0034, ADR-0035)
- `ProvenanceRecord = {origin, authority, taint = ∅, readers = Public, scope, derived_from = [], created_at, attestation?}` on every node, edge and content-bearing ledger event; excluded from `semantic_id`, included in `version_id`.
- `AuthorityClass = kernel > definition > principal > delegate > environment > external > unverified` (closed; join = min). Minting rules: `kernel` only by the runtime; `definition` only at `seal` or by `pin`; `principal` only for the run's human principal; `delegate` for every AgentProcess output (model, subagent, evolution, hosted participant); `environment` only for closed-schema values from closed-world tools in the sealed definition; `external` for open-world content and **all free text** not from kernel/definition/principal; `unverified` for imported/lifted/migrated/attestation-failed content — never coerced into `external`.
- `Label = (authority, taint, readers)`, join `(min, ∪, ∩)`; `authority` enforced at C0; `taint`/`readers` carried at C0, enforced at C2 (H2). Validity is orthogonal (three-valued, ADR-0014).
- Propagation: derivation joins inputs and deriver (`delegate` for model-produced summaries, `kernel` for deterministic projections); delegation attenuates (child ceiling ≤ parent's effective authority; results re-enter at ≤ `delegate`); per-call `context_label = ⊔ delivered items` on `context.assembled`; `effective_authority(p) = min(authority(proposer), context_label.authority)`; persistence ceilings by scope; **retrieval order validity → authority → readers → relevance** is a C0 contract of D1/D3; never widen outside the closed endorsement list `{seal, approval, validator, promotion, pin, policy_rule}`; a `delegate` origin never endorses; approval endorses one `effect_id`, never content.
- Role-placement invariant: the Model Profile owns `role_map: AuthorityClass → ProviderRole`; an item renders only into a role whose privilege ≤ `role_map(authority)`; provider roles are surfaces, never IR fields.
- Minimal monitor set (H1 implements 1, 2, 4, 5, 6, 7 at C0; H2 adds 3 and taint at C2): authority of proposal; grant coverage + permission validity; flow; taint gate via Π (OQ-101); endorsement legitimacy; persistence ceiling; delegation attenuation. The monitor reads records only.

### 6.3 The identity model (ADR-0027, ADR-0029, ADR-0036, ADR-0037, ADR-0038)
- Five identity kinds: content address (`ContentAddress{idp, algorithm, digest, media_type, size}`), version id, semantic id, allocated id (`RunId, EventId, TurnId, ModelCallId, ToolCallId, PermissionId, LeaseId` — time-ordered, opaque), logical name with append-only history. One reference type `VersionedRef`. Identity profile `idp/1`: one mandatory 256-bit standardized hash, JCS-class canonical form (integers/decimal strings, no doubles), domain tags (`blob ≠ node ≠ tree`), OCI-style `algorithm:hex`; ids are never rewritten; rotation via bridge records and audit checkpoints.
- Structural chain `run_id ⊃ turn_id ⊃ model_call_id ⊃ tool_call_id`; `effect_id = f(run_id, model_call_id, tool_call_id, ordinal)`; provider ids are `surface_ids` aliases; per-run dense `seq`; `parent_event_id` tree + `causes[]` links; fork by reference with `forked_from{run_id, at_seq, source_head_hash}`.
- `configuration_id` = semantic factor coordinate (model_ref, definition `semantic_id`, profile `semantic_id`, environment_ref, budget `semantic_id`; **seed excluded**); `configuration_version_id` = over `version_id`s **plus seed** — the run-manifest key; results rows `(configuration_version_id, run_id)`, aggregated by `configuration_id`; `bundle_id` recorded, never a coordinate; `registry_snapshot_id` over the referenced closure.
- Immutability I1–I5; supersession as an edge on the newer version; `RevocationRecord`; `StaleIndex` with `depends_on_revoked` annotated never hidden; `resolve(mode = execute)` never returns revoked/yanked/stale heads; sameness ladder L0–L4 from `HirDiff.classification`; reproducibility levels R0–R3 with pin-derived maximum claims; the bundle is a lock manifest whose members are pinned ids or explicit `unpinned[]` claims; `InstrumentRecord{…, dirty}` caps at R0.

### 6.4 The run ledger and effect lifecycle (ADR-0026, ADR-0028, ADR-0029, ADR-0030, ADR-0031, ADR-0032)
- Authoritative record = typed append-only event log + content-addressed blobs + immutable run manifest; every consumer view is `project(run, view_kind, until_seq)` with a `derived_from` watermark and a rebuild-equality test (D1 context view, B2 effect ledger, H6 chain heads, J5 results rows, L2 cost totals, I1 trace/cost/metric/audit views). History is never rewritten (rollback/compaction/redaction/fork are appended events). One fenced writer per run (`lease_generation`), durable-before-visible. Every event class declares `durability`, its minimum observability level, and its lowering to the Hosting-ABI vocabulary. Every event stamps `participant_class` and `observability_level` (`ledger` entailed by `native`). Durability = reconstruction; deterministic replay is a declared control-strategy capability (`n/a` otherwise).
- Canonical form + per-run hash chain `hash = H(leaf_tag ∥ canonical(envelope − hash) ∥ prev_hash)`; offload above a class threshold (default 64 KiB); redaction-safe hashing; the WS-B1 event table is read with the ADR-0026 amendment log (renames, additions, payload extensions, mandatory-provenance table).
- Effect lifecycle `intended → authorized | refused → prepared → committed → observed(applied | not_applied | partial) | unknown → probed → observed | compensated | reverted | abandoned`; write-ahead `committed` before dispatch for every non-`read_only` effect; every commit resolves; the model always sees a terminal or an explicit `unknown`; retries share `effect_id`; fencing inherited from the writer lease; `detached_effect_ids[]` recorded.
- Effect risk class `{reversibility ∈ {read_only, reversible, compensable, irreversible}, repeat_safety, scope ∈ {workspace_local, external}}` is **derived** from `EffectAttributes`; `effective_risk_class = max_by_danger(kernel_assessed, projected(declared))`, `unknown ⇒ {irreversible, non_idempotent, external}`; self-report and untrusted hints only raise. Delivery semantics per class (at-least-once for `read_only`/`reversible`; at-most-once + mandatory key for `compensable`; **no automatic retry ever** for `irreversible`); never "exactly-once effect"; idempotency key `H(run_id, effect_id, canonical(args), capability_version)`; kernel decision `{effective_risk_class, allow | ask | deny, reason, cache_key?}`; `CompensationPlan` registered at `prepare` (runtime record), compensators idempotent, `abandoned` always escalated and audited.

### 6.5 The resource taxonomy and budget contract (ADR-0039, ADR-0040, ADR-0041, ADR-0043)
- Kernel counters `tokens.input.{uncached, cache_read, cache_write[ttl_class]}`, `tokens.output.{visible, reasoning}`, `model_calls`, `tool_calls`, `turns`, `retries`, `spawns`, `approvals.{requested, granted}`, `evaluator_calls`, `network.calls`, `time.{wall_ms, working_ms, model_latency_ms, human_wait_ms}`, `env.{active_ms, reserved_ms}`, `spend`; gauges `context.occupancy`, `fan_out`, `delegation_depth`; totals derived by a declared `MeteringFormula`, never stored primary; integers only; `Money{micro_units, currency}`; `TokenVector` is the view under `hh-inclusive/1`; the profile's `usage_mapping` is what `normalizer_ref` points at.
- Raw usage lives on the producing event; every accountable event posts `control.budget.consumed{budget_id, dimension, amount, running_total, limit?, source_event, reservation_id?, attribution}` (idempotent on `(source_event, dimension)`); **nothing is unaccounted**; `attribution.charged_to ∈ {subject, instrument}` (graders, probes, Lab detectors, hosting adapters, Lab judges are `instrument`); spend is derived (`measurement.cost.attributed` with six-valued `CostProvenance`, `provenance_class`, `derivation`, `confidence ∈ {exact, bounded, estimate, unknown}`, `coverage`, `pricing_ref`); `NoPrice` never zero; totals are views.
- `BudgetNode{budget_id, scope, parent?, mode ∈ {slice, pool}, dimensions{hard?, soft[], metering?, grace?}}`; dynamic containment; reserve-before-spend (`InsufficientBudget` is a pre-dispatch refusal); root-first exhaustion; **soft thresholds are `HarnessRule` artifacts** (delivery/activation/following measured — budget compliance is a class-scoped metric); **hard ceilings fire only at decision points** (before a call; after an effect's terminal event) and end the run with `stop_reason = budget_exhausted` after every open effect is closed; gauge caps refuse the next increment; `amend` is ledgered; `budget_delta = loosening` is unacceptable in evolution contexts; approvals exhaustion converts `ask → deny`. F2 enforces; F3/F5 use `allocate/reserve`; C3/D1 render soft budgets; H7 budgets approvals.
- `MatchSpec{dimensions, mode ∈ {matched_cap, iso_cost, matched_total}, tolerance, pricing_table_ref?, model_scope}` mandatory on every arm; the engine **refuses** (`UnbudgetedArm`, `IncommensurableMatch`, `MissingPricingTable`, `MissingMatchSpec`); matched-total (search + eval + inference) for every C4 claim; utilisation and tails always reported; cache warmth controlled or stratified.
- Measurement points M1–M18 are the closed list of where cost/latency is observed; durations are integer ms from the measuring component's monotonic clock with `measured_at`; latency is multi-point per logical call (`model_attempt` spans, `turn_phase_profile`); conversions to external units happen only in lowering and are listed in the telemetry loss report.

### 6.6 The scorecard and experimental design (ADR-0013, ADR-0014, ADR-0045, ADR-0046, ADR-0047)
- `MetricDeclaration{name, dimension, level, value_type, direction, unit, requires_observability, applies_to_classes, admissible_granularities, detector_classes_allowed, oracle_classes_allowed, replicate_reducer, interval_method, outcome_class_policy, headline, veto, charged_to}` is the single form (C0/Stage 1); dimensions are tags; adding a dimension is an ADR.
- Result rows are keyed by `(model snapshot(s) with roles, harness at a declared granularity, environment image + fault/perturbation profile, task with split label, budget vector, replicate index)`; `seed` is the replicate axis; pairing across arms by task (by replicate only where all participants declare `seed_honoured`); `Design` and `PreRegistration` are first-class and immutable once the first run opens.
- Outcome classes `{scored, budget_exhausted, infrastructure_failure, oracle_failure, refused, cancelled}` precede metrics; `n/a{reason ∈ {class, observability, estimator_undefined, not_run, no_detector}}` is a typed value — never 0, never a proxy; per-task (c, n) stored so pass^k/pass@k are recomputable; intervals named (clustered-by-task default); tails reported.
- Participant class = transparency of H, **declared, never inferred**; `ledger ⇔ native`; admissible granularities native ⊇ {component-level, configuration-level, product-level}, hosted ⊆ {configuration-level (SUPPORTED coordinates), product-level}; `InadmissibleFactor` refused; `capability_vector = reconcile(declaration, probes)`, `unknown` never coerced.
- Validity three-valued and model-free; compliance = `context.artefact.delivered` → `context.artefact.activated` → `verification.artefact.followed` with `detector ∈ {deterministic, judged}`; realized-benefit decomposition is the reporting shape; `activation_observable` per artifact kind.
- `eval_budget` equality is an engine precondition (`UnmatchedBudget`); `SearchBudgetRecord` covers everything spent producing an arm's frozen artifact; three benefit kinds (`artifact_benefit` on a pre-search held-out split, `search_time_benefit` vs an equal-search-budget baseline, `transfer`); adaptive selection only inside search; C4 admissibility gates (ADR-0046 §7) are the operational form of ADR-0002's evidence standard.
- Nine oracle classes; headline capability at C0 admits only `{executable, end_state, output_check, trace_predicate, protocol_check}`; judges are `Validator{kind: judge}` with `ProfileRef`, `calibration_ref`, independence from every beneficiary snapshot, `charged_to = instrument`; oracle failure is an outcome class; veto invariants (`veto: true`) produce *success-with-veto*.

### 6.7 The trace model and instrumentation (ADR-0042, ADR-0043, ADR-0044)
- A span is `(scope-opening event, terminal event | open)` for one ledger scope; `scope_kind ∈ {run, turn, model_call, model_attempt, context_assembly, compaction, tool_call, tool_attempt, effect, permission, validation, subagent, environment_op, memory_op, wakeup}`; span identity = the opening `EventRef`; trace identity = the root run; **no telemetry store**; exporters are subscribers; export is lowering with a telemetry loss report; external ids are aliases; propagation rides `_meta`/env slots as `traceparent` + `tracestate` member `hh=run:<run_id>;ev:<event_id>` and lifts into `causes[]` — never a field on an IR entity.
- **The ledger is never sampled**; L0 accounting / L1 structural / L2 content (blobs by address) are always-on for native runs; L3 diagnostic is `ephemeral`; every sink declares `SinkPolicy{content_classes, redaction, sampling, rate_limit, max_field_bytes, requires_consent}`; every delivery is `measurement.export.delivered`; `audit_completeness = chain_ok ∧ no open scope past deadline ∧ no missing blob without tombstone`.
- The process-metric catalogue (efficiency, reliability, grounding incl. compliance, autonomy, security, evolvability, budget discipline) enters the registry as declarations computed over ledger events with `computed_from`; no metric is computed from an exported sample.
