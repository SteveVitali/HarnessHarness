# ADR-0176 — The embedding contract `hh-embed/1`: the WS-L1 §6.5 boundary contract completed into the single public kernel surface (operation groups, invariants I1–I9, frame model, closed error model); every surface is a client of it

**Status:** ratified, amended (Phase 3 synthesis)
**Owner workstream(s):** WS-K4 (with WS-L5 for the shared invariants; consumers WS-K1, WS-K2, WS-K3, WS-J1, WS-J3, WS-J5, WS-J6, WS-E4, WS-B1, WS-F1, WS-H7, WS-L6) · **Phase:** 3 · **Related:** ADR-0050 (D1–D3, §8), ADR-0005/0013 (act as a participant; class declared), ADR-0023/0025 (definition as data; `compose → resolve → validate_assembly → seal`; `verify_resume`), ADR-0026/0027/0029 (ledger, inclusive cursors, canonical form), ADR-0030/0031 (effect lifecycle), ADR-0035 (endorsement bases), ADR-0039/0040/0045 (account; `emit_metric` per run), ADR-0051…0053 (handles never in surfaces; `ask` shape; unattended), ADR-0096…0099 (protocol edges are different bindings; `ProtocolBinding`), ADR-0130 (restore idempotency; `WouldBlock(active_holder)`; idempotency keys), ADR-0136…0138 (R-NOSIDE; `connection_info`); CF-023, CF-058, CF-209, CF-208; CF-370, CF-371, CF-374; OQ-046 (Q-L1-14), OQ-130, OQ-131, OQ-246; R-2.11.4, R-2.12.3, R-2.11.1/2/3

## Context

ADR-0050 D3 adopted the WS-L1 §6.5 ecosystem-boundary contract (`hello/open_session/submit/stream_events/request_permission/cancel/account/close`; invariants I1–I5) as a C0/Stage-1 item owned by WS-K4 with WS-L5, and D1 fixed that the SDK/embedding API "is this generated client" over the kernel's local transport (Q-L1-14, ADR-0049 §4). Phase 2 added `idempotency_key` to every work-injecting verb (ADR-0130) and separated three bindings that share one verb *shape*: the internal ecosystem boundary (canonical events, unknowns rejected), the ACP session boundary (lowered events, unknowns preserved, `configuration` ceiling) and the Hosting ABI (baseline + capability-declared verbs) — CF-023/CF-208/CF-209. What remained undesigned is the contract as a *public surface*: which operations beyond the eight exist, what a host may inject, what a subscription delivers and how it resumes, what errors look like, and whether the CLI, web tooling, MCP server, Lab and third-party SDKs share it.

The WS-K4 audit read five embedding surfaces in source at pinned commits (OpenHands SDK + agent-server @3fc7b22, Pi harness/protocol/server @400d690, Claude Agent SDK @ad77094, Codex app-server/app-server-client/SDK @0735c51, Cloudflare Agents @b9142be) and the ACP v2 transport/initialization/extensibility pages @9b00c27. All native runtimes converge on one option record, one session handle, one bidirectional channel, and *upcalls* for the things the host owns (permission callback, host tools, hooks); all implement the §6.5 verbs plus `steer`, `fork` and `navigate`; Codex demonstrates one contract over stdio and in-process typed channels with identical envelopes ("not a second execution contract"); OpenHands' session protocol supplies a durable/ephemeral frame model with `seq`, attempts and aborts; no audited SDK carries provenance, content-addressed configuration identity or a typed error sum end to end.

## Options considered

1. **Ship the SDK as a bespoke high-level API per surface** (a language-idiomatic `Conversation` object, a separate web API, a separate Lab API), each hand-written over kernel internals. *Rejected:* three contracts to keep coherent; the Pi in-process-vs-wire divergence and OpenHands' `RemoteEventsList.reconcile` are the cost in production; violates ADR-0050 D2 ("nothing else crosses") and I1.
2. **Make the ACP artefact the embedding API** (hosts speak ACP to the kernel). *Rejected:* ACP carries lowered events, preserves unknowns and caps at `configuration` granularity (ADR-0098; CF-209); a native host needs canonical ledger frames, `project()`, the assembler and measurement verbs; CF-023 fixed shape-sharing, not a single binding.
3. **A minimal §6.5 contract only (eight verbs), everything else via `project()` reads and a generic `call(method, payload)` escape hatch.** *Rejected:* the generic call is the untyped escape hatch T-LCD-01/-07 forbid by analogue; hosts need typed upcalls (permission, host executor, hooks) with authority rules the schema must enforce (AC-K4-4).
4. **Chosen:** the §6.5 contract completed into `hh-embed/1` — six operation groups, nine invariants, a frame model over ledger cursors, a closed error sum — as the only kernel-facing public surface, consumed by every first-party surface and by generated third-party clients.

## Decision

1. **Identity and role.** `hh-embed/1` *is* the ADR-0050 D3 boundary contract. It is the only way anything outside the kernel drives a run; it is distinct from the Hosting ABI (WS-J6) and the ACP edge (ADR-0098), which share its verb shape but are different bindings. A run driven through it is a **native** attachment: durable frames are canonical ledger events (I4), `observability_level = ledger`, no lowering loss report exists at this boundary.
2. **Operations** (dossier §6.1; every operation returns a typed sum, every work-injecting one carries `idempotency_key`): **H** `hello`; **S** `open_session{new | resume | attach}`, `close`; **W** `submit`, `steer{expected_turn_id}`, `cancel{turn | run}`, `fork`, `navigate`, `respond_permission`, `respond_elicitation`, `report_host_effect`, `set_coordinate`; **R** `stream_events(from_seq)`, `read`, `head`, `lineage`, `project(view_kind)`, `account`, `describe`, `get_artifact`; **M** (behind `serves_measurement`) `emit_metric`, the ADR-0025 assembly operations, the ADR-0038 bundle operations, registry reads/publish; **U** upcalls `request_permission`, `invoke_host_capability`, `notify_hook`, `elicit`, each gated by a host capability declared at `hello`. `submit` returns on *acceptance* (`Accepted{turn_id}`); completion is the durable `lifecycle.turn.finished` frame (CF-370). `open_session(new)` names a sealed definition by reference or a document plus `Override[]`; sealing, root-handle minting, environment provisioning and `open_run` are kernel-side; the response echoes `RealizedSettings` (model role table realized, `cwd`, effective containment, Π mode) so a host never infers settings from its request. `open_session(resume)` is ADR-0130 `restore`; a concurrent resume returns `WouldBlock(active_holder)`. `attach` is a read-only attachment with no writer lease (viewers, the ACP bridge, adapter zero).
3. **Invariants.** I1 single schema source + generated bindings + CI drift check; I2 unknown fields refused (`UnknownField{path}`) except inside registered `ext` slots and prefixed `HostCapabilities.extensions`, preserved byte-for-byte and never deciding; I3 the client pins an exact kernel build and declares a floor — `hello` refuses below it (`KernelBelowFloor`) rather than warning; I4 durable frames carry the event in `idp/1` canonical form, hash-equal to the ledger (CF-058); I5 no authority crosses inward except through endorsement verbs (`respond_permission` as principal approval of one `effect_id`; `open_session.supplies` under `authority_cap`) — the host proposes, requests, observes, reports; **I6** every work-injecting operation is idempotent on its key across restarts (ADR-0130 R-4); **I7** no operation returns a live kernel object — sessions, environments, handles, views by id/address only (R-NOSIDE generalized; `HandleId`/`EnvHandleId` are unreachable from the contract schema); **I8** one contract, every binding — operation set, error sum and frame kinds identical over in-process, stdio and local-network bindings (ADR-0179); **I9** hosts on this contract are native attachments (`ledger` observability).
4. **Frame model.** `Frame = sync | durable{seq, event, hash} | ephemeral{kind, scope, attempt, order, payload} | item_started{item_id, attempt, anchor_seq} | item_aborted | lagged{dropped: {ephemeral}} | closed{reason}`. Durable frames are gap-free in `seq` and never dropped; ephemeral frames never carry `seq`, never advance the cursor and may be dropped (`lagged`); a slow consumer is disconnected (`closed{slow_consumer}`), never allowed to stall the writer (ADR-0026 durable-before-visible seen from the client); every `item_started{attempt}` is retired by exactly one durable item or `item_aborted`, higher attempts supersede lower ones (rewind on ADR-0130 R-2 retries); resumption is inclusive `from_seq` with a leading `sync{head_hash}` (ADR-0027); `security.permission.pending` is durable and its rendering ephemeral (ADR-0026 amendment), re-derivable via `project(pending_permissions)`.
5. **Error model.** A closed sum (dossier §6.3): handshake (`NotInitialized, ContractMajorUnsupported, SchemaMismatch{direction}, KernelBelowFloor, ExperimentalRequired{reason}, CapabilityNotDeclared`), shape (`UnknownField, SchemaViolation, SecretInPayload`), lifecycle (`UnknownSession, WouldBlock(active_holder), Draining, SessionDetached{reason}, DefinitionChanged, TurnMismatch, TurnActive`), assembly (ADR-0019/0025 errors verbatim), budget/policy (`InsufficientBudget, UnbudgetedArm, UnattendedRequiresInput, Refused{reason}`), effects (`UnknownEffect, AlreadyDecided, OptionNotOffered, Fenced`), environment (`EnvironmentUnavailable, UnknownCapability`), transport-level (`Overloaded, Disconnected, Timeout`). Every error carries `{code, retryable, detail?, event_ref?}`; `retryable` means safe to retry with the same key; kernel-internal conditions (`Fenced` on the writer, `Tampered`) surface only as `SessionDetached{reason, event_ref}`.
6. **Every surface is a client.** CLI (WS-K1) = in-process binding; web/desktop/IDE (WS-K2) = generated client over the local-network binding (`attach` for viewers); MCP server (WS-K3) = kernel-side server whose Lab tools wrap Groups S/M with server-minted handles (ADR-0097 D1); Lab (WS-J1/J3/J5, WS-I4) = stdio binding with Group M; ACP artefact = a client lowering Group R frames into `session/update` and raising Group U into `session/request_permission` (ADR-0098 D2/D3); third-party SDKs = generated clients with no runtime logic. Third-party component variants use the variant-host boundary (ADR-0023 D5; WS-L5), hosted participants the Hosting ABI (WS-J6) — neither is this contract (CF-023).
7. **Ledger additions requested of WS-B1:** `lifecycle.session.attached/detached{attachment_id, client, capabilities_negotiated, binding, contract_identity}`, `lifecycle.contract.deprecated_use{method, client}`; run-manifest fact `embedding{client, binding, contract_identity}` beside `protocol_bindings[]` (ADR-0099).

**T-LCD statement (ADR-0007 decision 5).** Satisfies T-LCD-12 (records in/out; out-of-process by construction; in-process binding conformance-tested), T-LCD-06 (no IR/ledger/contract reference to this boundary from native entities; hosting absent leaves it unchanged — AC-K4-12), T-LCD-07 (host capabilities declared at `hello`; experimental items opt-in; `unknown` never coerced for tri-state kernel capabilities), T-LCD-10 (identities travel as `semantic_id/version_id/ContentAddress`; names never parsed), T-LCD-11 (no lowering here; canonical frames), T-LCD-14 (Lab crossings budgeted and `instrument`-charged; `UnbudgetedArm` passes through), T-LCD-02 (host text as labelled `Text` leaves). Does not address T-LCD-01/-03/-04/-08/-09/-13/-15 (not introduced here). **ADR-0024 rung:** transport, negotiation, error typing, frame sequencing = MUST-code; capability defaults, hook-point list, connection bounds = MUST-data.

## Evidence (doc 3 §3.3 synthesis contract — all five mandatory)

- **(a) Mechanism evidence:** convergence of five native embedding surfaces on the §6.5 verbs plus steer/fork/navigate and on host upcalls (S-110 `conversation/base.py` L123–478, `conversation.py` L33–160; S-113 `harness/agent-harness.ts` L419–622; S-109 `client.py` L26–135, `_internal/query.py` L469–600; S-107 `app-server-protocol/src/protocol/v2/{thread,turn}.rs`, `sdk/typescript/src/{codex,thread}.ts`; S-557 `docs/agents/agent-class.md`); accept-then-complete prompt semantics (S-035 `prompt-lifecycle.mdx`; ADR-0098); resumable durable/ephemeral frames with attempts and aborts (S-110 `agent_server/session_protocol.py` L1–156; S-052 stream rewind via ADR-0026); drain-aware admission and attachment release after admitted calls settle (S-107 `turn_admission.rs`, `connection_rpc_gate.rs`; S-113 `server/src/session-router.ts`); typed request errors (S-110 `conversation_router.py` L203–236; S-113 `harness/types.ts` `Result`); strict unknown rejection at an internal boundary (S-113 `protocol/README.md`) vs preservation at protocol edges (S-035 `extensibility.mdx`; CF-209); per-run scorer crossing (ADR-0045 §9). No 2026 preprint is cited.
- **(b) Source-code precedent:** codex `codex-rs/app-server/src/in_process.rs` L1–80 and `app-server-client/README.md` (one contract, two bindings, same JSON-RPC envelope) @0735c51; software-agent-sdk `openhands-agent-server/openhands/agent_server/session_protocol.py` (frame kinds, `seq`, attempts) and `conversation/impl/remote_conversation.py` L128–500 (reconnect + reconcile — the cost of drift) @3fc7b22; pi-mono `packages/protocol/src/protocol.ts` (hello/version/routed targets/strict envelopes) and `packages/server/src/types.ts` (`ServerHost`, `RoutedSessionHandle`) @400d690; claude-agent-sdk-python `_internal/query.py` L231–300 (`initialize` carrying hooks/agents; upcall subtypes) @ad77094; agent-client-protocol `schema/v2/meta.json`, `docs/protocol/v2/transports.mdx` @9b00c27. The completed contract with nine invariants, a closed error sum and the every-surface-is-a-client rule is `no-precedent / novel` as an integrated contract; each element is precedented as cited.
- **(c) Disconfirming evidence considered:** (i) one contract for heterogeneous surfaces risks the intersection trap (S-154 via ADR-0007; Pi and Cloudflare deliberately keep two surfaces) — answered: the clients are heterogeneous *consumers of one runtime*, the record set (ADR-0050 D2) is already richer than any audited SDK, and richness is declined by capability/opt-out, never removed; AC-K4-2 fails a first-party private verb. (ii) OpenHands and ACP/MCP argue for tolerant readers ("clients must ignore what they do not recognize") — answered by CF-209 (canonical hash-equal events need strictness), by advertising `schema_hash` at `hello` so mismatch is detected before any message, and by AIP-180 additive rules keeping older clients valid. (iii) Carrying HIR documents and assembler calls across the boundary has no SDK precedent — answered: ADR-0023/0050 D2 already require it for the Lab; a host may pass a reference plus overrides and never see the document. None overturns.
- **(d) Conditionality:** independent of model tier and task class; assumes ADR-0026's durable-before-visible ledger and ADR-0130's idempotent restore exist at Stage 1; assumes WS-F1 declares `steer_mode`/`concurrent_input` (CF-371) — until then `steer` returns `Unsupported{by: control_strategy}`; assumes OQ-246 stays open (no `allow_pattern` options offered); the local-network binding assumes a WS-H3/K2 authentication scheme (OQ-401); connection bounds are MUST-data set by the S2 spike (OQ-131, AC-K4-9).
- **(e) Build-stage assignment:** **C0 / Stage 0** schema export → codegen pipeline; `hello`; S2 spike as acceptance check. **C0 / Stage 1** Groups H/S/W (minus `steer`, `set_coordinate`)/R, frame model, error sum, in-process + stdio bindings, conformance suite (AC-K4-1…4, -7, -8). **C0 / Stage 2** Group U host executor + `report_host_effect`, `notify_hook`, `fork/navigate`, `elicit` (AC-K4-5/-6). **C0 / Stage 3** Group M for the Lab (AC-K4-10). **C1 / Stage 4** `steer`, `set_coordinate`, ACP artefact as client, local-network binding. **C1 / Stage ≥ 5** generated clients in the late-bound surface ecosystem (AC-K4-11).

## Consequences

- WS-K1 implements the CLI over the in-process binding and may use `experimental` items; WS-K2 builds every screen over the generated client (viewers via `attach`); WS-K3's Lab tools wrap Groups S/M; WS-J3/J5/I4 cross only through Groups S/R/M (AC-K4-10); WS-E4's `render_session` is a client of Groups R/U.
- WS-B1 adds the three event/manifest items of decision 7; WS-F1 declares `steer_mode` and `concurrent_input` (CF-371); WS-H7 owns the `respond_permission` option set and OQ-246; WS-L5's variant-host boundary shares I1–I5 (and I6/I7) but is a separate endpoint; WS-J6 uses `attach` for adapter zero and never `open_session(new)` on a definition the Lab does not own.
- WS-L6 packages: one kernel build, generated clients, the contract's changelog and stability map; WS-I3 records the client's contract identity in `InstrumentRecord.component_versions`.
- `l1-spike-spec.md` S2 becomes the first executable check of this contract (AC-K4-9); OQ-046's WS-K4 half and OQ-130 are answered (ADR-0179).

## Reversibility

**Low for the shape** (every surface, the Lab and the ACP artefact are written against it from Stage 1; changing the verb set after Stage 3 re-keys every client and fixture) — mitigated by the stability policy (ADR-0178): additions are cheap, removals are majors. **Medium for the frame model** (a new frame kind is additive; changing `durable`/`ephemeral` semantics would contradict ADR-0026). **High for connection bounds, hook-point list and capability defaults** (MUST-data).
