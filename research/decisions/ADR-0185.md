# ADR-0185 — The spawn contract: subagents are child runs created only by kernel `spawn` composing `delegate` + `allocate` + `derive` + writer lease; `SubagentSpec`; capability and budget inheritance rules; `spawn_process` as the delegation domain (OQ-135)

**Status:** ratified, amended (Phase 4 synthesis)
**Owner workstream(s):** WS-F3 (consumers: WS-F4, WS-F5, WS-L8, WS-G3, WS-D5, WS-H1, WS-L2, WS-B3, WS-B5, WS-F1, WS-F2, WS-H6, WS-D1, WS-J3, WS-J6, WS-K2) · **Phase:** 4 · **Related:** ADR-0016/0017 (`AgentProcess`, `delegated-to`, `AuthorityWidening`), ADR-0026/0027 (child runs, `parent_run_id`, `spawn_event`, `causes[]`), ADR-0034 P2, ADR-0040 (`allocate`/`reserve`, `slice`/`pool`, gauges), ADR-0051…0053 (`delegate` D-1…D-5, Π `spawn_process` row), ADR-0063/0064 (child definitions are sealed/registered), ADR-0067 (cross-run anchors), ADR-0074 (isolation as the only label exemption), ADR-0085 (`subagent_task`), ADR-0096 (A2A child runs), ADR-0103 (`delegate` decision), ADR-0106/0107, ADR-0116 (critic processes), ADR-0121 (`ModelRole.subagent`), ADR-0123, ADR-0130/0131 (own lease; `child_terminal`), ADR-0136…0138 (`derive` D1–D6), ADR-0164 (observed-only hosted subagents); CF-394, CF-396, CF-397, CF-398; OQ-135, OQ-189, OQ-328; R-2.6.3, R-2.8.1, R-2.2.5, R-2.7.3

## Context

Doc 2 §5.7 frames subagents as "processes with isolated state, compute budgets, capabilities, and failure domains rather than … characters with job titles", and §11 Stage 4 requires "isolated workspaces/contexts and a shared artifact/event layer rather than a giant transcript". Four ratified contracts already require a child `AgentProcess` at Stage 4 and each defines one piece of it: ADR-0053 D-1…D-4 (attenuating `delegate`), ADR-0040 decisions 2–5 (`allocate` against `remaining`, `slice`/`pool`, reserve-before-spend, `fan_out`/`delegation_depth` caps), ADR-0138 decision 3 (`derive` modes with D1–D6), ADR-0130/0131 (a child holds its own writer lease; parents subscribe `child_terminal`). No ratified ADR says how they compose into one act, what record a spawn takes as input, or what the child's first context may contain.

The audit (dossier §4) finds every production runtime spawning a child as a fresh session with a four-slot record — instruction, tool subset, model, sometimes a turn cap (Claude SDK `AgentDefinition`, opencode `Agent{mode: subagent}` + `task`, Pi/prime-agent process spawn with `--tools`/`--model`, Codex `ThreadSpawn` config from the turn context, Prime Agent `rlm(prompt, model=)`) — and *none* attenuating authority as a kernel precondition (opencode inherits only parent *denies* and states "the subagent's own permissions determine its capabilities"; Codex hands the parent's environment snapshot to the child unconditionally), none allocating a typed budget with the task (all cap and roll up: `subagent_depth`, `max_threads`, `MAX_CONCURRENCY`, `rlmMaxDepth`, `maxTurns`), and none recording why a spawn happened. The delegation-fanout race (S-209, 11/63 incidents) is the documented failure of budget-by-roll-up under concurrency.

## Options considered

1. **Subagent as a tool call inside the parent run (one ledger, one lease, child events interleaved).** *Rejected:* violates ADR-0026's one-writer-per-run and ADR-0130's own-lease rule; the child's context, budget and authority would be indistinguishable from the parent's; recovery of a parent would re-drive the child (Codex/Claude SDK exclude child threads from daemon recovery for this reason).
2. **Four separate spawn paths** (critic spawn in G3, `subagent_task` in D5, ensemble members in C2, orchestrator workers in F3), each calling `delegate`/`allocate`/`derive` on its own. *Rejected:* four places to get attenuation, containment or lease creation wrong; four payload schemas for the audit table (WS-H6 needs one).
3. **Child authority from the child's own definition** (opencode/Claude SDK semantics), with the parent's denies inherited. *Rejected:* widening by definition; contradicts ADR-0034 P2 / ADR-0053 D-1 (ratified, constitutional).
4. **Parent transcript copied into the child by default** (Codex `fork_turns = all`, Claude Code forked subagents). *Rejected as the default:* re-imports the label-laundering channel ADR-0034 closes and makes the child's `context_label` a fiction; kept as typed `supplies.context_items`.
5. **A distinct `delegate` `EffectDomain` by dialect bump** (OQ-135 option b). *Rejected:* no monitor check needs a new domain — Π's `spawn_process` row already reads "allow if attenuation holds" (ADR-0052); the OS-process vs agent-process distinction is a `ResourcePattern` scope kind (ADR-0051 H-5).
6. **One kernel `spawn` operation composing the four ratified primitives atomically over a typed `SubagentSpec`, fresh context by construction, typed supplies, attenuated grants recorded as a delta, one event payload, `spawn_process` as the domain with an `agent_process` scope kind (chosen).**

## Decision

1. **A subagent is a run.** An `AgentProcess` (native or `hosted = OpaqueProcess`) reached by a `delegated-to` edge, executed as its own run (`run_kind = agent`) with `parent_run_id`, `spawn_event` (ADR-0027 decision 6), its own ledger, writer lease, `BudgetNode`, handle set and — when requested — its own derived environment handle. Nothing else distinguishes a child run from a root run.
2. **One path.** `spawn(parent, lease, decision: DecisionRef, spec: SubagentSpec, at) → Spawned{child_run_id, child_handles[], budget_id, env_handle_id?, spawn_event} | SpawnRefused{reason}` is the only operation that creates a child run. `Delegate` steps (ADR-0016), `subagent_task` lowerings (ADR-0085), critics (ADR-0116), `EnsembleProcedure` members (ADR-0123) and A2A tasks (ADR-0096) all reach it. Steps, atomic and idempotent on `(decision, H(spec))` (a crash mid-spawn re-runs to the same `Spawned` or a clean `SpawnRefused` with everything released): (1) envelope checks — `fan_out + 1 ≤ cap`, `delegation_depth + 1 ≤ cap`, `reserve(spawns, 1)`; (2) `authorize` as a `spawn_process`-domain proposal with `scope = ResourcePattern{kind: agent_process{harness_def_ref?, max_depth}}`; (3) `delegate` (ADR-0053 D-1/D-2); (4) `allocate(parent_budget, spec.budget.spec, mode)` (ADR-0040); (5) `derive` if requested (ADR-0138); (6) child run creation with `parent_anchor` (ADR-0067) and `acquire(writer(child))`; (7) `control.subagent.spawned` (payload in decision 5) and `subscribe(parent, child_terminal{child})` (ADR-0131); (8) `await` → `Cue.wait{delegation_completed}` (the parent may `suspend{awaiting_child}`), or `background` → return immediately.
3. **`SubagentSpec` (MUST-data).** `{process: native{harness_def (may equal the parent's semantic_id), profile_binding (default: parent's `subagent` role, ADR-0121/0124), control_strategy?, slots?} | hosted(Ref<OpaqueProcess>), goal: Goal{statement: Text, success_criteria[], budget, origin = delegated, parent}, role ∈ {subagent, judge}, requested_grants: [Grant], budget: {spec: BudgetSpec, mode ∈ {slice, pool}}, isolation: {context: fresh, environment: none | derive{mode, spec}, memory_namespace: child}, supplies: {context_items[], procedures[], tools ⊆ parent's sealed tool table, memories[]}, return_contract: ReturnContract{artifacts: [{kind, schema?, required}], summary: {schema?, max_tokens} | none, claims: bool}, wait: {mode ∈ {await, background}, timeout: TimeoutPolicy[subagent]}, on_parent_end ∈ {cancel, detach_to_child}, delegation_reason ∈ {parallelism, clean_context, isolation, independent_check, specialization}, topology_ref?, stage_index?}`.
4. **Inheritance rules (invariants; errors, never warnings).** **SP-1 never widen:** `child_handles ⊆ delegable(parent)` scope-wise, `ceiling ≤ eff(parent at spawn)`, requests attenuated never rounded up, `attenuation_delta` recorded; a child's `permission_request` is decided by the principal, never the parent process; `validate` rejects a `Delegate` step whose `requested_grants ⊄ authorizes(parent)` (`AuthorityWidening`). **SP-2 conserved budget:** `allocate` only if `hard ≤ parent.remaining`; `slice` remainders return on the child's terminal; `pool` children only tighten; charges propagate to every ancestor; exhaustion is root-first (ADR-0040). **SP-3 fresh context:** the child's first `context.assembled` ⊆ `supplies` ∪ its sealed definition ∪ kernel notices; parent items enter only as `ContextItem`s with their own provenance, labels and `delivery_id`; `context_label ≤ ceiling`; the parent's transcript bytes are never copied. **SP-4 bounded:** `fan_out`, `delegation_depth` and message-rate caps refuse the next increment (`SpawnRefused`), never stop a run. **SP-5 own lease, own ledger:** no cross-run appends; causality by `causes[]` and anchors. **SP-6 one decision per spawn:** `causes[] ∋ control.decision{kind: delegate, owner, delegation_reason}` (ADR-0103 I1). **SP-7 sealed children:** `process.harness_def` resolves to a sealed definition or registered variant; repo-supplied agent text enters only as `Text{authority ≤ external}` inside one (ADR-0063/0064). **SP-8 hosted children unchanged:** a hosted child is an `OpaqueProcess` with boundary budget/handles (ADR-0040 decision 7, ADR-0053 D-4); a subagent inside a hosted H is `spawned{observed: true}` with no child run (ADR-0164).
5. **Event payload (one schema for every spawn path; consolidates ADR-0053 D-6 and ADR-0067 decision 4 — CF-394).** `control.subagent.spawned{child_run_id, delegation_ref, child_handles[], parent_handle, ceiling, attenuation_delta, budget_id, mode, isolation_mode, env_handle_id?, supplies_digest, return_contract_ref, delegation_reason, owner, topology_ref?, wait_mode, on_parent_end, depth, parent_head_at_spawn{seq, hash}}`; `control.subagent.result{…}` / `cancelled{…}` per ADR-0187; audit-grade (ADR-0066).
6. **OQ-135.** `Delegate` is a `spawn_process`-domain effect with `EffectAttributes{additive, non_idempotent, closed, compensable(cancel)}` and an `agent_process` scope kind; no new domain.
7. **OQ-328.** Never a second kernel session on an instance: two subagents sharing an environment are two scoped handles under the parent's single session with distinct `attribution_token`s and E5 resource keys. **OQ-189 (F3 half):** a parent constrains a child's budget node only; per-slot shares are the child's definition parameters, overridable through `SubagentSpec.process.slots` as an `experiment`-class layer.

**T-LCD statement (ADR-0007 decision 5).** Satisfies T-LCD-06 (hosted children through the same operation; no native field added), T-LCD-07 (`subagents` tri-state on hosted; `n/a` never coerced), T-LCD-08 (the operation takes the child's profile binding and budget node as inputs), T-LCD-09 (`mode`, `isolation_mode`, `delegation_reason`, `depth` are explicit factors), T-LCD-12 (operation over records; the worker holding the child lease is out of process), T-LCD-14 (child budgets nest inside the arm's `MatchSpec`), T-LCD-05 (a profile-conditioned spawn default is a conditioned rule with a debt record), T-LCD-02 (`goal.statement` is a `Text` leaf with provenance). Not applicable: T-LCD-01/-03/-04/-10/-11/-13 (no model-facing surface or lowering is introduced). **ADR-0024 rungs:** `spawn`, SP-1…SP-8 and the payload schema are MUST-code; `SubagentSpec`, caps, defaults and `ReturnContract` are MUST-data.

## Evidence (doc 3 §3.3 synthesis contract — all five mandatory)

- **(a) Mechanism evidence:** processes-not-personas and the four design questions (state, writes, merge, containment) — doc 2 §5.7 (Tier B); attenuating delegation is `no-precedent` in shipped runtimes and constitutional here — ADR-0034 P2, ADR-0053 D-1 (ratified; Capsicum S-256, Miller S-254, Tier A); budget-by-roll-up overshoots under concurrent fan-out — S-209 (`provisional (mech)`, incident-level) and ADR-0040 (ratified); the child as a full session with independent context — S-036 (Tier B), S-116 `docs/rlm.md` ("a normal child `AgentSession` with an independent context and session directory"), S-064 (`provisional`: "the recursive unit is a full agent harness"); the four-slot spawn record — S-109 `AgentDefinition`, S-111 `Agent{mode: subagent}`, S-565 AOrchestra ⟨Instruction, Context, Tools, Model⟩ (`provisional`, corroborating); isolation as the only label exemption — ADR-0074 decision 5 (ratified); child transcripts kept apart from the parent — S-109 `subpath = "subagents/agent-{id}"`.
- **(b) Source-code precedent:** `claude-agent-sdk-python/src/claude_agent_sdk/types.py` L87–107 @ ad77094 (`AgentDefinition`), L2212–2216 (`agents` option); `opencode/packages/opencode/src/tool/task.ts` L100–123 @ 9f8db11 (depth walk; `ctx.ask({permission: "task"})` before spawn; `sessions.create({parentID, agent, permission})`), `agent/subagent-permissions.ts` (deny-only inheritance — the counter-example); `pi-mono/packages/coding-agent/examples/extensions/subagent/index.ts` L300–346 @ 400d690 (fresh process, `--no-session`, tool allowlist); `prime-agent/packages/coding-agent/src/core/rlm-runtime.ts` L272–319 @ 427ea4c (`rlmDepth/rlmMaxDepth`, `spawnedByRequestId`, host-owned child lifecycle); `codex/codex-rs/protocol/src/protocol.rs` L2835–2850 @ 0735c51 (`ThreadSpawn{parent_thread_id, depth, agent_role}`), `core/src/agent/control.rs` L741–812 (root registration at depth 1; unconditional environment inheritance; conditional exec-policy inheritance — counter-examples), `core/src/agent/control/execution.rs` (`max_threads` limiter), `core/src/tools/handlers/multi_agents_v2/spawn.rs` L286–320 (`fork_turns` — the precedent for typed `supplies.context_items`). The atomic composition, `attenuation_delta`, fresh-context-by-construction, one payload schema and the `agent_process` scope kind are **`no-precedent / novel`** as an integrated contract.
- **(c) Disconfirming evidence considered:** specialist children legitimately need tools the parent does not use (opencode/Claude SDK let the child's definition decide) — answered by `delegable` grants at `seal` or a principal-decided `permission_request`, never parent widening; copying the parent transcript avoids duplicated discovery (Codex `fork_turns`; S-036 duplicated searches) — kept as typed supplies so labels stay honest; a per-spawn `allocate`/`reserve` adds ledger writes and may under-utilise (ADR-0040 (c)) — accepted, staged: `slice` at Stage 4, `pool` reservation only for concurrent children; a single operation for critics, ensembles and workers may under-serve one of them — each is a preset over the same record and the audit found no spawn field outside the four slots plus caps. None overturns.
- **(d) Conditionality:** independent of model tier; assumes ADR-0053 `delegate`, ADR-0040 `allocate`, ADR-0138 `derive` and ADR-0130 leases exist at Stage 4 in minimal form; `pool` mode assumes concurrent children under one root ledger; hosted children assume ADR-0164/0165 mediation; the C1 slice is required by ADR-0053 (e), ADR-0116 (e) and ADR-0085 (e) regardless of whether the C3 orchestrator class is built.
- **(e) Build-stage assignment:** **C1 / Stage 4** — `spawn` steps 1–8 for native children with `wait = await`, `isolation.environment ∈ {none, fresh_from_image, fork_snapshot, scoped_subtree}`, SP-1…SP-8, the event payload, AC-F3-01/-02/-03/-07/-08/-09/-12; critics (G3) and `subagent_task` (D5) consume it. **C3 / Stage 4** — `background`, `detach_to_child`, `delegation_reason` enforcement (with ADR-0186). **C3 / Stage 5** — `share` mode children, recursive depth > 1. **C2** — hosted children over A2A. Stage note proposed on R-2.6.3 (CF-397): a C1/Stage 4 slice without a tier change.

## Consequences

- WS-G3, WS-D5, WS-C2 and WS-E4 replace their own spawn descriptions with calls to `spawn`; WS-H6's audit table takes decision 5's payload; WS-B1 adds the payload fields and `control.subagent.message/merged/detached` (CF-394).
- WS-F1's `delegate` decision carries `delegation_reason` and `owner`; WS-F2 refuses a `delegate` without a reason and implements the spawn's envelope checks; WS-F4 emits `owner = code` delegate decisions and never bypasses `spawn`.
- WS-F5 inherits SP-5 (no shared mutable context; shared state is artifacts, environments and its ownership model) and the `share` attribution rule.
- WS-K2's run-tree view is a projection over `parent_run_id`/`spawn_event`; WS-J3 treats `depth`, `mode`, `isolation_mode` and `delegation_reason` as factors.
- Scope register: R-2.6.3 gains a C1/Stage 4 stage note (CF-397).

## Reversibility

**Low** for SP-1/SP-2/SP-5 (they restate ratified ADR-0034/0040/0053/0130 at the seam; loosening any would reopen the S-104/S-209 classes); **medium** for the `SubagentSpec` field list and the event payload (additive by dialect bump; removing a field after Stage 4 is a ledger schema migration); **high** for defaults (`wait`, `on_parent_end`, caps — data).
