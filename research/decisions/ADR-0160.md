# ADR-0160 — The compatibility surface as an analysis product (OQ-019/OQ-050): model forms, minimum design per cell, `FittedSurfaceReport` with assumption-debt expiry, no interpolation across categorical axes, and evidence-ref-only consumption by profile learning

**Status:** ratified
**Owner workstream(s):** WS-J4 (with WS-A2 definition, WS-I6 debt management, WS-C3/I5 consumers, WS-J3 design, WS-J6 re-probe cadence) · **Phase:** 3 · **Related:** ADR-0012 (decision 7: surface as derived view; `FittedSurfaceReport`; `fit_surface` refuses `UnknownLevel`; model form is WS-J4's), ADR-0013 (admissible granularities), ADR-0020/0124/0126 (profile rules with assumption-debt records; observable expiry triggers; link refuses incomplete records), ADR-0037 (annotated-never-hidden; supersession), ADR-0041 (one `MatchSpec` per comparison set), ADR-0045/0046 (design, pairing, matched budget), ADR-0143/0144 (`SuiteValidityRecord`; strata), ADR-0007 (T-LCD-05 reflexive, T-LCD-09); ADR-0158 (estimators); OQ-019, OQ-034, OQ-050, OQ-365, OQ-368; R-2.10.4, R-2.1.1, R-2.9.6

## Context

Doc 2 §1/§10 ask for a *compatibility surface* — a response surface over model family/version × task × context budget × tool ABI × environment — and whether model-specific profiles can be compiled from it (OQ-019). ADR-0012 (ratified) settled the ontology: Ψ_θ : F → Dist(Δ) is a derived view over a mixed, mostly categorical factor space, estimated by designed experiment, persisted only as a `FittedSurfaceReport{…, configuration_ids[], expiry_condition}` that refuses `UnknownLevel`, never interpolates categorical axes, and leaves *model form and staleness policy* to WS-J4 (OQ-050). Model snapshots churn faster than a surface can be fitted (S-096/S-047 via WS-A2); ADR-0126 already gives profile rules observable expiry triggers and WS-I6 manages debt records. RSM (S-167) supplies interaction terms over designed factors but assumes continuous axes; crossed random-effects models are the statistician's tool for many sparse cells but need a fitter and assumptions. Every audited plane keys results by ≤ 3 factors and fits nothing (WS-A1 F6; WS-J4 F1).

## Options considered

1. **Learn a predictive model (regression/ML) over all runs and query it for unprobed configurations.** Rejected: interpolates categorical axes (forbidden by ADR-0012), goes stale silently, and would present borrowed estimates as measurements.
2. **Surface = the full-grid `contrast` report only.** Rejected as the *only* form: sparse six-factor grids leave most cells `unknown`; ordered budget axes (context window, budget dimensions) legitimately support curves; C2 users need shrinkage across many cells *with the shrinkage reported*.
3. **Auto-compile profile rules from the surface's conditionality region.** Rejected: ADR-0020/0124 make every conditioned rule a human-owned debt record with hypothesis, evidence and removal test; the surface can *supply evidence refs*, not rules (N-list: no self-widening authority).
4. **`fit_surface` = A3 over the probed grid with declared model forms, curves only on ordered axes, a minimum design per cell, a `FittedSurfaceReport` carrying an `AssumptionDebtRecord` with registry-triggered expiry, and evidence-ref-only consumption (chosen).**

## Decision

1. **Operation.** `fit_surface(rows, factors[], metric, model_form, MatchSpec) → FittedSurfaceReport + AssumptionDebtRecord`. It is the A3 `interaction` operation over the *full probed grid* of the declared factors plus one `curve_on_ordered_axis` per ordered axis, under one `MatchSpec` (`IncommensurableMatch` otherwise), paired by task across every cell.
2. **Model forms.** `model_form ∈ {contrast (C1 default: main effects and two-way interactions as paired differences of paired differences over fully crossed probed cells, cluster-bootstrapped), factorial_glmm (C2: fixed harness × model × environment effects, random task and task × model effects; shrinkage of each random interaction reported; higher-order interactions only here), curve_on_ordered_axis (per ordered budget-like axis — context window, any kernel budget dimension, horizon — with ≥ 3 probed levels; monotone or logistic fit re-estimated per resample)}`. Categorical axes (model snapshot, environment image, task family, tool-surface target, control boundary β, hosting mechanism) are **never interpolated**; a query for an unprobed level is `UnknownLevel` (ADR-0012).
3. **Minimum design per cell.** ≥ 2 levels per included factor; `replicates_per_cell ≥ 3`; `n_tasks ≥ 30` per cell; cells below the minimum are reported as `unknown{reason = insufficient, n}` — they remain in the report, never dropped, never estimated. Factors must be admissible for every contributing row (ADR-0013): component-level axes produce a native-only surface; hosted rows join only on SUPPORTED configuration-level coordinates.
4. **Report.** `FittedSurfaceReport{metric, factors, levels, design_ref, model_form, sample_sizes, estimates_with_ci{main_effects[], interactions[], curves[]}, conditionality_region: [level tuples with Δ > 0 and interval excluding 0], portability{sign_stability along the model axis, n_families}, configuration_ids[], unknown_cells[], fitted_at, expiry_condition, status ∈ {active, expiring, expired}, debt_record_ref, generated_from}` — a persisted report with provenance (ontology §4g), never stored as truth.
5. **Staleness policy (OQ-050; T-LCD-05 reflexively).** The report's `AssumptionDebtRecord{hypothesis: "Ψ_θ over these levels is stable", evidence_refs: [report_id], owner, expiry_condition, removal_test_ref: re-fit on fresh rows}` has `expiry_condition ⊇ {any model snapshot in configuration_ids superseded or retired (registry lifecycle event), any profile in configuration_ids whose semantic_id changed (sameness L2+), any referenced SuiteValidityRecord superseded, any environment image in configuration_ids superseded, fitted_at + max_age exceeded (placeholder 90 days, OQ-368)}`. On a trigger the report is annotated `expired` (ADR-0037: annotated, never hidden or deleted) and WS-I6's manager schedules the removal test; re-probe cadence for hosted participants is OQ-034's (J6/I6).
6. **Consumers (OQ-019 second half).** WS-C3/WS-I5 may cite entries of `conditionality_region` (with the report id and its `status`) as `evidence_refs` in a `ProfileRule`'s or `HarnessRule`'s `AssumptionDebtRecord`; an evidence ref to an `expired` report makes that rule `expiring` (ADR-0126 trigger). The engine never emits a rule, a profile, a compiled surface or a routing decision; "learning profiles from the surface" is a C4 consumer decision under ADR-0020/0124's link refusal.
7. **Reporting invariants.** Portability is reported only with ≥ 2 model families and ≥ 1 held-out level (AC-I2-10); a surface with any `unknown` cell on the model axis renders its portability verdict `inconclusive`; the report always shows `unknown_cells` beside estimates.

**T-LCD statement (ADR-0007 decision 5).** Satisfies T-LCD-05 reflexively (the report carries a debt record with observable expiry and a removal test), T-LCD-09 (explicit factors; interaction terms; per-cell distributions), T-LCD-14 (one `MatchSpec` per surface; paired Δ only), T-LCD-15 (component axes native-only; `unknown`/`n/a` typed), T-LCD-07 (hosted rows join only on SUPPORTED coordinates; `unknown` never coerced), T-LCD-12. Not applicable: T-LCD-01/-02/-03/-04/-06/-08/-10/-11/-13. **ADR-0024 rung:** `fit_surface`, the no-interpolation invariant, the report schema and expiry evaluation are MUST-code; minimum-design thresholds, `max_age`, model-form choice per experiment are MUST-data.

## Evidence (doc 3 §3.3 synthesis contract — all five mandatory)

- (a) Mechanism evidence: the surface is a derived view over a mixed categorical factor space — ADR-0012 (ratified; S-167 Tier A lineage); harness effects are model- and window-conditioned, so a surface has content — S-072, S-062, S-088 (`provisional`, corroborating one mechanism; no constants used); model churn breaks fitted assumptions — S-096/S-047 via WS-A2 (S-047 Tier B production); conditioned rules must carry expiry and evidence — ADR-0020/0124/0126 (ratified); random-effect shrinkage is the standard remedy for sparse crossed designs (statistics stream, WS-J4 §3 search; Tier A methodology), admitted only with shrinkage *reported*; small-n interval behaviour for the cells — S-508 (Tier B) via ADR-0158.
- (b) Source-code precedent: `METR/eval-analysis-public/src/horizon/utils/logistic.py` L8–60 and `wrangle/bootstrap.py` L167–240 @ 52cb829 (a curve on an ordered axis — human task time — re-fitted per resample; the only audited fitted-curve pipeline), `plot/multiverse_boxplot.py` (sensitivity over analysis choices — the `model_form` disclosure precedent); `omnigent/tests/harness_bench/verdict.py` @ 6a069da (`UNKNOWN`/`NOT_APPLICABLE` lattice — the `unknown_cells` shape); `lmarena/arena-hard-auto/show_result.py` L124–222 @ 196f6b8 (covariate-adjusted pairwise model — the `factorial_glmm` nuisance-adjustment precedent). **`no-precedent / novel`:** a designed-experiment surface persisted as a report with a registry-triggered expiry and evidence-ref-only consumption (no audited plane fits or stores anything of the kind; WS-A1 F6).
- (c) Disconfirming evidence considered: (i) a surface fitted on 30-task cells with 3 replicates is noisy — accepted: the report carries intervals per cell and `unknown` for anything below the minimum; the minimum is a placeholder subject to `power()` (ADR-0158 decision 10); (ii) never interpolating makes the surface mostly blank — accepted as the program's stance (ADR-0012 decision 7): blank cells are the honest picture and the input to J3's next design; (iii) `factorial_glmm` assumptions (normality of random effects, independence across tasks) are unverifiable on small grids — answered by C2 placement, mandatory shrinkage reporting, and the `contrast` report always rendered beside it; (iv) expiry on any snapshot supersession will expire most surfaces within weeks — accepted: that is the S-096/S-047 finding made operational; expired reports remain readable and their removal test is a re-fit; (v) refusing to auto-compile rules forgoes the doc 2 §10 vision — answered: the evidence-ref path preserves the vision inside ADR-0020's discipline, and a later ADR may widen it once a removal-test history exists. None overturns.
- (d) Conditionality: independent of model tier; assumes registry lifecycle events for snapshots/profiles/images/suites exist (ADR-0036/0037/0126/0143 — ratified) so expiry is observable; assumes the Lab can vary β and component axes only for native participants (ADR-0012/0013); curves assume ≥ 3 probed ordered levels — with fewer, the axis is treated as categorical.
- (e) Build-stage assignment: **C0 / Stage 1** — `FittedSurfaceReport` schema and its debt-record binding (schema only). **C1 / Stage 3–4** — `contrast` surfaces over the Stage 3 factorials (the D2 compaction and F1 control-strategy exemplars), `conditionality_region`, KA-10. **C2 / Stage 4–5** — `factorial_glmm`, `curve_on_ordered_axis`, expiry wiring to WS-I6, K2 surface view, hosted coordinates via J6. **C4 / Stage 6** — I5/C3 consumption as evidence refs.

## Consequences

- OQ-019 is answered on the analysis side (surface = designed-experiment report; profile learning = evidence refs under ADR-0020) and OQ-050 is answered (model forms, minimum design, expiry); the remaining half of OQ-019 (whether C3 compiles rules from evidence refs) stays a C4 question for WS-I5/C3.
- WS-I6 registers `FittedSurfaceReport` debt records in its manager; WS-J2's registry emits the lifecycle events the expiry reads; WS-J3 gets `unknown_cells` as a design input.
- WS-K2 renders the surface as a grid with `unknown` cells visibly blank and `status` on the report.
- Ontology §4f's `FittedSurfaceReport` gains `unknown_cells`, `status`, `debt_record_ref`, `portability` (additive; synthesis folds).

## Reversibility

**Medium.** Model forms and thresholds are data; adding a form is a dialect bump. Reversing "no interpolation" or "evidence refs only" would require a storage/staleness design and an authority rule that do not exist (ADR-0012 §Reversibility) and would let stale surfaces write rules — the cost the decision avoids. Stored reports survive any change of form because they record their own `model_form` and inputs.
