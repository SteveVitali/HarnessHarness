# ADR-0158 — Statistical method set for the Lab: task as the unit; declared estimator selection with labelled substitution and a small-n Bayesian fallback (OQ-129); paired difference-of-differences as the default interaction estimator (T-LCD-09); heavy-tail rules; rank intervals and indistinguishable sets; TOST equivalence; `interval_method` dialect bump

**Status:** ratified
**Owner workstream(s):** WS-J4 (with WS-I2 declarations, WS-J3 design/replicates, WS-J5 leaderboard) · **Phase:** 3 · **Related:** ADR-0045 (decision 2 factors; decision 4 distributional reporting; `interval_method` enum), ADR-0046 (decision 5 pairing and estimation; T-LCD-03/-04 equivalence), ADR-0047 (`reference_relative` verdict), ADR-0012 (decision 7: no interpolation across categorical axes; harness effect paired at matched budget), ADR-0114 (severity for tails), ADR-0007 (T-LCD-09); CF-095 (replicate axis), CF-337, CF-341; OQ-016, OQ-121, OQ-126, OQ-129, OQ-365/-02/-03/-05; R-2.10.4, R-2.9.2

## Context

ADR-0045 declares `interval_method ∈ {clt, clustered_clt(task), wilson, bootstrap, bayesian_beta}` with clustered-by-task as the default for task-level binary metrics and leaves the Bayesian reporter (OQ-129) and the interaction/surface model forms to WS-J4. The Stage 3 suite has 50–169 tasks per family and 3–8 replicates (ADR-0144). In that regime nominal-95 % CLT intervals under-cover (92.5 % at N = 100 and far worse at N = 30; S-508, ICML 2025 spotlight), Wilson or Beta-Bernoulli intervals are correct and cheap, paired Bayesian intervals are narrower for two systems on the same tasks, and only a clustered model achieves nominal coverage under clustering. Inspect's clustered SE treats a missing cluster id as an error (S-136 `std.py` L75–82). Cost/latency outcomes are heavy-tailed (doc 2 §8; HAL tails, S-134) so mean-based tests are dominated by runaway runs. T-LCD-09's canned analysis is a difference of two paired harness effects. Chatbot Arena reports bootstrap rank intervals and declares overlapping models indistinguishable (S-510, Tier A); HAL's reliability code bootstraps baseline and perturbed arms *independently* (S-134 `robustness.py`), overstating variance for a within-task factor.

## Options considered

1. **Keep ADR-0045's enum and defaults unchanged; document caveats.** Rejected: `clustered_clt` at 50–100 tasks under-covers; a `clt` interval on raw spend is invalid; nothing in the enum expresses a paired bootstrap, a permutation test or a substitution.
2. **One universal method (bootstrap everything).** Rejected: percentile bootstrap also under-covers at small task counts for binary outcomes (S-508); closed-form Wilson/clustered forms are valid and cheaper where they apply; a single method hides which assumption a cell rests on.
3. **Mixed-effects (crossed random effects) model as the universal estimator.** Rejected as the *default*: requires a fitter and distributional assumptions the C0/C1 ladder should not carry; admitted at C2 as a declared `model_form` (ADR-0160 / dossier §6.5).
4. **Declared estimator selection with floors and labelled substitution; Wilson/Beta fallback; paired difference-of-differences for interactions; paired bootstrap + permutation for heavy tails; bootstrap rank sets; TOST equivalence (chosen).**

## Decision

1. **Unit.** The task is the cluster, the pairing key and the resampling unit for every interval, test and rank; replicates enter through per-task reducers (ADR-0045 `replicate_reducer`) or hierarchical resampling (`family → task → replicate` when `Design.blocking` nests); a cell with one task renders `n/a{estimator_undefined}`; a row without a task id is `MissingClusterKey` (error, per the Inspect precedent).
2. **Estimator selection is declared and labelled.** `EstimatorSelection{declared: interval_method, floors{T_clt (placeholder 100 tasks), T_bca (30 tasks)}, fallback_chain, substituted?: {from, to, reason}}` is recorded on every interval. Rules: (a) `clustered_clt(task)` is admissible only when `n_tasks ≥ T_clt`; below it the engine substitutes **Wilson** for a single proportion and **Beta-Binomial with a declared `Beta(1,1)` prior** for paired or clustered binary cells, rendering the Bayesian interval labelled `credible{prior}` beside a Wilson interval whenever both are computable — this resolves OQ-129 (`bayesian_beta` is the small-n fallback default, never silently mixed with a frequentist interval); (b) unclustered `clt` is inadmissible for any task-level metric with replicates and for any `unit ∈ {tokens, money, ms}` metric; (c) every substitution is a labelled report fact, never a warning.
3. **Paired effects.** Effect = mean of per-task paired differences (percentage points for binary metrics) at matched budget (ADR-0012/0046); `test{kind ∈ {permutation_signflip (default; exact under exchangeability), wilcoxon_signed_rank (rank cross-check), paired_bayes}}` is reported *with* the effect and interval, never alone; `sign_profile{helped, hurt, unchanged}` counts tasks.
4. **Heavy tails.** For `value_type = decimal` metrics with `unit ∈ {tokens, money, ms}`: `bootstrap_paired` on per-task paired differences (BCa when `n_tasks ≥ T_bca`, percentile otherwise), permutation p, and `tail_effects{P50, P95, max}` each with a bootstrap interval; winsorized/trimmed means only as labelled secondaries; `max` is always shown; nothing is trimmed silently. Catastrophic-failure rate uses Wilson over runs classified `critical` in any severity register (ADR-0114).
5. **Interaction estimator.** `model_form = contrast` is the default: for factors F₁, F₂ the interaction estimate is the paired difference of paired differences over fully-crossed *probed* cells (e.g. Δ_{harness | model M₁} − Δ_{harness | model M₂}), cluster-bootstrapped by task with the same `ResamplePlan`; unprobed cells are listed `unknown` and never interpolated (ADR-0012). `factorial_glmm` (fixed harness × model × environment; random task and task × model; shrinkage reported) and `curve_on_ordered_axis` (monotone/logistic fit along an ordered budget-like axis with ≥ 3 probed levels; per-resample refit as in the METR pipeline) are C2 options declared on the report.
6. **Rank.** `rank()` resamples tasks, reports a rank interval per configuration and partitions configurations into **indistinguishable sets** by overlap of the *paired-Δ* intervals (not marginal intervals); the leaderboard consumes sets (J5 decides intra-set ordering, OQ-369).
7. **Equivalence.** `equivalence()` is two one-sided tests against `PreRegistration.equivalence_margin` per dimension: `equivalent` iff the paired-Δ interval lies within ±margin, `not_equivalent` iff it excludes the margin band, else `inconclusive` (ADR-0047 `reference_relative`).
8. **Resampling parameters.** `draws` per report class (placeholders 2000 confirmatory / 200 preview, OQ-366) and `seed` are declared in the spec and recorded in the report; one plan per report; hierarchical when nesting is declared.
9. **Enum growth (CF-337).** `interval_method` grows by dialect bump to `{clt, clustered_clt(task), wilson, bootstrap, bootstrap_paired{bca | percentile}, bayesian_beta{prior}}` and `ComparisonReport` gains `test{kind}`, `sign_profile`, `tail_effects`, `EstimatorSelection` (additive).
10. **Power (OQ-121 input).** `power()` simulates from pilot per-task rates under the declared design and reports the detectable Δ at `(n_tasks, replicates)` with the paired-binary CLT formula (S-234) as a cross-check; J3 owns the defaults.

**T-LCD statement (ADR-0007 decision 5).** Satisfies T-LCD-09 (the contrast estimator *is* the canned interaction analysis, executable against the explicit factor tuple with an interval), T-LCD-14 (paired effects only at matched budget; A8 refuses unequal budgets), T-LCD-15 (every estimator renders `n/a{estimator_undefined}` where undefined; class-inadmissible cells stay `n/a{class}`), T-LCD-12 (records and operations). Reflexively T-LCD-05: floors, priors and draws are MUST-data placeholders with OQ owners, revisited when the Stage 3 suite sizes are fixed. Not applicable: T-LCD-01/-02/-03 (supplies the operation), -04, -06, -07, -08, -10, -11, -13. **ADR-0024 rung:** the selection rule, estimators, tests and the no-interpolation invariant are MUST-code; floors, priors, draws, margins are MUST-data.

## Evidence (doc 3 §3.3 synthesis contract — all five mandatory)

- (a) Mechanism evidence: CLT under-coverage below a few hundred datapoints and the Wilson/Beta/paired/clustered remedies — S-508 (Tier B, accepted); questions as a super-population sample, clustered SE, paired differences, power — S-234 (Tier C, implemented in Inspect); bootstrap and BCa — S-516 (Tier A); pass^k/pass@k with n = replicates — S-127/S-235 (Tier A) and S-238 (`provisional`, the misuse); rank intervals and indistinguishable sets — S-510 (Tier A), rank instability at small n — S-239 (`provisional`, cross-check only); heavy tails dominate operational risk — doc 2 §8 (Tier B), HAL tails S-134; TOST — S-521 (Tier A); interaction terms over designed factors — S-167 (Tier A), no interpolation across categorical axes — ADR-0012 (ratified); the S-072 window × harness effect (`provisional`) illustrates what the contrast must recover and supplies no constant.
- (b) Source-code precedent: `inspect_ai/src/inspect_ai/scorer/_metrics/std.py` L57–120 @ 75f4891 (cluster partition as single source of truth; missing id is an error; finite-cluster correction; single cluster ⇒ 0 — J4 renders `n/a` instead), `scorer/_reducer/reducer.py` L164–189 (`pass_at` NaN below k); `tau-bench/tau_bench/run.py` L181–203 @ 59a200c (pass^k); `METR/eval-analysis-public/src/horizon/wrangle/bootstrap.py` L70–240 @ 52cb829 (nested resampling; per-resample refit), `utils/logistic.py` L8–60 (weighted logistic, fractional successes), `compute_task_weights.py` L14–57 (task/family weights); `lmarena/arena-hard-auto/utils/math_utils.py` L109–183 @ 196f6b8 (bootstrap pairwise model, `num_round = 100`), `show_result.py` L99–122 (5/95 % quantiles); `lm-evaluation-harness/lm_eval/api/metrics.py` L528–612, L625–690 @ ad8737ae (bootstrap SE, selection by metric kind, pooled SE). **Negative precedent rejected:** `hal-harness/reliability_eval/metrics/robustness.py` L60–80 @ 16bb03e (unpaired resampling of a within-task factor; fixed seed 42, 200 draws). **`no-precedent / novel`:** a declared selection rule with labelled substitution; paired difference-of-differences with cluster bootstrap as a Lab operation; permutation/tail-effect reporting on paired agent costs; TOST over scorecard dimensions.
- (c) Disconfirming evidence considered: (i) priors are contestable and credible ≠ confidence — answered by a fixed declared prior, the `credible` label, the Wilson companion and stored (c, n) for re-derivation; (ii) `contrast` discards cross-cell information a mixed model would borrow — answered: unprobed = unknown is the program's stance (ADR-0012); `factorial_glmm` is admitted at C2 with shrinkage *reported*; (iii) permutation tests need exchangeability, violated when replicate counts differ across arms — answered: pairing is by task on per-task reducers, so arms contribute one value per task; unequal replicates are an `InsufficientReplicates` cell per ADR-0046; (iv) bootstrap cost — answered by shared resample plans, closed forms where valid, `preview`; (v) S-239 argues pass@k-style rankings are unstable — accepted; it is why rank is reported as sets with intervals; (vi) T_clt = 100 is arbitrary — accepted as a placeholder (OQ-367); S-508 itself declines a hard N*. None overturns.
- (d) Conditionality: independent of model tier and task class; assumes the ADR-0045 row shape with per-task (c, n) and replicate indices; assumes 30–300 tasks per family (ADR-0144 sizes) — above ≈ 300 tasks the floors make `clustered_clt` the operative default; assumes pairing by task is possible (same task set across arms — an ADR-0046 precondition).
- (e) Build-stage assignment: **C0 / Stage 1** — `interval_method` dialect bump, `EstimatorSelection`, `ResamplePlan`, `ComparisonReport` additions. **C0 / Stage 3** — Wilson/Beta/clustered intervals with the selection rule, paired effects + permutation, tail effects, `contrast` interaction (AC-I2-1), TOST (AC-I2-6/T-LCD-03), KA-1/-2/-8/-9/-12. **C1 / Stage 3–4** — rank sets (J5), power (J3), hierarchical plans. **C2 / Stage 4–5** — `factorial_glmm`, `curve_on_ordered_axis`.

## Consequences

- WS-I2's registry rows keep their declared `interval_method`; the engine records substitutions, so no stored declaration changes (CF-337 is additive).
- WS-J5's leaderboard renders indistinguishable sets; WS-K2 shows intervals, substitution labels and sign profiles by default.
- WS-J3 must ensure identical task sets across compared arms and consumes `PowerReport` for OQ-121; `draws`/`seed` become fields of `AnalysisSpec` the launcher sets.
- WS-I5's C4 gates ("interval excluding zero at the pre-registered level") read intervals produced under this rule, so a gate can never pass on an under-covering CLT interval at small n.
- KA-1/-2/-7/-8/-9 are the Stage 3 acceptance fixtures for this ADR.

## Reversibility

**High.** Estimators are additive enum members; floors, priors and draws are data. Reverting to unlabelled CLT defaults is a one-line policy change whose cost is under-covering intervals silently entering C4 gates — the failure this ADR closes. Stored (c, n) and per-task values let any historical cell be re-estimated under either policy.
