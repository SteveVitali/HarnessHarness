# ADR-0039 — Unified resource taxonomy and accounting contract (canonical token roles, charges with attribution, spend derived with provenance)

**Status:** **ratified, amended** (Phase 2 synthesis, 2026-09-10); previously: **ratified, amended** (Phase 1 synthesis, 2026-09-10)
**Owner workstream(s):** WS-L2 (with WS-B1 for event envelope, WS-A3 for the `Budget` entity, WS-C1 for adapter lowering, WS-I1/I2 for export and metrics) · **Phase:** 1 · **Related:** ADR-0001, ADR-0004, ADR-0005, ADR-0007 (T-LCD-08, -13, -14, -15); ADR-0016 (entity 12), ADR-0026/ADR-0027, ADR-0030; CF-067, CF-068, CF-069, CF-070, CF-072; OQ-033 (answered), OQ-059, OQ-053, OQ-075, OQ-069, OQ-093, OQ-097; R-2.1.6, R-2.9.1, R-2.9.2

## Context

Doc 2 §4 names resource economics a cross-cutting property: tokens, model calls, wall-clock, VM minutes, network calls, fan-out and human approvals are consumed by every plane and "better" is judged on a capability-cost Pareto frontier. The scope register makes the model C0/Must (R-2.1.6). The Phase 1 neighbours already reserve slots for it — WS-A3's `Budget` entity, WS-B1's `control.budget.*` and `measurement.cost.attributed` classes, WS-A5's `(profile, accounting)` handed to every component class (T-LCD-08), WS-A2's budget vector — but none defines *what is counted, in what unit, by whom, and with what trust*.

The source audit (WS-L2 §4) shows that production harnesses disagree on the most basic quantity: Anthropic's `input_tokens` excludes cached tokens while OpenAI's prompt count includes them; HAL, OpenHands and opencode each carry ad-hoc normalisation; cache reads and writes are priced at 0.1×/1.25×/2× of base input depending on TTL; only goose records *where a cost number came from*; Harbor's hosted-agent adapters silently fall back from reported to estimated cost; Inspect and HAL *drop* judge/auxiliary usage from the record rather than re-attributing it. Phase 0 (§5.5) asked WS-L2 to define cost attribution per hosting mechanism with provenance and confidence (OQ-033).

## Options considered

1. **Minimal two-field usage (prompt/completion) plus a dollar figure**, as AutoGen and Symphony do. *Rejected:* cannot compute cache-hit rate, cannot match budgets across cache states, cannot express reasoning tokens; the incident catalogue's largest cluster is "cost-observability" (S-209).
2. **Adopt one provider's dialect** (e.g. inclusive `input`) as canonical and let adapters coerce. *Rejected:* lossy in one direction (inclusive counts cannot recover the uncached share), and cache write TTL classes have no slot.
3. **Separate usage events** (`measurement.usage.recorded`) duplicating what the producing event already carries. *Rejected:* two sources of truth for one quantity; WS-B1's "raw facts on the producing event, derived facts as views" rule.
4. **Exempt auxiliary/judge calls from accounting** (Inspect `suspend_token_limit`, HAL judge-logging stop). *Rejected:* a research instrument may never make cost disappear; re-attribution preserves the record.
5. **Canonical exclusive role decomposition + charges with attribution + spend derived with provenance/derivation/confidence/coverage (chosen).**

## Decision

1. **Resource dimensions are a closed kernel sum per HIR dialect plus registered `ext.*` dimensions.** Each dimension is a **counter** (monotone flow, summable, ceiling-bounded) or a **gauge** (instantaneous level, max-aggregated, cap-bounded). Kernel counters: `tokens.input.uncached`, `tokens.input.cache_read`, `tokens.input.cache_write[ttl_class]`, `tokens.output.visible`, `tokens.output.reasoning`, `model_calls`, `tool_calls`, `turns`, `retries`, `spawns`, `approvals.requested`, `approvals.granted`, `evaluator_calls`, `network.calls`, `time.wall_ms`, `time.working_ms`, `time.model_latency_ms`, `time.human_wait_ms`, `env.active_ms`, `env.reserved_ms`, `spend`. Kernel gauges: `context.occupancy`, `fan_out`, `delegation_depth`. `tokens.input.total`, `tokens.output.total` and any `tokens.blended` are *derived* by a declared metering formula, never stored as primary. Units: integers; money as scaled integer micro-units of a declared currency; time in ms (WS-B1 canonical-number rule).
2. **Raw usage lives on the producing event (R-ACC-1).** `model.call.completed.usage` carries the provider's raw usage *and* the canonical decomposition produced by the Model Profile's declared `usage_mapping{dialect ∈ {input_inclusive, input_exclusive}, cache_write_ttl_source, reasoning_source}`; tool/effect/environment/permission/validator events carry their own quantities. No separate usage event exists.
3. **Charges are ledger events with attribution.** `control.budget.consumed{budget_id, dimension, amount, running_total, limit?, source_event, reservation_id?, attribution}` is posted for every accountable event, idempotent on `(source_event, dimension)`. `attribution = {run_id, participant_ref, charged_to ∈ {subject, instrument}, budget_id, component_class?, component_variant_ref?, binding_locality?, model_ref{profile_ref, provider_model_id, serving_route, effort?}, ir_refs[]}`. **Nothing is unaccounted (R-ACC-2):** an accountable event without a charge fails ledger projection. **Subject vs instrument (R-ACC-3):** producers bound in the run's sealed Harness Definition (including its own validators, judges, compaction calls) charge `subject`; the experiment's grader, conformance probes, Lab-side activation/following detectors and hosting-adapter calls charge `instrument`. Both are always recorded; efficiency metrics default to `subject` and report `instrument` beside it.
4. **Spend is derived, never raw.** `measurement.cost.attributed{resource: spend, money: Money{micro_units, currency}, provenance: CostProvenance ∈ {provider_reported, gateway_reported, participant_reported, estimated_from_pricing, reconstructed_from_native_log, unknown} (ADR-0043) with derived provenance_class ∈ {measured, reported, reconstructed}, derivation ∈ {provider_priced{unit, rate_ref?}, table_priced{table_ref, table_version, tier?, ttl_class?}}, confidence ∈ {exact, bounded{lo, hi}, estimate, unknown}, coverage, pricing_ref?, source_event, model_ref, attribution}` (CF-105). Provenance is per hosting mechanism (ADR-0005): native adapter or model-boundary interception → `measured`; session-ABI `usage_update` or a participant's self-reported total → `reported`; container-installed native-log reconstruction → `reconstructed`. `exact` requires `measured` and `coverage = 1`; `reported` is `estimate` unless the participant's capability declaration marks cost accounting `supported` and a probe confirmed it (T-LCD-07). A missing pricing row is a refusal (`NoPrice`), never a zero. Pricing tables are versioned, content-addressed bundle artifacts with TTL-aware cache-write rates and optional context tiers.
5. **Totals are materialized views** (`cost_totals`, WS-B1) rebuilt from charges and spend rows, grouped by dimension × model_ref × charged_to × component variant × participant; never stored counters; reverts/rollbacks exclude charges by projection, never subtract them.
6. **Export:** token roles lower to the OpenTelemetry GenAI `gen_ai.usage.*` attributes (cache read/write, reasoning); `spend`, `charged_to` and provenance have no OTel slot and are carried as declared-loss attributes (T-LCD-11 pattern).
7. **T-LCD statement.** Satisfies T-LCD-08 (every component receives `(profile, accounting)`), T-LCD-13 (budget reminders are artifacts, see ADR-2), T-LCD-15 (token-role metrics declare `requires_observability`; `n/a` for hosted rows without usage), T-LCD-11 (declared loss on export), T-LCD-12 (operations only). Does not address T-LCD-07 itself (WS-J6) but supplies the `cost accounting` capability's probe semantics.

## Evidence (doc 3 §3.3 synthesis contract — all five mandatory)

- **(a) Mechanism evidence:** provider dialects disagree on inclusion of cached tokens and price cache roles differently by TTL — vendor documentation S-213 (Anthropic: `input_tokens` excludes cache; write 1.25×/2×; read 0.1×) and S-215 (OpenAI: cached included; 0.1×); three-dialect normalisation in HAL `hal/utils/weave_utils.py _normalize_usage` (S-134) and the denominator switch in OpenHands `llm/utils/metrics.py cache_hit_rate` (S-110). Cost provenance matters: goose `usage_ledger.cost_source` (S-112); Harbor's reported-else-estimated fallback (S-132 `agents/installed/claude_code.py` L1550–1560). Multi-agent token multipliers and variance explained by tokens (S-036, production). Budget-overrun incidents cluster on missing observability and missing primitives (S-209, `provisional (mech)`, incident catalogue auditable). Neutral export names exist without cost (S-212 OTel GenAI, Development status).
- **(b) Source-code precedent:** inspect_ai `src/inspect_ai/model/_model_output.py` `ModelUsage` (exclusive roles + cache write/read + reasoning + total_cost), `model/_model.py compute_model_cost` (TTL-aware), `model/_model_data/model_data.py ModelCost`; codex `codex-rs/protocol/src/protocol.rs TokenUsage/TokenUsageRecord` (roles; per-turn/per-thread totals keyed by response id) and `app-server-protocol/.../thread_usage.rs` (micro-unit money grouped by model/effort/speed); opencode `packages/opencode/src/session/session.ts` L370–410 (decimal pricing with tiers and provider-reported override) and `packages/core/src/session/sql.ts`; goose `crates/goose/src/session/session_manager.rs` `usage_ledger` + `CostSource`; claude-agent-sdk-python `types.py ModelUsage{costUSD, canonicalModel, provider}`; harbor `models/agent/context.py AgentContext`, `models/trajectories/metrics.py`. The *integrated* contract (canonical roles + attribution + provenance/derivation/confidence/coverage + subject/instrument) is `novel as integrated`; each piece is precedented.
- **(c) Disconfirming evidence considered:** minimal-usage frameworks are widely used (AutoGen `RequestUsage`, langgraph `recursion_limit`) — but they populate the overrun catalogue; exempting auxiliary calls is simpler (Inspect `suspend_token_limit`) — rejected because the instrument must not lose cost; prices drift and provider-reported costs are unauditable — mitigated by pinned tables and provenance stratification rather than by abandoning spend (WS-L2 §5 R1, R4, R6). None overturns: they argue for tiering and honesty fields, which the decision includes.
- **(d) Conditionality:** holds for any model tier and task class; assumes providers report per-call usage (true for all audited APIs) and that hosted participants can at least report totals (ADR-0001 minimum). `ttl_class` and context tiers are provider-conditioned and live in the pricing table, not in the kernel.
- **(e) Build-stage assignment:** C0 / Stage 0 (token roles, model_calls, tool_calls, turns, wall time on producing events) → Stage 1 (full kernel list, charge/spend event payloads, attribution, pricing-table schema, `cost_totals` view, adapter golden tests) → Stage 2 (env/network/approvals/occupancy/cache roles) → Stage 3 (metrics, stratified reporting). Pricing-table governance is C1 (OQ-093).

## Consequences

- WS-C1 adapters must declare a `usage_mapping` per Model Profile and pass golden-payload tests (AC-L2-1); WS-C4 must emit cache roles and cache-state; WS-B5/E5 emit environment and network quantities; WS-H7 emits approval counters and human wait; WS-G1/G3 judge calls carry `charged_to`.
- WS-B1 extends `control.budget.consumed` and `measurement.cost.attributed` payloads (CF-068); WS-B2's `Effect.cost` becomes a `ResourceVector` without tokens (CF-069); WS-A3 arbitrates the kernel dimension list (CF-067).
- WS-I2/J4 gain `charged_to`, `provenance`, `confidence`, `coverage` on every efficiency metric; class-scoped declarations render `n/a` rather than 0 for hosted rows lacking usage.
- WS-I3 bundles the pricing table version; WS-L4 content-addresses it.
- Answers OQ-033, OQ-059, OQ-053 (subject/instrument rule) and OQ-075 (locality stratification via attribution).

## Reversibility

**Medium.** Adding dimensions or provenance values later is a dialect bump with migration; removing the role decomposition after Stage 1 would invalidate every stored charge and cache metric. The subject/instrument split can be collapsed by view (cheap) but not re-derived if never recorded (expensive) — hence recorded from Stage 1.
