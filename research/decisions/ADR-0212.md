**Status:** ratified (Phase 5 synthesis-authored deferral ADR)
**Owner workstream(s):** WS-L1 role/WS-K4 (OQ-131/402), WS-H1 (OQ-132, OQ-133, OQ-142, OQ-201), WS-A3 (OQ-149, OQ-165, OQ-223), WS-A4/E2 (OQ-219), WS-B1/E3 (OQ-235/240); Phase 5 synthesis · **Phase:** 5 · **Related:** ADR-0050 §6 trigger 5, ADR-0179 D6, ADR-0051/0052/0053, ADR-0100, ADR-0057, ADR-0181 D6, ADR-0177 D4, ADR-0093/0094, ADR-0087, ADR-0026 (Phase-3 log), ADR-0197 D6, ADR-0198; Spec §3, §5a, §5d, §5g, §7, §11.4.1

## Context

Spec §11.4.1 lists the questions that block Stage 0 or Stage 1 — a C0 contract cannot be built there without a value or a placement the ratified ADRs leave open — and for each a MUST-data placeholder already in force. Doc 3 §8 requires a deferral ADR for every such question; none existed after Phase 4 (ADR-0208: "nothing is ratified as deferred here"). Every interim rule below is already ratified text; this ADR ratifies the *deferral* — that Stage 0/1 proceeds on the placeholder, names the entry test that closes each question, and records the debt (ADR-0197 D6; ADR-0198 D1).

## Options considered

1. **Resolve the questions here.** Rejected: each needs a measurement (OQ-131/402/133), a grammar the owning workstream has not designed (OQ-132/165/219), or a Π/HIR ruling with security consequences (OQ-142/149/201/223) — inventing them at synthesis violates the LEDGER binding constraints.
2. **Leave the gap markers and let the readiness pass decide.** Rejected: doc 3 §8 makes the deferral ADR the readiness gate's input, not its output.
3. **Defer with interim rules and entry tests (chosen).**
