# ADR-0163 — Leaderboard semantics: versioned definitions and snapshot views; no score without a validated reproducible object; class-aware strata; keys not names; matched budget or no rank; distributions; disclosure; annotate never hide; publication as export; suite validity — and retention floors for results objects

**Status:** ratified
**Owner workstream(s):** WS-J5 (consumers WS-J4, WS-K2, WS-K3, WS-J6, WS-I4, WS-L6, WS-H6) · **Phase:** 3 · **Related:** ADR-0006 N4 (not a public leaderboard service — CF-342), ADR-0001/0004/0013 (two participant classes on one plane; class-scoped metrics), ADR-0038/0141 (rows annotated with `bundle_ref`/`claimed_level`; leaderboard rows = row + name-history entry + bundle ref + status; annotated never hidden), ADR-0037 (name history; `StaleIndex`), ADR-0041/0046 (M1–M3, tolerance, `budget_match.status`), ADR-0045/0047 (distributions, `n/a{reason}`, veto), ADR-0140 (levels, `ReproReport{independent}`), ADR-0142/0143/0144 (suite validity, contamination, anti-leakage), ADR-0068 (retention order, `gc`, `Pinned`), ADR-0136 (discontinuity annotation), ADR-0007 (T-LCD-07/-09/-10/-14/-15); ADR-0161/ADR-0162; CF-342/-05/-06; OQ-085, OQ-112, OQ-173, OQ-331, OQ-110, OQ-121, OQ-372…04; R-2.10.5, R-2.9.3, R-2.9.4

## Context

doc 2 §8 states the goal: the bundle "turns a leaderboard row into an inspectable scientific object". ADR-0038/0141 fixed that leaderboards never key by name alone and that rows of retracted or revoked-dependency bundles are annotated, never hidden. The field's practice diverges: HELM summarizes immutable runs through a declarative schema and annotates contaminated cells with a level and description; the Open LLM Leaderboard keeps "Flagged" models listed with a discussion link and publishes a pinned harness commit, command and per-model `details`; SWE-bench requires logs, trajectories "not post-hoc" and best@k disclosure with a maintainer `checked` tag; Terminal-Bench 2.1 requires ≥ 5 trials and a Hub job id in a public PR; HAL shows cost per row and a Pareto frontier with the origin but no intervals; Harbor Hub rows are patchable and hideable; Terminal-Bench 1's board is a mutable `accuracy` column. *The Leaderboard Illusion* (preprint) documents private testing with retraction, sampling asymmetry and silent deprecation on a live board; BetterBench finds most benchmarks report no significance and are not easily replicated; Papers with Code's 11,745 leaderboards went static in 2025 with numbers but no objects behind them. Retention of results objects is unowned (OQ-085/OQ-112/OQ-173 J5 halves).

## Options considered

1. **A live mutable table (Harbor Hub / Terminal-Bench shape).** *Rejected:* ADR-0037 I1/ADR-0068 R1; retraction and hiding are indistinguishable from never having existed; no disclosure record.
2. **Rank by point estimate on any row that exists (Papers-with-Code shape).** *Rejected:* scores outlive objects (S-530); no intervals (BetterBench); contradicts ADR-0045 distributions and ADR-0038 bundle linkage.
3. **Publish everything, always (SWE-bench) or encrypt with a shared secret (HAL).** *Rejected as the leaderboard rule:* publication is ADR-0141's `PublicationPolicy`; the leaderboard must work unpublished inside the Lab.
4. **A separate leaderboard product/service.** *Rejected:* ADR-0006 N4.
5. **Versioned `LeaderboardDefinition` + pure `LeaderboardSnapshot` views with admission, class strata, matched-budget, distributional, disclosure and annotate-never-hide rules; publication as export; retention floors (chosen).**

## Decision

1. **Definition and snapshot.** `LeaderboardDefinition{definition_id = version_id, name via name history, title: Text, suite_manifest_ref, split_label, scope{participant_classes, granularity, model_scope}, admission: AdmissionPolicy, columns[]{metric_ref}, rank_rule{metric_ref, direction, interval_rule ∈ {point_only, interval_overlap_ties, rank_interval}, secondary[]}, strata[] ⊆ {participant_class, observability_level, model_family, hosting_mechanism, cache_policy}, disclosure_policy{require_experiment, show_registered_arms}, readers, contamination_policy_ref?, provenance}` is a versioned, name-published record. `LeaderboardSnapshot = project(definition, results store @ watermark_set)` with `snapshot_id = view_hash`, `entries[]`, `unadmitted[]{configuration_id, reason}`, `DisclosureSummary`, registry and pricing versions; snapshots are retained once published and are never deleted; `diff_snapshots` reports only flag/rank changes — an entry is never removed.
2. **`AdmissionPolicy{min_bundle_status ∈ {validated, attested, reproduced} (default validated), min_claimed_level (default R0), require_bundle_kind (default run per contributing row), min_replicates_per_task (per stage, OQ-121/OQ-375), required_match_spec_mode (M1 default; M3 for any arm with search_budget > 0), eval_budget_equality_across_entries = true, cache_policy_required?, allow_outcome_classes (ADR-0045 defaults), allow_veto_tripped = false, exclude_suite_retired = annotate, allow_hosted_observability ⊇ {events}}`** — MUST-data.
3. **Leaderboard rules L1–L9.** **L1** no score without a reproducible object: an entry is admitted iff every contributing row head carries a bundle annotation with `status ≥ min_bundle_status` and `claimed_level ≥ min_claimed_level`; otherwise `unadmitted[]` with reason; GC/redaction never removes an entry but sets `level_now` and `verifiable_by`. **L2** class-aware, never intersected: entries carry class and observability strata; inapplicable columns render `n/a{class | observability}`; rank is per stratum by default and cross-class only on columns applicable to every entry at `product` granularity, labelled so. **L3** keys, not names: one entry per `configuration_id`; names are display bindings. **L4** matched budget or no rank: one definition = one M1 matched-cap comparison (or M2 iso-cost frontier); arms with search spend need M3 and carry `selection{n_candidates_registered, rule, search_budget_ref}`; imbalance is a flag, unmatched is unadmitted. **L5** distributions: point + interval + `n` + per-task (c, n) ref + outcome counts; ties by `interval_rule`; `rank_interval` when computed (OQ-373). **L6** disclosure: entries cite their experiment run(s); the snapshot's `DisclosureSummary` counts arms registered/published/restricted, exclusions, pre-registered vs exploratory analyses; `undisclosed` under `require_experiment` (default true for published snapshots). **L7** annotate, never hide: retraction, `depends_on_revoked`, suite retirement, contamination, discontinuity, veto-tripped, DRIFT and `configuration_drift` are flags with `reason_ref`; a retracted entry remains in every snapshot that held it. **L8** publication is export: `publish(definition, snapshot, PublicationPolicy)` is an ADR-0141 lowering with a loss report, appends `measurement.leaderboard.published` and `measurement.export.delivered` per cited run, and computes `verifiable_by` for the reader set (OQ-331 J5 half: a digest-only L2 index yields `verifiable_by = R0`). **L9** suite validity: noise ceilings render beside the headline; suites retired for headline yield only round-trip/control views (ADR-0144).
4. **Retention (J5 halves of OQ-085/OQ-112/OQ-173), extending ADR-0068 R4:** `audit_envelope_floor ≥ experiment-ledger envelopes ≥ rows + row versions + analysis records + published snapshots ≥ bundle manifests ≥ blob tiers`; unpublished snapshots are cache; experiment runs are `warm` while any bound row is retained; blob GC never touches rows; `gc` is refused `Pinned` for addresses cited by a published snapshot's entries (extends ADR-0068 R2 — CF-347); redaction of cited evidence leaves the citation verifiable and flags the cell `evidence_redacted`; authorization: lab principal for `gc`/retraction, ADR-0068 R2 for redaction; durations and legal hold remain WS-L6 (OQ-173).
5. **Scope guard.** All of the above is the instrument's own results plane (lab-internal views by default); a hosted multi-tenant public service remains out of scope (ADR-0006 N4; CF-342).

**T-LCD statement.** Satisfies T-LCD-07 (strata declared, never a common subset; hosted entries stratified by capability vector), T-LCD-09 (entries per `configuration_id`; factor coordinates preserved), T-LCD-10 (names only as display bindings), T-LCD-14 (L4; `selection` record is the leaderboard form of search-vs-artifact separation), T-LCD-15 (L2 `n/a{reason}`; per-stratum ranks), T-LCD-11 (L8 loss report), T-LCD-06 (no hosted-only entry field), T-LCD-12 (operations; snapshot is a pure view). Not applicable: T-01…05, T-08, T-13. **ADR-0024 rung:** snapshot projection, admission checks, `DisclosureSummary` and `publish` are MUST-code; `LeaderboardDefinition`/`Snapshot`/`Entry` are dialect schema; `AdmissionPolicy` defaults, strata, columns, `readers`, contamination lists and retention durations are MUST-data.

## Evidence (doc 3 §3.3 synthesis contract — all five mandatory)

- **(a) Mechanism evidence:** bundle turns a row into an inspectable object — doc 2 §8 (Tier B), ADR-0038/0141; scores without objects decay — Papers with Code shutdown S-530 (production; 11,745 leaderboards static), provider snapshot drift S-047/S-049 via ADR-0038; leaderboards derived from released raw objects — HELM S-525/-04 (Tier A/B: "we release all raw model prompts and completions publicly"; contamination cells annotated with level + description), Open LLM Leaderboard S-529 (pinned harness commit + command; public `details`; "Flagged" models remain listed); disclosure failures — *The Leaderboard Illusion* S-523 (preprint, mechanism only), SWE-bench checklist S-488 (best@k disclosure; trajectories not post-hoc; `checked`), Terminal-Bench 2.1 S-489 (≥ 5 trials; job id in a public PR); intervals and replication as quality criteria — BetterBench S-531 (NeurIPS 2024: "most benchmarks do not report statistical significance … nor allow for their results to be easily replicated"), ADR-0045 (S-127 Tier A, S-234); cost per row and Pareto with origin — HAL S-135 (Tier A), ADR-0041; matched budgets — T-LCD-14, S-083 (`provisional (counter)`, via ADR-0041); class-scoped `n/a` — ADR-0004/0013/0045; retention order — ADR-0068 (Crosby–Wallach S-316 Tier A via H6).
- **(b) Source-code precedent:** helm `src/helm/benchmark/presentation/summarize.py` @63754d0 L395–436 (leaderboard = summarizer over immutable runs filtered by schema run groups) and `presentation/contamination.py` L1–60 (`ContaminationPoint{models, groups, level, description}` as ⚠/☠ cell annotations) — adopted; harbor `src/harbor/hub/leaderboards.py` @7d5285b L138–175 (`LeaderboardColumnConfig{accessor, type}`, `LeaderboardRankRuleConfig{accessor, direction, nulls}`) — adopted as the definition grammar with accessors restricted to `MetricDeclaration` refs; inspect_ai `src/inspect_ai/log/_headline.py` @75f4891 L1–80 (declared headline metric; stale declaration never silently narrows) — adapted (missing metric ⇒ `n/a{no_detector}`, unranked); **negative precedents rejected:** harbor `hub/leaderboards.py` L107–130, L217–300 (patchable rows, `hide`, replaceable trial links), terminal-bench `terminal_bench/db.py` @d28711d L27–60 and `dashboard/data_access.py` L67–120 (mutable accuracy column; cascade delete; schema re-declared in the dashboard with an embedded credential). **`no-precedent / novel`** as enforced rules: bundle-status/level admission; per-stratum ranking with typed `n/a`; a disclosure summary and `selection` record on entries; snapshot diff with no removals; reader-verifiable level.
- **(c) Disconfirming evidence considered:** L1 excludes foreign published numbers, GC'd payloads and thinly observed hosted runs and raises the bar for exploratory work; snapshots lag a live board; disclosure requirements add friction and can be gamed; the Leaderboard Illusion evidence is a preprint about a preference arena; HAL/Harbor/Terminal-Bench ship useful boards without any of this. *Why not overturning:* L1 governs entries, not rows — rows stay queryable with a typed `unadmitted` reason and foreign numbers enter as hosted R0 bundles with `unverified` authority visible; a live board is the latest snapshot at the current watermark; the disclosure record is descriptive and refuses only `undisclosed` entries under a publisher-chosen policy; the preprint contributes a failure signature already implied by T-LCD-14 and S-488; the existing boards are exactly the shapes whose failure modes (mutable rows, name keys, no intervals, no objects) the ratified ADRs already reject.
- **(d) Conditionality:** admission defaults assume Stage-3 bundles reach `validated` cheaply (R0 = manifest + ledger export, ADR-0140); `min_replicates_per_task` and interval methods are stage- and cost-conditional (OQ-121, OQ-373/-04); hosted strata depend on WS-J6's capability vectors (C2); publication defaults depend on WS-I4 contamination policies and WS-L6 consent (OQ-116/OQ-331); namespace authority for `define_leaderboard`/`publish` is OQ-110/OQ-372.
- **(e) Build-stage assignment:** **C0 / Stage 3** — lab-internal `leaderboard()` view with L1–L5 over rows + catalogue (no publication), AC-J5-3/-7/-9; **C1 / Stage 4** — `LeaderboardDefinition` via name history (with WS-J2), retained snapshots, `diff_snapshots`, L6–L9, `publish` as export, retention rules, AC-J5-4/-8; **C2 / Stage 5** — `min_bundle_status = reproduced` admission (independent reproduction, ADR-0140), hosted capability-vector strata, per-suite public `PublicationPolicy` defaults.

## Consequences

- WS-J4 supplies rank intervals and tie rules (OQ-373) and pools only across entries with equal level and `valid` status unless annotated (ADR-0141 consequence restated); WS-K2 renders flags, `unadmitted` reasons, disclosure summaries and `verifiable_by`; WS-K3 serves definitions and snapshots read-only.
- WS-I4 supplies contamination policies and `SuiteValidityRecord`s consumed as flags; WS-J6 supplies DRIFT records and capability vectors for hosted strata; WS-H6/L6 confirm the `Pinned` extension and retention durations (CF-347, OQ-173).
- ADR-0006 N4 wording is reconciled (CF-342): "leaderboard" in R-2.10.5 means these views; ontology's `Harness Lab` row is amended to "results store, experiment ledger, leaderboard views" (CF-346).
- ADR-0038 decision 3 and ADR-0141 decision 1 are satisfied and made operational; no ratified decision is contradicted.

## Reversibility

**Low** for L1, L3 and L7 (stored snapshots and citations depend on them; relaxing L1 would re-admit scores without objects — the failure the rule exists to prevent); **medium** for L2/L4/L5/L6 (policy fields; tightening is cheap, loosening after publication changes what published ranks meant); **high** for admission defaults, strata, columns, retention durations and the definition grammar (MUST-data; per definition).
