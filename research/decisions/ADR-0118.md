# ADR-0118 — The model gateway is a model-blind, dialect-parameterised transport component: it consumes the compiled provider request plan as data, yields a normalized model-event grammar with opaque owner-stamped leaves, and normalizes tool calls without repair

**Status:** **ratified** (Phase 2 synthesis, 2026-09-10)
**Owner workstream(s):** WS-C1 (with WS-A4/WS-C3 for the plan's dialect schema, WS-D1 for the rendered transcript, WS-B1 for event classes, WS-L2/WS-I1 for the terminal payload, WS-E3/WS-E5 for surface-name resolution and error rendering, WS-J6 for interposition) · **Phase:** 2 · **Related:** ADR-0005/ADR-0021 (protocols as edges; provider tool API as a lowering target), ADR-0007 (T-LCD-01/-04/-05/-06/-07/-08/-11/-12/-13/-15), ADR-0012 (boundary components; `home = model_boundary`, CF-026), ADR-0013 (hosted stays hosted), ADR-0015 (closed sums per dialect; extension rule), ADR-0019 (compilation stages; `relower`), ADR-0020 (Model Profile owns model-conditioned surfaces), ADR-0022 (`SurfaceArgMap`; E5 error rendering), ADR-0023/ADR-0025 (component classes), ADR-0026/ADR-0027 (ledger event classes; allocated ids; `surface_ids`), ADR-0029 (canonical form; redaction-safe hashing), ADR-0033/ADR-0034/ADR-0035 (authority minting; role placement; no widening), ADR-0039/ADR-0040/ADR-0043 (usage, reservation, timing obligations), ADR-0048 (Ontology v1 identifiers), ADR-0050 (D1 kernel placement; D2 no per-call boundary crossing; §8 language-use constraint); CF-044 (closed), OQ-072 (closed), OQ-063 (agreement), CF-158, CF-251/-02/-05/-08; R-2.3.1

## Context

Doc 3 §5 asks WS-C1 to design a provider-agnostic inference contract (messages/blocks, tool definitions, tool-call normalization, streaming events, usage/cost hooks, errors, capability discovery) and to fix the boundary with the Profile Compiler: "the adapter is semantic-neutral, the profile is model-specific". Phase 1 pre-registered the split (CF-044): the profile owns everything model-conditioned that changes the bytes the model sees and the compiler emits it as data; the gateway owns transport only and is parameterised by the *provider request plan*; a model-id branch in the gateway is a profile bug. OQ-072 (blocking) asked whether the gateway consumes that plan as data or owns per-provider serialisation tables.

The source audit (WS-C1 §3, §4a F1–F2, F5) read seven provider-abstraction layers at pinned commits — goose `crates/goose-provider-types/src/base.rs` (fae91d0), pi-mono `packages/ai/src/types.ts` (400d690), opencode `packages/opencode/src/session/llm.ts` and `provider/provider.ts` (9f8db11), gemini-cli `packages/core/src/core/contentGenerator.ts` (ed2ac40), OpenHands `openhands-sdk/openhands/sdk/llm/llm.py` (3fc7b22), codex `codex-rs/codex-api/src/common.rs` (0735c51), Inspect `src/inspect_ai/model/_model.py` (75f4891) — and two protocol texts (MCP `sampling/createMessage`, OTel GenAI spans). Every contract layer is small and provider-agnostic (system + messages + tools + options in; a stream of events out); the model-conditioned and dialect-conditioned knowledge is entangled with transport as code in every system (goose `formats/*.rs`, pi `api/*.ts` with ~40 `compat` flags, opencode's 1,909-line `transform.ts` applied inside a transport middleware, OpenHands substring-rule `ModelFeatures`). One event grammar underlies every streaming API (indexed blocks with start/delta/end plus a terminal), with a small set of provider-opaque islands (reasoning/thought/text signatures, encrypted reasoning items, provider notices such as codex `ServerModel` and `SafetyBuffering`). Tool-call normalization has five precedented hazards (ids, partial-JSON arguments, names, ordering, opaque attachments), and two audited adapters *repair* calls inside the adapter (opencode lower-cases names and rewrites unparseable calls to an `invalid` tool; pi `repairJson`) — a control decision hidden in transport. The only protocol-level inference contract (MCP sampling) leaves `stopReason` an open string and is deprecated as of 2026-07-28 (SEP-2577).

## Options considered

1. **Gateway owns per-provider serialisation tables (goose/pi/opencode shape); the profile supplies flags.** *Rejected:* two owners for the same knowledge; profile-owned fields leak into gateway code branches (the opencode failure signature, T-LCD-01); CF-044 already ruled against it.
2. **Compiler-owned run-time serialisation stage inside the gateway (OQ-063 alternative).** *Rejected:* the closed-world rule (T-LCD-13) needs one renderer with one ledger footprint; D1 renders, the gateway receives rendered material (OQ-063 synthesis guidance; CF-158).
3. **A protocol-level inference contract (MCP sampling shape) as the gateway interface.** *Rejected:* open-string stop reasons make consumers non-exhaustive and the Lab unable to stratify; the feature itself was deprecated — inference contracts belong inside a runtime that can version them (ADR-0005/ADR-0021 treat protocols as edges).
4. **Non-streaming primary operation (`generate`) with streaming as an optional add-on (Inspect shape).** *Rejected as primary:* `complete = collect(stream)` is a trivial derivation (goose, pi), the reverse is not; TTFT (ADR-0043 M2/M4), mid-generation cancellation and the `ephemeral` UI channel (WS-B1) require the stream; a dialect may still declare `streaming: unsupported` and emit one `completed`.
5. **Gateway repairs tool calls (name case-folding, JSON repair, `invalid`-tool rewriting) to keep the loop robust.** *Rejected:* a repaired call misattributes the model's proposal; the control strategy decides at its `act` decision point and E5 renders the model-facing error through the profile's `error_format` (ADR-0022).
6. **A registered, model-blind, dialect-parameterised gateway component that consumes the sealed `ProviderRequestPlan` as data, owns transport only, yields a normalized event grammar with opaque owner-stamped leaves, and normalizes tool calls strictly without repair (chosen).**

## Decision

1. **Class and placement.** `ModelGateway` is a registered component class (ADR-0023/ADR-0025), `home = model_boundary` (CF-026), receiving `(ModelProfile, ResourceAccount)` (T-LCD-08), locality-neutral (T-LCD-12); the C0 variant lives in the kernel layer named by ADR-0050 D1 and crosses no boundary per model call (ADR-0050 D2). It is **model-blind** (no model identity, no per-model branch in its code) and **dialect-parameterised** (one wire codec per `WireDialect`, selected by `plan.dialect`; descriptor per ADR-0119).
2. **Operations.** `open_call(run, lease, model_call_id, InferenceRequest) → CallHandle`; `stream(handle) → ModelEventStream`; `complete(handle) = collect(stream(handle))`; `cancel(handle, reason)`; `estimate_tokens(plan) → {count, method ∈ {provider_endpoint, declared_tokenizer, heuristic}, confidence}`; `discover(endpoint_ref) → [ModelDiscoveryClaim]`; `probe(kind, model_ref, budget) → [ConformanceRecord]`; `describe(dialect | endpoint_ref) → TransportCapabilityDeclaration` (the last three per ADR-0120). Failure modes are typed: `UnknownDialect`, `PlanSchemaViolation`, `EndpointNotAllowed`, `CredentialUnavailable`, `MissingReservation`, `EstimateUnavailable`, `EndpointUnavailable`, `ProbeBudgetExhausted`, and `ModelError` (ADR-0119).
3. **OQ-072 closed: the plan is data; the gateway owns transport only.** `InferenceRequest{model_call_id, model_ref{profile_ref, provider_model_id, snapshot_id?, serving_route?}, plan: ProviderRequestPlan, context_label, budget_reservation_id, attempt_policy, deadline_ms?, cache_state_hint, seed_request?, observability{capture_request, capture_response}}`. `ProviderRequestPlan{dialect, endpoint_ref, system[], messages: [RenderedMessage], tools: [DialectToolPayload], tool_choice ∈ {auto, required, none, named(surface_name)}, sampling{…}, reasoning{effort? | budget?, replay_items[]}, cache_markers[], response_format?, provider_params: map<key, TypedValue> (every key registered by the dialect's `plan_schema` — no open map), metadata_passthrough?: opaque(owner = dialect)}` is a sealed, content-addressed document (`plan_hash = H(canonical(plan))`) produced by ADR-0019 stage 4 (provider tool-API target) plus the D1-rendered transcript (`RenderedMessage.role` is already a provider surface — ADR-0034 `role_map` applied upstream). Kernel invariants: **I1 model-blind codec** — `serialize(dialect, plan)` and `decode(dialect, frames)` are pure functions of their arguments and a static gate finds no model identifier and no profile field in codec sources (AC-C1-1); **I2 closed-world** — bytes sent = `serialize(plan)` + framing/auth/dialect-mandated envelope fields listed in the descriptor, so `request_ref` is attributable to compiled identities (T-LCD-13); **I3 nothing unaccounted** — every terminal carries `usage{available}` (ADR-0039 R-ACC-2; `available = false` ⇒ `n/a`, never zero); **I5 no authority** — the gateway stamps the call's `context_label` and never endorses, widens or reads labels (ADR-0035); **I6 no secrets** — credentials are handles; `request_ref` blobs are redacted before hashing (ADR-0029).
4. **Normalized model-event grammar (kernel sum, closed per dialect — ADR-0015).** `ModelEvent = attempt.started{attempt_no} | message.started{surface_ids{response_id?}, served_model?} | block.started{index, kind ∈ {text, reasoning, redacted_reasoning, tool_call, provider_opaque}} | block.delta{index, Text | Reasoning | ToolArgs(partial_json_str)} | block.completed{index, NormalizedBlock} | usage.updated{partial, arrival ∈ {cumulative, delta}} | provider.notice{kind ∈ {rate_limit_snapshot, served_model, fallback_boundary, safety_buffering, reasoning_included, verification_required, models_etag, other}, payload: opaque(owner = dialect)} | attempt.failed{error, will_retry, next_delay_ms?} | completed{message, stop_reason, stop_details?, usage, timing, surface_ids} | failed{error, usage?, timing}`. Grammar invariants G1–G7 (WS-C1 §6.2): one `attempt.started` per attempt and `message.started` before any block; each index opened once and completed once; tool blocks complete with `arguments ∈ {Parsed, Unparseable{raw, reason}}`; exactly one terminal; `completed.message` reconstructible from `block.completed` alone (deltas are `ephemeral`, WS-B1 `model.stream.delta`); `provider.notice` never changes classification or accounting by itself and unknown kinds are preserved byte-for-byte; events carry `{model_call_id, attempt_no, seq_in_attempt}` with any provider sequence number as a surface alias.
5. **Normalized assistant message.** `ModelMessage{blocks: [TextBlock | ReasoningBlock{text?, signature?, redacted, owner} | ToolCallBlock{tool_call_id (allocated, ADR-0027), surface_ids{provider ids}, surface_name, namespace?, arguments: Parsed | Unparseable | Raw, provider_index, truncated, thought_signature?} | ProviderOpaqueBlock{kind, payload, owner}], stop_reason, stop_details?, raw_stop_reason?, usage: UsageRecord, served_model?, snapshot_id?, surface_ids, provenance{origin = model(…), authority = delegate}}`. Every signature or encrypted item is an `OpaqueLeaf` (WS-A3 `CompiledPayload`-class opaque bytes with `{format_tag, bytes_hash, owner{provider, model}, provenance}`) the gateway never interprets; D1's renderer decides replay or drop on re-lowering (OQ-067). Model text is `authority = delegate` (ADR-0033); provider explanation strings are `external`.
6. **Tool-call normalization rules T1–T7.** Ids: `tool_call_id` allocated per ADR-0027, provider ids only in `surface_ids`, never rewritten. Arguments: deltas accumulated verbatim, parsed as strict JSON at `block.completed` into canonical form (ADR-0029) or `Unparseable{raw, reason ∈ {invalid_json, truncated, empty}}`; partial-JSON parsing exists only for the ephemeral delta channel; **no repair** in the gateway. Truncation: `stop_reason = max_output` with an open tool block ⇒ `truncated = true`, `Unparseable{truncated}`, never `Parsed` of a prefix. Names: `surface_name` carried verbatim; resolution to a `ToolCapability` is E3's via `SurfaceArgMap` (ADR-0019/ADR-0022); unknown names are E3's `UnknownSurface`, not a gateway error. Order: provider order and `provider_index` preserved; parallel calls are a list. Opaque attachments ride as `OpaqueLeaf` with `owner`. Custom/grammar tools reserve `arguments: Raw(str)` for the C2 `freeform` mode (ADR-0048).
7. **Terminal payload (obligations to ADR-0039/ADR-0043, WS-B1 extension CF-252).** `model.call.completed/failed{usage: UsageRecord{raw, canonical, view (hh-inclusive/1), normalizer_ref (profile `usage_mapping` version, CF-106), available, arrival}, cost?: Money{…, provenance ∈ {provider_reported, gateway_reported, estimated_from_pricing, unknown}, confidence, pricing_ref?}, timing{latency_ms, attempts, ttft_ms?, queue_wait_ms, measured_at = adapter}, stop_reason, stop_details?, served_model?, snapshot_id?, surface_ids, rate_limit_snapshot?, error?}`; the gateway normalises once and stamps `normalizer_ref`; probes and discovery are charged `instrument`.
8. **Lowering.** To the Hosting-ABI vocabulary (`agent_message_chunk`, `usage_update`) and to OTel GenAI (`gen_ai.response.finish_reasons`, `gen_ai.response.model`, `error.type` with declared loss) per WS-I1's loss report (T-LCD-11). The same `InferenceRequest → ModelEventStream` pair is the interception schema for hosted participants (C2, WS-J6): same codecs, same events stamped `participant_class = hosted`, no `context.artefact.delivered` (ADR-0013).

## Evidence (doc 3 §3.3 synthesis contract — all five mandatory)

- (a) Mechanism evidence: contract layers are uniformly small and provider-agnostic while dialect/model knowledge is entangled with transport as code (S-112, S-113, S-111, S-119, S-110, S-107, S-136 — WS-C1 F1); one grammar underlies every streaming API with opaque islands (S-440 Anthropic streaming; S-107 `sse/responses.rs` and S-110 `_process_stream_event` for the Responses grammar; S-113 `AssistantMessageEvent` invariant "Updates and `done` must never appear before `start`" at `types.ts` L537 — F2); five tool-call hazards (S-113 `repairJson`, S-111 `experimental_repairToolCall`, S-112 `output_token_limit_tool_error`, S-110 `MessageToolCall{id, responses_item_id, origin}` — F5); function calls are compared as normalized name + typed arguments independent of wire format (S-442, Tier A); tool names and schema formatting are model-conditioned and so belong to the profile (S-177 via WS-A4); the protocol-level contract left `stopReason` open and was deprecated (S-153 `schema/2026-07-28/schema.ts` SEP-2577).
- (b) Source-code precedent: pi-mono `packages/ai/src/types.ts` L524–567 and `utils/assistant-message-frame.ts` (400d690) — indexed block grammar, terminal reconstructible without deltas; goose `crates/goose-provider-types/src/base.rs` L464–530 (fae91d0) — `complete = collect(stream)`; gemini-cli `packages/core/src/core/contentGenerator.ts` L38–60, L215–260 (ed2ac40) — four-operation interface with decorator composition and recording/fake variants; codex `codex-rs/codex-api/src/common.rs` L80–130 (0735c51) — provider-notice channel; Inspect `src/inspect_ai/model/_model.py` L408–430 (75f4891) — operation-shaped `generate`; OpenHands `openhands/sdk/llm/message.py` L122–160 (3fc7b22) — opaque signed/encrypted reasoning items with owner. Plan-as-sealed-data with a model-blind codec gate, and no-repair tool normalization as a kernel rule, are `no-precedent / novel as integrated`.
- (c) Disconfirming evidence considered: every audited system keeps request builders as code per API and some straddle the CF-044 line (goose cache-breakpoint look-back inside the serialiser; pi `compat` auto-detection from base URL; opencode transforms in transport middleware) — marker *placement* is a profile rule evaluated by D1 and expressed in the plan as positions the codec serialises without choosing, and the AC-C1-1 static gate is the tripwire (WS-C1 §5 R1); Inspect's non-streaming `generate` serves 47 providers — streaming-primary costs one derivation and buys TTFT/cancellation (§5 R6); repair makes loops robust in shipping products — robustness moves to the control strategy's `act` decision point with the proposal preserved (§5, F5). None overturns.
- (d) Conditionality: assumes providers expose a message/blocks API with tool calls (true for every audited API; a dialect without native function calling is served by the C2 shim wrapper, not by this contract); assumes the compiler can emit a plan rich enough to carry every marker/flag a profile sets (ADR-0021's lowering-target schema); holds for any model tier, task class and budget; interception for hosted participants is C2 and yields no plan hash.
- (e) Build-stage assignment: **C0 / Stage 0** (one dialect; `open_call/stream/complete/cancel`; usage + `latency_ms`) → **C0 / Stage 1** (grammar, `ModelMessage`, T1–T7, terminal payload, AC-C1-1/-2/-3/-7/-8/-10/-11/-13, recording/fake variant) → **C0 / Stage 3** (second dialect from a different provider family so T-LCD-04's two-profile compile also exercises two codecs) → **C2** (interposition and `freeform`/shim wrappers).

**T-LCD statement (ADR-0007 decision 5).** Satisfies T-LCD-01 (no model branch; static gate), T-LCD-04 (two profiles → two plans, one codec path), T-LCD-05 (dialect rules carry debt records — ADR-0119), T-LCD-06 (interception adds no native edge), T-LCD-07 (transport capabilities declared, never intersected — ADR-0120), T-LCD-08, T-LCD-11 (OTel/Hosting-ABI lowering with declared loss), T-LCD-12 (fake/recording variant in the same slot; out-of-process live variant admissible), T-LCD-13 (`request_ref` attributable to compiled identities), T-LCD-15 (`usage.available` yields `n/a`, never zero).

## Consequences

- WS-A4/WS-C3 fix the plan's per-dialect `plan_schema` as the ADR-0021 lowering target's schema; `relower` on a model switch changes the plan hash and, on a family change, the dialect — nothing else at the gateway. No new `ProfileRule.kind` is needed (CF-251).
- WS-D1 and WS-C1 must agree one name for the rendered document (`RenderedRequest` vs `ProviderRequestPlan`, CF-258); the semantics already agree (builder renders, gateway consumes).
- WS-B1 extends `model.call.requested/completed/failed` payloads and adds `model.call.attempt.*` (CF-089, CF-252); `model.stream.delta` stays ephemeral.
- WS-E3/WS-E5 receive `Unparseable` proposals and `surface_name`s and own their handling; WS-F1/WS-F2 own every request-changing retry as a new logical call (ADR-0119).
- WS-H3/WS-H4 supply credential handles and the endpoint allow-list; the gateway refuses before any bytes leave (AC-C1-13).
- The conformance suite (golden streams per dialect, two independent codec implementations agreeing) is the acceptance gate for every dialect added later.

## Reversibility

**Low.** The grammar, `ModelMessage` and the plan-as-data boundary are what every model-boundary neighbour (C2, C3, C4, D1, E3, F2, I1, J6) binds to at Stage 1; moving serialisation knowledge back into the gateway after Stage 1 would re-open CF-044 and invalidate the two-profile compile test. Adding block kinds, notice kinds or plan fields is a dialect bump under ADR-0015 and is cheap.
