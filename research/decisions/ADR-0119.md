# ADR-0119 — Closed stop-reason and error-class vocabularies with retry classes; `WireDialect` descriptors as expirable data with assumption-debt records; attempt policy as data; identical-bytes transport attempts only — a request-changing retry is a new logical model call

**Status:** **ratified** (Phase 2 synthesis, 2026-09-10)
**Owner workstream(s):** WS-C1 (with WS-F2 for attempt policy supply and counting, WS-C2 for the class → action table and reroutes, WS-C3/WS-I6 for dialect-document governance, WS-B1 for attempt events, WS-L2 for reservation reuse, WS-I1 for attempt timing) · **Phase:** 2 · **Related:** ADR-0007 (T-LCD-01/-05/-09/-10/-14/-15), ADR-0015 (closed sums per dialect; `unknown`; extension rule), ADR-0016 (`DecisionPoint` — `retry`/`escalate`), ADR-0020 (`AssumptionDebtRecord`, expiry states, `provider_api_family` selector), ADR-0026/ADR-0027 (event classes; `model_call_id`; `causes[]`), ADR-0039 (`usage_mapping` in the profile, R-ACC-2), ADR-0040 (retries reuse the reservation), ADR-0043 (attempt spans M4; `measured_at`), ADR-0048; CF-089, CF-106, CF-259/-04/-05, CF-254/-05/-06/-07, OQ-285/-07; R-2.3.1

## Context

Providers add stop reasons and error codes continuously (`pause_turn`, `sensitive`, `cyber_policy`, `misalignment_policy_violation`, `usage_not_included`, verification-required); Inspect paid a migration to rename one stop value (`length → max_tokens`, `_model_output.py` `migrate_stop_reason`); MCP left `stopReason` open and then deprecated sampling. The audited gateways classify errors by HTTP status (goose `http_status.rs`, "format-agnostic"), by provider `error.code` (opencode `provider/error.ts`), and by **provider message text** — pi `utils/overflow.ts` holds 25 context-overflow regexes across 17 providers and `utils/retry.ts` ~40 retryable phrases; OpenHands `llm/exceptions/classifier.py` keeps `LONG_PROMPT_PATTERNS` and `MALFORMED_HISTORY_PATTERNS`; goose `retry.rs` keeps `PERMANENT_REQUEST_FAILURE_MARKERS` quoting provider prose because a 4xx caused by a modified signed thinking block "is rebuilt on every retry — so retrying can never succeed" (L87). None of this changes the bytes the model sees, so CF-044 assigns it to the gateway; expressed as code it is the assumption debt T-LCD-05 forbids in profiles, and it rots as fast (two providers overflow silently and are detected from usage).

Two kinds of retry coexist in production. *Transport* retries replay identical bytes on transient classes (codex `codex-client/src/retry.rs` `RetryOn{429, 5xx, transport}`; goose `should_retry`; pi `provider-retry.ts` with `x-should-retry` and capped `retry-after`; Inspect `RetryDecision{transient | rate_limit, retry_after}`, retrying attempt/stream-idle timeouts and zero-chunk streams unconditionally). *Content* retries change the request: OpenHands bumps temperature to 1.0 on an empty response (`retry_mixin.py` L49–59); gemini-cli appends a nudge and re-sends; codex `SafetyBuffering` swaps to a faster model; opencode sets `maxRetries: 0` at the SDK and retries at the session. WS-C2's sidecar (CF-259/-04) asks that C1 own the emitted error class enum and `retry-after` lifting, F2 count/back off/stop and charge `retries` once, C2 own the class → action table; CF-263 asks that the goose markers become the profile capability `reasoning_replay{opaque}` → class `transcript_incompatible`, and that neither router nor policy inspect message text. ADR-0040 already requires retries to reuse the reservation and ADR-0043 requires attempt spans under the logical call (CF-089).

## Options considered

1. **Open-string stop reasons and error codes (MCP sampling shape; OTel `finish_reasons`).** *Rejected:* consumers cannot be exhaustive, the Lab cannot stratify on undeclared values, and the failure is silent; ADR-0015 fixes closed kernel sums per dialect for this reason.
2. **Textual classification rules as code inside the codec (pi/OpenHands/goose shape).** *Rejected:* identical rot with no expiry, no removal test and no visibility; a T-LCD-01/-10 defect by the WS-C2 reading.
3. **No retries in the gateway; all attempts driven by F2 above the adapter (opencode shape).** *Rejected as execution model:* attempt timeouts, stream-idle timeouts and zero-chunk streams are observable only inside the decoder; pushing every one up the stack costs a round trip and loses attempt timing. Kept as *policy* ownership — F2 supplies the policy and counts.
4. **Request-changing retries inside the gateway (temperature bump, nudge, model swap).** *Rejected:* they double-charge silently, hide provider health from the router, and misattribute what the model saw; a changed request is a new logical call decided at a `DecisionPoint` or by the router.
5. **Closed `StopReason` and `ModelErrorClass` sums with a `retry_class`, raw surface aliases and an explicit `unknown`; dialect knowledge as versioned `WireDialect` data documents whose textual rules carry `AssumptionDebtRecord`s with golden-fixture removal tests; `AttemptPolicy` as data supplied per call; gateway-executed identical-bytes attempts only (chosen).**

## Decision

1. **`StopReason` (closed, kernel):** `{end_turn, tool_use, max_output, stop_sequence, content_filter, refusal, pause_turn, deferred, cancelled, error, unknown}` + `raw_stop_reason` (surface alias) + `StopDetails{categories[{category, level?}], explanation?: Text(authority = external)}`. `pause_turn` ("resubmit the same call") is a control-strategy decision, never a gateway retry.
2. **`ModelError{class, retry_class ∈ {transient, rate_limit, permanent, ambiguous}, attribution ∈ {provider, transport, request, account, policy, response}, retry_after_ms?, http_status?, provider_code? (surface), message: Text(external, redacted), raw_ref?}`** with `ModelErrorClass` (closed): transport `network`, `timeout{connect | attempt | stream_idle}`, `stream_decode`, `server_error`, `overloaded`, `rate_limited`; request `auth`, `forbidden`, `not_found{endpoint | model}`, `invalid_request`, `context_length_exceeded`, `malformed_history`, `transcript_incompatible` (CF-263 adopted), `unsupported_feature`, `permanent_request`; account `quota_exhausted`, `credits_exhausted`, `usage_not_included`, `verification_required`; policy `content_policy`, `safety_blocked`, `refusal`; response `empty_response`, `invalid_response{no_stop_reason | thinking_only | malformed_tool_call | unexpected_tool_call}`, `served_model_mismatch`; control `cancelled`; `unknown`. Default `retry_class` per class is fixed in the kernel (transient: `network, timeout, stream_decode, server_error, overloaded, empty_response`; rate_limit: `rate_limited`; permanent: all request/account/policy classes; ambiguous: `unknown, invalid_response`); a dialect rule may only **narrow** transient → permanent, never widen. Growth is a dialect bump (ADR-0015), never an open string; the `unknown` rate per dialect is a class-scoped Lab health metric (OQ-291).
3. **`WireDialect` descriptor** — a gateway-owned, versioned, content-addressed data document selected by `provider_api_family` (the profile selector field, ADR-0020): `{dialect_id, version, framing ∈ {http_json, sse, websocket, jsonrpc_stdio}, plan_schema, envelope_fields, auth_kinds ⊆ {none, bearer, api_key_header, oauth, sigv4, command_backed}, endpoint_allowlist_ref, streaming, usage_arrival ∈ {final_only, cumulative_stream, delta_stream, absent}, usage_mapping_default, cache_semantics ∈ {explicit_breakpoints{max}, implicit_tolerant, implicit_strict, uncached, unknown}, cache_state_visible, count_tokens, deferred_requests, model_listing, snapshot_id_exposed, retry_after_sources[], retry_after_cap_ms, stream_idle_timeout_ms, rules: DialectRule[]}` with `DialectRule{rule_id, kind ∈ {status_to_class, error_code_to_class, error_text_to_class, stop_reason_map, reasoning_in_text, metadata_frame, notice_map}, params, debt: AssumptionDebtRecord}`. Every textual rule carries the ADR-0020 debt record; its `removal_test_ref` is a golden fixture; a dialect document with an incomplete record fails to load (T-LCD-05 applied reflexively). The profile's `usage_mapping` (ADR-0039, CF-106) overrides `usage_mapping_default` per model because cache-role inclusion differs per model on one dialect. The goose signed-block markers become one `error_text_to_class → transcript_incompatible` rule with a debt record whose expiry includes `model_version_change`; the *prevention* is the profile capability `reasoning_replay` consulted by the compiler.
4. **`AttemptPolicy` (data; supplied per call by F2 from profile/configuration; C0 default in the kernel):** `{max_attempts, base_delay_ms, max_delay_ms, jitter ∈ [0.8, 1.2], honour_retry_after, retry_after_cap_ms, retry_on ⊆ {transient, rate_limit}, stream_idle_timeout_ms, attempt_timeout_ms, connect_timeout_ms}`.
5. **Retry rules.** R-RT-1 retry only on `retry_class ∈ retry_on`; never on `permanent | ambiguous`. R-RT-2 **identical bytes**: every attempt re-sends `serialize(plan)`; the plan is immutable for the life of the `model_call_id` (hash equality across attempts is tested). R-RT-3 attempts share the reservation (ADR-0040) and the `model_call_id`; each attempt is a `model.call.attempt.started/completed/failed` span (CF-089; ADR-0043 M4) carrying `queue_wait_ms` (R-RT-6). R-RT-4 a server-supplied delay above `retry_after_cap_ms` is reported (`attempt.failed{will_retry: false, next_delay_ms}`) and the call fails `rate_limited` — the envelope/router decides. R-RT-5 `pause_turn`, `empty_response` after attempts, `invalid_response`, policy and account classes are terminal for the gateway; a "retry" that changes anything about the request is by definition a **new logical call** with a new `model_call_id` and `causes[] ∋ failed event`, opened at the control strategy's `retry`/`escalate` decision point (ADR-0016) or by the router (`model.rerouted`, WS-C2). Temperature bumps, nudges, name/JSON repair and model swaps are recorded as control-strategy patterns with debt records, never gateway behaviour (CF-255).
6. **Ownership split (reconciles CF-259/-04 — CF-256).** The gateway *executes* attempts and *emits* the class enum and `retry_after_ms`; F2 *supplies* the `AttemptPolicy`, reads `model.call.attempt.*` to count and stop, and charges `retries` once; C2 owns target choice and the class → action table. No component above the gateway may inspect provider message text.
7. **`measured_at` naming (CF-254).** Propose renaming ADR-0043's enum value `gateway` to `external_gateway` so it cannot be confused with this component; the gateway stamps `measured_at = adapter`.

## Evidence (doc 3 §3.3 synthesis contract — all five mandatory)

- (a) Mechanism evidence: stop reasons and error classes converge on a small closed core with a long provider tail across seven systems and two specs (S-113 seven stop values; S-136 six + `StopDetails`; S-153 four + open string; S-440 six; S-107 twelve error variants; S-112 fourteen; S-110 fifteen — WS-C1 F6); renames cost migrations (S-136 `migrate_stop_reason`); textual classification is dialect knowledge that rots (S-113 `overflow.ts` 25 regexes, `retry.ts`; S-110 `classifier.py`; S-112 `retry.rs` L87–95 — F3); two retry kinds exist and conflating them is a documented failure (S-112 permanent markers; S-110 `retry_mixin.py` temperature bump; S-119 nudge and `SafetyBuffering` analogue in S-107 — F4); attempt/idle-timeout/zero-chunk conditions are decoder-internal (S-107 `sse/responses.rs` idle timeout; S-136 `_model.py` L1736–1822).
- (b) Source-code precedent: Inspect `src/inspect_ai/model/_model.py` L222–275 (75f4891) — typed `RetryDecision{retry, kind, retry_after}`; goose `crates/goose-provider-types/src/retry.rs` L1–140 and `errors.rs` L1–70 (fae91d0) — permanent sub-class, jitter bounds, telemetry names; codex `codex-rs/codex-client/src/retry.rs` L1–90 and `model-provider-info/src/lib.rs` L68–155 (0735c51) — retry policy and transport config as data with `stream_max_retries`, `stream_idle_timeout_ms`; goose `crates/goose-providers/src/http_status.rs` and `declarative.rs` L148–200 — status mapping and declarative provider config; opencode `packages/opencode/src/provider/error.ts` (9f8db11) — `error.code` → class with `isRetryable`; goose `formats/openai.rs` L1099–1230 — metadata-frame vs error-frame discrimination. Textual classification as *expirable data with fixture-backed debt records*, and the closed `ModelErrorClass` with a kernel-fixed default `retry_class` that dialects may only narrow, are `no-precedent / novel as integrated`.
- (c) Disconfirming evidence considered: providers add codes monthly and MCP's open string plus deprecation suggests closed sums cannot keep up (WS-C1 §5 R2) — `raw_*` aliases, `unknown` and `provider.notice` lose nothing, values are *unclassified until the next dialect bump*, and the `unknown` rate is a visible metric; one debt record per regex is bureaucracy (§5 R3) — the unit is one rule per `(dialect, class)` with patterns as `params`; retries in the gateway can double-charge and hide health (§5 R4) — ADR-0040 reservation reuse and attempt events make them visible, and the identical-bytes rule bounds them to what a transport library does anyway. None overturns.
- (d) Conditionality: assumes providers signal retryability by status/header/code (true for every audited API; text rules cover the residue); the C0 kernel default `AttemptPolicy` assumes interactive-latency budgets (max_attempts small, delays capped at tens of seconds — goose/opencode/codex defaults); holds across model tiers and task classes; matched-budget comparisons (T-LCD-14) require that `retries` be charged once, which the F2 ownership guarantees.
- (e) Build-stage assignment: **C0 / Stage 1** (closed sums, `WireDialect/1` schema with debt records for the first dialect, `AttemptPolicy` as data, R-RT-1…6, `model.call.attempt.*`, AC-C1-4/-5/-6) → **C0 / Stage 3** (second dialect's rules and fixtures; `unknown`-rate metric) → **C1 / Stage 5** (dialect-document governance cadence with C3/I6 — OQ-285; deferred requests `stop_reason = deferred`; websocket framing). ADR-0024 ladder rung: `AttemptPolicy` and dialect documents enter at *parameter/entity*; the sums and retry rules are *Core*.

**T-LCD statement (ADR-0007 decision 5).** Satisfies T-LCD-01 (no provider text inspected above the gateway; rules in data), T-LCD-05 (every conditioned rule has a debt record and a removal fixture), T-LCD-09 (`AttemptPolicy` is a component-level factor; attempts are ledgered), T-LCD-10 (classification once, at the boundary), T-LCD-14 (`retries` charged once by F2), T-LCD-15 (`unknown` is class-scoped, never coerced).

## Consequences

- WS-C2 consumes `ModelError.class/retry_class/retry_after_ms` and owns `on_attempt_failed`'s class → action table; its `transcript_incompatible` name is adopted as a class (CF-257), with the mapping in a dialect rule and the prevention in the profile.
- WS-F2 supplies `AttemptPolicy` per call, counts attempts from the ledger, charges `retries` once, and opens new logical calls for every request-changing retry; WS-F1 places `retry`/`escalate` decision points accordingly.
- WS-B1 adds `model.call.attempt.*` (CF-089) and the `failed` payload; WS-I1 renames `measured_at: gateway → external_gateway` if accepted (CF-254).
- WS-C3/WS-I6 govern `WireDialect` documents alongside profiles (same expiry states); the `unknown`-rate threshold for `expiring` is OQ-291.
- Golden fixtures per dialect (status codes, `error.code`s, error texts, retry-after forms, proxy metadata frames, idle timeout, zero-chunk stream) are the acceptance gate (AC-C1-4/-5).

## Reversibility

**Medium.** Adding classes, stop reasons or dialect-rule kinds is an ADR-gated dialect bump and cheap. Moving classification back into code, or allowing request-changing retries inside the gateway, would silently break attempt accounting (ADR-0040/ADR-0043) and matched-budget claims after Stage 1 — the costly direction. The `retry_class` default table must be fixed before the first Lab rows (Stage 3); afterwards changes are a labelled factor change.
