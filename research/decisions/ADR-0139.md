# ADR-0139 — The reproducible harness bundle is a three-layer content-addressed object: a hashed lock manifest, a content-addressed payload tree, and a detached sidecar; identity is the tree rule and archives are transport; every member is a pinned reference or an explicit claim

**Status:** **ratified** (Phase 2 synthesis, 2026-09-10)
**Owner workstream(s):** WS-I3 (consumers: WS-J5, WS-J3, WS-J4, WS-J6, WS-I4, WS-I5, WS-I7, WS-H6, WS-K2, WS-L6, WS-L5) · **Phase:** 2 · **Related:** ADR-0038 (levels, member list, completeness, results/audit keys — inherited verbatim), ADR-0036 (identity kinds, `idp`, tree rule, N1–N8), ADR-0037 (immutability, supersession), ADR-0026/0027/0029 (ledger, lineage, canonical form, offload), ADR-0019/0021 (compiled bundle, loss reports), ADR-0025 (sealed definition, `registry_snapshot_id`), ADR-0033/0035 (provenance, endorsement), ADR-0042/0044 (export as lowering; content classes), ADR-0045/0046 (rows, design, budgets), ADR-0007 (T-LCD-02/-06/-09/-10/-11/-12/-14/-15), ADR-0024 (code-vs-config), ADR-0050 §8; CF-298…CF-302; OQ-332/-03/-05, OQ-112, OQ-117, OQ-030; R-2.9.3 (primary), R-2.10.5, R-2.8.6, R-2.9.4

## Context

ADR-0038 fixed *what* the bundle contains (sections `subject … ext`), that its `version_id` is the bundle id, that every member is a pinned id or an explicit `unpinned[]` claim, that it is a Merkle tree over member addresses, and that levels R0–R3 are declared and capped by pins. It left the *format* to WS-I3: how manifest and payload are laid out and transported, how each of the twelve doc 2 §8 members is made addressable, where attestations and reports live, and what "complete" and "valid" mean operationally. The source audit (dossier §4a) shows every mature evaluation harness converging on manifest + per-unit records + raw traces + verifier outputs + summary (Harbor trial dir `config.json/lock.json/results.json/agent/verifier/artifacts/manifest.json`; Inspect `.eval` zip `header.json/_journal/samples/summaries/reductions`; SWE-bench `all_preds.jsonl/logs/trajs/metadata.yaml`), recording inputs by digest at the moment of use (Harbor `TrialLock`, Inspect `EvalSpec.revision/packages`), and stopping at the agent's boundary (`AgentInfo.version: str`, ATIF `agent.version`). RFC 8493 BagIt formalizes payload manifests, a fetch list for remote payload and the complete-vs-valid distinction; in-toto's bundle layer shows the failure of the alternative — a collection of independently signed attestations that "is not authenticated as a whole" and admits deletion, replay and injection. Harbor must zero archive timestamps and ownership to get stable archive hashes, which is the mechanism argument for keeping identity on the tree rule (ADR-0036 N7) rather than on archive bytes.

## Options considered

1. **A single self-contained hashed document** (manifest with all payload inline, Inspect-`.eval`-style). *Rejected:* payload is offloaded blobs by ADR-0029 (64 KiB default) and image/task trees; inlining defeats dedup, header-first reads, partial verification and detached publication.
2. **A directory convention without a hashed manifest** (Harbor trial dir; SWE-bench submission). *Rejected:* no single attestation subject; equality by path; Harbor itself adds `lock.json` with digest equality to recover identity.
3. **A collection of independently signed attestations as the bundle** (in-toto bundle layer). *Rejected for the manifest:* not authenticated as a whole; deletion/replay undetectable; **adopted for the sidecar**, where accumulation without identity change is exactly what is wanted.
4. **Archive-bytes identity** (hash the zip/tar). *Rejected:* transport-dependent; requires Harbor-style zeroing and still differs across archivers; violates ADR-0036 N7.
5. **Three layers — hashed manifest (identity), content-addressed payload verified against it, detached sidecar referring to it; tree-rule identity; archives as transport; pinned-or-claimed members (chosen).**

## Decision

1. **Three layers.** *M (manifest):* the ADR-0038 `BundleManifest`, one canonical record under the pinned `idp` with schema `hh-bundle/1`, whose `version_id` is the bundle id; header fields `{schema, idp, bundle_kind ∈ {run, arm, experiment, lineage}, created_at, producer: ProvenanceRecord, participant_class, observability_levels, claims[], name_bindings[], fetch_policy}` added to ADR-0038's sections; `ext` registered, preserved, never deciding validity. *P (payload):* a content-addressed store of blobs and trees addressed by `ContentAddress`, every entry reachable from M with `status ∈ {present, fetch, redacted, gc}`. *S (sidecar):* versioned records referring to M by `version_id` and outside its hash — attestations (in-toto-shaped envelopes, subject = M's `version_id`), `ReproReport`s, `BundleValidationReport`s, `BundleStatusRecord`s, `ImportRecord`s. Nothing in S can raise a level; only a superseding bundle can.
2. **Identity is the tree rule; archives are transport.** `encode(bundle, transport ∈ {directory, zip, tar, registry_objects}) → bytes` and `decode(bytes) → bundle` round-trip to the same bundle id and tree addresses; archive entries carry no ownership or timestamps; archive bytes are never hashed for identity. Dossier §6.2 fixes the directory convention (`bundle.json`, `members/<idp>/<alg>/<hex>`, `fetch.json`, `attestations.jsonl`, `reports/`) as the reference transport.
3. **Member identity rules (dossier §6.3 table).** Every member is `MemberRef{role, ref: VersionedRef | ContentAddress, media_type?, size?, status, foreign?: ForeignRef{system, digest, label, provenance}}`. R-ID-1 every `ref` is a full digest under a readable `idp` (`UnpinnedMember` otherwise); R-ID-2 a `Claim` or `foreign` digest satisfies no level requirement above R0; R-ID-3 directory-shaped members use the one tree rule, foreign tree digests are carried as `foreign` and the native address computed on import when bytes exist (CF-087); R-ID-4 names appear only in `name_bindings[]`/`claims[]` (T-LCD-10); R-ID-5 `registry_snapshot_id` is over the closure (ADR-0036); R-ID-6 no member role exists only for hosted participants — hosted bundles fill a subset and list the rest as `unpinned{hosted_mechanism}` (T-LCD-06); R-ID-7 every locator is credential-free and a bundle containing secret material is invalid and unpublishable. The per-member table binds: model roles → `ModelSnapshotRecord` claims (WS-C1); definition → sealed `version_id + semantic_id`, dialect, `InstrumentRecord{dirty ∈ {true,false}}` (never unknown); profile → `version_id + semantic_id` + compiled `bundle_id`/`derivation_key`; instructions → **no separate member** (Text-leaf semantic ids + compiled surface; T-LCD-02); tools → capability ids + per-profile surface hashes + surface pins; extensions → WS-H5 `{extension_id, content, trust_record, attestation_refs[], surface_pin}`; environment → `EnvironmentRecord{image digest | foreign_digest, build_context?, snapshot_refs[], fault_profile?}`; permissions/policies → version ids; context/memory policies → variant records in the closure + optional memory snapshot; budgets → `Budget` ids + `MatchSpec`/`eval_budget`/`search_budget`; graders → validator/oracle version ids + executable tree addresses (or `foreign`) + judge profile/calibration refs; task data → `TaskDataRecord{manifest, tree, foreign_digest?, split_label, task_split_hash}`; traces → per-run `LedgerExport{events: chunked tree, checkpoints[], blob_index[], head, lineage_prefixes[]}`; plus results rows, declarations, design/pre-registration, pricing snapshot (`pricing_ref` is a member by default — OQ-117 I3 half), opacity/LCD/loss reports, optional interchange export.
4. **Complete vs valid** (RFC 8493 vocabulary). *Complete:* every member M references is listed with an address, a `fetch[]` entry or an `unpinned[]` claim, and every run-manifest reference of every subject run resolves inside `resolved_dependencies` (= ADR-0038 `check_completeness`). *Valid:* complete, and M re-hashes to its `version_id`, every present payload entry re-hashes to its address, every subject run's chain verifies, and `claimed_level ≤ max_supported_level`. Levels are claims about valid bundles only.
5. **Lifecycle by supersession.** A bundle never changes; regrade, re-pin, redaction, migration and correction produce a new manifest with `derived-from{old, reason}`; the old bundle and its rows are annotated, never rewritten or hidden (ADR-0037).
6. **Operations** (dossier §6.6): `bundle`, `encode/decode`, `fetch`, `supersede_bundle`, `lineage`, `diff`, `migrate_bundle`; validation and reproduction are ADR-0140; lifecycle/interop are ADR-0141.

**T-LCD statement (ADR-0007 decision 5).** Satisfies T-LCD-10 (identity excludes names and archive bytes; AC-I3-1), T-LCD-06 (R-ID-6), T-LCD-02 (no free-text instruction member), T-LCD-11 (foreign digests carried as typed claims), T-LCD-12 (operations over canonical bytes, out-of-process), T-LCD-15 (hosted bundles fill a subset with `n/a`, never 0), T-LCD-09 (rows keyed by the factor tuple are members), T-LCD-14 (budget records are members). Not applicable: T-01/-03/-04/-05/-07/-08/-13 (the bundle carries their reports; owned elsewhere). **ADR-0024 rung:** `bundle`/`encode`/`decode`/identity are MUST-code; the `hh-bundle/1` schema and member roles are dialect schema; `BundlePolicy`, `fetch` locations and the directory convention are MUST-data.

## Evidence (doc 3 §3.3 synthesis contract — all five mandatory)

- **(a) Mechanism evidence:** manifest + payload manifests + fetch list + complete-vs-valid — RFC 8493 BagIt (S-486, Tier A); metadata graph separate from fixity — RO-Crate 1.1 (S-485); an unauthenticated bundle of attestations admits deletion/replay/injection — in-toto `spec/v1/bundle.md` (S-222 @2dcd055); subjects matched purely by digest — in-toto `statement.md`; lock-file convergence and digest equality with paths as human metadata — Harbor `lock.py` (S-132 @7d5285b), Inspect `EvalSpec`/`EvalRevision` (S-136 @75f4891); deterministic archives require zeroed metadata — Harbor `publisher.py` L100–115 (mechanism for tree-rule identity); header-first readability — Inspect `.eval` header-only reads, `logs.json`; instrument drift as a boolean — Harbor `is_editable`, Inspect `dirty`; provider-side model and image identity are claims elsewhere — Harbor `ModelInfo`, `EnvironmentConfig` (no image digest), Inspect `model: str`, SWE-bench image tags; content addressing and tree rule — ADR-0036 (S-187 OCI, S-225 Nix, S-224 git).
- **(b) Source-code precedent:** harbor `src/harbor/models/job/lock.py` @7d5285b (L38–55 digest grammar; L60–121 digest equality, `SourceTrialLock`; L200–272 `JobLock`, "must match each trial's own lock.json exactly"), `src/harbor/models/trial/paths.py` L83–105, `src/harbor/models/trial/artifact_manifest.py`, `src/harbor/publisher/publisher.py` L100–115, `src/harbor/publisher/packager.py` L60–95, `src/harbor/upload/uploader.py` L678–701; inspect_ai `src/inspect_ai/log/_log.py` @75f4891 L993–1135, `log/_recorders/eval.py` L92–120, `log/_file.py` L495–520; SWE-bench `swebench/harness/run_evaluation.py` @02e7a74 L233–300; in-toto `spec/v1/{bundle,statement,resource_descriptor}.md` @2dcd055; RFC 8493. **`no-precedent / novel`** for: a hashed manifest whose members include profile, permissions, policies, provenance, opacity/LCD/loss reports and both configuration ids (consistent with ADR-0038 (b) and WS-A1 §6.3); the three-layer split with a sidecar that cannot raise a level; `MemberRef.status`/`foreign` as typed claim carriers.
- **(c) Disconfirming evidence considered:** partial pinning is the norm and ships credible science (Harbor/Inspect tags and strings; HAL no lock; Terminal-Bench `commit_hash = "unknown"`); in-toto argues against whole-bundle authentication for extensibility; interchange formats (ATIF v1.0–v1.8) churn faster than any manifest and WS-A1 called the bundle "≈ trial dir + ATIF + job config"; reference-not-copy composition loses Harbor-style self-containment. *Why none overturns:* partial pinning is legal and visible (`unpinned[]`, derived maximum) and R0 costs one manifest; extensibility is served by the unhashed sidecar and `ext`, identity by the closed manifest; the interchange is one member and a lowering target, so its churn never changes a bundle id (ADR-0038 option 2); self-containment is available on demand through `encode(self_contained)` and `fetch`, with the containment-equality check (S9, adr-3) preserving Harbor's invariant.
- **(d) Conditionality:** model- and task-independent; assumes ADR-0036's tree rule and `idp/1` (Stage 1) and WS-B1's chunkable canonical event pages; R2-relevant members (image digests, pinned snapshots) exist only where WS-B5/WS-C1 can supply them — coding/terminal environments first; hosted bundles depend on the hosting mechanism's observability level (ADR-0005).
- **(e) Build-stage assignment:** **C0 / Stage 1** (schema published; `MemberRef`; `InstrumentRecord.dirty` never unknown — inherited hooks); **C0 / Stage 3** (`bundle(kind = run)`, `encode/decode` for directory + one archive transport, `LedgerExport` tree, rows as members, AC-I3-1/-2/-13); **C1 / Stage 4** (`arm/experiment/lineage` kinds, `fetch`, `diff`, `supersede_bundle`, `migrate_bundle`, AC-I3-11/-12); **C2 / Stage 5** (R2-relevant member completeness with WS-C3/B5).

## Consequences

- WS-J5 stores manifests as versioned records and serves the bundle catalogue header-first; `bundle_ref` on rows is a derived annotation (adr-3, CF-298).
- WS-B1 exposes a chunked canonical event export (pages by seq range) so `LedgerExport` is a tree; WS-H6 exports checkpoints as their own members (CF-299).
- WS-H5's extension shape and WS-C1's `ModelSnapshotRecord` are consumed unchanged; WS-B5 must return image digests (already binding).
- WS-L2's pricing snapshot is a member by default; custody stays WS-L2 (OQ-093/OQ-117).
- WS-K2's viewer reads manifests without payload; WS-L5 publishes `hh-bundle/1` alongside HIR dialects.
- Scope note for R-2.9.3: C0 slice (manifest, completeness, R0/R1 native) inside a C1 item (CF-301).

## Reversibility

**Low** for layer M's identity rule and the pinned-or-claimed member rules (every stored bundle id depends on them); **medium** for the section/role catalogue (additive extension by dialect bump; removal is a migration); **high** for the directory convention, transports and the sidecar file names (conventions of `encode`, not identity).
