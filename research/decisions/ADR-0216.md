# ADR-0216 — Deferral of the Phase-5 review-raised gaps (OQ-467 per-kind `classify_home` table, OQ-465 second half `control.work_item.*` audit-field partition, OQ-468 CLI verbs without a stable `hh-embed/1` operation) with interim MUST-data rules and named entry tests

**Status:** ratified (Phase 5 fixer-authored deferral ADR; doc 3 §8)
**Owner workstream(s):** WS-A2/WS-A3 (OQ-467), WS-H6/WS-B1/WS-L8 (OQ-465), WS-K4/WS-K1/WS-H7 (OQ-468); Phase 5 fixer · **Phase:** 5 · **Related:** ADR-0012 D2, ADR-0016, ADR-0066 Rule C, ADR-0205 D1, ADR-0207, ADR-0167 N-4, ADR-0168 D1/D6, ADR-0070 D6, ADR-0176 D2, ADR-0178 D4, ADR-0197 D6, ADR-0198, ADR-0212 (form); Spec §2.2.3, §3.1.3, §5i, §7.1, §7.4, §11.4

## Context

The Phase 5 adversarial review (round 1) found three points the assembled spec marks `[[GAP]]` and no ratified ADR decides: (1) ADR-0012 D2 makes `classify_home` total over the thirteen HIR/1 entity kinds and AC-A2-1 fails readiness on a missing row, but no ADR publishes the per-kind table and §3.1.3 listed five kinds with two candidate planes; (2) ADR-0066 Rule C requires every audit-grade class to declare a content-free `audit_fields` partition, ADR-0066's Phase 4 log makes seven `control.work_item.*` classes audit-grade, but OQ-465 answered only the class half; (3) ADR-0167 N-4 and ADR-0168 D1/D6 ratify `run amend`, `run archive`, `approval leases`, `approval revoke-lease` and `approval grant` as CLI verbs with ledger semantics while `hh-embed/1` (ADR-0176 D2 as amended) names no operation for them, so K-1 (every command is a boundary-verb sequence) had no operation to bind to. Each needs a ruling by its owning workstream; inventing it at the fixer pass would violate the LEDGER binding constraints. Doc 3 §8 makes the deferral ADR the readiness gate's input.

## Options considered

1. **Resolve the three questions here.** Rejected: the `home` table is an ontology ruling (ADR-0048-class), the audit partition a ledger-taxonomy ruling (ADR-0026/0066 logs), the operation signatures a public-contract ruling (ADR-0176/0178) — each owned by a workstream that did not run at Phase 5.
2. **Leave the gap markers for the readiness pass.** Rejected: AC-A2-1, AC-R-2.12.6-6 and AC-R-2.11.1-2 would be uncheckable, and `decompose-spec` would inherit tickets with no data to implement.
3. **Defer with interim MUST-data rules and entry tests, in the ADR-0212 form (chosen).**

## Evidence (doc 3 §3.3 synthesis contract — all five mandatory)

- (a) Mechanism evidence: the ratified homes cited per row (ADR-0012 D2, ADR-0016, ADR-0066 Rule C, ADR-0205 D1, ADR-0178 D4, ADR-0167 N-4, ADR-0168 D1/D6, ADR-0070 D6); `registers/open-questions.md` rows OQ-465/467/468; the Phase 5 review findings completeness-r1-C-04/-C-06/-C-09; Spec §11.4.
- (b) Source-code precedent: `no-precedent / novel` for the deferral form; the `experimental`-tier mechanism follows Codex's `experimentalApi` gate (S-107, cited by ADR-0178); interim rules inherit their ADRs' precedents.
- (c) Disconfirming evidence considered: an interim `home` row could ossify into a schema default (countered by the readiness listing, the spec-debt row and the dialect-bump rule); an `experimental` operation could be relied on by a first-party surface (countered by ADR-0178 D4's removal test "no first-party surface references it" at promotion); ADR-0198 D3 forbids a `hypothesized` C0 decision — none of these rows is one (each rests on a ratified rule applied to ratified records).
- (d) Conditionality: independent of model tier, task class and budget.
- (e) Build-stage assignment: Stage 1 (OQ-467), Stage 2 (OQ-468), Stage 4 (OQ-465); entry tests at the stages tabled.
