# ADR-0061 — Egress mediation and observation contract: `decide_egress` with a fixed evaluation order, DNS as egress, attribution by `effect_id`, credential-binding anti-laundering, and `security.egress.*` / `security.containment.*` ledger events

**Status:** **ratified, amended** (Phase 2 synthesis, 2026-09-10)
**Owner workstream(s):** WS-H4 (consumers: WS-E5, WS-B5, WS-H1, WS-H3, WS-H6, WS-H7, WS-B1, WS-I1, WS-I2, WS-L2, WS-J6) · **Phase:** 2 · **Related:** ADR-0026/0029 (event classes, chain), ADR-0030/0031 (`effect_id`, `refused`, approval cache key, `kernel_assessed` sources), ADR-0033/0035 (provenance on events; `approval` endorses one effect; check 3 at C2), ADR-0039/0040 (`network.calls`; approvals budget; exhaustion ⇒ `deny`), ADR-0042/0044/0045 (spans, sink policy, `MetricDeclaration`), ADR-0007 (T-LCD-07/-12/-14/-15); CF-136, CF-137, CF-139; OQ-154/-02/-03/-07; R-2.8.4, R-2.8.3, R-2.8.6, R-2.8.7

## Context

Every production egress control read in source is a proxy or transparent redirect that decides per request over `(protocol, host, port, method)` with deny-over-allow, a non-public/SSRF guard, host normalisation, and — in the mature ones — an audit event per decision and a per-execution attribution token (Codex `network-proxy/src/{network_policy.rs, policy.rs, connect_policy.rs, attribution.rs}`; sandbox-runtime `request-filter.ts`; Harbor's nftables+SNI sidecar). Their documented residuals are identical: TLS bodies are not inspected by default, DNS is a covert channel unless resolved outside, non-HTTP protocols ride SOCKS or are unmediated on some platforms, and an approved host is a capability grant (S-053: 24/25 exfiltrations via an allowlisted upload endpoint; Back-Reveal's disguised retrieval calls). The one mitigation the products converged on structurally is per-credential host binding at the proxy (sandbox-runtime `credential-sentinel.ts`: substitution "only when the destination matches THAT credential's hosts … prevents laundering credential A through credential B's allowlisted host"; Codex `CredentialRecord.host_binding`) plus method restriction (Codex cloud `GET/HEAD/OPTIONS`). No audited system keys decisions to the harness's effect identity, meters bytes, or reports egress asks as a budgeted resource; HarnessHarness has all three seams already ratified (`effect_id`, `network.calls`, approvals budget).

## Options considered

1. **Kernel-only blocking (`net.mode = none`) with no mediator; any network use requires `public`.** *Rejected:* forces the S-053 dichotomy the products abandoned (everything or nothing) and gives the Lab no per-host factor; kept as the C0 *default*, not the only mode.
2. **Environment-variable proxying (`HTTP_PROXY`) without namespace removal.** *Rejected:* relies on well-behaved clients (S-289 "not kernel blocking"); DNS and raw sockets bypass it. Admissible only as a declared lowering loss on backends that cannot remove the namespace.
3. **Mandatory TLS termination and body inspection at C0.** *Rejected:* puts a CA and plaintext inside the trust boundary, breaks pinned clients, and adds "no content filtering" by itself (Claude Code docs); kept as an optional `tls.terminate` (OQ-154).
4. **Decision-per-request by the reference monitor (H1) directly.** *Rejected:* the monitor reads records, not sockets (ADR-0035); latency per connection; instead the mediator decides `allow`/`deny` from policy and forwards only `ask` to the monitor (Codex "decider" pattern).
5. **A mediator with a fixed, testable evaluation order over normalised records, attribution by `effect_id`, credential-binding anti-laundering, DNS resolved outside, and one ledger event per decision (chosen).**

## Decision

1. **Modes.** `net.mode = none` — the environment has no network namespace or `connect`-class syscalls (EP2-enforced; probed at attach). `mediated` — the namespace is removed and the only route out is a bridged channel (unix socket / loopback port / transparent redirect) to a mediator running on the host side of the boundary; setting proxy environment variables alone never counts as `mediated` (it is a `lowering_loss`). `public` — no mediation; requires `principal` authority and a `residual_channels` entry.
2. **`decide_egress(policy, req) → EgressDecision`.** `req = {effect_id, tool_call_id, env_handle, protocol ∈ {http, https_connect, socks5_tcp, socks5_udp, tcp_transparent, dns}, host_raw, host_norm = normalize(host_raw), resolved_addrs[], port, method?, credential_sentinels[]}`; `EgressDecision = {decision ∈ {allow, deny, ask}, source ∈ {mode_guard, unattributed, deny_rule, non_public_guard, protocol_guard, allow_rule, approval_cache, default_unmatched, monitor}, rule_ref?, reason ∈ {denied, not_allowed, not_allowed_local, method_not_allowed, port_not_allowed, protocol_not_allowed, mode_none, unattributed, budget_exhausted}, credential_binding_applied: [CredentialRef]}`. **Evaluation order is normative:** (1) `mode_guard`; (2) attribution — no resolvable `effect_id` ⇒ `deny(unattributed)`; (3) `deny` rules on `host_norm` and on every `resolved_addr`; (4) `non_public_guard` on `resolved_addrs` (loopback, private, link-local, CGNAT, TEST-NET, reserved, unique-local, unspecified, multicast) unless `allow_listed`; (5) protocol/port/method guards (`methods_default = {GET, HEAD, OPTIONS}` unless a rule widens); (6) `allow` rule ⇒ `allow`, applying `credential_bindings` only for sentinels whose *own* binding names `host_norm` (anti-laundering invariant: a sentinel bound to host A is forwarded unchanged to host B); (7) `approval_cache` keyed `H(canonical pattern, scope)` (ADR-0031 decision 6), run/session lifetime; (8) `default_unmatched` ⇒ `deny`, or `ask(monitor)`, which reserves one unit of `approvals.requested` (ADR-0040; exhausted ⇒ `deny(budget_exhausted)`), resolves only through an `approval` endorsement of this `effect_id` (ADR-0035), and may append an **exact-host** `allow` rule at `scope ∈ {session, run}` only. `normalize` is a specified pure function (lowercase; strip brackets, ports, trailing dots; canonical IPv6 with zone id preserved; `*.apex` = subdomains only, `**.apex` = apex and subdomains; global `*` admissible only in `allow`) with property tests.
3. **DNS is egress.** `dns.resolver = mediator` (default for `mediated`): the environment never resolves names; the mediator resolves *after* the host decision and re-checks `resolved_addrs` (step 3–4). `listed_nameservers`: only those addresses on port 53 are reachable (Harbor's `resolv.conf` rule); `none`: no resolution. Name lookups that reach the mediator are `protocol = dns` requests and are decided and ledgered like any other.
4. **Attribution.** The executor (WS-E5) mints one opaque attribution token per `(run_id, effect_id, attempt_no)`, delivers it to the child through the bridged channel preface (Codex `\0CDXPXY1` frame precedent), never through the model-visible environment; the mediator maps token → `{run_id, effect_id, env_handle}`, rejects unknown tokens and environment mismatches, and stamps `effect_id` on every decision. Unattributable connections are denied.
5. **Ledger events (security plane; mandatory provenance; `durability = durable`; minimum `observability_level = events`).** `security.egress.requested{effect_id, tool_call_id, protocol, host_norm, port, method?}`; `security.egress.decided{…EgressDecision, latency_ms, bytes_out?, bytes_in?}`; `security.containment.applied{env_handle, policy_version_id, effective_policy_hash, backend, isolation_class, enforcement_evidence, lowering_loss_ref, probes_ref}`; `security.containment.violated{point, backend, kind ∈ {fs_read, fs_write, exec, net, unix_socket, syscall, privilege}, subject, evidence_kind ∈ {kernel_log, exit_signal, mediator, heuristic_output}, effect_id?}` (heuristic detections — exit-code/keyword classifiers as in Codex `denial.rs` — are labelled and never authorise); `security.containment.amended{from_version_id, to_version_id, diff, basis, endorser, effect_id, scope}`; `security.containment.unverified{field_group, reason}`. A denial is returned to the model as a typed `Observation{source: environment, authority: environment}` `{host_norm, reason, rule_ref?}` (never free text above `external`).
6. **Metering and metrics.** Each `allow` posts `control.budget.consumed{dimension: network.calls}` (ADR-0039) with `attribution.charged_to = subject` (agent traffic) or `instrument` (probes, Lab detectors); proposed registered `ext` dimensions `hh.net.bytes_out`, `hh.net.bytes_in`, `hh.egress.decisions.{allowed, denied, asked}`, `hh.containment.violations` (CF-137). `MetricDeclaration`s computed from these events: `egress.ask_rate`, `egress.approval_rate`, `containment.violation_rate`, `containment.amendments_per_run`, `classifier.miss_rate{requires_observability: end_state, detector_classes_allowed: deterministic}`; hosted participants whose mechanism cannot supply `effect_id` render `n/a{observability}` for per-effect rows (T-LCD-15).
7. **Residuals are declared, not hidden.** `tls.terminate = false` by default; `inspect_hooks` and WS-H2's reader-set flow check (ADR-0035 check 3, C2) are the declared closers of `approved_host_body`; `methods` and `credential_bindings` are the C0 part (CF-136).

**T-LCD statement (ADR-0007 decision 5).** Satisfies T-LCD-12 (decision function over records; mediator out-of-process), T-LCD-14 (egress `ask` is a budgeted approval; AC-H4-11 compares under matched budgets), T-LCD-15 (`n/a{observability}` for hosted attribution; `charged_to`), T-LCD-07 (decision `source` and lowering loss let the Lab stratify by what was actually mediated), T-LCD-11 (backends that cannot mediate a protocol record it as loss). Not applicable: T-LCD-01…06, -08…-10, -13. **ADR-0024 ladder rung:** rules are MUST-data; `normalize`, `decide_egress`, the mediator and the attribution channel are MUST-code (Core).

## Evidence (doc 3 §3.3 synthesis contract — all five mandatory)

- (a) Mechanism evidence: approved-domain exfiltration (24/25) and "allowlist as capability grant" — S-053 (Tier B); DNS/UDP/raw-socket/TLS residuals and "not kernel blocking" — S-289/-03 (Tier B docs); Firecracker "all egress traffic from a guest is … untrusted, and should be filtered at the host-level" — S-294; Landlock ABI v4 TCP bind/connect restriction as a kernel-level port guard — S-293 (Tier A); method restriction and default-off internet — S-291; disguised retrieval calls as exfiltration — S-297 (`provisional (mech)`); per-tool `send_email` recipient/reader policy — S-099 (via ADR-0035); approvals are a budgeted, fatiguing resource — S-053, ADR-0040 (ratified).
- (b) Source-code precedent: `codex/codex-rs/network-proxy/src/network_policy.rs` L66–100 (`Deny | Ask`; `source ∈ {baseline_policy, mode_guard, proxy_state, decider}`), L363–450 (`evaluate_host_policy` order and `emit_policy_audit_event`), `policy.rs` (normalisation; `is_non_public_ip` with RFC 1122/6598/6890/5737/2544 ranges; `*.`/`**.` expansion; global `*` rejected in denylists), `connect_policy.rs` L60–110 (resolved-address re-check), `attribution.rs` L14–70 (attribution frame; unknown token and environment mismatch ⇒ `PermissionDenied`), `runtime.rs` L97–113 (`BlockedRequest`), `credential_broker.rs` (host-bound real/dummy values), `config.rs` L363–380 (`Limited` = GET/HEAD/OPTIONS), `core/src/network_policy_decision.rs` (typed denial messages to the model), `exec-server-protocol/src/network_policy.rs` (`network/policyRequest`, `network/policyDecision{scope, decision, source, reason, protocol, host, port, method, client, policy_override}`); `sandbox-runtime/src/sandbox/request-filter.ts` (403 with reason; `BODYLESS_METHODS`), `credential-sentinel.ts` (per-credential `injectHosts`; anti-laundering), `linux-sandbox-utils.ts` L620–740 (`--unshare-net` + unix-socket bridges), `sandbox-schemas.ts` (`SandboxAskCallback`; port-suffixed patterns); `harbor/src/harbor/environments/docker/harbor-docker-egress-control-sidecar/bin/network-policy` (nftables TCP redirect; DNS only to listed resolvers; non-TCP rejected) and `gost.yaml` (SNI allowlist). Keying decisions to the harness's `effect_id`, budgeting `ask`, metering bytes with `charged_to`, and the mediator-resolves DNS default are `no-precedent / novel` as a contract.
- (c) Disconfirming evidence considered: "custom code is the weakest layer" (S-053) — does not overturn: the custom part is a pure decision function with property tests and a fixed order, over an off-the-shelf transport (Harbor) or OS primitive; the escape battery targets it. Allowlists do not stop body-level exfiltration — accepted and declared as a residual with C2 closers; the C0 contract claims destination, credential and method bounding only. TLS termination breaks pinned clients and adds a CA — accepted; optional. Attribution tokens can leak to the model-visible environment — mitigated by preface-only delivery and per-attempt rotation; a leaked token still authorises only that effect's scope. Mediator latency per request — bounded by record comparison; measured (`latency_ms`).
- (d) Conditionality: independent of model tier; assumes `mediated` mode is backed by namespace removal or an equivalent kernel channel restriction on the backend (otherwise recorded as lowering loss and the run is stratified); assumes WS-E5 can deliver the attribution preface; approval semantics assume a reachable principal (unattended runs set `default_unmatched = deny`, S-104's scheduled-task vector).
- (e) Build-stage assignment: **C0 / Stage 1** — `none` mode probes, `security.containment.applied/violated/unverified`; **C0 / Stage 2** — mediator with `decide_egress`, `normalize`, attribution, `security.egress.*`, approval cache, `network.calls`, credential-binding slot with WS-H3; **C0 / Stage 3** — AC-H4-04/-05(i–iii)/-06 executable, metrics; **C1 / Stage 4** — transparent-redirect backend class, hosted participants; **C2** — `tls.terminate`, `inspect_hooks`, WS-H2 flow check.

## Consequences

- WS-E5 mints and delivers attribution tokens and reports the mediator channel type; WS-B5 exposes the bridged channel on the handle.
- WS-B1 adds the six security-plane classes (mandatory provenance per ADR-0035 decision 4); WS-H6 attests them through the chain; WS-I1 projects `environment_op`/`effect` spans from them.
- WS-H7 owns the cadence/UX of egress `ask` and reads `egress.ask_rate`; WS-H3 supplies `CredentialRef` and the sentinel/substitution mechanism; WS-H2 owns the C2 closers.
- WS-L2/WS-A3 rule on the proposed `ext` dimensions; WS-I2 registers the metric declarations; WS-J6 maps hosted mechanisms to `n/a{observability}` where attribution is impossible.

## Reversibility

**Medium.** Adding protocols, reasons, sources or metrics is additive. Relaxing the evaluation order (e.g., allow before deny, or skipping the resolved-address re-check) or dropping attribution would silently re-open SSRF/DNS/unattributed egress and break the per-effect audit that WS-H6/J5 consume; those two rules are load-bearing.
