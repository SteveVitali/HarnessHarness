**Status:** ratified (Phase 5 synthesis-authored deferral ADR)
**Owner workstream(s):** WS-G3/C2 (OQ-422), WS-I5/F4 (OQ-423), WS-A3/F1 (OQ-425/292), WS-F5/E1/J2 (OQ-429), WS-L8/B3/F5 (OQ-431), WS-J3/J4 (OQ-437), WS-H1/I5/L5 (OQ-439), WS-I7/I6/J4 (OQ-443), WS-C1/C3/I7 (OQ-449), WS-G3/I2/I7 (OQ-451), WS-K4 (OQ-456), WS-G3/I2 (OQ-459), WS-J3/G3/L8 (OQ-466), WS-I5/L7/J2 (OQ-440); Phase 5 synthesis · **Phase:** 5 · **Related:** `synthesis/phase-4.md` §5, ADR-0116/0117, ADR-0196 D4, ADR-0016/0017 (HIR/2 backlog; CF-416), ADR-0191 D1, ADR-0207 O-5/ADR-0193 D3, ADR-0156 P4 (CF-421), ADR-0195 G5/G7, ADR-0200 M3/M5/V5, ADR-0120, ADR-0178 D4/ADR-0202 D4, ADR-0202 D5, ADR-0207 D6, ADR-0209 D3, ADR-0198; Spec §5b, §5e, §5f, §5h, §6, §7, §11.4.2

## Context

`synthesis/phase-4.md` §5 lists the Phase-5 deferral candidates that block no stage: each has a ratified interim rule and an owner, and each would extend a contract only after evidence the ladder has not yet produced. Spec §11.4.2 carries them with gap markers and adds OQ-440 (the promotion test `research-grade → instrument-grade`, ADR-0209 D3) and OQ-445 (joined to ADR-0210). Doc 3 §8 requires the deferral ADR; the phase-4 memo (§6.3 item 5) instructs Phase 5 to ratify it.

## Options considered

1. **Ratify the interim rules as final.** Rejected: several (OQ-437 `live_split`, OQ-443 coalition credit into `RemovalVerdict`, OQ-451 judged outcomes in `confirmatory` attribution) would change acceptance semantics without the evidence the entry tests require.
2. **Fix OQ-440's promotion test here.** Rejected: ADR-0209 D3 assigns the test to the readiness report; this ADR records the interim rule and the report's obligation.
3. **Defer with entry tests (chosen).**

## Evidence (doc 3 §3.3 synthesis contract — all five mandatory)

- (a) Mechanism evidence: `synthesis/phase-4.md` §5; the ratified homes per row; `registers/open-questions.md`.
- (b) Source-code precedent: `no-precedent / novel` for the deferral form.
- (c) Disconfirming evidence considered: the phase-4 memo's own note that these are non-blocking argues for leaving them as register rows — countered by doc 3 §8 and §11.6 rule 1 (a deferral without an entry test is refused).
- (d) Conditionality: every row is C4-adjacent and inherits ADR-0002 (d)/(e); OQ-440's interim rule assumes no automated family has yet replicated across suites.
- (e) Build-stage assignment: outside the ladder; entry tests at Stage 5–6 or by ADR.
