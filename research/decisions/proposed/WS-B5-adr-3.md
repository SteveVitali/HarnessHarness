# WS-B5-adr-3 — The effect-operation surface (closed, effect-domain-tagged, no side door), workspace derivation for subagents / verifiers / replicates / branches, and environment accounting (`env.reserved/active/suspended_ms`, per-class declared meters — OQ-095, OQ-118)

**Status:** proposed
**Owner workstream(s):** WS-B5 (consumers: WS-E5, WS-E1, WS-H1, WS-H4, WS-H3, WS-F3, WS-G1, WS-G3, WS-B4, WS-I1, WS-I2, WS-I4, WS-J3, WS-J5, WS-L2, WS-K2/K4) · **Phase:** 2 · **Related:** ADR-0016 (`EffectDomain`; delegation attenuates), ADR-0030/0031 (`read_only` free of the write-ahead barrier; `baseline_ref`), ADR-0034 (P2 delegation; never widen), ADR-0035 (checks 4, 7), ADR-0039/0040/0043 (dimensions; slices; M-points; `CostProvenance`), ADR-0044/0045 (`n/a{reason}`; class-scoped metrics), WS-B5-adr-1/-2, WS-E5-adr-1 (executor operations; I-1 complete mediation; resource keys), WS-E5-adr-2 (attribution token), WS-H4-adr-1/-2 (`ResourceLimits`; `NetPolicy.mode`; egress only via the mediator), WS-H3-adr-2 (`env_apply`, SV-7), WS-G1 (`EvidenceKind.end_state`), WS-G2 (`EnvironmentStateRef`), WS-L2 F6 (three clocks); CF-WS-B5-03, CF-WS-B5-06, CF-WS-H4-04, CF-088; OQ-095, OQ-118, OQ-WS-B5-04, OQ-WS-E5-02; R-2.2.5, R-2.6.3, R-2.5.5, R-2.9.1

## Context

Doc 2 §11 requires that execution workers "expose effectful operations through narrow handles"; ADR-0016 fixed the closed `EffectDomain` sum; WS-E5 fixed the executor operations and the complete-mediation invariant; WS-L2 separated wall, working and environment clocks and left environment minutes during hibernation (OQ-095) and the always-on meter set (OQ-118) to B5. The audit found every environment abstraction exposes a handful of effect-shaped operations (execute, read/write files, upload/download, signal; sometimes snapshot/pause) and nothing else (OpenHands `BaseWorkspace`, Inspect `SandboxEnvironment`, Harbor `BaseEnvironment`, Codex exec-server, browser-use); that subagent, verifier, replicate and branch isolation are all *derivations* of an environment (Cursor isolated VMs and parent-outliving subagents, Inspect per-sample environments, Harbor verifier sessions, Shepherd forks); and that environment time is lease-shaped with idle states (Cursor hibernation, E2B pause "kept indefinitely", OpenHands `keep_alive`/`pause_on_close`).

## Options considered

1. **Open operation surface: the handle is a generic RPC endpoint** (OpenHands agent-server exposes settings, secrets, skills, conversations). *Rejected:* untyped side doors defeat complete mediation and let environment reads enter unlabelled (M-CPE vector, WS-L3 F5).
2. **File reads outside the effect model** (Inspect/OpenHands read freely). *Rejected:* ADR-0031 already makes `read_only` effects cheap; unlabelled reads are the privilege-escalation channel.
3. **Separate isolation primitives per consumer** (subagent spawn, verifier sandbox, replicate provisioning, branch fork each their own). *Rejected:* four implementations of containment meet, credential attenuation, budget slicing and lineage; one `derive` with modes writes them once.
4. **Fold hibernated minutes into `reserved`** (OQ-095 option a). *Rejected:* makes an always-on harness and a hibernating one incomparable under matched budget (T-LCD-14).
5. **Closed effect-domain-tagged surface, `derive` with four modes, three kernel-clock counters plus declared meters (chosen).**

## Decision

1. **Effect-operation surface (closed sum on the handle):** `exec/read/write_input/signal/terminate/list_detached/terminate_detached` (WS-E5, domains `exec`/`spawn_process`); `fs.read/read_dir/metadata/canonicalize` (`fs_read`, `read_only`); `fs.write/create_dir/remove/copy` (`fs_write`; `baseline_ref` at `prepare`); `upload(tree|bytes → path)` / `download(path → ContentAddress)` (`fs_write`/`fs_read`; `download` realises `EvidenceKind.end_state`); `snapshot(kind, roots?)` / `diff(baseline)` (kernel-internal; `charged_to` per `taken_by`); `connection_info()`, `health()`, `status()`, `meters()` (kernel-internal, pure); `env_apply(EnvSpec)` at attach (WS-H3); `set_containment` only via WS-H4 `amend()`; `derive(mode, spec)`. Every model-reachable member names its `EffectDomain` and is invoked only by the kernel dispatcher on behalf of an `effect_id` under the WS-E5 contract.
2. **R-NOSIDE (no side door):** no component other than the kernel dispatcher holds a reference able to invoke `exec`/`fs.*`/`upload`/`download`; executors receive an `ExecutionRequest`, not the handle; the Lab, surfaces and hosting adapters receive `connection_info`, `health`, `meters`, snapshot refs and `download` as instrument effects only. **R-NONET:** the handle has no network operation; egress exists only through WS-H4's mediator from inside the environment.
3. **`derive(parent, mode ∈ {fresh_from_image, fork_snapshot, share, scoped_subtree}, spec) → child env_handle_id`.** `fresh_from_image` is the only mode for experiment replicates; `fork_snapshot` for branches (B4), independent verifiers (G1/G3, `taken_by = instrument`) and subagents needing the parent's workspace; `share` (C1) is a scoped handle on the same instance under E5 resource keys; `scoped_subtree` is `share` with `fs.write.allow = [subtree]`. Invariants: **D1** child containment `= effective(parent ⊓ child_layer)`; **D2** child bindings ⊆ parent's; **D3** child budget is a `slice`, `env.*` posts to the child's node; **D4** `on_parent_end ∈ {teardown, detach_to_child}` (ownership transfer ledgered; refused for `share`/`scoped_subtree`); **D5** merge is never implicit — the parent applies the child's artifacts/`FsChangeSet` as its own `fs_write` effects with baselines; **D6** lineage via `EnvHandle.parent` and `action.environment.derived`.
4. **Accounting.** Kernel-clock counters, always-on from Stage 1, `measured`, producer = environment service, measurement points M-ENV-1…3 (amendment to ADR-0043): `env.reserved_ms` (provisioning entry → terminal), `env.active_ms` (in `ready` with a live session), `env.suspended_ms` (in `suspended`); invariant `reserved ≥ active + suspended`. **OQ-095:** `env.suspended_ms` is a third counter with a declared weight in `MeteringFormula`s (default 0 in the compute-minutes view; pricing-table-driven in the spend view) — never folded into `reserved` or `active`. **OQ-118:** always-on = the three counters + `network.calls` (WS-H4); `env.cpu_ms`, `env.memory_peak_bytes` (gauge), `env.disk_bytes` (gauge), `env.snapshot_bytes`, `env.provision_ms`, `env.snapshot_ms`, `env.resume_ms` are declared per class with `provenance ∈ {measured, estimated, unavailable}`; `unavailable` renders `n/a{reason: no_detector}`; `estimated` (e.g. from `resource_factor`-style parameters) is flagged in `CostProvenance`. `ResourceLimits` (WS-H4) map to budget dimensions; exhaustion is a budget event at a decision point, never a silent kill. `charged_to`: subject for the run's instance, recovery snapshots and subagent children; instrument for verifier environments, Lab snapshots and probes.
5. **Seams adopted verbatim:** WS-H4's `containment` slot, `ContainmentReport`, `effective()`, `amend()` (CF-WS-H4-01 closed); WS-H3's `env_apply`, placeholder-only bindings, `isolation_class` gate for `wrapped_long_lived` (obligations closed); WS-E5's `attach/detach/snapshot/diff/list_detached` and `on_kernel_loss` (CF-WS-E5-01 closed). Isolation vocabularies reconciled per CF-WS-B5-01 (H4 enum = mechanism on the handle; H5 classes map onto it; E1 `isolation_min` ranges over H4's enum).
6. **T-LCD statement:** T-07 (meters/modes tri-state), T-09 (env counters as explicit budget dimensions), T-12 (operations), T-14 (`suspended_ms` separated so matched budgets are well-defined), T-15 (`n/a` for undeclared meters and hosted rows), T-11 (surface lowering: MCP `roots` carries only a root — declared loss). ADR-0024 rung: surface, R-NOSIDE, `derive` invariants and counters MUST-code; modes' defaults, weights, limits MUST-data; a model-conditioned default is a conditioned rule (T-05).

## Evidence (doc 3 §3.3 synthesis contract — all five mandatory)

- **(a) Mechanism evidence:** small effect-shaped surfaces everywhere — S-110 `openhands-sdk/openhands/sdk/workspace/base.py` (seven operations), S-136 `src/inspect_ai/util/_sandbox/environment.py` L138–290 (`exec/write_file/read_file/connection`), S-132 `src/harbor/environments/base.py` L909–1160, S-107 `codex-rs/exec-server-protocol/src/protocol.rs` (`exec`, `process/*`, `fs/*`; `ExecMetadata` "attribution … not authorization"), S-122 `browser_use/sandbox/views.py`; complete mediation — S-WS-E5-01 (via WS-E5); unlabelled environment reads as the escalation channel — S-103/S-104 (via ADR-0033, `provisional (mech)`); isolation as derivation — S-052 (isolated VMs; "A subagent might even outlive its parent"; shareable environments), S-136 L452–490 (`sample_init` per sample), S-132 (verifier session ids), S-078 (fork; byte-identical discard; `provisional`); lease-shaped environment time — S-052 (hibernate between messages), S-WS-B5-01 (pause "kept indefinitely"; ≈ 4 s/GiB; `onTimeout: 'pause'`), S-110 `remote_api/workspace.py` L64–70, L100–110 (`resource_factor`, `keep_alive`, `pause_on_close`); three clocks — WS-L2 F6 (S-136 `_util/working.py`, S-109).
- **(b) Source-code precedent:** the operation sets above; codex `exec-server/src/capability_discovery.rs` (bounded, sandbox-applied reads as the only discovery path); harbor `environments/resource_policies.py` (refuse unsupported resource modes); inspect_ai `environment.py` L474–490 (`sample_cleanup(interrupted)`). The effect-domain tagging with R-NOSIDE, the unified `derive`, and `env.suspended_ms` are `no-precedent / novel` as an integrated contract.
- **(c) Disconfirming evidence considered:** tagging every read costs a ledger event and a monitor check; Inspect/OpenHands read freely and are widely used; a single `derive` may under-serve verifiers (need end state, not a fork) and shared-mutation subagents; hibernation cost is storage, arguably not "environment minutes" at all. *Why it does not overturn:* `read_only` effects skip the write-ahead barrier and may offload observation (ADR-0031, WS-E1); verifiers use `download`/`fork_snapshot` with `taken_by = instrument`; `share` exists for shared mutation under resource keys; recording `suspended_ms` separately with a declared weight is exactly what lets the Lab decide whether it counts, instead of deciding silently.
- **(d) Conditionality:** independent of model tier; assumes the ADR-0031 delivery semantics so `read_only` is cheap; `share`/`scoped_subtree` assume E5 resource keys (C1); meter availability depends on backend class and is declared; weights in `MeteringFormula`s are Lab data, not constants.
- **(e) Build-stage assignment:** **C0 / Stage 1** (surface with R-NOSIDE/R-NONET; `fs.*`, `upload/download`, `path_baseline` snapshot; three counters; AC-B5-01/-09); **C0 / Stage 2** (`derive(fresh_from_image | fork_snapshot | scoped_subtree)`; per-class meters; `diff`; AC-B5-08/-10); **C0 / Stage 3** (overhead and snapshot-cost measurement; AC-B5-12); **C1 / Stage 4** (`share`, `detach_to_child`, provider meters, `suspended_ms` in spend views).

## Consequences

- WS-F3 builds spawn/isolate/merge on `derive` + D5 and owns conflict policy; WS-G1/G3 take verifier environments via `fork_snapshot`/`download` charged to the instrument; WS-J3/I4 provision replicates with `fresh_from_image` only.
- WS-L2/I1 append M-ENV-1…3 to the measurement-point list and read `env.*` from lifecycle events (CF-WS-B5-06; CF-088 rule); WS-L2 rules on `ext` vs dialect bump for the declared meters together with CF-WS-H4-04.
- WS-H1 gains nothing new: every handle operation reaches it as an ordinary proposal; WS-K2/K4 get `connection_info` for human hand-off and never a handle reference.
- WS-E5's `world_changed` signal is emitted at `fs_tree` root granularity (OQ-WS-E5-02 input).

## Reversibility

**High** for meters and modes (data; additive); **medium** for R-NOSIDE (loosening it is a security regression that would need a superseding ADR and would reopen the M-CPE channel).
