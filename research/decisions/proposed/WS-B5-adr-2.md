# WS-B5-adr-2 — Environment identity and snapshot semantics: three identity layers (`EnvironmentRecord` as the environment factor, `EnvHandleId` as the instance, content-addressed `SnapshotRecord` as the state), a closed `SnapshotKind`, rules S1–S7, and the OQ-089 answer

**Status:** proposed
**Owner workstream(s):** WS-B5 (consumers: WS-B2, WS-B3, WS-B4, WS-E5, WS-G1, WS-G2, WS-I2, WS-I3, WS-I4, WS-J3, WS-J5, WS-L4, WS-H3, WS-A3) · **Phase:** 2 · **Related:** ADR-0027 (allocated ids), ADR-0029 (content addresses; offload), ADR-0030/0031 (`baseline_ref`; `BaselineUnavailable` downgrade), ADR-0036 (five identity kinds; tree rule; `configuration_id` includes `environment_ref`; N7 provider ids are surfaces; N8 one tree rule), ADR-0037 (immutability; `unpinned` claims), ADR-0038 (R0–R3; `EnvironmentRecord` in the bundle; "WS-B5 must return image digests, not tags"), ADR-0045 (replicate seed material includes the image digest), WS-B5-adr-1, WS-B5-adr-3, WS-E5-adr-1 (`snapshot/diff` executor operations), WS-H3-adr-1 (SV-4 snapshots carry placeholders); CF-WS-B5-02, CF-087; OQ-089, OQ-WS-B5-02, OQ-WS-B5-05; R-2.2.5, R-2.2.4, R-2.9.3, R-2.12.1

## Context

ADR-0036 fixed five identity kinds and put `environment_ref` into `configuration_id` without saying whether it is a semantic or a version id; ADR-0038 made image digests a WS-B5 obligation and left `EnvironmentRecord` for Stage 2; ADR-0030 made `baseline_ref` mandatory for the reversible class and left the snapshot mechanism to OQ-089. The audit found every harness records images as tags (Harbor `docker_image: str`, OpenHands `server_image`, Codex `environment_id` strings) and none content-addresses environment *state*, while the platforms built for agents distinguish snapshot kinds with different semantics: Modal's filesystem snapshots are image-like and forkable, its memory snapshots are exact clones that close connections and cannot be taken while an exec runs, E2B's pause keeps memory unless `keepMemory: false`, Shepherd's copy-on-write forks are byte-identical on discard. Codex additionally snapshots *shell state* as an executor-owned cache.

## Options considered

1. **One identity: the environment is its image tag/name** (all audited harnesses). *Rejected:* an unpinned experimental factor; violates ADR-0036 N7/ADR-0038.
2. **Two identities: definition + instance, no state identity** (Harbor `environment_id` + `session_id`). *Rejected:* the reversible class, B4 forks and G1 end-state evidence all need to name a *state*; without a content address two snapshots of the same state are different things and restore cannot be verified.
3. **Snapshot everything as memory snapshots** (Cursor/E2B style) so replay is exact. *Rejected as the rule:* backend-opaque, expiring, not content-addressable by the instrument, quiescence-constrained; admitted as one declared kind.
4. **Three layers with a closed `SnapshotKind`, content addressing only where the instrument can compute it, `path_baseline` as the C0 minimum (chosen).**

## Decision

1. **Definition layer.** `EnvironmentRecord{class, image: ContentAddress | foreign_digest{scheme, value, source}, build_context?: tree ContentAddress, platform, provisioning: ProvisioningRecipe (MUST-data; hooks as `Procedure` refs per transition), containment_policy: {semantic_id, version_id}, limits, nondeterminism: [NondeterminismDeclaration], capabilities_expected, ext}` is a versioned record under `idp/1` with `version_id` and `semantic_id` (surface = backend spellings; provenance/`ext` excluded). **`environment_ref = EnvironmentRecord.semantic_id` in `configuration_id`; `EnvironmentRecord.version_id` in `configuration_version_id` and the run manifest** (CF-WS-B5-02 clarification of ADR-0036 N6). A mutable image tag fails `resolve` with `UnresolvedRef` unless listed in `unpinned[]`.
2. **Instance layer.** `EnvHandleId` is an allocated, time-ordered, opaque id (ADR-0027 class) minted at `provision`; never a factor coordinate; appears in the bundle only as `subject.env_handle_ids[]` lineage.
3. **State layer.** `SnapshotRecord{snapshot_ref: ContentAddress over the canonical record (domain tag `snapshot`), env_handle_id, at_seq, kind, base: image ContentAddress | SnapshotRef, content: tree ContentAddress (fs_tree) | foreign_digest (fs_layer, memory) | [{path, ContentAddress}] (path_baseline), roots_covered, quiesced, taken_by ∈ {subject, instrument}, size_bytes, expires_at?}`.
4. **`SnapshotKind` (closed):** `path_baseline` (per-path addresses before a write; **C0 minimum** for the reversible class), `fs_tree` (identity-profile tree rule over `roots_covered`; deterministic; R1/R2-grade), `fs_layer` (backend delta from `base`; `foreign_digest`), `memory` (full state incl. processes; `foreign_digest`; requires `quiesced`), `shell_state` (executor-owned convenience; **excluded from every identity, baseline and bundle**).
5. **Rules.** **S1** `snapshot(kind)` is admissible only for kinds the handle declares `supported`; `unknown` ⇒ `UnknownCapability` (never coerced). **S2** `restore(snapshot_ref)` yields a *successor* handle; in-place revert exists only where `capabilities.restore_in_place = supported` and is B4's `revert` effect with a `reverts` edge. **S3** equal `fs_tree` addresses are the same state; `restore` verifies the restored tree address (`RestoreMismatch`). **S4** reproducibility: R2 requires `image` as a `ContentAddress` and every restored-from snapshot in the bundle; `foreign_digest` images or memory snapshots cap the claim at R0/R1/R3 with `unpinned[]` entries. **S5 (OQ-089):** the reversible class is backed by `path_baseline` at C0/Stage 1 for every class; by `fs_tree` over `writable_roots` at Stage 2 within `limits.snapshot_bytes`; by `fs_layer`/`memory` only where declared (C1/C2 with WS-B4). `BaselineUnavailable` (`SnapshotTooLarge`, backend refusal, `NotQuiescent`) *downgrades* the effect's class per ADR-0030 and is ledgered — it never proceeds silently and never refuses the effect by itself. **S6** snapshots carry credential placeholders only (WS-H3 SV-4) and record the containment policy in force; a `memory` snapshot restored under a different policy must re-`attach` and re-verify. **S7** `expires_at` mirrors backend expiry; an expired referenced snapshot becomes an `unpinned[]` entry.
6. **`diff(baseline) → FsChangeSet{added, modified, removed: [{path, before?, after?}]}`** is the projection G2/F3/B4 consume; `download(roots) → tree ContentAddress` is how `EvidenceKind.end_state(env_handle)` (WS-G1) enters the ledger.
7. **T-LCD statement:** T-09 (record = factor; instance never a coordinate; replicate seed material carries the image digest), T-10 (backend spellings are surface), T-11 (`foreign_digest` carried as a claim, never silently dropped), T-15 (R-levels `n/a` for hosted where unobservable), T-07 (snapshot kinds tri-state). ADR-0024 rung: identity derivation and tree rule MUST-code; record fields MUST-data.

## Evidence (doc 3 §3.3 synthesis contract — all five mandatory)

- **(a) Mechanism evidence:** snapshot kinds and their constraints — S-WS-B5-02 (Modal: filesystem snapshot "calculated as the difference from your base image"; memory snapshot "exact clone … all running processes will still be running"; "Open TCP connections will be closed"; "not possible to snapshot … while a `Sandbox.exec` command is still running"; 7/30-day expiry), S-WS-B5-01 (E2B pause keeps memory; `keepMemory: false`); CoW fork and byte-identical discard — S-078 (`provisional`, mechanism only); executor shell state as a bounded non-authoritative cache — S-107 `codex-rs/exec-server/src/shell_snapshot.rs` L36–46; content-hashed definition identity — S-132 `src/harbor/environments/base.py` L231–242; per-path baselines — S-107 `core/src/turn_diff_tracker.rs` (via ADR-0031); identity/tree rules — ADR-0036 (git/Nix/OCI via WS-L4 S-224/S-225/S-187).
- **(b) Source-code precedent:** harbor `environments/base.py` (`environment_id` content hash; `session_id`; `context_id`); codex `exec-server/src/shell_snapshot.rs` (kind excluded from identity), `core/src/turn_diff_tracker.rs` (`path_baseline`); opencode `snapshot/index.ts` (workspace snapshots as git objects — via ADR-0027); inspect_ai `environment.py` L416–510 (fresh environment per replicate). The three-layer model with a content-addressed state layer and the closed kind sum is `no-precedent / novel` as an integrated contract.
- **(c) Disconfirming evidence considered:** Harbor and Inspect publish credible results with image tags (S-132, S-136 — CF-087); memory snapshots cannot be content-addressed by us and expire; tree-hashing large workspaces is slow; Shepherd's numbers are `provisional`. *Why it does not overturn:* ADR-0038 already legalises partial pinning with visible `unpinned[]`; opaque kinds are admitted with capped claims; `fs_tree` is required only at baseline/bundle points over declared roots; `path_baseline` keeps C0 cheap; snapshot cost is measured (AC-B5-12), not assumed.
- **(d) Conditionality:** assumes coding/terminal environments whose state is mostly filesystem (browser/GUI environments will lean on `memory`/provider snapshots with `foreign_digest` and cap at R3); assumes the `idp/1` tree rule (ADR-0036); independent of model tier.
- **(e) Build-stage assignment:** **C0 / Stage 1** (`EnvironmentRecord` with image digest in the run manifest; `path_baseline`; `UnresolvedRef` on tags; AC-B5-05); **C0 / Stage 2** (`fs_tree` snapshot/restore/verify; `diff`; `EnvironmentRecord`/`SnapshotRecord` bundle members with WS-I3; AC-B5-04/-07); **C1 / Stage 4** (`fs_layer`, provider adapters, expiry handling); **C2 / Stage 5–6** (`memory`, `restore_in_place` with WS-B4).

## Consequences

- WS-L4/I2/J5 read `environment_ref` as the record's `semantic_id` (aggregation) and pin its `version_id` (execution); WS-I3 adds `SnapshotRecord`s the run restored from to the bundle's `configuration.environment.snapshot_refs[]`.
- WS-B2/E5: `prepare` takes `path_baseline` by default; `BaselineUnavailable` downgrade is ledgered with the reason.
- WS-B4 gets `fork_snapshot` and `restore_in_place` as declared capabilities and owns branch/replay semantics over them; WS-G2 consumes `diff` and discontinuity records.
- WS-I4 supplies images by digest (or `foreign_digest` claims) and records `fault_profile_ref` separately from the record.

## Reversibility

**Medium-high.** Adding a snapshot kind is a dialect bump; changing the record's fields is a migration with `supersedes{reason: migration}`; removing content addressing from the state layer would only lower reproducibility claims (the kinds remain).
