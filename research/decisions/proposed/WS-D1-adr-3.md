# ADR-NNNN — Layout, ordering and rendering ownership: six kernel-reserved slots with fixed minimum authority; profile-owned slots, precedence, comparators, cache tiers and reminders as conditioned rules; the builder executes the compiled transcript-renderer spec (OQ-063); context-label reset semantics and the `external` quarantine slot (OQ-105)

**Status:** proposed
**Owner workstream(s):** WS-D1 (consumers: WS-C3, WS-A4, WS-C1, WS-C2, WS-D2, WS-F3, WS-H1, WS-L3, WS-I2, WS-I6) · **Phase:** 2 · **Related:** WS-D1 ADR-1/ADR-2; ADR-0034 (RP; P2 isolation; P3 context label), ADR-0033 (seven classes; `unverified` distinct bottom), ADR-0035 (endorsement basis list), ADR-0019 (`ModelSurface.layout`, `transcript_renderer`, `relower`, closed-world rule), ADR-0020 (`ProfileRule` kinds `prompt_layout`, `transcript_render`, `compaction_reminder`; debt record on every rule; expiry), ADR-0021/0022 (role collapse in lowering loss reports), ADR-0040 (soft thresholds as `HarnessRule` artifacts), ADR-0007 (T-LCD-01/-05/-08/-10/-13); CF-044, CF-079, CF-WS-D1-01/-05; OQ-063, OQ-104, OQ-105, OQ-067, OQ-WS-D1-04/-05; R-2.4.1, R-2.3.3

## Context

ADR-0034 makes the Model Profile the owner of `role_map: AuthorityClass → ProviderRole` and fixes the role-placement invariant; ADR-0019 makes the profile the owner of the static layout and of a transcript-renderer spec applied "at run time by the context builder", and left ownership of the per-turn rendering code open (OQ-063; synthesis guidance: the builder executes it). WS-L3 asked whether a quarantine slot exists and how the label resets across compaction, turns and isolation (OQ-105). The WS-D1 audit found: every builder has a fixed small set of top-level slots (browser-use `system/state/context[]`; OpenHands `static`/`dynamic` system blocks plus the projected transcript; Codex base instructions, developer bundles, user fragments, transcript; Pi system prompt + projected session); cache tier is a slot attribute (OpenHands `CacheTier`); world-state diffing and reminder placement are per-model choices (Codex `WorldStateSection.render_diff`, `reminder_threshold_tokens` per slug); the "later position gets more attention" rule is hard-coded in OpenHands; and position effects are model-conditioned with Tier-A evidence (Liu et al., TACL 2024) and provider-divergent shape (Chroma 2025, 18 models). Codex's transcript rendering — id normalization, media stripping, reasoning replay — is applied per turn (WS-A4 F3).

## Options considered

1. **Kernel-owned layout and ordering** (one canonical prompt order for all models). *Rejected:* ordering is a model-conditioned surface (S-WS-D1-01/-02; S-049 deleted layout guardrails); T-LCD-01/-05 require it to live in the profile with an expiry.
2. **Profile-owned everything, including which slot classes exist and their minimum authority.** *Rejected:* a profile could then declare a `memory` slot at `definition` authority and admit `external` memories — the M-CPE bug moved into a data file; the reserved slots and their floors must be kernel constants.
3. **Renderer executed by the model gateway (C1).** *Rejected:* the gateway owns transport only (CF-044); rendering decides roles and must be bounded by I-RP against the plan, which the gateway does not see; a gateway that re-roles is the opencode failure signature.
4. **A label-exempt quarantine slot** (external content rendered but not joined into the context label). *Rejected:* the model reads it; Fides/Biba semantics and ADR-0034 P3 require the join; the utility path is isolation (P2), not exemption.
5. **Six kernel-reserved slots with fixed `min_authority`; profile-declared additional slots, precedence, within-slot comparators, cache tiers, `diffable`, demotion wrappers and reminders as conditioned rules; the builder executes the compiled renderer spec and hands data to the gateway; label recomputed per plan; `external` is the quarantine slot and joins (chosen).**

## Decision

1. **Reserved slots (kernel constants; a layout lacking any fails `link`, ADR-0019 stage 1 — `InvalidLayout`):** `kernel` (`min_authority = kernel`; omission item, kernel notices, soft-budget reminders), `definition` (`definition`; sealed-definition instructions, pinned skills/procedure indexes), `principal` (`principal`; the human's task and messages, promoted memories), `transcript` (`delegate`; model outputs with their paired observations and subagent results, in ledger order), `external` (`external`; discovered instruction files, open-world observations, unsealed skills, agent-written memories, environment free text — the **quarantine slot**), `unverified` (`unverified`; lifted/imported/attestation-failed content). Kernel and definition slots are `cache_tier = static`; `transcript` is `transcript`; the rest default `dynamic`.
2. **Profile-owned (each a `ProfileRule` with an assumption-debt record, ADR-0020):** additional slots (`SlotDeclaration{slot_id, min_authority ≥ unverified, admit_unknown_validity, admits: set<CandidateKind>, cardinality, cache_tier, diffable, budget_share?, order{precedence, within_slot: ComparatorRef}}`), slot precedence (a total order over slots), within-slot comparators (recency, relevance-score, pinned-first, …; registered, deterministic), `diffable` (by-reference delivery of unchanged sections — Codex world-state precedent), demotion wrappers (OQ-104; profile-owned `Text` leaves, opacity-counted, with expiry — OQ-WS-D1-05), reminder placement and thresholds (`compaction_reminder`), and every "put X last" rule (`prompt_layout`). A profile may not lower a reserved slot's `min_authority`, raise any slot's `min_authority` above the ceiling of the kinds it admits in a way that makes it empty by construction without declaring `cardinality = 0..0` (a lint at `link`), or declare a slot that admits `transcript_item` other than `transcript`.
3. **Kernel-fixed ordering rules:** slot precedence is total and applied first; within-slot order is the policy's through the declared comparator (WS-D1 ADR-1); the paired observation of a tool call is always adjacent to its call (I-PAIR); the omission item, when present, is rendered last in the `kernel` slot. Nothing else about order is kernel-fixed.
4. **Rendering ownership (answers OQ-063).** `render(plan, renderer_spec, profile) → RenderedRequest{messages[], surfaces_revealed[], trace[]}` is a builder operation executing the compiled `ModelSurface.transcript_renderer` (ADR-0019) as data: role assignment `role(item) = min(role_map(slot.min_authority), role_map(authority(item)))` (never above either), id normalization, empty-part filtering, reasoning-field placement, image downgrade, tool-result naming — all `transcript_render` rules. Every rendered span traces to a `delivery_id`. The C1 gateway consumes the result as data and may not re-order, merge, split or re-role (CF-044/CF-WS-D1-01). `relower` (ADR-0019 §7) re-runs `render` on the *same* plan under the new spec; items the new profile cannot represent are dropped with a typed kernel placeholder and listed in `model.surface.relowered.dropped_items[]` (OQ-067 C0 default; summarising is a D2 variant). Targets with fewer roles collapse classes and the lowering loss report says so (ADR-0021; T-LCD-11).
5. **Context-label reset semantics (answers OQ-105).** `context_label` is recomputed from the plan on every call and never carried over; compaction that removes `external`/`unverified` items restores it; items delivered by reference join as if delivered; the `external` slot joins (no label-exempt slot exists); a new principal message never raises it; the only exemption is isolation — a fresh `AgentProcess` context whose results re-enter the parent as `subagent_result` candidates at ≤ `delegate` with union taint (ADR-0034 P2). Turn boundaries do not reset the label; only what is in the window matters.
6. **Lab obligations.** Because every ordering, diff and reminder rule is conditioned, the Lab recipe "retire rule R" (ADR-0020) applies to layout; `world_state_diff` vs full reinjection is a standard Stage 3–5 arm reporting cache spend and `followed` compliance (OQ-WS-D1-04); demotion-wrapper text is ablatable like any `Text` leaf.

**T-LCD statement.** Satisfies T-LCD-01 (no per-model branch in the builder; every model-conditioned layout choice lives in profile-owned fields), T-LCD-05 (every layout/reminder/diff rule carries a debt record and an expiry), T-LCD-08 (comparators and thresholds arrive with the profile), T-LCD-10 (provider roles and order are surfaces; the plan and the IR carry none), T-LCD-11 (role collapse declared in the loss report), T-LCD-13 (by-reference deliveries remain attributable). Not applicable: T-LCD-02/-03/-04/-06/-07/-09/-12/-14/-15 (covered by ADR-1/ADR-2 or other owners). **ADR-0024 rung:** reserved slots, floors and the ordering rules in decision 3 = MUST-code; every profile slot, comparator, tier, wrapper and reminder = MUST-data (conditioned rules).

## Evidence (doc 3 §3.3 synthesis contract — all five mandatory)

- **(a) Mechanism evidence:** role-placement invariant and profile-owned `role_map` — ADR-0034 RP (ratified; CaMeL/Fides/DLM lineage); model-side instruction hierarchy is defeated by assembly, so role assignment must be bounded by a record — S-104/S-103 (`provisional (mech)`), S-220 (via WS-L3); position effects are real and model-conditioned — S-WS-D1-01 (Tier A: U-shaped curve "even for explicitly long-context models"), S-WS-D1-02 (18 models; shuffled haystacks outperform coherent ones; provider-divergent distractor effects); layout guardrails become dead weight as models change — S-049, S-047 (Tier B, via doc 2 §5.1); transcript rendering is a per-turn, per-model lowering — ADR-0019 (WS-A4 F3: opencode `normalizeMessages`, goose `thinking_block_is_stale`, pi `transform-messages.ts`); the gateway owns transport only — CF-044 ruling; low-water-mark label recomputed from what is delivered — ADR-0034 P3 (Fides `current_label`, Biba); isolation as the utility path — ADR-0034 P2 (S-036/S-038 subagent summaries).
- **(b) Source-code precedent:** `software-agent-sdk/openhands-sdk/openhands/sdk/context/prompts/section.py` L18–33, L120–143 (`CacheTier{STATIC, DYNAMIC}`, `PromptBlocks`), `agent/agent.py` L525–546 (dynamic block uncached), `context/memory.py` L70–75 ("the later position gets more model attention" as a hard-coded rule — the counter-example that must become a conditioned rule); `codex/codex-rs/core/src/context/world_state/mod.rs` L210–275 (`WorldStateSection{ID, Snapshot, render_diff}`, `PreviousSectionState`, `WorldStateHash`) and `core/src/context/token_budget_context.rs` L1–130 (`ContextWindowGuidance` as a separate `developer` message; `render_diff` only on change); `codex/codex-rs/core/src/context_manager/history.rs` L740–770 (`trim_pre_turn_context_updates` — full reinjection fallback after rollback); `browser-use/browser_use/agent/message_manager/views.py` L63–80 (`MessageHistory.get_messages`: system → state → contextual — a fixed slot precedence); `pi-mono/packages/agent/src/harness/session/context.ts` L24–45 (excluded assistant stop reasons; compaction summary then retained tail — a fixed within-transcript order). The six reserved slots with kernel floors and the builder-executed renderer bounded by the plan are `no-precedent / novel` as a contract; cache tiers, diffing and fixed slot precedence are precedented as cited.
- **(c) Disconfirming evidence considered:** position effects are universal enough to hard-code — overturned by their provider-divergent shape (S-WS-D1-02) and by Cursor's deletion history; a data-only renderer may not express every provider quirk (opencode's 1,900-line `transform.ts`, WS-A4 §5) — absorbed by ADR-0020's versioned rule kinds and the reported `ext` block, and by keeping the plan unchanged so a gateway-side rule (if C1 ever needs one) is a profile bug visible in `lcd_report`; a quarantine slot that joins the label taints every call that reads external content (Biba label creep) — accepted as correct semantics with per-call recomputation, compaction and isolation as the mitigations (ADR-0033 (c)); six reserved slots may be too few or too many — reversible by dialect bump. None overturns.
- **(d) Conditionality:** independent of task class; assumes the profile's capability declaration names the provider roles available (ADR-0020) so `role_map` collapse is declared; the compliance cost of `external`-slot delivery and the cache benefit of by-reference delivery are Stage 3–5 measurements, not assumptions; unattended runs have no `principal` messages in-window and bind the `definition` slot as the ceiling (ADR-0033 (d)).
- **(e) Build-stage assignment:** **C0 / Stage 1** (reserved slots and floors; `SlotDeclaration` schema; `InvalidLayout` at `link`; decision-3 ordering rules); **C0 / Stage 2** (`render` executing the renderer spec; `RenderedRequest` to C1; label reset semantics with H1); **C0 / Stage 3** (re-lowering test AC-D1-13; role-collapse loss reports with A4/E4); **C1 / Stage 5** (profile slot families, comparators, `diffable`, demotion wrappers, reminder rules — WS-C3; `world_state_diff` arm); **C4** (debt-record manager over layout rules — WS-I6).

## Consequences

- WS-C3 designs the slot and comparator rule kinds inside ADR-0020's closed enum (`prompt_layout` gains `slot_declaration`, `comparator`, `diffable`; `transcript_render` gains role assignment bounded by the plan) and supplies the two minimal C0 profiles with the six reserved slots only.
- WS-A4's `link` validates layouts (`InvalidLayout`); its trace map covers every rendered span through `delivery_id`; `relower` calls the builder's `render`.
- WS-C1 accepts `RenderedRequest` as the provider request plan's message component and never re-roles; WS-C2's mid-run switch is a `relower` + `render`, recorded.
- WS-H1 reads one `context_label` per call and needs no slot knowledge; WS-F3 applies P2 at spawn and admits results at ≤ `delegate`.
- WS-D2 knows that dropping `external` items restores the label and may prefer them as compaction targets when the policy asks for label recovery.
- WS-L3's OQ-105 is closed; OQ-104 receives the demotion-wrapper placement (`external` slot, profile-owned leaf, expiry).

## Reversibility

**Medium.** Reserved-slot membership and floors are a dialect constant (cheap to change before Stage 2, expensive after because the privilege-preservation fixtures and H1's `context_label` semantics depend on them). Moving `render` to the gateway is a medium change (rules are data; the plan is unchanged). Every profile-owned layout rule is reversible by construction — that is what the debt record is for.
