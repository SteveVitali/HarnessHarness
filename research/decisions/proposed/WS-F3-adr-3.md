# ADR-NNNN — Merge semantics via artifacts and events (`SubagentResult`, `ReturnContract`, one `subagent_result` candidate, parent-applied baselined merge with `MergeConflictRecord` and a closed `MergePolicy` sum) and failure containment C-1…C-10 with the KP-14/16–19 battery extension (OQ-278, OQ-328)

**Status:** proposed
**Owner workstream(s):** WS-F3 (consumers: WS-F5, WS-F4, WS-G2, WS-G1, WS-D1, WS-B3, WS-B5, WS-F2, WS-H6, WS-L2, WS-I2, WS-J5, WS-K2, WS-J6) · **Phase:** 4 · **Related:** WS-F3-adr-1, WS-F3-adr-2, ADR-0014 (realized benefit), ADR-0016 (`Artifact`, `produced-by`), ADR-0029 (content addresses), ADR-0030/0031 (`fs_write` with `baseline_ref`; `unknown`), ADR-0034 P2 (results re-enter `≤ delegate` with union taint), ADR-0040 (release on child terminal; root-first), ADR-0044 (`harness_overhead.subagent`), ADR-0045 (outcome classes), ADR-0051 H-6 (cascade revocation), ADR-0058 SV-7, ADR-0060/0061, ADR-0067 (`child_head`), ADR-0074 (`subagent_result` candidate), ADR-0092 (no silent truncation), ADR-0101 (attribution token), ADR-0103 (`delegation_completed` cue), ADR-0106 (stop protocol step 2), ADR-0107 (`RetryPolicy`/`TimeoutPolicy[subagent]`), ADR-0112/0113 (claims; completion gate; `stale_belief`), ADR-0130/0131/0132 (recovery table `subagent` row; `child_terminal`; `awaiting_child`; goal inboxes; KP battery), ADR-0137 (`path_baseline`/`fs_tree`), ADR-0138 D4/D5, ADR-0164/0165 (hosted results, mediation); OQ-278, OQ-328, OQ-WS-F3-01/-02; R-2.6.3, R-2.6.5, R-2.2.3, R-2.2.5

## Context

Doc 2 §11 Stage 4 requires "a shared artifact/event layer rather than a giant transcript"; §5.7 names "how results are merged" and "how failures are contained" as the two design questions after state and writes. The audit finds three result channels in production and never the transcript: opencode returns the last text part of the child's final message and hides it from the user; the Claude Agent SDK keeps subagent transcripts in a separate `subpath` and forwards only `tool_use`/`tool_result` blocks by default; Pi chains pass only the final assistant text as `{previous}`; Prime Agent returns "only through explicit `agent_message` replies or files, never as an `rlm()` return value"; Anthropic's subagents "store their work in external systems, then pass lightweight references back" to avoid "the 'game of telephone'"; Symphony's workers return nothing — the tracker and per-issue workspace are the result. OrchBench identifies the retention ratio of cross-agent transfers as the dominant lever (S-WS-F3-01, `provisional`). Merge into a shared tree is either absent (Cursor's isolated copies, with no documented return path) or implicit (shared directories, last write wins); no runtime records a merge as parent-attributable effects — the only ratified rule is ADR-0138 D5. Failure handling converges on "child failure is a result" (opencode `Subagent failed (task_id …)`, Pi `isError` chain stop) but diverges on the parent's death: cancel cascade (opencode `Effect.onInterrupt → cancel`, Pi SIGTERM/SIGKILL), detach (Cursor "outlive its parent", Prime Agent daemon children addressable "until its parent session closes"), or undefined (Codex/Claude SDK exclude child threads from daemon recovery).

## Options considered

1. **Child transcript appended to the parent's context** (the "giant transcript"). *Rejected:* doc 2 §11; the parent's `context_label` would join every child input (ADR-0074 makes isolation the exemption precisely so results re-enter at `≤ delegate`); token cost is the 15× multiplier (S-036).
2. **Free-form final message only** (opencode/Pi). *Rejected as the sole channel:* no size cap, no schema, no artifact references, retention unmeasurable; kept as the `summary` artifact under a `ReturnContract`.
3. **Implicit merge over a shared tree** (shared directory; last write wins). *Rejected for isolated modes:* unattributable writes defeat complete mediation and G2 reconciliation; admitted only as `share`/`scoped_subtree` where every child write is already a ledgered, attributed effect.
4. **Kernel-resolved merge conflicts** (the runtime picks a winner). *Rejected:* the ownership model is WS-F5's and task-conditioned; the kernel fixes the record and the closed policy sum, not the winner.
5. **Parent death kills children always** (opencode/Pi). *Rejected as the only rule:* Cursor and Prime Agent show legitimate parent-outliving work; ADR-0138 D4 already has `detach_to_child`; a parent *crash* (as opposed to a stop) must never kill a child that holds its own lease (ADR-0130).
6. **`SubagentResult` under a declared `ReturnContract`; one `subagent_result` candidate; parent-applied baselined merge with a conflict record and a closed `MergePolicy` sum; child outcomes as cues; stop cascades unless detached; crash never cascades; caps refuse (chosen).**

## Decision

1. **`SubagentResult`** (payload of `control.subagent.result`, written under the *parent's* lease after the child's terminal event; content-addressed): `{child_run_id, delegation_ref, outcome_class (ADR-0045 sum), stop_reason (ADR-0106 sum), child_head{seq, hash, checkpoint_ref} (ADR-0067), artifacts: [ArtifactRef] (content addresses; `produced-by` the child; labels as produced), fs_changes?: FsChangeSet | SnapshotRef (isolated environment modes), summary?: Ref<Artifact{kind: subagent_summary}> (authority = min(⊔ child inputs, delegate); validated against `ReturnContract.summary.schema` when declared), claims: [ClaimRef] (the child's claim ledger by reference), usage: ResourceVector, budget_released, verdicts: [VerdictRef], return_contract_satisfied: bool, violations: [{field, reason}]}`. `control.subagent.cancelled{child_run_id, reason ∈ {parent_stop, timeout, revoked, principal}, child_head?}` is the other terminal.
2. **M-1 One candidate, never a transcript.** The parent's context builder receives exactly one `Candidate{kind: subagent_result}` (ADR-0074) per result, rendered by the profile from `summary` plus artifact handles, at `authority ≤ delegate`, `taint ⊇` the child's accumulated taint, `derived_from.kind = subagent_result` (ADR-0034 P2). The child's ledger, transcript view and artifacts are reachable **by reference** for validators, surfaces and humans, never as parent context. `context.artefact.delivered/activated` and `verification.artefact.followed` on the summary make retention (`subagent_retention`) a class-scoped metric (T-LCD-13).
3. **M-2 Return contracts are enforced by the child's envelope.** A missing required artifact, a summary over `max_tokens`, or a schema failure yields `return_contract_satisfied = false` with typed `violations`; the kernel never truncates (ADR-0092); the parent's strategy decides — `retry{target: delegation}` under `RetryPolicy[subagent]` opens a *new* child run with `attempt_no + 1` and the same `delegation_ref`, or it proceeds.
4. **M-3 Workspace merge is the parent's effect.** For `fresh_from_image`/`fork_snapshot` children: `merge(parent, lease, result, policy: MergePolicy) → Merged{effect_ids[], conflicts[]} | MergeConflict{conflict_records[]}` computes `FsChangeSet = diff(child_snapshot, child_baseline)`, checks each path against the parent's current `path_baseline`/`fs_tree` (ADR-0137), and applies non-conflicting changes as the parent's own `fs_write` effects with `baseline_ref` (revertable — ADR-0138 D5) through `authorize` (a child write into a path the parent may not write is refused at merge — the child-as-deputy channel closes here). Conflicts produce `MergeConflictRecord{path, parent_baseline, child_before, child_after, parent_current, detected_at}` and `control.subagent.merged{child_run_id, effect_ids[], conflicts[], policy}`. `MergePolicy ∈ {refuse, parent_wins, child_wins, three_way(Ref<Procedure>), ask}` is a closed sum fixed here; the semantics of `three_way` and the ownership model behind `parent_wins`/`child_wins` are WS-F5's (OQ-WS-F3-02); C1 admits `refuse` and `ask`. For `share`/`scoped_subtree` children no merge exists: every write is a ledgered effect under the child's `attribution_token` (ADR-0101) and E5 resource keys; the parent's next `verify` observes the world state.
5. **M-4 Claims (OQ-278).** A parent `achieved` claim citing a child's `achieved` binds to the child's reconciliation records through `claims[]` + `child_head.checkpoint_ref`; the parent's completion gate (ADR-0113) re-reconciles only claims about handles the parent itself commits at merge (`effect_ids[]`) and any claim whose subject changed after `child_head.seq` (`stale_belief`, D4); child claims about the child's own isolated environment are consumed as `evidence_class = reconciled` with `origin = subagent`; `divergence_profile` aggregates over the run tree keyed by `run_id`, never averaged.
6. **M-5/M-6 Settlement.** On `result | cancelled`: the `slice` remainder is released (`control.budget.released{reason: child_finished}`); `usage` is the child node's `consumed` view; `cost_view` counts child cost once under `harness_overhead.subagent` (ADR-0044); `on_parent_end = cancel` tears the child's derived environment down after `merge`/`download`; `detach_to_child` transfers ownership (`control.subagent.detached{child_run_id}` + `action.environment.derived` ownership change).
7. **Containment (kernel-enforced).** **C-1** every child terminal reaches the parent as `Cue.delegation_completed{child_run_id, result_ref, outcome_class}` — never an exception; **C-2** parent stop → `control.subagent.cancelled{parent_stop}` to every `on_parent_end = cancel` child (ADR-0106 step 2), drain ≤ `TimeoutPolicy[subagent].hard_max_ms`, unresponsive child recorded `result{outcome_class: infrastructure_failure{child_unresponsive}}` and finished by its own lease expiry; **C-3** parent crash never kills a child — on `restore` the recovery table's `subagent` row keeps it and resubscribes `child_terminal`; a child finishing while the parent is down writes `occurred` to the parent's ledger or goal inbox (never lost, AC-B3-07); **C-4** child crash is the child's own recovery; the parent waits ≤ the `subagent` scope deadline, then `cancelled{timeout}`; **C-5** blast radius: child containment `= effective(parent ⊓ child)` (ADR-0138 D1, deny-wins), credentials ⊆ parent's placeholders (SV-7), egress under the parent's `NetPolicy`, no handle reference crosses (R-NOSIDE); **C-6** exhaustion root-first (ADR-0040 decision 4); **C-7** revocation cascades (ADR-0051 H-6); **C-8** `fan_out`/`delegation_depth`/message caps refuse the next increment, never kill; **C-9** a detached child's completion targets the parent's goal subscription; if the goal is finished it is `skipped{run_finished}` and audited (ADR-0131 W-4); **C-10** hosted children fail at the boundary (`cancel` verb; uncovered calls refused; `result` carries `mediation` and cost `confidence`, ADR-0165); an observed-only subagent inside a hosted H has `n/a` containment.
8. **OQ-328.** `share` is always a scoped handle under the parent's single kernel session; a human co-editing through `connection_info` produces `environment`-authority world changes seen at the next `verify`, never a session.
9. **Battery extension (ADR-0132's shared battery).** KP-14 (child running, parent killed) → child completes, its `occurred` reaches the restored parent; **KP-16** (parent stop with running children) → each `cancel` child `cancelled{parent_stop}` within `hard_max`, `detach_to_child` children untouched; **KP-17** (child killed mid-effect) → child restores under its own lease, parent waits ≤ deadline, no duplicate effect; **KP-18** (child exhausts while parent spent) → child stops with the parent's `Exceeded`; **KP-19** (parent handle revoked mid-run) → child's next covered proposal is `NoCoveringGrant`. Plus AC-F3-04 (no child transcript bytes in the parent's model surface — static check on `context.assembled`), AC-F3-05 (every merged byte has a parent `fs_write` with `baseline_ref`; out-of-root child writes refused at merge; revert restores the baseline), AC-F3-12 (spawn/merge interrupted at each step re-runs to the same outcome).

**T-LCD statement (ADR-0007 decision 5).** Satisfies T-LCD-13 (summary artifact carries the delivery chain — retention measurable per profile), T-LCD-15 (`subagent_retention`, `merge_conflict_rate`, `return_contract_violation_rate` class-scoped; hosted rows `n/a` where unmediated), T-LCD-14 (child usage settles into the arm's budget; nothing unaccounted), T-LCD-12 (`merge`, `send_message` are operations over records), T-LCD-02 (summaries are `Text` leaves with provenance and a label), T-LCD-06/-07 (hosted results through ADR-0164's lifting; nothing native changes), T-LCD-05 (a profile-conditioned `summary.max_tokens` default is a conditioned rule with a debt record). Not applicable: T-LCD-01/-03/-04/-08/-09/-10/-11. **ADR-0024 rungs:** M-1…M-6, C-1…C-10, the `MergeConflictRecord` and the battery are MUST-code; `ReturnContract`, `MergePolicy` choice, caps, `on_parent_end` defaults are MUST-data.

## Evidence (doc 3 §3.3 synthesis contract — all five mandatory)

- **(a) Mechanism evidence:** "shared artifact/event layer rather than a giant transcript" — doc 2 §11 Stage 4 (Tier B); references-not-copies to avoid information loss and token overhead — S-036 (Tier B); retention ratio of cross-agent transfers as the lever — S-WS-F3-01 (`provisional`); results re-enter at `≤ delegate` with union taint and isolation as the only label exemption — ADR-0034 P2, ADR-0074 (ratified); merge never implicit — ADR-0138 D5 (ratified); claims reconciled against handles and `stale_belief` — ADR-0112/0113 (ratified); child failure as a result, cancel on parent interrupt — S-111 `task.ts`, S-113; parent-outliving children — S-052 (Tier B), S-116; child threads excluded from daemon recovery — S-107 `daemon_snapshot.rs` (via WS-B3), motivating own-lease recovery (ADR-0130); stop-protocol child cancel — ADR-0106 step 2 (ratified).
- **(b) Source-code precedent:** `opencode/packages/opencode/src/tool/task.ts` L214–226 (last-text result; `Subagent failed` as an error result), L330–367 (interrupt cascades cancel), L232–262 (background completion injected as a synthetic message) @ 9f8db11; `claude-agent-sdk-python/src/claude_agent_sdk/types.py` L1494–1512, L2158–2166 @ ad77094 (separate subagent transcript subpath; text forwarding off by default); `pi-mono/packages/coding-agent/examples/extensions/subagent/index.ts` (chain passes `getFinalOutput` only; `isError` stops the chain; SIGTERM→SIGKILL on abort) @ 400d690; `prime-agent/packages/coding-agent/docs/rlm.md` §2 and `skills/agent-message/SKILL.md` @ 427ea4c (results via messages/files; children addressable until the parent closes; explicit delete); `symphony/SPEC.md` L806–811 @ e0ccc83 (terminal issue → clean workspace, release claim). The `ReturnContract`, `SubagentResult` with claims by reference, parent-applied merge with `MergeConflictRecord`, and containment C-1…C-10 as ledger invariants are **`no-precedent / novel`** as an integrated contract.
- **(c) Disconfirming evidence considered:** re-applying every child write as a parent effect doubles I/O and is slower than a shared tree (Cursor, opencode) — answered by `share`/`scoped_subtree` modes with per-write attribution and by measuring merge cost per mode (AC-F3-10); a size-capped summary loses information the parent needs (OrchBench retention) — answered by artifacts-by-reference plus a *measured* retention metric rather than an unbounded text channel; letting children outlive parents leaks budget and environment — answered by `detach_to_child` being explicit at spawn, ledgered, refused for shared modes, and goal-scoped for completion; a parent that must re-reconcile everything a child claimed loses the point of delegation — answered by M-4's narrow re-reconciliation set. None overturns.
- **(d) Conditionality:** independent of model tier; assumes ADR-0137 snapshots exist for isolated modes (Stage 2) and E5 resource keys for `share` (C1); `three_way`/`parent_wins`/`child_wins` semantics depend on WS-F5; hosted results depend on ADR-0164/0165 mediation; retention metrics require `events` observability on the summary artifact.
- **(e) Build-stage assignment:** **C1 / Stage 4** — `SubagentResult`, `ReturnContract` enforcement, M-1/M-2/M-4/M-5, `merge` with `MergePolicy ∈ {refuse, ask}`, C-1…C-8, KP-14/16–19, AC-F3-04/-05/-06/-12. **C3 / Stage 4** — `parent_wins`/`child_wins`/`three_way` from WS-F5, `detach_to_child` with goal inboxes (C-9), `control.subagent.merged/detached` in the audit table. **C2** — hosted results and C-10 with WS-J6.

## Consequences

- WS-F5 owns `MergePolicy` semantics and the ownership model; it inherits the `MergeConflictRecord` shape and "no implicit merge".
- WS-D1 renders the `subagent_result` candidate from `summary` + artifact handles; WS-C3 owns its rendering rule (a conditioned rule with a debt record where model-specific).
- WS-G2 consumes M-4: child claims by reference; the gate's re-reconciliation set; `divergence_profile` aggregation keyed by run.
- WS-B3 adds KP-16…19 to the shared battery (ADR-0132); WS-F2 implements C-2's drain and the `subagent` deadline; WS-H6 adds `control.subagent.merged/detached` as audit-grade; WS-B1 takes the new classes (CF-WS-F3-01).
- WS-I2/J5 register `subagent_retention`, `merge_conflict_rate`, `return_contract_violation_rate`, `duplicate_work_rate`.

## Reversibility

**Low** for M-1 (transcript exclusion; reversing it reopens the label-laundering and cost failures) and for C-3/C-5/C-6/C-7 (restatements of ratified ADRs at this seam); **medium** for the `MergePolicy` sum and `ReturnContract` fields (grow by dialect bump; removing after Stage 4 strands merged records); **high** for defaults (`on_parent_end`, `max_tokens`, deadlines — data).
