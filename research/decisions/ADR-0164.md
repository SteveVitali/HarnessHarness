# ADR-0164 — The Hosting ABI's depth: baseline verbs, capability-declared verbs, deliberately excluded verbs, the `HostedEvent` minimum observable event set with lifting tables, and the mediation stamp (resolves OQ-004, OQ-248)

**Status:** ratified, amended (Phase 3 synthesis)
**Owner workstream(s):** WS-J6 (consumers: WS-J3, WS-J4, WS-J5, WS-K4, WS-B1, WS-I2, WS-I3, WS-E4, WS-H1, WS-L2) · **Phase:** 3 · **Related:** ADR-0001, ADR-0005, ADR-0010, ADR-0013, ADR-0018, ADR-0026, ADR-0033, ADR-0053 (D-4, D6), ADR-0096, ADR-0098 (D2, D6), ADR-0099, ADR-0136 (R-NOSIDE), ADR-0141 (D6); ADR-0007 (T-LCD-06/-07/-11/-12/-13/-15); CF-023, CF-027, CF-073, CF-209, CF-348, CF-352; OQ-004, OQ-248, OQ-378; R-2.10.6

## Context

ADR-0001 fixed the thin observational ABI as "start/resume/cancel · stream events · supply context/tools/skills · request permission · account cost" and left its depth to WS-J6 (OQ-004). ADR-0005 reframed the ABI as a *minimum observable event set plus a capability declaration* implementable by three hosting mechanisms; ADR-0013/0018 fixed the descriptor and the IR-side `OpaqueProcess`; ADR-0098 D6 fixed the session-ABI baseline as ACP v2's stable core. The audit (WS-J6 §4 F1–F3, F8) finds that the intersection of production hosts' verbs is `{open, submit, cancel, close}` plus a usage report, that the union is vendor-shaped (Codex ~120 methods), and that what differs between mechanisms is not detail but *who produced the evidence*: a session-ABI `tool_call_update` is a participant claim, an intercepted model call is a kernel measurement, a container-installed trajectory is a post-hoc reconstruction. doc 2 §5.11 also lists "inspect artifacts" as an ABI verb; no audited host has it. Without a fixed verb set the ABI drifts toward the union (an escape-hatch ABI) or the intersection (an LCD ABI); without a mediation distinction a hosted participant *reporting* zero tool calls would score perfect autonomy (the T-LCD-15 failure in disguise).

## Options considered

1. **Union ABI** — mirror every verb any host exposes (steer, fork, compact, queue, goals, realtime). *Rejected:* an escape-hatch ABI; every verb beyond the baseline would be implemented by one product and `unsupported` elsewhere, and Lab-commanded `fork/compact/spawn` decisions inside an opaque H are unattributable (ADR-0013 class criterion).
2. **Intersection ABI** — four verbs and a usage number. *Rejected:* the LCD signature (feature intersection, S-154); no room for declared capabilities to ever be used; comparisons could not stratify.
3. **Session-ABI only (ACP verbs verbatim)** — *Rejected:* privileges one mechanism (ADR-0005 forbids); container-installed and interception hosts have no session protocol.
4. **A "chat endpoint" ABI** (prompt in, text out, cost). *Rejected:* doc 2 §5.11's explicit warning; loses permission, tool and lifecycle observation entirely.
5. **Chosen:** a small mechanism-neutral **baseline** (`describe, open, submit, cancel, resume, close, stream_events, probe`; upcalls `request_permission`, `report_usage`), **capability-declared** verbs (`set_coordinate` per coordinate, `steer`, `account` exact, `export`, `elicit`; `resume` mode), an explicit **excluded** list, one **`HostedEvent`** vocabulary with per-mechanism lifting tables and loss classes, and a **mediation stamp** on every hosted event.

## Decision

1. **Baseline control verbs** (every mechanism satisfies them, possibly trivially): `describe(participant_ref) → ParticipantDescriptor`; `open(participant_ref, HostedRunSpec{run_id, environment: connection_info, placement, supplies{context, tools = sealed MCP surface ref, procedures}, coordinates, budget_view, abi_version}) → HostedSession`; `submit(session, Input, idempotency_key) → accepted | refused` (returns on acceptance; completion is `turn.finished`); `cancel(session)` (terminal within `cancel_deadline_ms` or synthesized `unobserved`); `resume(participant_ref, spec, ResumeCursor{cold | warm}) → HostedSession` (verb baseline; mode declared `resume ∈ {none, cold_only, warm_reattach}`); `close(session) → EndState`; `stream_events(session, from_cursor) → stream<HostedEvent>`; Lab-side `probe(participant_ref, dimension, fixture) → ProbeResult`. "start" (ADR-0001) = `open` + `submit`.
2. **Capability-declared verbs** (default `unknown`; never removed because a participant lacks them — T-LCD-07): `set_coordinate(session, name, value)` per declared coordinate (`model`, `mode`, `thought_level`, …); `steer`; `account` (exact; the baseline is the `usage.reported` event); `export` (`trajectory_export`); upcall `elicit` (lowered to a `message_human` effect proposal decided by H7, never adapter-answered); `request_permission` is a baseline verb whose *surface* is declared (`permission_surface ∈ {protocol, hook, approval_mirror, none}`).
3. **Excluded verbs** (each guards T-LCD-06/-07): `inspect_artifacts` (environment-handle operation `snapshot/diff/download`; resolves CF-352), `set_policy`/`grant`/`deliver_credential`/`set_budget` (policy, authority, credential values and budgets never enter the loop — ADR-0053 D-4, ADR-0058 SV-7, ADR-0040), `fork`/`compact`/`spawn_subagent`/`set_control_strategy` (observed only), `inject_tool` after `open` (closed-world rule), `read_ledger`/`read_transcript` (no ledger exists for an opaque H; native-as-hosted uses `_hh/ledger/read` outbound only), `checkpoint`/`restore`, `authenticate`, `install_extension`. Tool calls to Lab-supplied tools are **not** ABI upcalls; they arrive at the sealed MCP surface (ADR-0096) as native tool calls with the hosted process as `delegate` caller.
4. **`HostedEvent`** = `{seq (dense per session), session, at (adapter monotonic ms), kind, payload, provenance{origin ∈ {participant, intercept, environment, adapter}, authority}, mediation ∈ {mediated, observed, unobserved}, event_channel ∈ {protocol, hook, log, proxy, handle}, raw_ref?, ext}`. Kinds: `session.opened/closed`, `turn.started/finished{stop_reason_raw, stop_reason}`, `message.delta/completed`, `thought.delta`, `tool.proposed{kind_hint}`, `tool.completed{status, content, locations}`, `permission.requested/decided`, `usage.reported{used, size, cost?, groups[]?}`, `model.call.started/completed` (only with `model_io`), `artefact.delivered`, `coordinate.changed`, `compaction.observed`, `subagent.observed`, `conformance.observed`; plus native `environment.*`/`security.egress.*`/`security.credential.*` rows emitted by the kernel's own channels. Lifting into ledger classes follows the WS-J6 §6.1 table (the inverse of ADR-0098 D2 for session-ABI; per-format lifters for container-installed; proxy records for interception) with loss class per event kind; `StopReason` lifts `other`/`_vendor` to `infrastructure_failure{error_class: participant_unclassified}` with the raw value preserved (OQ-378 may refine).
5. **Mediation semantics.** `mediated` — the kernel produced or gated the fact (Lab MCP surface, egress proxy, broker, environment helper, intercepted model call) and a kernel `causes[]` link exists; `observed` — reported live by the participant through a protocol/hook channel; `unobserved` — reconstructed post hoc or synthesized. The adapter cannot assert `mediated`. Participant-reported tool events never produce `action.effect.*` rows; only Lab-mediated calls enter the effect lifecycle.
6. **Invariants.** I-1 every session has a well-formed lifecycle (missing terminals synthesized `unobserved`); I-2 dense `seq`; I-3 unknown kinds and `_`-prefixed values preserved in `ext`/`raw_ref` and listed in the mechanism's `LoweringLossReport`; I-4 no hosted event carries authority above `delegate` unless `origin ∈ {intercept, environment, adapter}` with closed-schema content; I-5 every hosted ledger row stamps `participant_class = hosted`, the descriptor's `observability_level`, and `mediation`.
7. **OQ-248.** A network-remote A2A peer is `hosting_mechanism = session_abi` + `ProtocolBinding{a2a}` + `process_placement = remote_service`; no enum bump.

**T-LCD statement.** Satisfies T-LCD-06 (verbs and events lower to `OpaqueProcess`/`ParticipantDescriptor`/ledger classes; no IR field added; hosting-disabled build unchanged), T-LCD-07 (baseline + declared; `unknown` never coerced; exclusions prevent intersection creep), T-LCD-11 (lifting tables with loss classes per mechanism; unknowns preserved), T-LCD-12 (operations; adapters out-of-process), T-LCD-13 (`artefact.delivered` observable; `activated/followed` class-scoped), T-LCD-15 (mediation stamp prevents zero-scoring on unmediated events). Not applicable: T-LCD-01/-02/-03/-04/-08/-10. ADR-0024 rung: transport, lifting and the mediation stamp are MUST-code; the lifting tables and verb-status tables are MUST-data.

## Evidence (doc 3 §3.3 synthesis contract — all five mandatory)

- (a) Mechanism evidence: verb convergence across hosts — S-118 `inner/executor.py` L611–696, S-035 `schema/v2/meta.json`, S-107 `app-server-protocol/src/protocol/v2/{thread,turn}.rs`, S-132 `agents/base.py` (Tier B, source); evidence-producer differs by mechanism — S-137 ("All model calls are captured … agent internals opaque"), S-132 `AgentContext` post-run population, S-118 ACP executor (participant claims); `session/prompt` returns on acceptance — S-035 `prompt-lifecycle.mdx`; preserve-unknowns rule — S-035 `extensibility.mdx`; artifact inspection is an environment operation — ADR-0136 `snapshot/diff/download`; authority minting rules — ADR-0033; hosted children at the boundary — ADR-0053 D-4; LCD signatures — S-154, ADR-0007. S-079/S-140 (`provisional`) corroborate only that hosts drive opaque loops and that proxies capture model calls.
- (b) Source-code precedent: omnigent `omnigent/inner/executor.py` (verbs and event dataclasses) and `inner/acp_executor.py` L775–800 (policy-first, `-32601` for unknown methods) @6a069da; agent-client-protocol `schema/v2/{meta.json, schema.json}` @9b00c27; codex `codex-rs/app-server-protocol/src/protocol/v2/{turn.rs, thread.rs, thread_usage.rs}` @0735c51; harbor `src/harbor/agents/base.py`, `models/agent/context.py` @7d5285b; inspect_ai `src/inspect_ai/agent/_bridge/{bridge.py, sandbox/service.py}` @75f4891. The mechanism-neutral verb/event vocabulary with a **mediation stamp** and an explicit exclusion list is `no-precedent / novel` in combination.
- (c) Disconfirming evidence considered: (i) a thin ABI cannot hold context policy fixed or cap tokens on session-ABI participants (ADR-0001 (c); WS-J6 F6) — answered by typing the limitation (`budget_enforcement`, ADR-0165) rather than deepening the ABI toward product-specific policy surfaces; (ii) the mediation stamp adds an axis to `n/a` reasons — answered: one closed enum on the envelope; without it observed and mediated tool counts would be summed; (iii) cloud harness products expose no hosting interface at all (S-056/S-057) — answered: the ABI is an instrument boundary for comparison (ADR-0003), and the four comparison hosts that matter exist; (iv) ACP v2 may move again — answered: the ABI is mechanism-neutral, so a protocol change moves one adapter's tables (ADR-0098 pin). None overturns.
- (d) Conditionality: independent of model tier and task class; assumes hosted participants can at minimum open/submit/cancel and report usage (ADR-0001 conditionality); assumes the Lab provisions the environment for in-environment placements (otherwise `end_state` is `unknown`); `elicit` lowering assumes WS-H7's `message_human` path; `allow_always` options wait on OQ-246.
- (e) Build-stage assignment: **C0 / Stage 3** — `HostedEvent` schema and `proj_ABI` as a native-ledger projection (required by the Stage-4 ACP artefact and AC-J6-2); **C2 / Stage 4** — verbs, lifting for session-ABI, probe verb; **C2 / Stage 4–5** — interception and container-installed lifters.

## Consequences

- WS-K4 implements the ACP transport for Adapter A and keeps the ecosystem boundary (`hello/open_session/…`) as a distinct binding (CF-023); the two share a shape, never a schema.
- WS-B1 adds `lifecycle.hosted.{attached, detached, coordinate_set, drift_observed}` (ADR-0053 D6 family) and the `mediation` payload field on hosted rows to its amendment log; WS-I1 exports `mediation` as a span attribute with declared loss.
- WS-J3/J4/J5 stratify on `mediation`, `capability_vector` and `observability_level`; WS-I2 registers `requires_mediation` (CF-349).
- Spec §6 (hosting) lists the excluded verbs with their substitutes so "inspect artifacts" is not re-imported from doc 2.
- WS-E4 §6.5 wording aligns: `policy` is an adapter input, not a participant input (CF-348).

## Reversibility

**High** for the capability-declared set (add or retire by registry entry with a debt record); **medium** for the baseline verb set (adding a baseline verb obliges every adapter; removing one re-labels stored hosted rows' loss reports); **medium** for the mediation stamp (removing it would require re-auditing every security/autonomy metric reported on hosted rows — the same cost profile as ADR-0013's `ledger ⇔ native` rule).
