## 1. Scope & boundary

This workstream resolves **OQ-004 — the depth of the Hosting ABI**: which operations a hosted participant must and may expose, which events it must and may emit, how the reference runtime mediates its environment, permissions, credentials and budget, how its cost is accounted, which scorecard dimensions apply to it, how versions and extensions are negotiated so the ABI does not decay into a lowest-common-denominator (LCD) interface, and how three concrete classes of external harness attach through abstract adapters. It delivers the acceptance criterion the brief names — *a hosted participant joins an experiment and produces a class-labelled scorecard* — and the LCD-battery report for the ABI.

It **does not re-decide** (neighbours named): the two participant classes and the class criterion (ADR-0001/0013 — consumed verbatim; class is *declared*, never inferred from mechanism); the IR-side representation `AgentProcess.hosted = OpaqueProcess` and its tri-state `CapabilityDeclarationRecord` (ADR-0018 — the ABI *lowers to* it and adds fields only through `ext` or a dialect bump); the ACP edge itself — artefact, v1 compatibility profile, exhaustive event-class lowering table, permission transport, `_hh/*` methods (ADR-0098; WS-E4 — this dossier inherits its decision 6 as the session-ABI *baseline* and publishes the probe suite ADR-0098 asks for); the internal ecosystem boundary verb set (`hello/open_session/submit/stream_events/request_permission/cancel/account/close`, ADR-0050 D3, WS-K4/L5 — a *different binding* that must not be conflated with the Hosting ABI, CF-023/CF-209); the environment handle, its lifecycle and the out-of-process helper (ADR-0136…0138; WS-B5 — hosted participants receive `connection_info`, never a handle: rule R-NOSIDE); the reference monitor, delegation and the policy-first rule for hosted permission requests (ADR-0051…0053 D-4; WS-H1); credential channels (`credential_supply`, ADR-0057/0058 SV-7; WS-H3); egress mediation EP3 with attribution tokens (ADR-0061; WS-H4); cost provenance and the six-valued `CostProvenance` (ADR-0039/0043; WS-L2); the scorecard, `n/a{reason}` semantics and matched-budget engine refusals (ADR-0045…0047; WS-I2/J3/J4); bundle roles for hosted runs (ADR-0139…0141; WS-I3); benchmark adapters (ADR-0142; WS-I4). The experiment engine's factor admission (`InadmissibleFactor`) and the report generator are WS-J3/J4; this dossier supplies the capability-vector strata and the hosted-specific metric declarations they consume.

## 4. Findings

### 4a. Mechanism evidence (a failure mode exists / an architecture is implementable)

**F1 — Every production host converges on the same five control verbs and the same six observable event families; nothing else is common.** Omnigent's `Executor` (S-118 `inner/executor.py` L611–696) exposes `run_turn` (prompt), `interrupt_session` (cancel), `enqueue_session_message` (steer/queue), `close_session`, and a `supports_*` family; its event stream is `TextChunk / ReasoningChunk / ToolCallRequest / ToolCallComplete / TurnComplete{usage} / TurnCancelled / ExecutorError / Compaction* / SubAgent*`. ACP v2 (S-035 `meta.json`) has `session/new|resume|prompt|cancel|close` and update kinds `state_update / agent_message* / agent_thought* / tool_call_update / tool_call_content_chunk / usage_update / config_option_update / plan_update / …`. Codex's app-server (S-107 `v2/`) has `thread/start|resume`, `turn/start|interrupt|steer`, item notifications, `thread/tokenUsage/updated`, `permissions/requestApproval`. Harbor's installed-agent interface (S-132 `agents/base.py`) has `setup / run / resume / load / handoff` with a post-run `AgentContext` and no event stream at all. The intersection of *verbs* is therefore `{open, submit, cancel, close}` + a usage report; the union is large and vendor-shaped (steer, queue, fork, compact, realtime audio, goals). This is exactly the AWT/WORA shape (S-154): an ABI defined as the intersection would be four verbs and a number; an ABI defined as the union would be Codex's 120-method surface. The only non-LCD design is the one ADR-0005/0013/0018 already fixed: a **small baseline** plus **declared capabilities** verified by probes (T-LCD-07). This dossier's contribution is to fix *which* verbs and events are baseline and to make the rest declarable without ever removing them.

**F2 — "Declared" and "observed" capability are distinct objects in every host that takes conformance seriously, and the two-layer split is what keeps the declaration honest.** Omnigent maintains a *static* declaration (`HarnessCapabilities`, pre-spawn, 17 fields, optional fields `None ⇒ UNKNOWN`) and a *runtime* layer (`Executor.supports_*`, "actual in-subprocess behavior — only after spawn"); its bench seam document says the bench must "read the **static** one" as the expectation and let live probes be the verification half, so that "a DRIFT now means *a harness's capability declaration is false*" (S-118 `designs/harness-capabilities-bench-seam.md`). `verdict.reconcile` returns DRIFT only when both sides are concrete and differ, and the confidence caveat records that only 4 of 23 harnesses have `interrupt/streaming` "verified live" while 19 are "declared best-effort by integration mode" — declared values are *not ground truth* until probed. Harbor freezes `AgentCapabilities` per adapter class and refuses a bridge kind the agent did not declare (`bridges/base.py` L28). ACP's `initialize` exchanges `AgentCapabilities`/`ClientCapabilities` where omission means UNSUPPORTED on the wire — which ADR-0013 (CF-027) already re-maps to `unknown` at the analysis layer. Mechanism conclusion: the ABI must carry (i) an append-only, version-pinned declaration, (ii) a probe suite keyed by *dimension* not by *verb*, (iii) a verdict lattice in which `SKIPPED` (probe could not run) is distinct from `UNKNOWN` (no probe) and neither can establish DRIFT.

**F3 — Hosts see three different things through three mechanisms, and the difference is not "more or less detail" but *who produced the evidence*.** Session-ABI hosts (Omnigent ACP executor, OpenHands `ACPAgent`, Harbor ACP bridge) receive *participant-reported* events: a `tool_call_update` is the participant's claim that it called a tool; `usage_update` is its claim about tokens. Interception hosts (Inspect bridge, ClawGym II proxy) *measure* model I/O at a boundary they own: "All model calls are captured and produce the same transcript output as when using conventional agents" (S-137) — but tool events are invisible unless the agent calls a host-granted tool ("Ordinary function tools are never withheld — those are executed by the bridged agent inside the sandbox"). Container-installed hosts (Harbor's 50 adapters) *reconstruct* from native logs after the fact (`populate_context_post_run`; `claude_code.py` ATIF conversion) and get `end_state` from the container. Under ADR-0033 these are three authority classes: kernel-produced (`kernel`), participant-produced (`delegate`, or `unverified` when lifted from a log), and environment-produced (`environment` for closed-schema helper results). The scorecard cannot treat "tool call count" from a `tool_call_update` and from the kernel's effect ledger as the same metric. This yields the **mediation stamp** in §6.1: every hosted event carries `mediation ∈ {mediated, observed, unobserved}`, and metrics declare the mediation they require in the same way they declare observability.

**F4 — Policy never travels into the hosted loop; it is evaluated at the boundary, and the production evidence is unanimous.** Omnigent answers a hosted agent's `session/request_permission` by "Omnigent's TOOL_CALL policy + human-consent elicitation … NOT a blind approve" and answers any other agent→client request with `-32601` "so the agent fails loudly rather than acting on empty data" (S-118 `acp_executor.py` L775–800). Databricks' managed Omnigent forbids custom policy code and forces model access through a gateway (S-060). Inspect drops the agent's own generation parameters by default so "the resolved Inspect model configuration" is authoritative (S-137). The counter-example is OpenHands' auto-approve (`options[0]`, WS-E4 F-row), which ADR-0098 decision 3 already rules inadmissible. Combined with ADR-0053 D-4 (the kernel holds the hosted child's handles and refuses uncovered calls at the boundary), this fixes the mediation rule: the ABI has **no verb that delivers a policy, a permission, a credential value or a budget to the participant**; it has verbs through which the participant *asks* and the kernel *decides*, plus channels (gateway, egress proxy, broker, environment) through which the kernel *enforces* what it can. What it cannot enforce is declared, not assumed (F6).

**F5 — Cost has a different provenance per mechanism and the same adapter often has two.** OpenHands' ACP adapter takes tokens from `response.usage` (participant-reported) and *estimates* cost from a pricing table (S-110 L912–958); Omnigent's cursor adapter obtains usage only by registering a vendor `stop` hook that fires in the interactive loop (S-118 `docs/cursor-native-cost-tracking.md`); Harbor's `AgentContext` carries `cost_usd` "optional per step" reconstructed after the run; Codex's app-server reports `estimated_usage_credits_micros` per model/effort group (S-107 `thread_usage.rs`); Inspect meters at the proxy. ADR-0039/0043 already has the six-valued `CostProvenance`; the ABI's contribution is to fix *which value each mechanism produces by default*, to require both to be recorded when both exist (interception + `usage_update`), and to turn their disagreement into a conformance dimension (`cost_accounting` DRIFT) rather than silently preferring one.

**F6 — Budget enforceability is per dimension and per mechanism; pretending otherwise breaks T-LCD-14 for mixed-class arms.** A session-ABI participant with no interception exposes no verb by which the Lab can stop it at N tokens (ACP has no token cap; CF-073 makes instruction-delivered caps advisory); the Lab *can* stop it on wall-clock (`session/cancel`), on turns (refuse the next `submit`), on approvals (refuse at `request_permission`), on network calls (EP3 proxy refuses) and on spend only where the model path is gateway-mediated. Container-installed participants add `env.active_ms` (the handle) and lose approvals. Interception adds tokens (the proxy can refuse the next model call — the same decision point ADR-0040 uses for native runs). So a `MatchSpec{dimensions: [tokens…], mode: matched_cap}` over an arm whose participant cannot be capped in tokens is not a matched-cap comparison; it is a matched-*report* comparison. WS-J3's engine must know the enforceability of each dimension per arm — the descriptor field `budget_enforcement` in §6.2 supplies it — and refuse or degrade (`IncommensurableMatch`) when a cap is unenforceable on any arm. This is the strongest concrete consequence of "the ABI is thin" for the comparison engine.

**F7 — Version drift is the normal condition at this edge, and every mature host pins, generates and probes rather than trusting a version string.** Every audited ACP host still speaks v1 while the spec serves v2 (ADR-0098 context); Codex ships `v1`/`v2` namespaces, a generated-bindings header and an experimental-API filter (S-107 `export.rs` L45, L109–148); OpenHands keeps a CI drift check between SDK and client registries; Omnigent's bench treats a version bump as a re-probe trigger and its plugin interface rejects plugins that "override builtin harness names". ADR-0099 already fixes `ProtocolBinding` with probe-first pinning at protocol edges. The ABI-level rule that follows is that a **participant version is a claim** (ADR-0037/CF-087 spirit): `version_identity = H(declaration ∥ participant_version)` (ADR-0018), and a `ConformanceRecord` is keyed by that identity so probes expire when it changes. The adapter itself is a conditioned artefact with an assumption-debt record (T-LCD-05 reflexive) — its removal test is "no participant version in the registry matches the adapter's selector".

**F8 — `inspect artifacts`, `fork`, `compact`, `spawn` and `read transcript` are the verbs that would re-import the LCD trap, and each has a substitute that costs the participant nothing.** doc 2 §5.11 lists "inspect artifacts"; no audited host implements it as a verb — Harbor reads the container after the run, Omnigent reads the vendor transcript file, ACP carries `locations` and `content` on `tool_call_update`. Artifact inspection is an *environment-handle* operation (`snapshot/diff/download`, ADR-0136) that the Lab already owns when it provisions the environment; making it an ABI verb would require the participant to expose its own artifact model (an intersection feature). `fork`/`compact`/`spawn` are observed (`SubAgent*`, `Compaction*`, `thread/fork`) but commanding them from the Lab would make a Lab-side control-strategy decision inside an opaque H — exactly what ADR-0013's class criterion says the Lab cannot attribute. `read transcript`/`ledger_read` is meaningful only for a native harness presented as hosted (ADR-0098 `_hh/ledger/read`); a hosted product's transcript is an artefact lifted at `unverified` authority (container-installed), not a verb.

### 4b. Performance evidence (benchmark lifts) — each tagged `provisional` if 2026 single-team/preprint

- S-079 Harness-of-Harness: "+52.25 percent average relative gain … after three iterations" over standalone harnesses on GameCraft-Bench / FrontierSWE / ProgramBench — `provisional`; **discounted**: the baseline is one attempt, HoH is three iterations, no matched budget (doc 2 §8; S-083 critique; T-LCD-14). Used here only as mechanism evidence that a host can drive opaque harnesses by constraining verifiable outputs.
- S-140 ClawGym II: +9.98 / +14.81 points on ClawGym-Bench with a 30B model over two harnesses, "stable over 200–400 optimization steps" — `provisional`; not load-bearing (interception is adopted on mechanism grounds from S-136/S-137 source, not on these numbers).
- S-133 Harbor Adapters: parity between adapted and original agent infrastructure — `provisional (mech)`; the mechanism (parity as a pre-registered `compare`) is what ADR-0142 adopted; no number here is used.
- S-135 HAL (Tier A): the largest black-box comparison corpus; its single-run, no-interval rows are the disconfirming precedent WS-I2 F2/F3 answered. No performance number is load-bearing for any recommendation in §6.

The **integrated design** — one baseline + declared-capability ABI implemented by three mechanisms behind one adapter contract, with a mediation stamp on every event, per-dimension budget enforceability feeding the matched-budget engine, and a self-consistency test through `proj_ABI` — is `no-precedent / novel` in combination (ADR-0005 (b) already recorded that Harbor, Inspect and Omnigent each implement at most two mechanisms and none joins them to a typed native ledger).

## 5. Disconfirming evidence & negative results

**Against any Hosting ABI at all ("cloud harness products show the layer is the runtime, not a host").** Cloudflare's docs draw the runtime/harness line cleanly and then document *no* interface for foreign harnesses (S-056); Flue is a fixed Pi-only stack (S-057); AWS and Microsoft ship single-loop declarative harnesses (S-058/S-059). Only Omnigent-class products actually host heterogeneous loops, and Databricks' managed version narrows even that (no custom policy code). *Why this does not overturn:* the ABI's purpose is *comparison*, not hosting-as-a-product (ADR-0003/0006 N1/N2); the four host precedents that matter for comparison (Harbor, HAL, Inspect, Omnigent) all exist and are cheap (ADR-0010). It does sharpen the scope: the ABI is an *instrument boundary*, and the dossier removes every verb that only a hosting *product* would need (F8).

**Against a thin ABI ("too thin to compare fairly").** ADR-0001 (c)(ii) already concedes that context policy cannot be held fixed across hosted participants; F6 adds that tokens cannot be *capped* on session-ABI participants without interception, so a token-matched comparison with a hosted arm is not what it claims to be. *Why this does not overturn:* the answer is to make the limitation typed and refusable (`budget_enforcement`, `IncommensurableMatch`, capability strata), not to deepen the ABI — deepening it toward "set the participant's context policy" is the intersection trap (no two products expose the same policy surface). Interception is offered as a declared upgrade, not a requirement.

**Against declared capabilities ("declarations are just guesses").** Omnigent's own seam document admits 19 of 23 declarations are "best-effort" and unverified (S-118). *Why this does not overturn:* that is the argument *for* the probe suite and the `unknown`-until-probed rule, and for keying `ConformanceRecord`s to `version_identity` so declarations expire; a declaration that is never probed contributes `unknown` strata, which the engine surfaces rather than hides (T-LCD-07). The residual risk — a probe that passes on a fixture and fails on real tasks — is bounded by making DRIFT observable *during* experiments too (§6.4 I-8: any run-time contradiction of a SUPPORTED entry appends a `ConformanceRecord{observed_in: run}`).

**Against the mediation stamp ("adds a third axis to every metric").** Metrics already declare class and observability (ADR-0045); adding mediation multiplies `n/a` reasons. *Why this does not overturn:* without it, `tool_calls` from a participant's `tool_call_update` and from the kernel's effect ledger would be summed into one column, which is the T-LCD-15 failure ("a hosted participant scoring 0 on attribution") in disguise — a hosted participant *reporting* zero tool calls would score perfect autonomy. The stamp is one closed enum on the hosted event envelope, and only security/grounding metrics require `mediated`; efficiency/capability metrics accept `observed`.

**Against session-ABI first ("every host is on ACP v1; the v2 core may move again").** ADR-0098 (c)(i) answers this with the pinned derivation key and the v1 compatibility profile; this dossier adds that the ABI baseline is *mechanism-neutral by construction* — the same verb set is satisfied by the Codex app-server (`thread/*`, `turn/*`) and by a container-installed adapter (Harbor `run/resume` + log reconstruction) — so a change in ACP changes one adapter, never the ABI.

**Against self-consistency as an acceptance test ("native-as-hosted proves nothing about foreign harnesses").** True: `proj_ABI` self-consistency (AC-J6-2) validates the *lifting* path and the class-scoped scorecard, not any adapter. *Why it stays:* it is the only executable test of T-LCD-11 for events that needs no third-party binary, it makes ADR-0013 decision 5 ("`proj_ABI` is total") checkable, and it is the fixture on which the probe suite itself is validated (a probe that mis-scores the reference harness is wrong).

**Negative results recorded.** (i) No audited host sequences `idle` after persistence (ADR-0098 context) — hosted `turn.finished` is therefore *observed*, never durable-before-visible; recovery after a host crash mid-turn is "resume from the participant's last reported state" with a `world_state.discontinuity`. (ii) No audited host reports `activated`/`followed` for supplied context; T-LCD-13 on hosted rows stops at `delivered` unless `instruction_delivery` is SUPPORTED and a detector exists. (iii) No audited host can attribute a participant's *internal* model calls to roles (primary vs subagent vs judge) except Codex's usage groups — the realized `ModelRoleTable` for hosted rows is `n/a` beyond the primary role unless intercepted.

## 6. Recommendation for the spec

### 6.1 The Hosting ABI: verb set, event vocabulary, mediation stamp (resolves OQ-004)

**Shape (ADR-0005 preserved).** The Hosting ABI = a **participant descriptor** (ADR-0013) + a **capability declaration** (ADR-0018 record, extended per §6.2) + a **control verb set** (Lab → participant) + an **upcall set** (participant → Lab) + the **minimum observable event set** (`HostedEvent`) with its lifting into ledger classes. Verbs are *baseline* (every mechanism must satisfy them, possibly trivially) or *capability-declared* (default `unknown`; never removed because some participant lacks them — T-LCD-07). The session-ABI baseline is ACP v2's stable core exactly as ADR-0098 D6 fixed it; the verb names below are the mechanism-neutral names the other two mechanisms also satisfy.

**Control verbs (Lab → participant), with rationale.**

| verb | signature (operations · inputs → outputs) | status | rationale / mechanism mapping |

| upcall | contract | status |
|---|---|---|

**Deliberately excluded verbs (each exclusion is a T-LCD-06/-07 guard).** `inspect_artifacts` (environment-handle operation; F8); `set_policy` / `grant` / `deliver_credential` (policy and authority never enter the loop, F4; credentials only as broker-bound channels per `credential_supply`, ADR-0058 SV-7); `set_budget` (budgets are enforced at the boundary, F6; an *advisory* budget instruction is a supplied `ContextItem` delivered only if `instruction_delivery` is SUPPORTED — CF-073); `fork`, `compact`, `spawn_subagent`, `set_control_strategy` (Lab-commanded decisions inside an opaque H; observed only); `inject_tool` after `open` (violates the closed-world rule — the supplied surface is sealed at `open`; a later catalogue epoch is a new session); `read_ledger` / `read_transcript` (no ledger exists for a hosted H; native-as-hosted uses `_hh/ledger/read` outbound only); `checkpoint`/`restore` (environment handle, ADR-0136); `authenticate` (ADR-0058; the adapter binds channels, never the Lab through the ABI); `install_extension` (ADR-0065 path only, native).

**The minimum observable event set — `HostedEvent`.** Envelope: `HostedEvent{seq, session, at (adapter monotonic clock, integer ms), kind, payload, provenance: ProvenanceRecord{origin ∈ {participant, intercept, environment, adapter}, authority}, mediation ∈ {mediated, observed, unobserved}, event_channel ∈ {protocol, hook, log, proxy, handle}, raw_ref?: blob address of the un-lifted payload, ext}`. `mediation` semantics: **mediated** — the kernel produced or gated the fact (an effect through the Lab's MCP surface, the egress proxy, the broker, the environment helper, or an intercepted model call); **observed** — the participant reported it live through a protocol/hook channel; **unobserved** — reconstructed after the fact from logs or absent (the adapter emits synthetic terminal events so every session has a well-formed lifecycle). ### 6.2 Data-model sketch: descriptor extension, adapter record, conformance

- `ParticipantDescriptor` (ADR-0013, unchanged) + `CapabilityDeclarationRecord` (ADR-0018 fields: streaming, interrupt, steer, live_queue, resume, fork, compaction, images, subagents, permission_surface, instruction_delivery, model_family, effort_vocabulary, trajectory_export, native_config) **extended through the registered `ext` block `hh.hosting/1`** (dependency direction ABI → IR preserved; a dialect bump may later promote fields): `credential_supply` (ADR-0058), `receipts` (ADR-0067), `account_exact`, `elicitation`, `model_io_intercept ∈ {base_url, client_patch, none, unknown}` (resolves OQ-038: interception is an *optional capability* of any participant, upgrading `observability_level` to include `model_io`; class unchanged), `process_placement ∈ {in_environment, lab_host, remote_service}`, `tool_supply_channel ∈ {mcp, none}`, `context_supply_mode ∈ {prompt_blocks, files, both, none}`, `coordinates: map<coordinate_name, tri-state>`, `budget_enforcement: map<dimension, {enforced, advisory, unenforceable}>` (derived by the adapter from mechanism + placement + interception; e.g. session-ABI in-environment without interception: `time.wall_ms: enforced, turns: enforced, approvals.requested: enforced, network.calls: enforced, spend: enforced iff gateway-mediated else advisory, tokens.*: advisory`), `abi_versions: [string]`, `event_channels ⊆ {protocol, hook, log, proxy}`. All tri-state where a claim is possible; `unknown` never coerced.
- `AdapterRecord{adapter_id, version_id, hosting_mechanism, participant_selector (version range as a claim), declaration_defaults: CapabilityDeclarationRecord, placement_supported ⊆ {…}, lowering_table_ref, loss_report_ref, debt: AssumptionDebtRecord{hypothesis: "participant versions matching selector behave per declaration_defaults", evidence: ConformanceRecord refs, owner, expiry_condition: "selector matches no registered participant version or DRIFT on a P0 dimension", removal_test}}` — the adapter is a conditioned artefact (T-LCD-05 reflexive), MUST-code for transport/lifting, MUST-data for its tables (ADR-0024).
- `ConformanceRecord{participant_version_identity, adapter_version_id, dimension, declared: tri-state, observed: Verdict ∈ {supported, unsupported, partial, not_applicable, unknown, skipped}, verdict: Verdict ∪ {drift}, observed_in ∈ {probe(probe_run_id), run(run_id)}, evidence_ref, at}` — immutable; `capability_vector(participant_version) = reconcile(declaration, latest ConformanceRecords)`; `skipped`/`unknown` never establish DRIFT (Omnigent `_CONCRETE`).
- `HostedRunSpec`, `HostedSession{session_id, participant_version_identity, adapter_version_id, opened_at, placement, mechanism, observability_level, cursor}`, `HostedEvent` (§6.1), `ProbeResult{verdict, note, detail_ref}` (Omnigent shape).
- Bundle members for hosted runs (ADR-0141 D6, unchanged): lifted events + `hosted.native_record`, descriptor `version_id`, adapter `version_id` + its loss report, supplied items pinned, `ConformanceRecord`s referenced; `claimed_level ∈ {R0, R3}`, R2 only with `end_state`.

| **Durability** (ADR-0026/0130) | `turn.finished` is observed, never durable-before-visible; a Lab crash mid-turn resumes by `resume(cold \| warm)` per declaration and records `world_state.discontinuity`; every hosted-session write to the ledger goes through the run's single fenced writer (the adapter holds no lease). | observed |

### 6.4 Negotiation, extension and the probe suite (T-LCD-05/-07/-11)

- **Version handshake.** `describe` returns `abi_versions` (e.g. `hh-hosting/1`); the Lab pins the highest mutually supported *major*; a participant advertising none is attached at `hh-hosting/1` with every declaration `unknown` (never refused for silence — T-LCD-07). Session-ABI participants additionally negotiate the protocol (`ProtocolBinding`, ADR-0099, probe-first); the ABI version is orthogonal to the protocol version. Unknown majors are refused (`AbiVersionUnsupported`); unknown minors are accepted with unknown fields preserved.
- **Extension rule.** New capability fields enter through `ext hh.hosting/n` (registered prefix, preserved byte-for-byte, **never deciding authority/budget/validity** — ADR-0015); promotion to the kernel record is a HIR dialect bump. Vendor methods (`_goose/…`, Codex experimental APIs) are reachable only from an adapter that declares them as a capability with a debt record; the ABI never exposes a raw pass-through verb (no escape hatch — T-LCD-01 by analogue). Unknown events/values are preserved (§6.1 I-3), never dropped, never interpreted.
- **Probe suite (baseline dimensions P-01…P-16, Lab-side, fixture sessions; each declares `applies_to_mechanisms`).** P-01 `basic_turn` (always included; prerequisite), P-02 `streaming` (delta count; single coalesced delta = `partial`), P-03 `interrupt` (cancel a long turn; terminal within deadline), P-04 `tool_calling_supplied` (a Lab-supplied MCP tool is called; its effect is `mediated`), P-05 `tool_calling_own` (a participant-native tool call is *observed* via the protocol/hook channel), P-06 `policy_deny` (a `deny` Π row blocks a mediated call; the participant reports failure, not success — the ADR-0098 AC-E4-7 fixture), P-07 `policy_ask` (an `ask` row produces `permission.requested` and the turn blocks until decided), P-08 `context_delivery` (a supplied `ContextItem` is `delivered`; a marker-echo detects `activated` where a detector exists), P-09 `coordinate_model` (set the `model` coordinate; echo + intercepted/served model agrees), P-10 `coordinate_other` per declared coordinate, P-11 `usage_reporting` (a `usage.reported` event with non-zero tokens; if intercepted, agreement within tolerance), P-12 `resume_cold` / P-13 `resume_warm` (marker recall after `resume`), P-14 `steer`, P-15 `credential_channel` (a declared channel is bound and a canary through an undeclared one is refused — LT-01 shape), P-16 `end_state` (the environment snapshot at `close` reflects a marker file). Verdicts per Omnigent's lattice; `skipped` when the environment cannot exercise the probe; every probe reconciles against the declaration and appends a `ConformanceRecord`; DRIFT on a P0 dimension (P-01, P-03, P-04, P-06, P-09, P-16) makes the participant version `quarantined` for experiments until re-declared (OQ-034 answered: DRIFT *excludes* on P0 dimensions and *annotates* on the rest).
- **Invariants.** (I-6) an adapter refuses to attach a mechanism or placement the declaration does not claim (Harbor bridge rule); (I-7) `capability_vector` is recomputed whenever `version_identity` changes and every `ConformanceRecord` older than the current identity is `stale` (annotated, never hidden — ADR-0037); (I-8) a run-time contradiction of a SUPPORTED entry appends `ConformanceRecord{observed_in: run}` and the results row carries the stratum `drift_observed`; (I-9) the engine stratifies on the vector, never on the declaration alone.

### 6.5 Scorecard applicability (T-LCD-15) and hosted-specific metrics

Rule: a metric applies to a hosted row iff `applies_to_classes ∋ hosted` **and** `requires_observability ⊆ observability_level` **and** the new precondition `requires_capabilities ⊆ {c : capability_vector[c] = supported}` **and** `requires_mediation` is met. (The `requires_capabilities` and `requires_mediation` fields are proposed additions to `MetricDeclaration` — CF-349; today `steer_rate`, `crash/recovery_rate`, `approval_*` encode this informally.) By dimension (from WS-I2's table): **Capability** — `task_success`, `partial_credit`, `coverage`, `quality_rubric`, `horizon_50`: apply (`end_state`); **Reliability** — `pass^k`, variance, `runaway_rate`, `tail_*`, `catastrophic_failure_rate`: apply; `crash_rate/recovery_rate`: `requires_capabilities = {resume}`; `duplicate_effect_rate` (veto): `n/a{class}` — replaced on hosted rows by `observed_duplicate_action_rate` (non-veto, `observed`); **Grounding** — `validator_pass_rate` via end-state validators only; `claim_state_agreement`, `evidence_traceability`, `execution_alignment_failure_rate`: `n/a{class}`; judged variants: `requires_observability ∋ model_io`; **Efficiency** — all apply with `confidence` stratum; `cache_hit_ratio` needs `model_io` or reported cache buckets; **Autonomy** — `human_interventions`, `approval_burden`, `unassisted_success`: `requires_capabilities = {permission_surface}`; `steer_rate`: `{steer}`; **Security** — `utility_under_attack`, `targeted_asr`: apply (`end_state`); `exfiltration_blocked`, `egress_attempts`: apply (`mediated(egress)`); `secret_leak` (veto): applies with broker+proxy (§6.3); `permission_violation_rate` (veto): `requires_mediation = mediated(effects)` — `n/a{mediation}` otherwise; `blast_radius`: `n/a{class}` except the `end_state` diff outside the workspace (`observed_blast_radius`); `audit_completeness` (veto): `n/a{class}`; **Portability** — apply at product/configuration level (model coordinate SUPPORTED); **Evolvability** — `n/a{class}`. **Hosted-specific declarations (new, `applies_to_classes = {hosted}`):** `hosted_observation_completeness` (fraction of sessions with a well-formed lifecycle without synthesized terminals; the hosted analogue of `audit_completeness`, non-veto), `mediation_coverage` (mediated ÷ (mediated + observed) tool events — how much of the participant's action space the Lab actually governed), `usage_report_agreement` (|reported − measured| ÷ measured per token role when both exist; a `cost_accounting` conformance dimension), `conformance_drift_count`, `synthesized_terminal_rate`. Every `n/a` carries `reason ∈ {class, observability, capability, mediation, estimator_undefined, not_run, no_detector}` — `capability` and `mediation` are proposed additions to ADR-0045's reason enum (CF-349).

### 6.6 Three adapter sketches (abstract; no product is a dependency)

**Adapter A — session-ABI adapter for an ACP-speaking coding CLI (goose / gemini-cli / opencode / Devin-class; v1 today).** Mechanism `session_abi`; placement `in_environment` (the CLI is installed by the Lab into the task environment at `set_phase(setup)`; the protocol transport is bridged through the helper's exec channel); declaration defaults: `streaming: supported`, `interrupt: supported`, `permission_surface: protocol`, `tool_supply_channel: mcp`, `context_supply_mode: prompt_blocks`, `coordinates{model, mode, thought_level}: unknown` until probed, `steer/fork/compaction/subagents: unknown`, `resume: cold_only`, `model_io_intercept: base_url` where the CLI honours a provider base URL (then `observability_level = {events, model_io, end_state}`, else `{events, end_state}`); budget enforcement: wall/turns/approvals/network enforced, tokens advisory unless intercepted; permission: policy-first; cost: `participant_reported` + `gateway_reported` when intercepted. Lowering table = ADR-0098 D2 inverted (lifting), loss classes as in §6.1; v1 hosts through the compatibility profile with `unknown` for removed features. This is the Stage-4 first adapter (ADR-0005 ordering).

**Adapter B — model-boundary interception adapter for a vendor CLI with hooks but no session protocol (Claude Code / cursor-agent / Codex-CLI-headless class).** Mechanism `model_boundary_intercept`; placement `in_environment`; the Lab's proxy serves the provider dialect(s) at a local endpoint inside the environment (Inspect sandbox-bridge shape), so every model call is `mediated`, cost is `gateway_reported`/`provider_reported`, and tokens are an *enforced* budget dimension (the proxy refuses the next call at the ceiling — the ADR-0040 decision point); tool events arrive through vendor hooks where present (`event_channel: hook`; Omnigent `PreToolUse`/`stop` precedent) as `observed`, else reconstructed from the vendor transcript at `close` as `unobserved`; `permission_surface: hook` where a pre-tool hook can veto (then `policy_deny` is probeable and `permission_violation_rate` applies for hook-gated calls), else `none`; `coordinates{model}` supported by proxy override (Inspect name-prefix precedent; the participant stays hosted — OQ-048/ADR-0013 consequence); `resume: warm_reattach` if the vendor session file is preserved in the environment snapshot. The generation-parameter policy (drop vs forward) is a declared adapter parameter with a debt record.

**Adapter C — container-installed adapter reconstructing from native logs (Harbor installed-agent class; also the fallback for any CLI with a transcript format).** Mechanism `container_installed`; placement `in_environment`; verbs: `open` = install + configure (Harbor `setup`), `submit` = process start with the instruction (`run`), `cancel` = kill, `close` = snapshot + log sync + reconstruction (`populate_context_post_run`); `stream_events` is a post-hoc stream (`mediation: unobserved`, `origin: participant`, `authority: unverified`) built by a per-format lifter (JSONL transcript, rollout file) that recognises the vendor's compaction boundary (last-boundary rule) and tool records; `observability_level = {end_state}` plus `events` only for lifecycle rows the adapter itself produced; cost `reconstructed_from_native_log` or `unknown`; budgets: wall/network/env-time enforced, everything else unenforceable; permissions: `none` (the participant runs in the vendor's own autonomy mode — recorded as a coordinate); coordinates: `model` via vendor config file (probe P-09 checks the log's reported model), `native_config: supported` (Harbor field). Component metrics, autonomy metrics and mediated security metrics are `n/a`; capability, efficiency (estimate), portability and end-state security metrics apply. **Adapter zero — native-as-hosted (`proj_ABI`).** The reference runtime presented through its own ACP artefact (ADR-0098) attached by Adapter A: the fixture on which the probe suite and the lifting are validated (AC-J6-2); it must be `hosted` for a Lab that does not own the definition and yields `observability_level = {events, end_state}` (+ `model_io` when intercepted) — never `ledger`.

**OQ-248 answer.** A network-remote A2A peer is `hosting_mechanism = session_abi` with `ProtocolBinding{a2a}` and `process_placement = remote_service`; no enum bump — placement, not mechanism, is what differs, and the A2A lowering table (WS-E4 §6.2) already declares `no_slot` for tool/permission/model events.

### 6.7 Acceptance criteria

- **AC-J6-1 (brief's criterion; T-LCD-09/-15).** A `Design` with one native arm and one hosted arm (Adapter A over a fixture participant) on the Stage-3 suite runs to completion; the results rows carry `participant_class`, `observability_level`, `capability_vector` strata and cost `confidence`; the scorecard renders every native-only metric as `n/a{reason}` on the hosted row, never 0 or a proxy; `InadmissibleFactor` is raised for a component-level factor on the hosted arm.
- **AC-J6-2 (self-consistency; T-LCD-11 for events).** The reference harness run natively and run as adapter-zero on the same task/seed/budget yields identical values for every metric with `requires_observability ⊆ {events, end_state}` and `requires_mediation ≠ mediated(effects)`; every metric outside that set is `n/a{class \| observability}` on the hosted row; the lifting's loss report lists exactly the classes ADR-0098 D2 maps to `none`/`hint_only`.
- **AC-J6-3 (T-LCD-07).** Attaching a participant with an empty declaration yields a vector of `unknown` and admissible granularities collapse to `product-level`; after the probe suite, only probed dimensions change; a probe that cannot run yields `skipped`, never `unsupported`; DRIFT on P-06 quarantines the version.
- **AC-J6-4 (policy-first; ADR-0098 AC-E4-7).** With a `deny` Π row, a hosted participant's mediated call never executes and the participant observes a failure; with an `ask` row, the turn blocks on `security.permission.pending`; an adapter configured to auto-approve fails admission (static check).
- **AC-J6-5 (T-LCD-06).** The build with the hosting tier absent passes the native acceptance suite unchanged; the spec DAG has no edge from any HIR entity or C0 contract to the Hosting ABI; `hosting_edges = []` in `lcd_report`.
- **AC-J6-6 (F6; T-LCD-14).** A `MatchSpec{dimensions: [tokens], mode: matched_cap}` over an arm whose `budget_enforcement[tokens] ≠ enforced` is refused with `IncommensurableMatch`; the same design with interception enabled is accepted; `iso_cost` over `spend` is accepted only where every arm's spend confidence is `exact` or `bounded`, otherwise the Pareto report renders bands (CF-105).
- **AC-J6-7 (H3/H4).** A hosted participant receives no credential value except through a channel in `credential_supply`; a canary planted in an undeclared channel never leaves EP3 (LT-01/LT-10 fixtures pass on hosted rows); `secret_leak` is computed, not `n/a`.
- **AC-J6-8 (T-LCD-05 reflexive).** Every `AdapterRecord`, every `_hh/*` method and the ABI version record carry a complete assumption-debt record; `link` refuses an adapter without one; a "retire adapter" recipe runs the removal test.
- **AC-J6-9 (cost).** When interception and `usage.reported` coexist, both `measurement.cost.attributed` rows exist with distinct provenance and `usage_report_agreement` is reported; a participant reporting nothing yields `NoPrice`/`unknown`, never zero.
- **AC-J6-10 (versioning).** An unknown ABI major is refused; an unknown minor attaches with unknown fields preserved; a changed `participant_version` invalidates the capability vector until re-probed.
