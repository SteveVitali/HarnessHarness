## Ontology terms

| term | definition | notes |
|---|---|---|
| **authority handle** (definition; supersedes the name-only row) | The runtime object-capability materialising a HIR/1 `Permission` for one AgentProcess: an unforgeable, allocated `HandleId` in the kernel's handle table with `{permission_ref, holder, issuer, grants[], ceiling, validity, parent_handle?, delegable, origin_basis}`; never present in any model-facing surface; the only thing the reference monitor checks coverage against. | WS-H1; CF-037; ADR-0051 |
| **handle table** | The kernel projection `project(run, handle_table, until_seq)` over `security.permission.granted/revoked`; rebuild-equal to the live table. | WS-H1; ADR-0026 rule |
| **kernel decision** | `KernelDecision{effect_id, allow | ask | deny, effective_authority, taint, effective_risk_class, handle_ids[], policy_ref, checks[], assessment_inputs_ref, cache_key?, decider}` — the output of `authorize`; recorded on `security.permission.decided`. | WS-H1 extends ADR-0031's shape |
| **policy table Π** | `PolicyTable{version_id, mode ∈ {attended, unattended}, rows[], default: deny, conditioned_on?, assumption_debt?}` keyed on `(EffectDomain, risk pattern, effective-authority range)`; a MUST-data artifact of the sealed definition at `definition` authority interpreted by MUST-code. | WS-H1/H7; OQ-101 |
| **pre-authorization** | A `definition`-issued authority handle minted at `seal` under the `policy_rule` endorsement basis from a `HarnessRule{trigger, action: pre_authorize(scope, lifetime)}`, bounded by `authority_cap`; the only way to make an `ask` cell resolve without a human. | WS-H1/H7; ADR-0035 basis |
| **raise-only input** | Any decision input (model self-report, classifier, judge, hook, reviewer) that can move a kernel decision toward `deny` or raise the effect risk class but can never move it toward `allow` or lower a class. | WS-H1; ADR-0031 monotone rule generalised |
| **complete mediation** (ledger invariant) | For every `effect_id`, a `security.permission.decided{allow}` precedes `action.effect.committed` in `seq`, exactly once per attempt cycle; enforced at append and in `audit_completeness`. | WS-H1/B1/H6; Anderson S-251 |
| **decision replay** | Recomputing `authorize(p, at)` from the recorded proposal, handle-table snapshot, Π version and `assessment_inputs_ref` reproduces the stored kernel decision. | WS-H1/H6 |
| **attenuation chain** | The `parent_handle` linkage from a delegated handle to its ancestor, along which grants only narrow, ceilings only fall and revocation cascades. | WS-H1/F3/J6 |
| **unattended mode** | The Π mode in which every `ask` resolves to `deny` unless a pre-authorization covers the effect; mandatory for scheduled/persistent-goal runs. | WS-H1/H7/B3 |
| **reference-monitor TCB** | The enumerated MUST-code set of ADR-0053 decision 1 (handle table, `authorize`/`delegate`/`revoke`, label operations and the kernel `context_label` stamp, deterministic assessors, Π interpreter, endorsement/ceiling checks in the append path, the approval verb, the enforcement points, the `SurfaceArgMap` evaluator); contains no `Text` leaf and makes no model call. | WS-H1; OQ-021 |
