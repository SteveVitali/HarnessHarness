## Ontology terms

| term | definition | notes |
|---|---|---|
| subagent | A child `AgentProcess` (native or `hosted`) reached by a `delegated-to` edge and executed as its own run (`run_kind = agent`, `parent_run_id`, `spawn_event`), created only by kernel `spawn`; identical to a root run except that its authority, budget and containment are bounded by its parent's at spawn. | WS-F3 (proposed); typed form of doc 2 §5.7's "process". Never a persona. |
| child run / parent run / run tree | The runs related by `parent_run_id`/`spawn_event`; the tree is a projection over `control.subagent.*` and `lifecycle.run.created{parent_anchor}` (ADR-0027/0067). | WS-F3; view consumed by WS-K2. |
| `spawn` (operation) | `spawn(parent, lease, decision, SubagentSpec, at) → Spawned | SpawnRefused` — the one kernel operation creating a child run by composing `delegate` (ADR-0053), `allocate` (ADR-0040), `derive` (ADR-0138) and `acquire(writer)` (ADR-0130) atomically. Distinct from the `spawn_process` effect domain it is authorized under (scope kind `agent_process`). | ADR-0185. Resolves the `spawn` / `spawn_process` name overlap: the domain is the *effect class*, the operation is the *kernel act*. |
| `SubagentSpec` | The MUST-data record a `delegate` decision or `Delegate` step supplies to `spawn`: process, goal, role, requested grants, budget + mode, isolation, supplies, return contract, wait, `on_parent_end`, `delegation_reason`, topology ref. | ADR-0185 decision 3. Precedents: Claude SDK `AgentDefinition`, opencode `Agent{mode: subagent}`, AOrchestra tuple. |
| return contract | `ReturnContract{artifacts[{kind, schema?, required}], summary{schema?, max_tokens} | none, claims}` — what a parent will accept from a child, enforced by the child's envelope; violations are typed, never truncated. | ADR-0187 M-2. |
| `SubagentResult` | The content-addressed payload of `control.subagent.result`: outcome class, stop reason, `child_head`, artifacts by content address, optional `subagent_summary` artifact, claims by reference, usage, contract satisfaction. | ADR-0187 decision 1. |
| subagent summary (artifact kind) | `Artifact{kind: subagent_summary}` at `authority = min(⊔ child inputs, delegate)`; the only child-authored text that may enter the parent's context, as the `subagent_result` candidate; carries the T-LCD-13 delivery chain so retention is measurable. | ADR-0187 M-1; extends ADR-0074's candidate kind. |
| `merge` (operation) / merge policy / merge conflict record | `merge(parent, lease, result, MergePolicy) → Merged | MergeConflict`; applies a child's `FsChangeSet` as the parent's own baselined `fs_write` effects (ADR-0138 D5); `MergePolicy ∈ {refuse, parent_wins, child_wins, three_way(Ref<Procedure>), ask}` (closed); `MergeConflictRecord{path, parent_baseline, child_before, child_after, parent_current, detected_at}`. | ADR-0187 M-3; semantics of the three resolving policies are WS-F5's. |
| topology preset | Closed sum `TopologyPreset ∈ {T0 single, T1 orchestrator_worker, T2 pipeline, T3 recursive_full_harness, T4 independent_verifier, T5 ensemble, T6 background_detached, T7 hosted_peer}` — delegation shapes as MUST-data over one spawn contract; a Lab factor. | ADR-0186 decision 1. T4 = ADR-0116, T5 = ADR-0123, T7 = ADR-0096/0164. |
| orchestrator (component class) | The C3 component class that binds topology presets, wait policies and messaging over `spawn`/`merge`; receives `(ModelProfile, ResourceAccount)`; never holds a handle. | ADR-0186. Not "the orchestrator" of Symphony (an external scheduler) — that is an L8 surface over T6. |
| recursive full-harness delegation | T3: a child whose `harness_def.semantic_id` equals its parent's (a full harness, not a bare model call), bounded by `delegation_depth`; every level attenuates and contains. | ADR-0186 decision 2. Precedents S-064 (`provisional`), S-116 `rlm()`. |
| delegation reason | `delegation_reason ∈ {parallelism, clean_context, isolation, independent_check, specialization}` on every `control.decision{kind: delegate}` with `owner ∈ {code, model}`; a factor on results rows; `realized_benefit_by_reason` is the class-scoped metric over it. | ADR-0186 decision 4. Doc 2 §11 Stage 4's three reasons plus isolation and specialization (S-036, S-052). |
| family-scoped message / peer message | `control.subagent.message{sender (kernel-derived), receiver ∈ {parent, child, sibling}, payload_ref, delivery_mode ∈ {steer, follow_up}}` delivered as a cue at a decision point; tree-local reach; never endorses. | ADR-0186 decision 3; precedent S-116 `agent-message`. |
| attenuation delta | The recorded difference between `SubagentSpec.requested_grants` and the `child_handles` `delegate` actually issued; on `control.subagent.spawned`; the observable of SP-1. | ADR-0185 decision 4. `no-precedent`. |
| detached child | A child spawned with `on_parent_end = detach_to_child` whose environment ownership transferred (`control.subagent.detached`) and whose completion targets the parent's goal subscription. | ADR-0187 M-6, C-9; ADR-0138 D4 term `on_parent_end` reused. Precedent S-052. |
