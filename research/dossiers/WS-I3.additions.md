## Ontology terms

| term | definition | notes |
|---|---|---|
| **bundle layer** (manifest / payload / sidecar) | The three parts of a reproducible harness bundle: the hashed `BundleManifest` (identity), the content-addressed payload verified against it, and the detached sidecar of versioned records (attestations, reports, status) that refer to the manifest by `version_id` and cannot change its identity or raise its level. | WS-I3 / WS-H6 / WS-J5. Precedent: in-toto bundle layer (sidecar), RFC 8493 (payload manifests). |
| **member reference (MemberRef)** | `{role, ref: VersionedRef \| ContentAddress, media_type?, size?, status ∈ {present, fetch, redacted, gc}, foreign?}` — the only way a bundle names a member; `ref` is always a full digest under a readable `idp`. | WS-I3 / WS-L4. |
| **foreign reference** | `ForeignRef{system, digest, label?, provenance}` — a digest or version label computed by another system (Harbor, Inspect, SWE-bench, OCI registry, git), carried as a claim next to the native address (or alone when bytes are unavailable); never satisfies a level requirement above R0. | WS-I3 / WS-I4 / WS-J6 (CF-087). |
| **bundle claim** | `Claim{role, value, provenance}` — a fact asserted about a bundle that is not derivable from its bytes (provider model identity, submission checklist facts, participant version); carries `authority ≤ external` or `unverified`. | WS-I3 / WS-L3. Precedent: SWE-bench `metadata.yaml` tags. |
| **fetch entry / detached bundle** | `FetchEntry{address, size?, locations[], expires?}`; a bundle with fetch entries is *detached*; it is complete but not valid until fetched and verified. | WS-I3 / WS-L6 (OQ-332). Precedent: BagIt `fetch.txt`. |
| **complete bundle / valid bundle** | *Complete:* every referenced member is listed as an address, a fetch entry or an explicit `unpinned[]` claim and every run-manifest reference resolves inside `resolved_dependencies`. *Valid:* complete, and the manifest, every present member and every subject run's chain verify, and `claimed_level ≤ max_supported_level`. Levels are claims about valid bundles. | WS-I3 / WS-L4. Precedent: RFC 8493 §3. |
| **ledger export (tree)** | `LedgerExport{events: chunked canonical pages by seq range, checkpoints[], blob_index[], head, lineage_prefixes[]}` — the per-run `traces` member; a tree address so partial verification and header-first reads work. | WS-I3 / WS-B1 / WS-H6 (CF-299). |
| **level basis / max supported level** | `LevelBasis{level, requirement_id, satisfied_by: MemberRef \| Unpinned}` over the closed requirement set `B-R0…B-R3`; `max_supported_level` is the highest level every requirement of which is satisfied by a member (never a claim); recomputed at validation. | WS-I3 / WS-L4 / WS-I2. `no-precedent / novel`. |
| **bundle validation report** | `BundleValidationReport{status ∈ {valid, complete_not_valid, incomplete, invalid}, diagnostics[], derived{max_supported_level, basis[], missing[], fetchable[], foreign[], unpinned[], redacted[], gc[], payload_size}, view_hash}` — output of the staged `validate_bundle` (S1–S9), all stages reported. | WS-I3. Precedent: WS-A5 `validate_assembly` discipline. |
| **bundle status record** | `BundleStatusRecord{bundle_ref, status ∈ {assembled, validated, attested, published, restricted, reproduced, superseded, retracted}, readers, reason, supersedes?, provenance, created_at}` — lifecycle by supersession; never a mutation of the bundle. | WS-I3 / WS-J5 / WS-H6. Precedent (shape only): Inspect `ProvenanceData`. |
| **independent reproduction** | A `ReproReport{verdict = reproduced, independent = true}` produced on an installation and by a signer distinct from the bundle's producer; the only basis for status `reproduced`. Maps to ACM "reproducibility (different team, same artifacts)"; a producer's own re-run is repeatability. | WS-I3 / WS-H6 (OQ-334). |
| **bundle diff** | `BundleDiff{sections: member deltas, definition_diff: HirDiff?, sameness: L0–L4, configuration_delta, level_delta}` — the Lab's "what differs between two arms" operation; pure. | WS-I3 / WS-J4 / WS-L4. |
| **publication policy** | `PublicationPolicy{readers, content_classes, redaction, payload_protection ∈ {none, restricted_store}, loss_report}` — governs `export`; L2 content leaves only where each item's `readers` label admits the audience; every publication is `measurement.export.delivered` with a loss report. | WS-I3 / WS-I1 / WS-L6 / WS-I4 (OQ-331). |
| **bundle catalogue** | A WS-J5 header-only view over bundle manifests keyed by `configuration_id`, kind, level, status and participant class; the source of the derived `bundle_ref` annotation on results rows. | WS-I3 / WS-J5 (CF-298). Precedent: Inspect `logs.json`. |
| **import record** | `ImportRecord{format, source, foreign_manifest: ContentAddress, mapping_loss: LoweringLossReport, lifted_authority = unverified}` — produced by `import`; the foreign manifest is kept byte-for-byte as a member. | WS-I3 / WS-J6 / WS-I4. |
| *(amendment)* **bundle manifest** | Add header fields `{schema: hh-bundle/N, producer, participant_class, observability_levels, claims[], name_bindings[], fetch_policy}`; `traces` per run is a `LedgerExport` tree; `results` adds design/pre-registration/arm/match-spec/search-budget refs; `reproducibility` adds `max_supported_level`, `basis[]`, `evidence[]`, `independent_reproductions[]`. | WS-I3 amending WS-L4's row (ADR-0038 sections unchanged). |
| *(amendment)* **reproducibility level** | Add: the maximum claimable level is derived from `basis[]` (members only); `repeatability` vs `reproducibility` (ACM) is reported by `ReproReport.independent`; replicability is `transfer`, never a bundle level. | WS-I3 amending WS-L4's row. |
