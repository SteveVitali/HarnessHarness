## Ontology terms

| term | definition | notes |
|---|---|---|
| checkpoint (view) | `project(run, checkpoint_view, until_seq)`: the ledger watermark plus the control strategy's `checkpoint_ref`, effect summary, open scopes, environment handles, subscriptions, budget state, `resume_set` heads and pending permissions; may be materialised as a blob, never authoritative. | WS-B3; ADR-0026 view discipline |
| restore / recovery plan / recovery action | The procedure that takes over a run's writer lease, verifies the chain, applies the recovery table to every open scope and appends `lifecycle.run.resumed{recovery_decision}`; `RecoveryPlan{lease, from_seq, recovery_decision, actions[]}`; each `RecoveryAction` is a ledgered, idempotent step keyed by scope id. | WS-B3; extends WS-B1 `recovery decision` |
| recovery table | The normative mapping from (open scope kind, phase) to recovery action (WS-B3 §6.3). | WS-B3 |
| run state | Derived view `created | active | suspended | finished` over `lifecycle.*` events; `recovering` is transient and never durable. | WS-B3 |
| suspended run / suspend reason | A run that released its writer lease deliberately while waiting on subscriptions; `SuspendReason ∈ {awaiting_approval, awaiting_event, awaiting_timer, awaiting_child, awaiting_effect, awaiting_environment, operator_pause, hibernated}`; invariant S-1: no `prepared`/`committed` effect open. | WS-B3 with WS-H7 |
| lease scope | `writer(run) | effect(effect_id) | resource(key) | environment(handle) | wakeup(subscription_id, occurrence_key)`; all leases share `{holder, generation, expires_at, progress?}` and the generation fence. | WS-B3; extends WS-B1/B2 lease terms |
| holder identity | `{host, pid?, start_id?, participant_ref, instance_id}` recorded on a lease so liveness can be probed without pid-reuse ambiguity. | prime-agent / OpenHands precedent |
| liveness-probe shortening | Taking over a lease before `expires_at` when the holder on the same host is provably dead; an optimisation of recovery delay, never of safety (the fence remains the generation). | WS-B3 |
| wakeup subscription | Durable record `{subscription_id, owner: run | goal, trigger, policy, state}` created by `control.wakeup.scheduled`. | WS-B3 |
| trigger | Closed sum `timer | schedule | permission_decided | child_terminal | effect_terminal | environment_ready | retry_due | external | manual`. | WS-B3; HIR/1 dialect |
| wakeup occurrence / occurrence key | Durable `control.wakeup.occurred` written by whoever observes the event (kernel or ingress) before any run acts; keyed by `(subscription_id, occurrence_key)`; external payloads carry `authority = external`. | WS-B3; `no-precedent` |
| wakeup claim / fired / skipped | Firing = claiming an occurrence under the run's fresh writer lease (`control.wakeup.fired`); a second claim or a coalesced/expired/finished-run occurrence is `control.wakeup.skipped{reason}`; semantics: at-least-once occurrence, idempotent fire. | WS-B3 |
| delivery mode | `steer` (deliver before the next model call) vs `follow_up` (deliver after the current effect's terminal / at the next decision point); never mid-effect. | prime-agent / Cursor precedent |
| ingress adapter | A registered out-of-process component that turns PR/CI/tracker/chat/webhook events into `control.wakeup.occurred` records with `authority = external`. | WS-B3 → WS-K1/K2/L8 |
| goal activation / continuation chain / continued_from | A run is one activation of a `Goal`; activations chain by `lifecycle.run.created{continued_from{run_id, at_seq, head_hash}, activation_no}` — fork-by-reference restricted to non-diverging continuation; carried state = `resume_set` + goal-scoped budget node. | WS-B3; ADR-0027 shape; Temporal Continue-As-New precedent |
| inbox run | The destination of goal-scoped occurrences when no activation is open (`kind: inbox`, no strategy); exact identity OQ-WS-B3-02. | WS-B3 |
| environment verdict | `attached | reattachable | lost{cause}` returned by `verify_environment` on every resume; recorded as `action.environment.verified`. | WS-B3 with WS-B5/E5 |
| healing policy / heal | `HealingPolicy{on_lost ∈ {reprovision, snapshot_restore_then_reprovision, ask, fail}, max_heals, verify_after?, preserve_detached}`; `heal` reprovisions as a ledgered `reversible`/`workspace_local` effect and reports `lost_items_ref` to the model with `authority = environment`. | WS-B3 |
| recovery grace | The manifest constant added to the writer-lease ttl to bound how long preserved detached children and reservations outlive a dead holder. | WS-B3 with WS-E5 |
| kill-point matrix | The failure-injection battery KP-1…15 × four effect risk classes (+ stale-worker, duplicate-occurrence, exhaustion-mid-effect) with the `duplicate_effect_count` veto — the one shared durability acceptance suite. | WS-B3; Logos shape (`provisional`) generalised |
