## Ontology terms

| term | definition | notes |
|---|---|---|
| profile chain | The ordered list of Model Profiles from base to leaf that `resolve_profile` returns for one `model_ref`, merged per field under a declared policy (`override | append | forbid_override`); the leaf's hash identifies the chain. | ADR WS-C3-1 §5; ADR-0020 §1 "chain" made concrete. |
| profile rule inventory (`ProfileRuleInventory/1`) | The versioned catalogue fixing, per ADR-0020 rule kind, the typed `params`, owned surface fields, application point, dependency capabilities and admissible compliance detector class. | Grows only by ADR; the metered `ext` block is its input. |
| null profile | The kernel-defined profile with reserved slots only, `native_fc`, identity naming and no templates; the baseline for the owned-field diff (V2) and the Profile Compiler's own removal test. | ADR WS-C3-2 §2. |
| fallback profile | An explicitly bound profile for unprofiled models whose debt hypothesis is "unprofiled model" and whose status may never be `active` beyond a `date` expiry; `fallback_used` is a manifest fact. | Replaces silent defaults (codex `used_fallback_model_metadata`). |
| selector pattern | The closed grammar `exact(id) | prefix(id) | range(family, lo?, hi?) | any` for `Selector.version_pattern`; never a regex or substring test. | CF-WS-C3-02; OQ-WS-C3-01. |
| successor profile / `successor_ref` | A selector field naming the profile that replaces this one after `retirement_at`; the data form of a model upgrade pointer. | codex `upgrade`; C2 reroute `reason = policy`. |
| compatibility token | An optional provider-supplied opaque value (`provenance = reported`) on the capability declaration whose change signals that transcript/compaction compatibility with the served model changed; a re-lowering and expiry trigger. | codex `comp_hash`; CF-WS-C3-04. |
| profile validity / profile conformance / profile compliance | Three tests of one rule: the profile is well-formed and compiles to what its author meant (compiler); the served model has the declared capability (gateway probes); the model follows what the rule renders (Lab compliance metrics). | ADR WS-C3-2; refines ADR-0020 §6 and ontology *validity vs compliance*. |
| golden surface | The content address, recorded at profile publish, of each compiled tool surface / layout / renderer spec per `(profile_hash, capability semantic_id)`; a mismatch after a compiler upgrade is a compiler regression. | gemini-cli snapshot precedent. |
| ProfileTestReport | The immutable registry record `{validity, golden, equivalence, probes, compliance}` per profile hash, referenced by every bundle compiled under the profile. | ADR WS-C3-2 §1. |
| probe spec | `ProbeSpec{capability, kind, fixture_ref, samples, budget, verdict_rule}` — one deterministic capability question executed by the gateway `probe`, charged `instrument`, yielding a `ConformanceRecord`. | Extends ontology *profile conformance probe*. |
| expiry trigger | An observable (served-model drift, compatibility-token change, fingerprint DRIFT, selector unmatched, date, dependency probe failure, evidence age, removal-test report) that fires an `expiry_condition`; version strings never do. | ADR WS-C3-3 §1. |
| removal test | A pre-registered paired `Design` `P` vs `P − R` under `matched_cap` whose verdict is non-inferiority on every headline metric plus a bounded reliably-regressed share, reported as `ComparisonReport{benefit_kind: artifact_benefit}`. | The operational form of T-LCD-05 "retire rule R". |
| profile status event | `model.profile.status.changed{profile_ref, rule_id?, from, to, trigger, evidence_ref, causes[]}` and siblings `model.profile.probed`, `model.profile.expired_used`. | WS-B1 `model` category. |
| profile_prose | The opacity-report bucket counting tokens of profile-owned `Text` leaves rendered into the surface; excluded from harness `opacity_ratio`; `profile_opacity_ratio` per profile hash. | Answers OQ-064. |
| per-role profile binding | The run-manifest map `ModelRole → ProfileRef` (`primary`, `summarizer`, `judge`, `subagent(class)`, `shim_interpreter`); every model call stamps its role's `profile_ref`. | CF-WS-C3-05; OQ-WS-C3-05. |
| demotion wrapper | A `prompt_layout`-owned `Text` leaf that renders an item below every admitting slot into the `external` slot without changing its authority; counted in `profile_prose`; expires with its rule. | Confirms OQ-104 (profile side); D1 executes. |
