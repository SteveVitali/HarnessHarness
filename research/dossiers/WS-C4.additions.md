Answered here (proposed resolutions for the register): **OQ-097** — cache warmth is a declared per-arm factor `cache_policy ∈ {cold_start, natural, primed}`; `cold_start` (salted affinity key) is the default for matched-cap/iso-cost; `natural` records kernel-derived `expected_state` beside gateway-observed `observed_state` and the comparison engine stratifies; the engine refuses arms with mixed policies (`IncommensurableMatch`); all three audited vendor APIs report per-call cache-read counts, none exposes pre-call state (WS-C4 §6.3, §6.7; WS-C4-adr-2 decision 5). **OQ-117** (partial) — retention classes and `cache_semantics` live on the dialect descriptor (C1 registry); `pricing_ref` is a bundle member; avoided-cost estimates cite `pricing_ref`. **OQ-WS-C1-06** (partial) — `estimate_tokens` feeds `expected_state = uncacheable` below `min_cacheable_tokens`.

## Ontology terms

| term | definition | notes |
|---|---|---|
| cache semantics | Closed sum `{explicit_breakpoints{max_markers, lookback_positions, position_rule, retention_classes, min_cacheable_tokens, isolation}, implicit_prefix{strictness, affinity_key, retention_classes, min_cacheable_tokens, reporting_granularity_tokens}, explicit_resource{ttl_classes, storage_priced, reference_form}, uncached, unknown}` describing how a model endpoint reuses a prompt prefix; carried as data on the `WireDialect` descriptor (default) and the Model Profile's `cache_control_convention` capability (override); declared → probed. | WS-C4; goose `CacheSemantics` generalised; never chosen by a provider/model branch (T-LCD-01). |
| cache kind (K1–K6) | The six caches between the kernel and a model snapshot: K1 provider prefix cache (observed/shaped), K2 compile cache (ADR-0019), K3 catalog cache (WS-E3), K4 tool-result/retrieval cache (a `Memory{kind: tool_result}`), K5 exact-match response cache, K6 similarity-keyed semantic cache (C2). | WS-C4 §6.1. |
| cache tier | `SlotDeclaration.cache_tier ∈ {static, dynamic, transcript}` (WS-D1); the kernel orders tiers `static → dynamic → transcript` (LC-1) and forbids volatile candidate kinds in `static` (LC-3). | Adopts WS-D1's term; adds the ordering invariant. |
| static hash | `H(canonical(static-tier bytes ∥ tool surfaces ∥ dialect-listed prefix-affecting parameters))` computed per model call; equal across consecutive same-purpose calls unless an invalidating event intervened (LC-2). | WS-C4 §6.2; OQ-WS-C4-02 refines its membership. |
| prefix affinity key | `AffinityKey{full: ContentAddress = H(scope ∥ static_hash ∥ purpose), wire: prefix ≤ dialect.max_key_length, scope, purpose}` — the kernel-derived identity a provider may use to route/segregate prefix caching; the wire form is a surface alias; never a raw session id or secret. | WS-C4 §6.3; codex purpose-scoped keys, pi clamp as precedents. |
| purpose (of a model call) | `purpose ∈ {main, compaction, probe, judge, subagent(id)}` — the affinity-key namespace of a call; `purpose ≠ main` never extends the main prefix (LC-6). | WS-C4 §6.3. |
| expected cache state / observed cache state | `expected ∈ {warm, cold, uncacheable, unknown}` derived by the kernel from the durable prefix under lease semantics (last same-key call, retention class, margin, invalidating events, concurrent siblings); `observed ∈ {warm, cold, unknown}` stamped by the gateway from `cache_read > 0` / `usage.available`. | WS-C4 §6.3; refines WS-L2's ratified `cache warmth`. |
| expectation agreement | `#calls(expected = observed) / #calls(expected ≠ unknown)` — the health metric of a dialect's declared retention class; its decay is the removal test of the class's assumption-debt record. | WS-C4 §6.4. |
| miss reason | Closed sum `{ttl_elapsed, concurrent_sibling, provider_eviction, parameter_change, compaction, context_edit, relower, profile_version, definition_version, tool_set_change, marker_policy, dialect_change, unknown}` attributed by the kernel projection to a call with `expected = warm ∧ observed = cold` or following a known invalidating event. | WS-C4 §6.3/§6.6. |
| retention class | `{class_id ∈ {short, long, extended}, nominal_ms, guaranteed: bool}` — the abstract TTL a request may ask for, lowered per dialect (`5m`/`1h`; `in_memory`/`24h`/`30m`; seconds). | WS-C4 §6.1; pi `CacheRetention`, goose `CacheTtl` precedents. |
| marker position / lookback anchor / carrier block | A `caching_markers` rule writes marker positions `{tier_boundary(static), tier_boundary(dynamic), transcript_tail{…}}` on the plan; a lookback anchor is a secondary marker placed `anchor_distance_positions` behind the tail so the next call's tail stays within the provider's lookback window; a carrier block is a block kind eligible to bear a marker (dialect-declared; never thinking/unsigned reasoning/empty text). | WS-C4 §6.2; goose L53–83, L131–154. |
| cache policy (arm factor) | `cache_policy ∈ {cold_start, natural, primed{prime_ref}}` on every arm's `MatchSpec`; `cold_start` salts the affinity key per run; `natural` records and stratifies; `primed` runs a declared priming call charged `instrument`; mixing is `IncommensurableMatch`. | WS-C4 §6.7; answers OQ-097. |
| avoided cost | The tokens/spend a harness-level cache hit did not incur, derived from the entry's recorded roles under the pinned pricing table with `provenance = estimated_from_pricing`, `confidence = estimate`; reported beside realised spend, never subtracted. | WS-C4 §6.4. |
| `model.cache.resolved` | Ledger event per K2–K6 lookup: `{cache_kind, key, scope, outcome ∈ {hit, miss, bypass, stale_withheld, refused}, reason, entry_ref?, verifier_verdict?, avoided{…}, attribution}`. | WS-C4 §6.4; CF-WS-C4-02. |
| tool-result memory (K4) | `Memory{kind: tool_result}` written for `read_only ∧ idempotent` capabilities declared `cacheable`, keyed on `(capability semantic_id, version_id, canonical args, environment stamp, readers)`, carrying the observation's label and a WS-D4 `InvalidationContract`; a hit is delivered as an `Observation` with `origin = cache(entry_ref)`. | WS-C4 §6.5; no second lifecycle scheme. |
| environment mutation epoch | A kernel counter per `environment_ref` incremented on every committed effect with `domain ∈ {fs_write, exec, net_egress, spawn_process}`; K4 entries stamped on an earlier epoch are `stale_withheld` (RFC 9111 invalidate-after-unsafe). | WS-C4 §6.5 IR-3; CF-WS-C4-05, OQ-WS-C4-06. |
| response cache (K5) | Exact-match cache keyed `H(plan_hash ∥ model_ref ∥ replicate ∥ configuration_version_id)` serving a recorded `ModelMessage`; admissible only for `reproduce`, recording/fake gateways and declared `deterministic_replay`; a hit is `served_from_cache` with `timing = n/a{not_run}`. | WS-C4 §6.5; inspect_ai key partition. |
| verified semantic cache (K6) | C2 component variant: similarity-keyed lookup whose marginal matches are served only after a registered `Validator` passes and are then promoted; entries carry the writer's label and are `readers`-scoped; `false_hit_rate` mandatory. | WS-C4 §6.5; S-WS-C4-04/05/06. |
| served_from_cache | Field on `model.call.completed` (entry ref) and count on results rows marking calls served by K5; excluded from latency metrics (`n/a`). | WS-C4 §6.5. |
