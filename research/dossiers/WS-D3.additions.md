## Ontology terms

| term | definition | notes |
|---|---|---|
| memory hierarchy | The five addressing classes — working context, artifact memory, episodic memory, procedural memory, durable session state — over three substrates (run ledger + blobs; versioned-record registry with name histories; workspace/environment tree), with one `retrieve` operation. | WS-D3 ADR-1. Layers are classes, not stores; no plane or authority of their own. |
| working context (layer W) | The `ContextPlan` projection for one model call; never a retrieval source. | WS-D1 owns the plan. |
| artifact memory (layer A) | Content-addressed bytes and trees (blobs, workspace) plus named artifacts; valid iff bytes resolve and the name is not yanked. | ADR-0029/0036/0037. |
| episodic memory (layer E) — verbatim / distilled | Verbatim: ledger `EventRef` ranges and offloaded observations by content address. Distilled: `Memory{kind: episodic}` versions with `source_trajectories` and `derived_from` ranges that remain addressable. | Dossier F8; S-349 (`provisional`). |
| procedural memory (layer P) | `Procedure`/skill versions with an **index form** `{name, description, triggers, location}` delivered `handle_only`; activated by `trigger{keyword, path_glob, explicit}`. | WS-D5 owns the Procedure IR. |
| durable session state (layer S) | The run ledger and its views plus **named session artifacts** (progress notes, feature/task list, goal state, bootstrap script) behind name histories; read by B3 as the `resume_set`. | S-041, prime-agent `goals.ts`. |
| memory store | The component-class store of `Memory` versions and manifests: `put/bind/revoke/resolve/manifest/enumerate/stale_candidates`; in- or out-of-process. | T-LCD-12; goose MCP memory as existence proof. |
| memory manifest | `MemoryManifest{scope, entries[{name, version_id, kind, one_line}], version, provenance}` — the typed index/entrypoint (`MEMORY.md`, `memory_summary.md`), name-bound, rebuilt by consolidation, delivered eagerly under a profile budget rule. | OpenHands/Claude Code/OpenHarness/Codex precedent. |
| derived memory (vs materialized view) | A record produced by a `deriver = delegate` from ledger ranges — immutable, versioned, provenance-bearing, not rebuildable to equal bytes — as opposed to a deterministic `kernel` projection rebuildable to equal `view_hash`. Test: `project()` twice ⇒ equal hash; `extract()` twice ⇒ two versions with `supersedes{consolidation}`. | ADR-0026 boundary applied to memory. |
| retrieval request / query kind | `RetrievalRequest{model_call_id, at, layers, query, constraints, reader, budget, ranker, profile, account, mode}`; `RetrievalQuery` closed sum `{by_address, by_name, by_path_glob, by_run, lexical, discover, trigger, structural (C1), similarity (C2)}`. | WS-D3 ADR-2. |
| retrieval result / retrieved item / retrieval report | `{items: [Candidate + {layer, address, provenance, validity, rank_evidence, handle?}], report{request_hash, watermark, enumerated, filtered{validity, authority, readers}, ranked, returned, omitted_by_budget, no_authoritative_items, ranker_ref, deterministic, cost}}`. | Ledgered as `context.retrieval.completed`. |
| retrieval ranker | Component class `retrieval_ranker` scoring already-filtered candidates over a kernel-fixed feature vocabulary that excludes authority/validity/readers; declares `deterministic: bool`. | Variants: `deterministic_default`, `lexical_weighted`, `structural_pagerank`, `recency_importance`, `similarity_rerank` (C2). |
| rank evidence | `{ranker_ref, score?, features}` on every retrieved item; never keys on names. | T-LCD-10. |
| slot constraints | `{slot_min_authority, validity_required, admit_unknown_validity, readers_required}` copied from the target slot declaration; inputs to `retrieve`, never ranker outputs. | WS-D1 slot declaration. |
| retrieval watermark / read-your-writes | `at = (run_id, seq)` from the context view's `derived_from`; the store must have applied every `context.memory.written` ≤ `at` or fail `StaleStore` — never fail-open. | AIOS barrier shape; ADR-0027 `seq`. |
| omitted by budget | Items ranked but not returned because the token/count budget was reached; listed whole in the report; nothing truncated. | Mirrors WS-D1 omission records. |
| no-authoritative-items | Report flag: `enumerated > 0 ∧ returned = 0 ∧ filtered.authority > 0`; distinct from an empty enumeration. | ADR-0034 `NoAuthoritativeItems`. |
| structural index / lexical index | Materialized views: symbol/reference graph over a tree `ContentAddress` (repo-map shape); token/substring index over ledger ranges, memory bodies and manifests; `derived_from` includes the builder's version. | Aider `repomap.py`; Codex substring search. |
| resume set | View `names[] → head version_id` of the layer-S artifacts a sealed definition declares for resume; heads without validator verdicts are `unknown` validity. | WS-B3 consumer. |
| consolidation | A `Procedure` run under a memory-scope writer lease whose only writes are new versions with `supersedes{reason: consolidation}`, manifest rebinds and revocations; inputs `stale_candidates`, `memory_usage`, episodic layer in `audit` mode; watermark and diff ledgered. | Codex Phase 2 shape; never in-place edits. |
| memory kind | `MemoryKind = {episodic, procedural_note, preference, reference, decision}` — a ranker feature and manifest attribute; never decides authority/validity/readers. | OQ-200. |
| cited (activation signal) | A parseable citation in the model's reply naming a delivered artifact; recorded as `activated{signal: cited, origin = model}` with lower confidence than `tool_used`. | Codex `<oai-mem-citation>`; OQ-204. |
| store dimension (`store ∈ {instructions, memory}`) | Field on persistence effects distinguishing instruction locations (ADR-0035 ceilings verbatim) from the runtime-owned memory store (write ceiling `delegate`, label cap `external`). | WS-D3 ADR-3; CF-172. |
| `StaleStore` / `RankerNotDeterministic` / `EmbedderUnpinned` / `IndexUnavailable` | First-class retrieval error classes (never warnings). | WS-D3 ADR-2. |
