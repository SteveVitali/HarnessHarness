## Ontology terms

| term | definition | notes |
|---|---|---|
| escalation input | The closed, record-derived input the kernel hands the approval component for one proposed effect: effect identity, `EffectClass`, `effective_risk_class`, `effective_authority`, `context_label`, provenance, grant coverage, compensation/dedup/baseline facts, containment, attendance, budget state, lease hit, batch, retry and delegation depth. | WS-H7 / WS-H1. Never contains model-authored text. |
| policy table Π (floor vs narrowing) | `Π(effective_risk_class, EffectDomain, effective_authority, containment, attendance) → allow | ask | deny`; the floor rows Π-1…Π-12 are MUST-code (owned by WS-H1); a sealed definition may only narrow them through `authority_cap`-bounded leaves. | Answers OQ-101's row question; H1 owns placement. |
| reviewer chain / reviewer ref | The ordered stages that resolve `ask`: `policy_rule → lease → hook → auto_reviewer → human(principal | reviewer under ApproverGrant)`; non-human stages only narrow or pass; failure is closed above `reversible`. | WS-H7. `escalate` (a `DecisionPoint`) is a move along the chain. |
| never-auto set | Effects no mode, layer, hook, lease or reviewer may approve automatically: `permission_request` widenings, `irreversible ∧ external` driven by `≤ external` authority, revoked/stale permissions, explicit `ask` leaves, consent-step `message_human` effects, `scope = user` persistence endorsements. | Constitutional; precedent Claude Code "actions no mode auto-approves". |
| approval granularity (G0 / G1 / G2) | G0 per-effect endorsement of `(effect_id, args_canonical_hash)`; G1 per-pattern lease; G2 per-class `Permission` grant in the sealed definition (configuration, not approval). | WS-H7. |
| approval lease | `ApprovalLease{lease_id, key = H(ToolCapability semantic_id ∥ canonical(pattern) ∥ scope ∥ policy_fingerprint), pattern, scope ∈ {turn, run, session}, holder, granted_by, origin_permission_id, expires_at?, expires_with, max_uses?, uses, policy_fingerprint, risk_ceiling, revoked_at?}`; a hit is `decider = cache`. | Answers OQ-091. Precedent Codex `ApprovedForSession`, goose expiry. |
| action pattern | A capability-declared projection of the argument space used as a lease key (command prefix, path-prefix set, host:port:protocol, server+tool+shape, payee+ceiling); aligned with `SurfaceArgMap`; never a bare id or tool name. | WS-E1 declares; WS-E5 canonicalizes (OQ-086). |
| policy fingerprint | `H(sealed definition version_id ∥ approval_mode ∥ Π narrowing leaves)`; any change revokes all leases and cached verdicts. | Precedent Codex exec-policy fingerprint; Claude Code "changing your permission mode or rules drops all cached verdicts". |
| approver grant | `ApproverGrant{grant_id, approver, delegated_by: human principal, may_decide{domains, max_risk_class}, may_lease, may_escalate_to?, expires_at, attestation?}`: the only route by which a human other than the run's principal decides; attenuating; never held by an `AgentProcess`. | WS-H7 / WS-L8; authority class OQ-WS-H7-01. |
| attendance | Run-manifest fact `interactive | async | unattended` describing whether and how a human can be reached during the run. | WS-H7 / WS-B3. |
| unattended policy | `UnattendedPolicy ∈ {deny (default), defer, auto_review}`: the configured resolution of `ask` when no human is reachable. | Extends ADR-0035 (d); CF-WS-H7-03. |
| automatic reviewer | A `Validator{kind: judge}` component variant that scores a proposed effect (`risk_level × authorization → outcome`) from an evidence set restricted to `authority ≥ principal` items plus the proposal, running as an attenuated read-only `AgentProcess`; its verdict is an *input* to a `policy_rule`, never an endorsement. | Precedent Codex Guardian, Claude Code classifier, goose read-only judge. Conditioned rule with debt record. |
| approval mode | Typed Harness Definition parameter `manual | tiered | auto_review | pre_approved_only | unattended_deny | unattended_defer | bypass` that selects Π narrowing and chain stages; lowers to ACP session modes, Codex `AskForApproval`, Claude Code modes, goose modes. | Surface presets are lowerings; the IR parameter is the identity. |
| explanation vs model justification | `Explanation{rule_id, risk_factors[], what_would_auto_approve?, model_justification?}`: kernel fields are record-derived; `model_justification` is a `Text` leaf with `authority = delegate`, rendered with distinct provenance. | T-LCD-02; counters ATR "minimizing language". |
| narrowing hint | A kernel-generated suggestion of the lease or leaf change that would make a class of prompts auto-approvable; acts only through a human `allow_lease`; rate-limited. | Never automatic widening (ADR-0017). |
| approval batch | `batch_id` grouping pending requests of one `effective_risk_class`, reviewer and scope for a single prompt; one endorsement per effect; `irreversible` never batched. | Counters ATR "embedding". |
| approval rate (fatigue indicator) | Class-scoped metric `granted / requested` with `denial_rate`, latency and lease-hit ratio; a high, denial-free rate on a class is an information-content signal, not a safety signal. | S-053's 93% as the shape. |
| denial-driven evasion | The trajectory pattern in which a denied effect is re-attempted by an alternative path (unsandboxed re-run, different tool); bounded by attenuation, `retry_of` fresh review and the repeated-denial fallback. | Precedent Codex orchestrator second attempt; Claude Code "tries an alternative". |
