## Ontology terms

| term | definition | notes |
|---|---|---|
| exposure mode | The closed sum `{direct, indexed, deferred, code_mode, hidden}` describing how one compiled tool surface is presented to the model in one model call; exactly one per surface per plan; admitted modes compose narrow-only (definition ∩ profile ∩ policy). | WS-E3-adr-1. Codex `ToolExposure`; Anthropic/OpenAI `defer_loading`; goose disclosure styles. |
| index form / index granularity | The typed projection of a tool surface delivered under `indexed` mode (`name, title?, summary, namespace?, tags[], search_text_fields`), at granularity `surface | namespace | source`. | WS-E3-adr-1/2. D1 `handle_only` candidate = `indexed(surface)`. |
| exposure plan | The per-model-call ledger record `{plan_id, model_call_id, catalog_id, entries[(surface_id, mode)], discovery_surface_ids[], order, budget_estimate, omitted[{surface_id, reason}], derived_from, deterministic}` produced by `select_surfaces`; order is append-only within a run. | WS-E3-adr-1. |
| revealed set | Run state projected from `action.tool.surface.revealed/evicted`: the surfaces currently `direct` for the model with `cause` and `retention ∈ {call, turn, run, until_evicted}`. | WS-E3-adr-1. |
| `callable ⇔ revealed` / `SurfaceNotRevealed` | Kernel invariant: a proposal may name only a surface that was `direct` in the plan of the producing model call (or `code_mode` for program-originated proposals); violations are refused with the typed condition `SurfaceNotRevealed` carrying no definition. | WS-E3-adr-1; run-time face of the closed-world rule (ADR-0019). |
| discovery capability / discovery surface | The kernel-provided `ToolCapability` `discover_surfaces` (`effects = pure`; `DiscoveryQuery → DiscoveryResult` of index forms) whose model-facing surface is profile-owned and which has two lowerings: kernel-executed (answered by a `catalog_index` variant) and provider-hosted. | WS-E3-adr-2. Anthropic `tool_search_tool_*`, OpenAI `tool_search`, codex `tool_search`. |
| tool catalog / catalog entry | `Catalog{catalog_id, epoch, bundle_id, sources[], entries[], index_ref}`; a `CatalogEntry` is one compiled surface with `admitted_modes`, `pinned`, `index_form`, `size`, `effect_summary` (hint projection), `permission_coverage` (advisory), `label`, `availability`. | WS-E3-adr-1. |
| catalog index (`catalog_index`) | Registered component class `build/query` over the catalog, declaring `deterministic` and `search_text_fields`; variants `exact_name, static_allowlist, lexical_regex, bm25, hierarchical, embedding, model_ranked, filesystem`; ships an offline retrieval suite (`recall@k`, `nDCG@k`, instrument-charged). | WS-E3-adr-2. |
| catalog delta / catalog epoch / drift policy | `CatalogDelta{source_ref, cause, added, removed, changed}` from `sync_source`; `CatalogEpoch{epoch, catalog_id_prev, catalog_id, bundle_delta, loss_report, adopted_by}` produced by `adopt`; `drift_policy ∈ {freeze, adopt, ask}` (Lab default `freeze`). | WS-E3-adr-3. |
| catalog exposure ratio | Class-scoped efficiency metric `|direct ∪ indexed| ÷ |catalog|` per model call, computed from `action.tool.exposure.planned`. | WS-E3-adr-2. |
| selection recall@need / unrevealed need | Grounding/reliability metrics over the exposure plan against a task oracle `required_surfaces[]`: fraction of required surfaces `direct` at first need; runs in which a required surface was never revealed. | WS-E3-adr-2; oracle protocol OQ-WS-E3-05. |
| code-mode disclosure | Sub-policy of the `code_mode` exposure mode: `{catalog, filesystem, sidecar}` deciding how program-callable surfaces are described to the model (goose `ToolDisclosure`). | WS-E3-adr-1; owned with WS-E2 at C2. |
