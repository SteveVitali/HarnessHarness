## Ontology terms

| term | definition | notes |
|---|---|---|
| **resource dimension** | A named, unit-bearing quantity the runtime accounts for; kernel dimensions form a closed sum per HIR dialect (`tokens.input.uncached`, …, `spend`, `context.occupancy`, `fan_out`, `delegation_depth`); `ext.*` dimensions are registered extensions. | WS-L2 / WS-A3 arbitrates the kernel list (CF-067). |
| **counter (flow)** / **gauge (level)** | A counter is monotone, summable across children and time, and ceiling-bounded; a gauge is instantaneous, max-aggregated and cap-bounded (context occupancy, concurrent fan-out, delegation depth). Budgets bound counters; caps bound gauges. | Precedent: OpenHands `TokenUsage.context_window` combined by `max`; Codex context-window percentage. |
| **resource vector** | `map<DimensionId, amount>` — the WS-A2 budget vector B ∈ ℝ^k made concrete; used for consumption, reservation, ceilings and totals. | WS-L2 / WS-A2. |
| **metering formula** | The declared function that turns role counters into the quantity a budget meters: identity, `billed_weighted{w_sampling, w_prefill}` (Codex), an expression over `{input, output}` (Inspect), `novel_seen` (provider task budget), or `provider_unit{name}`. Comparisons require equal formulas across arms. | Resolves CF-072. |
| **budget node** | Runtime instantiation of a WS-A3 `Budget`: `{budget_id, scope, parent?, mode, dimensions{hard?, soft[], metering?, grace?}}` with projected `consumed/reserved/remaining`; nodes form a tree with one root per run and one accounting authority. | ADR-0040. |
| **budget slice** / **budget pool** | Delegation modes: a *slice* is moved out of the parent's available amount to the child and moved back on completion (affine); a *pool* is shared, the child may only tighten, and reservations enforce conservation. | Precedents: Inspect nested scopes (slice); Codex shared session-tree budget (pool). |
| **reservation** / **reserve-before-spend** | A pre-dispatch hold `{reservation_id, budget_id, holder, quantity, expires_with: lease}`; Σ reservations + consumed ≤ ceiling along the ancestor chain; consumed or released by the resulting charge. | S-209 principle; Codex guardian request-level precedent. |
| **charge** | The `control.budget.consumed` event: one posting of a `ResourceQuantity` against a budget node, idempotent on `(source_event, dimension)`, carrying an attribution. | ADR-0039. |
| **attribution** / **charged_to** | `{run_id, participant_ref, charged_to ∈ {subject, instrument}, budget_id, component_class?, component_variant_ref?, binding_locality?, model_ref, ir_refs[]}` on every charge and spend row; `subject` = producers bound in the sealed Harness Definition; `instrument` = grader, probes, Lab-side detectors, hosting adapter. | Answers OQ-059 / OQ-053. |
| **cost provenance** / **cost derivation** / **cost confidence** / **coverage** | Provenance = who observed the quantity (`measured`, `reported`, `reconstructed`; per hosting mechanism); derivation = how money was obtained (`provider_priced`, `table_priced{table, version, tier, ttl_class}`); confidence ∈ `{exact, bounded{lo,hi}, estimate}`; coverage = fraction of a run's model calls with usage available. | Answers OQ-033; extends WS-B1's `provenance` enum. |
| **pricing table** | Versioned, content-addressed bundle artifact `{model_ref → rates per role incl. cache_write[ttl_class], tiers[]}`; a missing row is `NoPrice`, never zero. | WS-I3 / WS-L4; governance OQ-093. |
| **advisory (soft) budget** / **enforced (hard) budget** / **grace allowance** | A soft threshold's action is a `HarnessRule` inserting a model-facing budget reminder whose delivery/activation/following are T-LCD-13 events; a hard ceiling is enforced by the control envelope at decision points only; grace is a soft action permitting a terminal summarising call, never a ceiling widening. | Precedents: Claude SDK `TaskBudget` vs `max_budget_usd`; Codex reminders vs `SessionBudgetExceeded`. |
| **budget exhaustion** (stop reason) | The typed outcome `control.budget.exceeded` + `control.decision{stop, reason: budget_exhausted{dimension}}` + `stop_reason = budget_exhausted`, produced only after every committed effect reached a terminal or `unknown` state (WS-B2). | WS-F2 enforces. |
| **working time** vs **wall time** | `time.working_ms = time.wall_ms − waiting` where waiting is time blocked on rate limits, queues or human approval; matched wall-clock comparisons that ignore waiting confound provider throttling with harness efficiency. | Precedent: Inspect `_WorkingLimit`, `_util/working.py`. |
| **cache warmth** | The cache state (`warm | cold | unknown`) of a model call's prefix at request time; an experimental confound that must be controlled or stratified. | OQ-097. |
| **matched-cap** / **iso-cost** / **matched-total** comparison | The three `MatchSpec.mode`s: identical hard ceilings with utilisation reported; equal realized consumption via `P(success | consumed ≤ c)` frontiers; equal `search + eval + inference` totals with the frozen artifact evaluated under `eval_budget` alone. | ADR-0041; T-LCD-14. |
| **budget utilization** | `consumed / hard` per dimension per arm; mandatory in every matched-cap report. | WS-I2 / WS-J4. |
| **MatchSpec** | `{dimensions[], mode, tolerance, pricing_table_ref?, model_scope ∈ {same_snapshot, cross_model}}` — mandatory on every experiment arm; the engine refuses ill-typed or missing specs. | WS-J3 enforces. |
