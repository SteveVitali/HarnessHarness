## Ontology terms

| term | definition | notes |
|---|---|---|
| **router** | The boundary component (`home = model_boundary`, ADR-0012) that chooses, per logical model call and per *model role*, which model snapshot the gateway calls, subject to the compatibility guard; a registered component class with an operation-shaped contract receiving `(ModelProfile resolver, ResourceAccount)`. | Distinct from the gateway ("model adapter", WS-C1: transport) and the Profile Compiler (WS-C3: surfaces). Precedent: litellm `Router`; opencode `getSmallModel`. |
| **routing policy** | A versioned, content-addressed data document `{kind ∈ closed enum, params, error_actions, max_migration_loss, conditioned_rules[]}` bound to model roles; MUST-data (ADR-0024); family/provider-keyed rules are conditioned rules with `AssumptionDebtRecord`s. | Composable as an `ordered-many` pipeline (OQ-073). |
| **routing request** / **routing decision** | The typed input to `select` (role, task class, compiler-derived required capabilities, budget view, latency target, quality prior ref, kernel-computed trajectory digest, lifted preferences, context label) and its typed output (selected `ModelRef`, reservation, policy ref, candidates considered with verdicts, inputs read, `deviation`, `relower_required`). | The decision is the payload of `model.route.decided`. |
| **model role** / **role table** | `ModelRole ∈ {primary, utility, compaction, subagent, judge, router_predictor}`; `ModelRoleTable = map<ModelRole, {primary, alternates[], policy_ref}>` — the typed form of Ontology v1 *model set* as configured in a sealed Harness Definition. | `configuration_id.model_ref` denotes the table's `semantic_id` (CF-WS-C2-02). Precedent: S-036 lead/subagent; opencode `small_model`. |
| **realized model set** / **routing deviation** | The multiset of `ModelRef`s that actually served calls per role in a run (manifest end state) and the run-level boolean `realized ⊄ configured primaries`; a Lab factor stratified like DRIFT (ADR-0004), never silently pooled. | Mechanism: S-WS-C2-10 (`provisional (mech)`), S-062. |
| **retry** vs **reroute** | A retry is a new `model_attempt` on the same target under the same `model_call_id` (envelope-owned); a reroute is a new target for the same `model_call_id` (router-owned), recorded by `model.rerouted` and, across profiles, preceded by `model.surface.relowered`. | Precedent: litellm in-group retry vs cross-group fallback; codex `ModelDownshift`. |
| **compatibility guard** | The conjunction G-1…G-7 a candidate must pass before any call: live profile resolves; required capabilities `supported`; transcript migration within bound and no unresolved effect; reservation succeeds; price exists when read; lifted preferences only attenuate; hosted participants excluded. | Composes ADR-0019/0020/0039/0040 objects; refusals are typed errors. |
| **fallback chain** | The `fallback_chain{targets[], max_reroutes, allowed_classes[]}` policy kind: an ordered list of alternates for a role, consulted by `on_attempt_failed` per error class; `[]` = fail fast (the pre-registered experiment default). | Precedent: litellm typed fallback lists. |
| **health view** / **cooldown** | A materialized ledger projection per `(provider_model_id, serving_route)` over `model.call.attempt.*` events — attempts/failures by class, latency quantiles, `cooldown_until?` — consumed by `health_aware`/`latency_cap` policies; never an authoritative separate store (ADR-0042). | Precedent: litellm `cooldown_handlers.py`. |
| **quality prior** | `QualityPrior{scope: {model_ref, task_class?, harness_def?}, metric, estimate, interval, n, source_ref: FittedSurfaceReport \| ComparisonReport, valid_until, unknown_levels[]}` produced by J4 from the compatibility surface (ADR-0012) and read by `quality_target`/`learned` policies; `unknown` levels are refused, never interpolated. | Ties routing to Ψ_θ without making it computable by the runtime. |
| **ensemble procedure** | A HIR `Procedure` at the `delegate` decision point with `kind ∈ {sample_k_vote, mixture_of_agents, cascade}`, member roles, a reducer (`majority_deterministic`, judge `Validator`, `first_passing_validator`), a `slice` budget and a stop rule; k individually routed, individually ledgered model calls; comparable only under matched-total budget. | Never a router feature. Precedents: S-WS-C2-07/08/02. |
| **serving route (reported)** | `model_ref.serving_route` (ADR-0039) whose downstream choice was made by an external gateway; candidates `unknown`, cost provenance `gateway_reported`, deviation `unknown` — stratified (T-LCD-07 pattern). | OQ-WS-C2-07. |
