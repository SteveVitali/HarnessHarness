## Ontology terms

| term | definition | notes |
|---|---|---|
| **protocol edge** | A standardized boundary (MCP, ACP, A2A) at which HarnessHarness exchanges typed documents with a foreign process; each edge has a fixed *role* — tool supply, session, or delegation — and attaches to exactly one ledger seam. | instrument/object boundary; ADR-0096 |
| **tool-supply channel** | The edge role through which callable tools cross a process boundary; there is exactly one standardized channel (MCP); ACP references it via `mcpServers`, A2A has none. | ADR-0096 D1 |
| **session boundary** (edge role) | The run-envelope seam where a native harness is presented as a session (ACP agent) or a foreign session is attached as a hosted participant; distinct from the internal *ecosystem boundary* though sharing its verb shape (CF-023). | ADR-0096 D2 |
| **delegation edge** | The edge role for `delegated-to` into a remote `OpaqueProcess` (A2A task = child run at `product` granularity). | ADR-0096 D3 |
| **protocol binding record** (`ProtocolBinding`) | Runtime record in the run manifest: protocol, role, spec pin (version label + schema content hash), era, negotiated version, peer info (claim), capabilities declared (preserved wire form) and observed (tri-state), extensions, transport, negotiation event. | ADR-0099; feeds the capability vector |
| **protocol era** | `modern | legacy` — which lifecycle a peer speaks when a protocol revision changed the handshake (MCP 2026-07-28 vs `initialize`-era); recorded per binding; each legacy era carries an assumption-debt record. | ADR-0097/-4 |
| **compatibility profile** | A compiler-emitted lowering of an artefact to a previous protocol major (e.g. ACP v1) with its own lowering loss report and assumption-debt record; expires by removal test. | ADR-0098 |
| **event-class lowering table** | The versioned table mapping every ledger event class to a protocol update kind (or `none`) with loss class ∈ {exact, narrowed, hint_only, no_slot}; the concrete form of ADR-0026's "every class declares its lowering". | ADR-0098 decision 2; refines ontology term *event class lowering* (WS-B1) |
| **projection (protocol enum)** | A fixed, versioned map from an IR sum (`EffectDomain`, run status, `stop_reason`, kernel decision, `EffectAttributes`) to a protocol enum (`ToolKind`, `TaskState`, `StopReason`, `PermissionOptionKind`, `ToolAnnotations`); lives in the compiler's target module; never an IR field. | ADR-0096 D5; generalises ADR-0021 decision 3 |
