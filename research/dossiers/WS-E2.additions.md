## Ontology terms

| term | definition | notes |
|---|---|---|
| **exposure mode** | The closed six-valued choice of how a capability set is exposed to a model: `primitive` (1↔1, `SurfaceArgMap`), `split` (n surfaces ↔ 1 capability with constant-bound parameters), `composite` (1 surface ↔ n capabilities via a `PlanMap`), `freeform` (text input under a grammar leaf parsed by a Core parser), `code_mode` (container surface; model-authored program calls nested surfaces in a sandbox), `shim` (text input parsed into a call by an interpreter model). Selected only by profile rules. | WS-E2 / WS-C3 / WS-E3. Refines ontology *interaction mode* (WS-A4): `native_fc` ↔ primitive/split/composite; `freeform`, `code_mode`, `shim` unchanged. |
| **surface family** / **surface variant** / **reference variant** | Per capability set exposed together: `SurfaceFamily{family_id, capability_refs[], reference_variant, variants[]}`; a *variant* is one exposure-mode rendering selected by a closed `VariantSelector`; the *reference variant* is the `native_fc` primitive rendering used as the E4 comparand and as the fallback when a rule is retired. | WS-E2 / WS-C3. gemini-cli per-family manifests as partial precedent. |
| **surface binding** | `SurfaceBinding{surface_id, exposure_mode, capability_refs: [semantic_id], mapping: SurfaceArgMap \| PlanMap, rule_ids[], evidence_ref, safety_ref, effects_bound, family_id, variant_id}` — total over surfaces; the record the trace map, reference monitor and `action.tool.*` events reference; the only accounting key (E7). | WS-E2 / WS-H1 / WS-B1 / WS-I1. |
| **plan map** | A `Procedure` restricted to `Branch(predicate over surface fields) · Invoke(Ref<ToolCapability>, ArgBinding) · Verify` with no `Loop/Delegate/Opaque/Instruction` and optional `session_state: Ref<Artifact>`; the composite mapping under which E1–E3 are decidable per branch. | WS-E2 / WS-A4 / WS-H1. Resolves OQ-066. |
| **schema dialect transform** | `SchemaDialectTransform{dialect_id, strict ∈ {prefer, require}, ops[{op, path}], narrowed[{path, from, to}]}` — the declared operation list by which a capability schema is lowered to a provider dialect; every op states its effect on the accepted input set; undeclared narrowing is an error. | WS-E2 / WS-C3 / WS-C1. pi `makeStrictJsonSchema` (declared) vs opencode/goose sanitisers (silent). |
| **result render spec** / **offload** | `ResultRenderSpec{mode ∈ {full, truncate, concise, offload}, declared_loss, validator_reads}`; *offload* stores the untruncated result as a content-addressed `Artifact` and delivers a preview with a `derived-from` edge, admissible only with a compiled `read_artifact` surface. `full` is the reference mode; compression is never a default. | WS-E2 / WS-C3 / WS-D1 / WS-E5. |
| **surface failure** | A closed class of pre-dispatch failures of the model-facing surface — `{unparseable, unknown_surface, unmapped_argument, domain_violation, missing_required, multiple_calls_unsupported, grammar_violation, session_state_invalid}` — distinct from capability failures; no executor runs, no `Effect` exists; ledgered as `action.tool.surface_rejected`. | WS-E2 / WS-B1 / WS-H1 / WS-I2. SWE-agent parser codes; Cursor `InvalidArguments`. |
| **catalogue rendering** | The model-facing description of a code-mode container's nested surfaces (typed declaration samples, server-grouped tree), derived only from the nested `ToolSurface`s. | WS-E2 / WS-E5. codex `augment_tool_definition`; opencode `describeCatalog`. |
| **safety evidence (S1–S4)** | Per-surface record `{S1 no authority widening, S2 complete mediation of nested steps, S3 synthesized text labelled and placed, S4 fail closed}` attached beside `EquivalenceEvidence`; `n/a` never 0. | WS-E2 / WS-H1 / WS-H2. Novel as an integrated contract. |
| **wrapper synthesis** / **surface proposal** / **admission** | The gated pipeline `propose → map → static E → S1–S4 → E4 → admit as conditioned rule → observe → expire/retire`; a *surface proposal* is `{candidate, provenance, hypothesis: AssumptionDebtRecord, target_home}`; *admission* is endorsement by `validator` then `seal` (ADR-0035 basis) into a `ProfileRule` or `HarnessRule`. | WS-E2 / WS-I5 / WS-I6 / WS-G3. |
| **surface rejection rate** | Class-scoped metric `action.tool.surface_rejected ÷ model-emitted calls` per (profile, family); `applies_to_classes = {native}`, `requires_observability = {ledger}`. | WS-E2 / WS-I2 / WS-I1. |
