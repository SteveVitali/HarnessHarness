## Ontology terms

| term | definition | notes |
|---|---|---|
| capability record | The registry object for one `ToolCapability`: the HIR node (semantic + surface fields) plus a registry envelope `{registered_at, registrar, trust_record_ref, name_history_ref, dialect_range, status, usability}`; immutable per `version_id`. | WS-E1; consumers WS-J2, WS-E3, WS-A4. |
| capability source | Closed sum `native_variant | procedure | mcp_listing | provider_hosted | participant_supplied` naming where a capability record came from, with per-source default provenance/authority of its declarations and lifecycle. | WS-E1; not to be confused with `capability declaration/vector` (hosted participants) or `authority handle`. |
| scope binding | `{param_path, scope_kind ∈ {fs_path, host, recipient, spend_amount, secret_ref, process_target, memory_scope, resource_key}, canonicalization}` declaring which canonical capability parameter carries the scope a `Permission` grant / authority handle matches against. | WS-E1 for WS-H1 (H-5); `scope_bindings_unknown` = coverable only by unscoped grants. |
| precondition domain | One member of the closed sum `param_domain | path_within | host_within | env_requires | state_requires | capability_requires`, each with a declared check point (compile / bind / prepare / link). | WS-E1; answers phase-1 §6.9 "preconditions as checkable domains". |
| observation contract | `{content_class, size_class, offload_policy, streaming, error_classes}` on a capability: how its results are sized, offloaded, classified for sinks, and which typed error classes it may return. Result authority is derived by the kernel, never declared. | WS-E1 for WS-D1, WS-I1, WS-E2 (E5/E6). |
| declared cost model / measured cost profile | `cost_model.declared` = advisory per-dimension estimates with confidence and provenance; `measured_ref` = a ledger projection (`tool_cost_profile`) of observed usage. Never read by accounting or `MatchSpec`; absent ⇒ `unknown`. | WS-E1 ADR-3; owners of the view OQ-WS-E1-03. |
| execution requirement | `{environment_class, isolation_min, interrupt, dedup_support_required?, concurrency}` — what an executor binding must satisfy for a capability; checked by `bind`. | WS-E1 for WS-E5/B5. |
| exposure hint / exposure mode | `exposure_hint.default ∈ {direct, deferred, on_demand_only}` (semantic-excluded hint for WS-E3's per-turn selection) / surface field `exposure_mode ∈ {primitive, composite_member, hidden}`. Selection is a run-time act over compiled identities (ADR-0019). | WS-E1 / WS-E3; Codex `ToolExposure` precedent. |
| listing hash | `H(canonical(Tool document))` of an imported protocol listing; the subject of a `pin` attestation and the trigger of `refresh`-as-supersession. | WS-E1 / WS-E4 / WS-H5. |
| search projection | The surface-independent text and structure (`purpose`, parameter names/descriptions, effect domains, namespace) a registry exposes for catalog retrieval; never includes profile-owned names. | WS-E1 for WS-E3; ToolRet motivation. |
| tool registry policy | The registered component class (`tool_registry_policy`) parameterising admission by source/trust, collision handling, refresh cadence and exposure defaults; receives `(ModelProfile, ResourceAccount)`. The store itself is MUST-code. | WS-E1; T-LCD-08. |
| unknown_domain | Candidate distinguished `EffectDomain` value for effects lifted from hints alone; projects to `{irreversible, non_idempotent, external}`. | Pending OQ-WS-E1-05 (WS-A3/H1 decide representation). |
