## Ontology terms

| term | definition | notes |
|---|---|---|
| compaction strategy | Registered component class `compaction_strategy` (`cardinality: ordered-many`, `required_inputs ⊇ {ModelProfile, ResourceAccount}`) invoked at `DecisionPoint = compact`; contract `assess / propose / execute / declare`. | WS-D2 ADR-1. Precedents: OpenHands `CondenserBase`, goose `CompactionModel`, Pi `compact`. |
| compaction operation | One of the closed sum `Evict{item_ids, placeholder}`, `Offload{item_ids, handle, excerpt_policy}`, `Summarize{input_ids, schema_ref?, insert_at, previous_summary_ref?, instructions_ref}`, `Restructure{input_ids, schema_ref, extractor ∈ {deterministic, model}, outputs}`; `ext` ops must declare deriver and consumed set. | The four sponsor strategies as ops, not classes (dossier F1). |
| compaction proposal | `{proposal_id, ops[], expected_reclaim, requires_model_call, summarizer_profile?, max_summary_tokens?, fallback[]}` — the deterministic output of `propose`; content-addressed; recorded on `context.compaction.started`. | No precedent records the proposal separately (dossier §5 negative iv). |
| compaction record | `{compaction_id, proposal_id, applied_ops[], forgotten, tokens_before, tokens_after, occupancy_after, context_label_after, status, summariser_usage?, duration_ms}` — the payload of `context.compaction.completed`. | Generalises OpenHands `Condensation`, Codex `CompactedItem`, Pi `CompactionEntry`, Inspect `CompactionEvent`. |
| compaction trigger | Closed sum `{occupancy_hard, occupancy_soft{rule_id}, overflow_reactive{error_ref}, request_principal, request_model{tool_call_id}, schedule{rule_id}, relower{dropped_items}}`. | Codex `CompactionTrigger{Manual, Auto}` + `CompactionReason`; OpenHands `Reason{REQUEST, TOKENS, EVENTS}`. |
| compaction requirement | `none | soft | hard` — the strength of a trigger; `hard` means the next model call cannot proceed without reclaim. | OpenHands `CondensationRequirement`. |
| forgotten set | The item ids (or range) an applied compaction removed from the context view; on the event; = `derived_from` inputs of any summary. | OpenHands `forgotten_event_ids`; ADR-0034 P1. |
| compaction summary | `Artifact{kind: compaction_summary}` produced by `Summarize`; provenance `{origin: model, authority = min(⊔ inputs, delegate), taint = ∪, derived_from = forgotten ids + model_call_id + instructions_ref}`; validity `unknown`. | Never above `delegate`; admitted only to `transcript`/`external` slots. |
| compaction checkpoint | `Artifact{kind: compaction_checkpoint}` — a schema-typed `Restructure` output (goal / constraints / progress / decisions / next steps / files) whose fields are `Text` leaves or typed values. | goose `StructuredSummary`, gemini `<state_snapshot>`, Codex `notes`, Pi structured prompt. |
| omission item | The kernel-authored `Text` leaf inserted by `Evict{placeholder: kernel_omission}` ("omitted evidence does not authorize actions"); = WS-D1's kernel omission notice. | Codex `guardian_budget_omission`; Anthropic placeholder text. |
| input reduction | Declared policy applied when the summariser's own window overflows: `trim_oldest | drop_tool_results_middle_out{percent} | shrink_strings{factor}`; recorded on the record. | Codex `remove_first_item`; goose `REMOVAL_PERCENTAGES`; OpenHands hard-reset scaling. |
| fallback ladder | Kernel rule on `hard`: variant failure/ineffectiveness ⇒ `proposal.fallback` ⇒ `fallback_variant` ⇒ C0 `evict_oldest` ⇒ `CompactionImpossible`. | gemini truncation-only after failure; Codex fresh window; Harbor "progressively simpler fallbacks". |
| reclaim / target reclaim / minimum reclaim | Tokens removed from occupancy by a compaction; the target (`window_cap × target_fraction`); the minimum below which the result is `ineffective`. | gemini inflated-count refusal; OpenHands `minimum_progress`. |
| re-acquisition rate | Process metric: deliveries or reads after compaction c whose content address / `artefact_id` ∈ forgotten(c), ÷ |forgotten(c)|; `trace_predicate` oracle; native only. | S-WS-D2-05 mechanism (`provisional`); computed from ratified events. |
| repeated-action rate | Process metric: effects after c whose idempotency key (ADR-0031) equals one before c, ÷ effects after c; `trace_predicate`; native only. | S-WS-D2-04 mechanism (`provisional`). |
| recall probe at compaction | Process metric: fraction of deterministically extractable facts from forgotten(c) present in the summary artifact or reachable by a recorded handle; `n/a{no_detector}` where no extractor exists. | Pi `details{readFiles, modifiedFiles}` extractor shape. |
| boundary-local paired continuation | Lab recipe: fork by reference at `context.compaction.started`, continue k turns with and without the proposal, compare process metrics under equal budgets. | TRACE / Slipstream mechanism (`provisional`); ADR-0027 fork; ADR-0046 pairing. |
| model-owned compaction | A `compaction_strategy` variant declaring `control_boundary_compact = model`: ops are proposed by the model through declared `ToolCapability`s, validated by the kernel invariants. | Codex token-budget `notes` + `new_context`; MemGPT paging; folds. |
| provider compaction | A variant whose `execute` delegates to a gateway capability the profile declares (`compact_20260112`, Codex remote v2); summary `delegate`-derived; forgotten set recorded as a range when the provider drops blocks; iteration usage charged separately. | S-WS-D2-09; Codex `compact_remote_v2.rs`. |
| tool-result clearing | *(amended)* `Offload` when a content-addressed handle with a declared read capability exists; `Evict{kernel_omission}` otherwise. | CF-WS-D2-04; S-038 "safest lightest touch". |
| summarizer profile | `ProfileRef` parameter naming the model profile used for `Summarize`/model-`Restructure`; a component-level factor and a member of the run's model set. | gemini per-model aliases; OpenHands independent LLM; opencode `compaction` agent. |
