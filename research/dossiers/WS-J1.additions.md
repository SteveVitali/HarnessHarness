## Ontology terms

| term | definition | notes |
|---|---|---|
| **assembly service** | The C1 Lab-facing orchestration over the kernel's assembly operations (`desugar → compose → resolve → validate_assembly → seal`, ADR-0025) exposing `assemble / plan / apply / validate_batch / explain`; semantics-free (every output byte-identical to the kernel's on the same inputs); the only path by which a sealed definition enters the registry and a run (invariants M-1/M-2). | WS-J1 / WS-J2 / WS-K1. Lives in the ADR-0050 laboratory layer; the operations it calls live in the kernel layer. |
| **AssemblySource** (authoring source) | The authoring document above the sealed grammar: `{dialect, root_kind ∈ {native, hosted}, base?, layers[], overrides?, imports?, ext}`; every production desugars to ADR-0023/0024 constructs before `resolve`; never sealable. | WS-J1. Precedent: OpenHands `AgentProfile` (references) vs `AgentSettingsConfig` (resolved); goose recipe template vs rendered recipe. |
| **desugaring (assembly)** | The pure, total, order-defined map from an `AssemblySource` to the `[Layer]` list `compose` consumes: `base` → lowest-precedence layer; `overrides` → one content-addressed `experiment` layer; imports → typed entities with `Text` leaves at `≤ external`; selectors pinned by `resolve`; `root_kind` selects the `AgentProcess` variant. | WS-J1. Invariant: output validates against the `hir/1` schema alone. |
| **assembly plan** | The dry-run output `AssemblyPlan{diff, defaulted_paths, authored_paths, layer_map, drift?, exit ∈ {no_changes, changes, error}, sameness}` — identical in verdict to a real `assemble` (dry-run parity). | WS-J1 / WS-K1. Precedent: Terraform plan; Kubernetes `dryRun=All`; OpenHands `resolve_agent_profile_dry_run`. |
| **AssemblyDiff** (assembly diff view) | A total, injective, never-stored projection of a `HirDiff` into assembly-level buckets (`slot_rebind, slot_toggle, slot_param_change, value_change, space_change, entity_*, edge_change, cap_change, profile_constraint_change, surface_only, ext_only, provenance_only`) carrying the ADR-0017 classification and the ADR-0037 sameness level; `flatten(project(d)) = d.ops`. | WS-J1 / WS-I5 / WS-I7. Not a second edit unit: `apply`/`invert` remain `HirDiff`'s. |
| **snapshot drift** | The typed diff between the sealed forms of one `AssemblySource` resolved under two `registry_snapshot_id`s; ops are `Rebind`/`ReplaceLeaf` on pinned references only; reported as `C-REF-6` with severity by sameness level (L1 info, L2 warning, L3 error); never applied to an arm whose `Design` has opened (`freeze` default); adoption is an explicit logged `HirDiff`. | WS-J1 / WS-J3 / WS-J2. Definition-level analogue of ADR-0095 catalog epochs; distinct from ontology `DRIFT` (observed ≠ declared conformance, WS-J6). |
| **assembly diagnostic** / **diagnostic code** | `AssemblyDiagnostic{code, class, severity, path, source_layer?, subject, stage, detail, remedy, owner_adr}` — the only form in which any assembly-pipeline rejection reaches a caller; `code` is drawn from a closed per-dialect list (`C-<CLASS>-<n>`) with no catch-all; a rejection without a code is `C-INT-1` and a defect. | WS-J1. Precedent: opencode `Diagnostic{kind, path, message}`; goose bidirectional parameter errors; OpenHands `AgentProfileDiagnostics`. |
| **degraded validation profile (hosted)** | The rule over `validate_assembly` stages for `AgentProcess.hosted`: stages 1, 3, 4, 5, 7(`hosting_edges`, identity) run; stages 2, 6 and 7-opacity return `n/a{reason: class}` (never pass, never 0); `slots`/`profile_binding` refused (`C-CLASS-6`). No IR field is added (T-LCD-06). | WS-J1 / WS-J6. |
| **defaulted path** | A path in a sealed definition whose value was filled by the kernel from `ParameterSpec.default` or a class's `base_param_schema` default rather than authored; listed in every plan; defaulting never adds a slot. | WS-J1. Precedent: Kubernetes dry-run "generated values"; goose `ensure_analyze_for_developer` as the counter-example. |
