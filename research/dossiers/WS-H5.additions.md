## Ontology terms

| term | definition | notes |
|---|---|---|
| extension | A behaviour-changing dependency of a Harness Definition that is not part of the instrument: skill, hook, plugin, MCP server, repository instruction file, fetched instruction, third-party component variant. Every extension is three things — text the model reads, code a machine runs, claims about what it may do — each labelled independently. | WS-H5; "plugin" remains third-party packaging (Ontology v1) |
| extension kind | Closed sum `{skill, hook, plugin, mcp_server, instruction_file, fetched_instruction, component_variant, other(ext)}` per HIR dialect. | WS-H5 |
| extension record | Registry-layer versioned record `{extension_id, kind, name, content: ContentAddress, manifest, contributes[], locator, trust, provenance, ext}` referencing the HIR nodes an extension contributes; never a HIR entity. | WS-H5 / WS-L4 domain tag / WS-J2 |
| extension trust record | The CF-055 trust record: `{text_authority, code_identity[], isolation, grants, declared_claims, attestations[], attestation_status, scans[], text_hygiene, installed_by, installed_at, scope, status, review_ref?}` — three independent legs (text authority; code identity + isolation; grants). | WS-H5 / WS-L5 |
| location neutrality ("no automatic elevation by configuration location") | Invariant L1: an extension's text authority is a total function of `(kind, origin, attestation_status)` and never of its directory, settings layer, marketplace, scope or a "trusted folder" fact; violation is the `LocationElevation` validation error. Trust prompts are scope conditions on declared sources. | WS-H5; closes S-103/S-104 for extensions |
| declared source | An Assembly-level declaration `{directory_scan, marketplace, registry, git, archive, mcp_endpoint, instruction_files}` from which `discover` enumerates candidates at `resolve`; there is no run-time discovery (closed-world rule). | WS-H5 / WS-A5 |
| trust root policy | `definition`-plane `HarnessRule` artifact `{allowed_sources, accepted_signers, required_predicates, require_signature_for, hash_only_ceiling, max_age?, drift_policy, scanner_policy, model_install, archive_policy}` layered with `authority_cap`; the endorser of `pin` events. | WS-H5 / WS-H1 / WS-L6 |
| surface pin / surface drift | The content address of an MCP server's lifted surface document (`initialize` incl. `instructions`, `tools/list`, `resources/list`, `prompts/list`) recorded at `resolve`; a mismatch at connection is `ExtensionSurfaceDrift`, a typed `HirDiff` over lifted `ToolCapability` surfaces, handled per `drift_policy`. | WS-H5 / WS-E4; ETDI/Invariant precedent |
| isolation class | `{in_process (kernel only), subprocess_confined, container, remote, host_unconfined}` — where an extension's code may run; defaults per kind; every start is a ledgered effect. | WS-H5 / WS-B5 / WS-E5 |
| claim vs grant | A *claim* is what an extension says about itself (`allowed-tools`, MCP `ToolAnnotations`, plugin permission manifests) and never reaches the monitor; a *grant* is a `Permission` conferred by an issuer of class ≥ `principal`. | WS-H5 / WS-H1; MCP hints rule |
| model-install path | The kernel Procedure by which an agent-initiated extension install proceeds as ordinary effects, is approved as one install effect, and yields an extension at ≤ `external` with taint, attenuated grants, confined isolation and a non-widening definition edit. | WS-H5 / WS-H1 / WS-H7 |
| advisory scan / advisory validator | A `Validator{kind: advisory}` (malware advisory, secret pattern, hygiene, description–code mismatch) whose result `{clean, flagged, unavailable}` is recorded on the trust record and may deny/quarantine under policy but never raises a class. | WS-H5 / WS-G1 |
| text hygiene report | Advisory record of invisible/bidirectional/tag code points and description–code mismatches in extension text; bytes preserved in the `Text` leaf; shown at `review`. | WS-H5 / WS-D1 |
| instruction file | Extension kind for repository instruction files (AGENTS.md-class) discovered through an `instruction_files` declared source; `external` by default; `definition` only when the author sealed its content hash. | WS-H5 / WS-D1 |
