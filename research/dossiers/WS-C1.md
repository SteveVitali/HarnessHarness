## 1. Scope & boundary

This workstream decides **what the model gateway is and is not**: the one component through which every native model call leaves the kernel and every provider response re-enters it. Concretely it fixes (a) the gateway's operations, inputs, outputs, invariants and failure modes; (b) the **normalized model-event grammar** a streaming call yields and the **normalized assistant message** it settles into; (c) **tool-call normalization** (ids, argument accumulation, parse failure, truncation, ordering, opaque signatures); (d) the **closed stop-reason and error-class vocabularies** with retry classes, and the attempt policy that transport retries obey; (e) the usage, cost-provenance and timing emissions the gateway owes ADR-0039/0043 (`usage_mapping`, `normalizer_ref`, `emit_call_timing/usage/cost`, M3/M4); (f) **capability discovery** at the model boundary — transport capabilities, model discovery as claims, provider snapshot ids, served-model drift, the fingerprint probe (OQ-111) and `seed_honoured` (OQ-122); (g) the **boundary with the Profile Compiler**: the gateway is *semantic-neutral and model-blind*; it consumes the compiled **provider request plan** as data (CF-044 guidance, now closed as OQ-072) and owns transport only; (h) a **conformance suite** (golden streams per wire dialect) as acceptance criteria.

It explicitly leaves to neighbours: every model-conditioned surface decision — tool dialect, naming, strict-schema subsets, cache-marker placement, layout, transcript rules, error *rendering* (**WS-C3** under ADR-0020, lowered by **WS-A4** under ADR-0019); execution of the transcript-renderer spec (**WS-D1**, OQ-063 synthesis guidance accepted: the context builder renders, the gateway receives rendered material); routing, fallback across models, ensembles (**WS-C2** — the gateway *reports* provider-side substitution, never chooses a model); cache *policy* and semantic caching (**WS-C4** — the gateway reports cache roles and cache-state where visible); budget `check/reserve` (**WS-F2**, ADR-0040 — the gateway posts usage; it never decides whether a call may start); content-level retries and nudges (**WS-F1/F2** — a retry that changes request bytes is a control decision, §6.4); the ledger envelope and event durability (**WS-B1**); credential storage and egress policy (**WS-H3/H4** — the gateway uses credential handles and endpoint allow-lists it does not own); the tool-shim / code-mode interaction modes (**WS-E2/C3**, C2 — variants that *wrap* the gateway); model-boundary interception of hosted participants (**WS-J6**, C2 — §6.9 states what the gateway offers it); every language, runtime, library or transport-library choice (ADR-0050 §8 — nothing below names one; precedent file paths are evidence, not dependencies).

## 2. Key questions

1. (doc 3 §5, verbatim) Design the model adapter: provider-agnostic inference contract (messages/blocks, tool definitions, tool-call normalization, streaming events, usage/cost accounting hooks (L2/I1), errors/retries, capability discovery e.g. context window, modalities, caching support).
2. (verbatim) The boundary with the profile compiler (C3) — the adapter is semantic-neutral, the profile is model-specific.
3. (brief) Deliver the adapter contract (operations, normalized request/response/streaming event types, error classes, usage accounting); capability descriptor; acceptance criteria (conformance suite); ADR. Read ≥3 provider-abstraction layers in source.
4. (phase-1 §6.9, binding) C1 declares `usage_mapping` per profile, stamps `normalizer_ref`, `emit_call_timing/usage/cost`, exposes provider snapshot ids and runs the fingerprint probe.
5. (OQ-072, blocking) Does the gateway consume the compiled provider request plan as data, or own per-provider serialisation tables?
6. (added) Where does *dialect*-conditioned knowledge that is not *model*-conditioned live — HTTP-status-to-error mapping, stop-reason mapping, usage field names, framing, retry-after parsing — given CF-044 says the profile owns what changes the bytes the model sees and the gateway owns transport?
7. (added) What is the minimal event grammar that every audited streaming API can be decoded into without loss, and which items must stay opaque?
8. (added) What can the gateway legitimately retry, and what must it refuse to retry?
9. (added) What does "capability" mean at the model boundary once T-LCD-07's declare/probe/never-intersect rule is applied to transports and models rather than participants?
10. (added) How should provider nondeterminism and silent model substitution be surfaced so the Lab can stratify on them (OQ-111, OQ-122, CF-033)?

## 4. Findings

### 4a. Mechanism evidence (a failure mode exists / an architecture is implementable)

**F1 — Every audited gateway is really three layers, and the two that carry model-conditioned knowledge are always entangled with transport.** goose: `Provider::stream` (contract) → `formats/<api>.rs` (per-API serialisation + stream decode) → `ApiClient` (auth, TLS, timeouts, redirects). pi: `StreamFunction` (contract) → `api/<api>.ts` builders parameterised by `Model.compat` flags → fetch/websocket transport with `provider-retry.ts`. opencode: `LLM.stream` → either a "native" runtime or a third-party SDK path, with a middleware `transformParams` hook where per-model message transforms are applied *inside the transport call*. gemini-cli: `ContentGenerator` (four operations) → decorators → SDK. OpenHands: `LLM.completion/responses` → feature flags → third-party client. codex: `ResponseEvent` decoder → `ModelProviderInfo` transport record. Inspect: `ModelAPI.generate` → 47 providers. **Implication (OQ-072):** the *contract* layer is uniformly small and provider-agnostic (a request with system/messages/tools + options in, a stream of events out); what differs is where dialect and model knowledge are placed. CF-044's split is implementable exactly because the audited contract layers already exclude model knowledge — what remains to decide is the home of *dialect* knowledge (F3) and the shape of the plan the gateway consumes (§6.1).

**F2 — There is one event grammar underneath every streaming API, with a small set of provider-opaque islands.** Anthropic (S-WS-C1-01): message start → indexed content blocks with start/delta/stop → message delta(s) → message stop; tool arguments as partial-JSON deltas; signature deltas. OpenAI Responses (codex `sse/responses.rs`, OpenHands `_process_stream_event`): `response.created/in_progress` → `output_item.added` → per-item deltas (`output_text`, `function_call_arguments`, `reasoning_summary_text`, `refusal`) → `output_item.done` → `response.completed | failed | incomplete{incomplete_details}`; `sequence_number` on every event. OpenAI-compatible chat completions (goose `formats/openai.rs`): choice deltas with tool-call fragments, usage-only chunks with empty `choices`, and *metadata frames without `choices`* interleaved by proxies. pi normalises all of them into `start → {text,thinking,toolcall}_{start,delta,end} → done | error` with the invariant "updates and `done` must never appear before `start`"; goose collapses to `(Option<Message>, Option<Usage>)` items with "partial text but complete tool calls"; opencode's processor consumes a third-party part vocabulary (`text-*`, `reasoning-*`, `tool-input-*`, `tool-call`, `finish`). What stays opaque everywhere: reasoning signatures (`thinkingSignature`, `signature_delta`, `encrypted_content`), thought signatures on tool calls (Google), text signatures (Responses item ids), and provider notices (codex `ServerModel`, `SafetyBuffering`, `RateLimits`, `ModelVerifications`). **Implication (§6.2):** a normalized grammar of *indexed blocks with start/delta/end plus a terminal* is lossless for every audited API provided (i) opaque items are carried as owner-stamped leaves (WS-A3 F5), (ii) provider notices have their own channel rather than being dropped, and (iii) the terminal message is reconstructible without the deltas (pi's `AssistantMessageFrame` excludes "terminal settlement" so replay carries only parsed arguments; WS-B1 already makes `model.stream.delta` ephemeral).

**F3 — Dialect-conditioned knowledge that is *not* model-conditioned exists, is textual, and rots.** HTTP status → class mapping (goose `http_status.rs` "format-agnostic"); `retry-after` in three forms with caps (goose 3600 s; pi throws above cap; opencode 30 s without headers); in-stream error frames vs metadata frames (goose `classify_choiceless_frame`); context-overflow detection by **25 regexes** (pi `overflow.ts`) or 8 substrings (OpenHands `LONG_PROMPT_PATTERNS`), with two providers that *do not error* on overflow and must be detected from usage; malformed-history rejections (OpenHands `MALFORMED_HISTORY_PATTERNS`, 9 provider phrasings); retryability by ~40 phrases (pi `retry.ts`) or `x-should-retry` headers; usage field-name fallbacks (goose `get_usage`); `<think>`-tag reasoning inside text for some open models (goose `ThinkFilter`); cumulative vs final usage (Anthropic `message_delta` cumulative; Responses on `completed`; chat completions on a trailing empty-choices chunk). None of this changes the bytes the model sees, so CF-044 assigns it to the gateway — but expressed as code it is the same assumption debt T-LCD-05 forbids for profiles, and it changes as often (pi's overflow list cites 17 providers; goose's permanent-failure list quotes provider error prose verbatim). **Implication (§6.4):** the gateway's dialect knowledge is a **data document per wire dialect** (`WireDialect` descriptor) whose textual rules carry assumption-debt records and whose removal test is a golden fixture; the codec is model-blind *and* dialect-parameterised. `usage_mapping` stays in the Model Profile (CF-106) because cache-role inclusion differs per *model* on the same dialect (OpenHands' cache comment; goose's inclusive doc vs Anthropic exclusive) — the dialect supplies its default.

**F4 — Two kinds of retry exist in production and only one is safe inside a gateway.** *Transport retries* replay identical bytes on transient classes (codex `RetryOn{429, 5xx, transport}`; goose `should_retry`; pi `provider-retry.ts`; Inspect `RetryDecision{transient | rate_limit, retry_after}`; Inspect retries attempt/stream-idle timeouts and zero-chunk streams unconditionally). *Content retries* change the request: OpenHands bumps temperature to 1.0 on an empty response; gemini appends a nudge message and re-sends; codex's `SafetyBuffering` swaps to a `faster_model`; gemini's `handleFallback` moves to another model with user intent `{retry_always, retry_once, retry_with_credits, stop, retry_later, upgrade}`. goose documents the failure of conflating them: a 4xx caused by signed thinking blocks "is rebuilt on every retry — so retrying can never succeed", hence a *permanent* sub-class of 4xx. **Implication (§6.4):** the gateway retries only on identical bytes and only on `retry_class ∈ {transient, rate_limit}` under an `AttemptPolicy` supplied as data; every attempt is a `model.call.attempt.*` event (CF-089) sharing the logical `model_call_id` and its reservation (ADR-0040); anything that changes the request is a *new logical call* decided at a `retry`/`escalate` decision point (F1/F2) or by the router (C2), never inside the gateway.

**F5 — Tool-call normalization has five independent hazards, each precedented.** (i) *Ids*: provider ids differ in charset and lifetime (Responses `item_id` + `call_id`; chat `tool_call.id`; Anthropic `tool_use.id`); OpenHands keeps both `id` and `responses_item_id` with `origin`; ADR-0027 already rules provider ids are `surface_ids` aliases and `tool_call_id` is allocated. (ii) *Arguments*: arrive as partial JSON strings; pi parses at block end with `partial-json` plus `repairJson` (control characters, bad escapes); opencode's `experimental_repairToolCall` rewrites an unparseable call into a synthetic `invalid` tool; goose marks arguments truncated by the output-token limit as a typed tool error. (iii) *Names*: opencode lower-cases mismatched names in the adapter; goose splits `extension__tool` and reads a provider index from tool meta; PA-Tool (Tier A) shows names are model-conditioned. (iv) *Ordering and parallelism*: goose stores `TOOL_META_PROVIDER_INDEX_KEY`; BFCL scores parallel and multiple calls as a set matched by AST. (v) *Opaque attachments*: Google thought signatures ride on the tool call (pi `thoughtSignature`). **Implication (§6.3):** the gateway allocates ids, accumulates and parses arguments *strictly* at block end, never repairs semantics (an unparseable call is a typed `Unparseable{raw, reason}` argument value the control strategy sees — E3/E5 render the model-facing error through the profile's `error_format`), preserves provider order and index, carries opaque signatures as owner-stamped leaves, and leaves name→capability resolution to E3 through the compiled `SurfaceArgMap` (ADR-0022) — the gateway knows surface names only.

**F6 — Stop reasons and error classes converge on a small closed core plus a long provider tail.** Core stop reasons across pi (7), Inspect (6), MCP (4 + open string), Anthropic (6: `end_turn, max_tokens, stop_sequence, tool_use, pause_turn, refusal`), Responses (`completed | incomplete{max_output_tokens, content_filter} | failed`), gemini (`InvalidStreamError` 9 kinds incl. `SAFETY_BLOCKED, RECITATION_BLOCKED, MALFORMED_FUNCTION_CALL, THINKING_ONLY_RESPONSE`). Error classes: goose 14, codex 12, OpenHands 15, opencode 2 + codes, Inspect `RetryDecision` + `StopDetails{categories}`; Cursor's taxonomy places `ProviderError` beside tool-side classes. Renames cost: Inspect migrates `length → max_tokens` with a validator; MCP left `stopReason` open and then deprecated sampling altogether. Provider-specific tail: `pause_turn` (resubmit), `sensitive`, `cyber_policy`, `misalignment_policy_violation`, `usage_not_included`, `credits_exhausted{top_up_url}`, `ValidationRequiredError` (account verification). **Implication (§6.4):** closed sums for `StopReason` and `ModelErrorClass` with a `raw` surface alias, an explicit `unknown`, a `retry_class`, and a `provider.notice` channel for the tail — growth is a dialect bump, never an open string in the kernel (ADR-0015 closed-sum rule).

**F7 — Provider-side model substitution and nondeterminism are facts the gateway can observe and no audited system records as ledger facts.** Substitution: codex `ServerModel` ("backend safety routing"), Anthropic server-side fallback (a `fallback` block "at each model boundary"), pi `responseModel` with cost re-priced at the served model, Inspect `ModelFallback{model, fallback_model, count}`, OTel `gen_ai.response.model` "the model actually used". Nondeterminism: 80 distinct outputs in 1,000 temperature-0 completions, caused by batch-dependent reduction order (S-WS-C1-02; corroborated S-WS-C1-04 `provisional`), so a sampling `seed` cannot be assumed honoured (CF-095, OQ-122) and a fingerprint cannot be a single hash (OQ-111). Snapshot ids: Responses returns a served model id and, for some dialects, a system fingerprint; Anthropic returns `model` on `message_start`. **Implication (§6.5):** every `model.call.completed` carries `served_model` and `snapshot_id?`; `served_model ≠ requested` is stamped and priced at the served model (ADR-0039 `model_ref.serving_route`); the fingerprint probe is *distributional* (per-prompt agreement rates over n samples), charged `instrument`, and yields DRIFT that annotates and splits arms (ADR-0013 semantics); `seed_honoured` is a tri-state declared per model and probed.

**F8 — Capability discovery at the boundary is three different things.** *Transport capabilities* (streaming kinds, usage-in-stream, cache semantics, deferred requests, count-tokens endpoint, model listing, websocket): codex `ModelProviderInfo{supports_websockets, stream_idle_timeout_ms}`, goose `DeclarativeProviderConfig{supports_streaming, dynamic_models}`, goose `CacheSemantics`, pi `Transport`, Inspect `max_connections/connection_key`. *Model capabilities* (context window, max output, modalities, native FC, reasoning replay): ADR-0020's declaration; in the audit computed by substring rules (OpenHands `ModelFeatures`), `switch` (gemini `tokenLimits`), third-party metadata tables (OpenHands, opencode), or provider listing endpoints (goose `fetch_model_info`). *Observed conformance*: none of the audited gateways probes; goose derives context limit by precedence override → configured → canonical → default; OpenHands halves max-output when it equals the window and refuses windows < 16k. **Implication (§6.5):** transport capabilities are a gateway-owned declared record (tri-state, probed); model capabilities remain profile-owned (ADR-0020) and the gateway supplies *discovery results as claims* with `authority = external` (ADR-0033 — closed-schema values from an open-world endpoint are not `environment`), which the profile pins and probes compare (DRIFT); precedence is *pinned profile value wins, discovery is evidence*.

**F9 — Usage and timing must be emitted by the component that observes them, once, with the mapping named.** goose `ProviderUsage{cost_source}` and `stats{time_to_first_token_ms}`; pi `Usage.cost{…}` computed from `Model.cost` (table) unless the provider reports; opencode `includeRawChunks` because one provider's billed amount is only in raw chunks; codex `RateLimits` snapshots in-stream; OpenHands' single-source cache buckets (WS-I1 F-precedent). Attempt vs logical timing (ADR-0043 M3/M4) is observable only inside the gateway; queue waiting on a connection semaphore (Inspect) is *wall − working* (ADR-0039 `time.working_ms`). **Implication (§6.6):** the gateway is the sole emitter of M3/M4, of `usage{raw, canonical, normalizer_ref, available}` and of `Money{…, provenance ∈ {provider_reported, gateway_reported, estimated_from_pricing}}` (ADR-0043 six-valued), plus `queue_wait_ms` so that throttling never masquerades as harness latency.

## 5. Disconfirming evidence & negative results

**Against "the gateway consumes the plan as data and owns transport only" (R1, OQ-072).** Every audited system keeps request builders as *code per API*, and some knowledge straddles the CF-044 line: goose places cache breakpoints with a 20-block look-back heuristic inside the serialiser (`cache_semantics.rs` `apply_chat_payload_breakpoints`), pi auto-detects `compat` flags from the base URL, opencode applies message transforms in a transport middleware. If the serialiser must *know* message structure to place markers, is it still "transport"? *Why this does not overturn:* marker *placement* is a profile `caching_markers` rule (ADR-0020 kind) evaluated by the renderer (D1, under the closed-world rule) and expressed in the plan as marker positions; the codec serialises positions it did not choose; the look-back heuristic becomes a rule with a debt record. What legitimately stays in the codec is knowledge of the *wire* — and §6.4 makes even that data. The residual is that the plan's dialect schema must be rich enough to carry every marker/flag a profile can set; ADR-0021 already treats the provider tool API as a lowering target with a schema, and the conformance suite's "model-blind codec" gate (AC-C1-1) is the tripwire.

**Against closed `StopReason`/`ModelErrorClass` sums (R2).** Providers add codes monthly (`pause_turn`, `sensitive`, `cyber_policy`, `misalignment_policy_violation`, `usage_not_included`, verification-required); Inspect paid a migration to rename one value; MCP chose an open string and then deprecated the whole sampling feature (SEP-2577), suggesting protocol-level inference contracts do not survive provider churn. *Why this does not overturn:* the failure mode of an open string is silent — consumers cannot be exhaustive, and the Lab cannot stratify on a value nobody declared; ADR-0015 fixes closed kernel sums per dialect for exactly this reason. The design keeps `raw_stop_reason`/`raw_error` as surface aliases, an explicit `unknown` class, and a typed `provider.notice` channel, so nothing is *lost* — it is *unclassified until the next dialect bump*, and the count of `unknown` per dialect is a Lab metric (a `WireDialect` health signal). MCP's deprecation is read as evidence that inference contracts belong *inside* a runtime that can version them, not in a cross-vendor protocol — consistent with ADR-0005/ADR-0021 treating protocols as edges.

**Against textual error rules as conditioned rules with debt records (R3).** pi's overflow list alone has 25 regexes across 17 providers; a debt record per pattern is bureaucracy, and the patterns change faster than any evidence refresh. *Why this does not overturn:* the unit is one rule per `(dialect, class)` — e.g. `openai_chat.context_length_exceeded` — with one debt record whose removal test is the golden fixture; patterns inside a rule are its `params`. The alternative (code) rots identically with no expiry and no fixture. The Lab metric "unknown-class rate per dialect" makes rot visible, which code never does.

**Against any retry in the gateway (R4).** opencode sets `maxRetries: 0` at the SDK and retries at the session; OpenHands and gemini retry *content* failures with request changes; codex retries at three layers (`HttpRequest`, `Sampling`, `RemoteCompactionV2`). A gateway that retries can double-charge budgets, hide provider health from the router, and mask attempts from the ledger. *Why this does not overturn:* ADR-0043 already requires attempt spans under the logical call, ADR-0040 requires retries to reuse the reservation, and the rule "identical bytes, transient or rate-limit class only, attempts as events" bounds the gateway's retries to what a transport library does anyway — it just makes them visible. Content retries are excluded (F4); routing is C2's.

**Against fingerprint probes and `seed_honoured` (R5).** Nondeterminism makes a fingerprint noisy (80 outputs in 1,000); probes cost money; providers change behaviour without changing ids (S-047, CF-033), so a probe can only detect, never prevent. *Why this does not overturn:* the probe is distributional (agreement rate per prompt over n samples, compared against a pre-registered band), charged `instrument`, run at experiment boundaries rather than per call, and its verdict is DRIFT — a fact that annotates and splits arms (ADR-0013), never a gate. That is the honest instrument behaviour CF-033 asked for.

**Against a stream-primary contract (R6).** Inspect's `generate` is non-streaming and serves 47 providers; some gateways buffer whole responses; streaming adds idle-timeout and partial-state failure modes. *Why this does not overturn:* goose and pi show `complete = collect(stream)` is a five-line derivation, the reverse is not; streaming is required for TTFT (ADR-0043 M2/M4), cancellation mid-generation, and the `ephemeral` UI channel WS-B1 already defines; a dialect may declare `streaming: unsupported`, in which case its codec emits one `completed` — declaration, not intersection (T-LCD-07 applied to transports).

**Against making the gateway a component class at all (R7).** Doc 2 §7's audit finds hand-rolled loops and no framework imports; a pluggable gateway invites the "generic SDK" scope creep N1 forbids. *Why this does not overturn:* the gateway is one class with one C0 variant and a dialect-keyed codec set; pluggability exists so that (i) interposition for hosted participants (C2) and (ii) a fake/recording variant for the conformance suite and deterministic replay (ADR-0028 capability) can bind in the same slot — both are instrument needs, not framework ambitions.

**Negative results (audit).** (N1) No system exposes cache *state* (warm/cold) per call; only cache-read counts — OQ-097 cannot be answered from the gateway alone. (N2) No system probes `seed` support; Inspect and OTel merely carry the request value. (N3) The Responses API reference page could not be fetched (HTTP 403); event names were verified in two independent source readings (codex, OpenHands). (N4) MCP sampling — the only protocol-level inference contract — is deprecated as of 2026-07-28.

## 6. Recommendation for the spec

### 6.1 The gateway as a component class (operations, inputs/outputs, invariants, failure modes)

`ModelGateway` is a registered **component class** (ADR-0023/0025) with `home = model_boundary`, receiving `(ModelProfile, ResourceAccount)` per T-LCD-08, locality-neutral (T-LCD-12; the C0 variant lives in the kernel, ADR-0050 D1, and crosses no boundary per model call — ADR-0050 D2 forbids per-call crossings). It is **model-blind**: its code contains no model identity and no per-model branch; it is **dialect-parameterised**: one *wire codec* per `WireDialect` (§6.4), selected by the plan's `dialect` field.

| operation | input → output | invariants | failure modes |
|---|---|---|---|
| `open_call(run, lease, model_call_id, request: InferenceRequest) → CallHandle` | allocates nothing (ids come from B1/F2); validates `request.plan` against `WireDialect(plan.dialect).plan_schema`; obtains an endpoint + credential *handle* (H3) for `plan.endpoint_ref`; appends `model.call.requested{model_call_id, model_ref, request_ref (blob iff model_io), plan_hash, view_hash, token_estimate, cache_state_hint}` | plan is a sealed data document (`plan_hash = H(canonical(plan))`); no clock/env value enters the bytes except what the plan declares as slots already filled by D1; `budget_reservation_id` present (F2 reserved before dispatch, ADR-0040) | `UnknownDialect`, `PlanSchemaViolation`, `EndpointNotAllowed` (H4 allow-list), `CredentialUnavailable`, `MissingReservation` |

**Data model.** `InferenceRequest{model_call_id, model_ref{profile_ref, provider_model_id, snapshot_id?, serving_route?}, plan: ProviderRequestPlan, context_label (ADR-0034, from `context.assembled`), budget_reservation_id, attempt_policy: AttemptPolicy, deadline_ms?, cache_state_hint ∈ {warm, cold, unknown}, seed_request?, observability: {capture_request: bool, capture_response: bool}}`. `ProviderRequestPlan{dialect: WireDialectRef, endpoint_ref, system: [RenderedSection], messages: [RenderedMessage], tools: [DialectToolPayload], tool_choice ∈ {auto, required, none, named(surface_name)}, sampling{temperature?, top_p?, top_k?, stop_seqs?, max_output}, reasoning{effort? | budget?, replay_items[]}, cache_markers[], response_format?, provider_params: map<key, TypedValue> (each key registered by the `WireDialect` schema — no open map), metadata_passthrough?: opaque(owner = dialect)}` — emitted by ADR-0019 stage 4 (provider tool-API target) plus the D1-rendered transcript; the gateway treats it as bytes-to-be-framed. `RenderedMessage{role: ProviderRole (a surface — ADR-0034 `role_map` was applied upstream), blocks: [RenderedBlock], surface_ids}`.

**Invariants (kernel-level).** I1 *Model-blind codec*: `serialize(dialect, plan)` and `decode(dialect, frames)` are pure functions of their arguments; a static check of the codec's source finds no model-name literal and no profile field (AC-C1-1). I2 *Closed-world*: the bytes sent equal `serialize(plan)`; the gateway adds only framing, auth and dialect-mandated envelope fields listed in the `WireDialect` descriptor — so `request_ref` is attributable to compiled identities (T-LCD-13). I3 *Nothing unaccounted*: every terminal event carries `usage{available}`; `available = false` yields `n/a` coverage, never zero (ADR-0039 R-ACC-2, T-LCD-15). I4 *Identical-bytes retry* (§6.4). I5 *No authority*: the gateway never endorses, never widens, never reads labels beyond stamping the call's `context_label` onto its events (ADR-0035). I6 *No secrets in the ledger*: credentials are handles; `request_ref` blobs are redacted per the H3 secret pattern before hashing (ADR-0029 redaction-safe hashing).

### 6.2 Normalized model-event grammar and the normalized message

```
ModelEvent =
  | attempt.started{attempt_no}
  | message.started{surface_ids{response_id?}, served_model?}
  | block.started{index, kind ∈ {text, reasoning, redacted_reasoning, tool_call, provider_opaque}}
  | block.delta{index, delta: Text(str) | Reasoning(str) | ToolArgs(partial_json_str)}
  | block.completed{index, block: NormalizedBlock}
  | usage.updated{partial: TokenVector, arrival ∈ {cumulative, delta}}      -- optional per dialect
  | provider.notice{kind ∈ {rate_limit_snapshot, served_model, fallback_boundary, safety_buffering,
                            reasoning_included, verification_required, models_etag, other},
                    payload: opaque(owner = dialect)}
  | attempt.failed{error: ModelError, will_retry: bool, next_delay_ms?}
  | completed{message: ModelMessage, stop_reason, stop_details?, usage, timing, surface_ids}
  | failed{error: ModelError, usage?, timing}
```

**Grammar invariants.** G1 exactly one `attempt.started` per attempt; `message.started` precedes any block event of that attempt. G2 each `index` is opened once and completed once; deltas only between. G3 `tool_call` blocks complete with `arguments ∈ {Parsed(object), Unparseable{raw, reason}}` — never dropped, never repaired (§6.3). G4 exactly one of `completed | failed` closes the stream; after it nothing is emitted. G5 `completed.message` is reconstructible from `block.completed` events alone (deltas are `ephemeral`, WS-B1 `model.stream.delta`); the ledger stores only terminals and attempts. G6 `provider.notice` never changes classification or accounting by itself; consumers that understand a kind (C2 for `served_model`, F2 for `rate_limit_snapshot`) may act; unknown kinds are preserved byte-for-byte (ADR-0015 extension rule). G7 events carry `{model_call_id, attempt_no, seq_in_attempt}`; a dialect `sequence_number` is a surface alias.

**Normalized assistant message.** `ModelMessage{blocks: [TextBlock{text, signature?: OpaqueLeaf} | ReasoningBlock{text?, signature?: OpaqueLeaf, redacted: bool, owner{provider, model}} | ToolCallBlock{tool_call_id (allocated, ADR-0027), surface_ids{provider_call_id, item_id?}, surface_name, namespace?, arguments: Parsed | Unparseable, provider_index, truncated: bool, thought_signature?: OpaqueLeaf} | ProviderOpaqueBlock{kind, payload: OpaqueLeaf, owner}], stop_reason: StopReason, stop_details?: StopDetails{categories[{category, level?}], explanation?: Text(authority = external)}, raw_stop_reason?: string, usage: UsageRecord, served_model?, snapshot_id?, surface_ids{response_id?}, provenance: ProvenanceRecord{origin = model(model_ref, run_ref, response_id), authority = delegate}}`. `OpaqueLeaf` = WS-A3 `CompiledPayload`-class opaque bytes with `{format_tag, bytes_hash, owner{provider, model}, provenance}` — the gateway never interprets it; D1's renderer decides replay or drop on re-lowering (OQ-067). Text content produced by the model is `authority = delegate` (ADR-0033 minting rule); provider explanation strings are `external`.

**Lowering.** To the Hosting-ABI vocabulary: `block.delta{Text}` → `agent_message_chunk`, `usage.updated/completed.usage` → `usage_update` (WS-B1 event-class lowering); to OTel GenAI: `completed.stop_reason` → `gen_ai.response.finish_reasons`, `served_model` → `gen_ai.response.model`, `ModelError.class` → `error.type` (declared loss: OTel defines no class values) — listed in I1's telemetry loss report (T-LCD-11).

### 6.3 Tool-call normalization (rules)

T1 **Ids.** On `block.started{tool_call}` the gateway requests a `tool_call_id` from the id allocator (ADR-0027, nested under `model_call_id`); every provider id (`call_id`, `item_id`, `tool_use.id`) is stored in `surface_ids` and used only to correlate the provider's *own* subsequent frames and, on the next turn, the rendered tool result (D1 reads `surface_ids` from the ledger; the gateway never rewrites them). T2 **Arguments.** Deltas are accumulated verbatim; at `block.completed` the accumulated string is parsed as strict JSON; success → `Parsed(object)` (canonical form, ADR-0029, so `args_canonical_hash` for `effect_id`/idempotency keys is stable); failure → `Unparseable{raw, reason ∈ {invalid_json, truncated, empty}}`. Partial-JSON parsing exists only for the ephemeral delta channel (UI); it never feeds the ledger. **No repair**: control-character escaping, name case-folding and "invalid tool" rewriting (pi, opencode) are rejected in the gateway — a repaired call would misattribute the model's proposal; the control strategy decides what to do with an `Unparseable` proposal at its `act` decision point and E5 renders the error observation through the profile's `error_format` (ADR-0022 E5). T3 **Truncation.** `stop_reason = max_output` with an open tool block → `truncated = true` and `arguments = Unparseable{reason: truncated}` (goose precedent); never `Parsed` of a prefix. T4 **Names.** `surface_name` is carried verbatim (plus `namespace` when the dialect separates it); resolution `surface_name → ToolCapability` is E3's via the bundle's trace map / `SurfaceArgMap` (ADR-0019/0022); an unknown surface name is E3's `UnknownSurface` outcome, not a gateway error. T5 **Order.** Blocks keep provider order; `provider_index` is recorded; parallel calls are a list, and "parallel supported" is a profile capability (ADR-0020 `parallel_tool_calls`) the plan already honoured. T6 **Opaque attachments.** Thought/text signatures ride as `OpaqueLeaf` on the block with `owner`. T7 **Custom/grammar tools** (codex `custom_tool_call_input`, pi `customInput`) are C2 (`freeform` interaction mode, ADR-0048); the grammar reserves `arguments: Raw(str)` for them so the C0 sum can grow by dialect bump.

### 6.4 Wire dialects, error classes, stop reasons, attempt policy

**`WireDialect` descriptor** (gateway-owned, versioned, content-addressed data document; selected by `provider_api_family` — the same field as the profile selector, ADR-0020): `{dialect_id, version, framing ∈ {http_json, sse, websocket, jsonrpc_stdio}, plan_schema (JSON-Schema-class: which `provider_params` keys exist and their types), envelope_fields (what the codec adds beyond the plan), auth_kinds ⊆ {none, bearer, api_key_header, oauth, sigv4, command_backed}, endpoint_allowlist_ref (H4), streaming ∈ {supported, unsupported, unknown}, usage_arrival ∈ {final_only, cumulative_stream, delta_stream, absent}, usage_mapping_default, cache_semantics ∈ {explicit_breakpoints{max}, implicit_tolerant, implicit_strict, uncached, unknown}, cache_state_visible, count_tokens, deferred_requests, model_listing, snapshot_id_exposed, retry_after_sources[], retry_after_cap_ms, stream_idle_timeout_ms, rules: DialectRule[]}` with `DialectRule{rule_id, kind ∈ {status_to_class, error_code_to_class, error_text_to_class, stop_reason_map, reasoning_in_text, metadata_frame, notice_map}, params, debt: AssumptionDebtRecord}` — every textual rule carries the ADR-0020 debt record and its `removal_test_ref` is a golden fixture (T-LCD-05 applied reflexively to the gateway, as the battery requires of the Hosting ABI). The profile's `usage_mapping` (CF-106) overrides `usage_mapping_default` per model. Growth of `unknown`-class outcomes per dialect is a class-scoped Lab metric.

**`StopReason`** (closed, kernel): `{end_turn, tool_use, max_output, stop_sequence, content_filter, refusal, pause_turn, deferred, cancelled, error, unknown}` + `raw_stop_reason` alias + `StopDetails`. `pause_turn` means "the provider asks for resubmission of the same call" — a control-strategy decision, not a gateway retry.

**`ModelError`**: `{class: ModelErrorClass, retry_class ∈ {transient, rate_limit, permanent, ambiguous}, attribution ∈ {provider, transport, request, account, policy, response}, retry_after_ms?, http_status?, provider_code?: string (surface), message: Text(authority = external, redacted), raw_ref?: blob}` with `ModelErrorClass` (closed): transport `network`, `timeout{connect | attempt | stream_idle}`, `stream_decode`, `server_error`, `overloaded`, `rate_limited`; request `auth`, `forbidden`, `not_found{endpoint | model}`, `invalid_request`, `context_length_exceeded`, `malformed_history`, `unsupported_feature`, `permanent_request` (goose's signed-block case); account `quota_exhausted`, `credits_exhausted`, `usage_not_included`, `verification_required`; policy `content_policy`, `safety_blocked`, `refusal`; response `empty_response`, `invalid_response{no_stop_reason | thinking_only | malformed_tool_call | unexpected_tool_call}`, `served_model_mismatch` (only when the plan forbids substitution); control `cancelled`; `unknown`. Default `retry_class` per class is fixed in the kernel (transient: `network, timeout, stream_decode, server_error, overloaded, empty_response`; rate_limit: `rate_limited`; permanent: everything in request/account/policy; ambiguous: `unknown`, `invalid_response`) and a dialect rule may only *narrow* transient → permanent (goose markers), never widen.

**`AttemptPolicy`** (data, supplied per call from profile/configuration; C0 default in the kernel): `{max_attempts, base_delay_ms, max_delay_ms, jitter ∈ [0.8, 1.2], honour_retry_after: bool, retry_after_cap_ms, retry_on ⊆ {transient, rate_limit}, stream_idle_timeout_ms, attempt_timeout_ms, connect_timeout_ms}`. **Retry rules.** R-RT-1 retry only on `retry_class ∈ retry_on`, never on `permanent | ambiguous`. R-RT-2 identical bytes: the attempt re-sends `serialize(plan)`; the plan is immutable for the life of the `model_call_id`. R-RT-3 attempts share the reservation (ADR-0040) and the `model_call_id`; each attempt is a ledger span (M4). R-RT-4 a server-supplied delay above `retry_after_cap_ms` is *reported* (`attempt.failed{will_retry: false, next_delay_ms}`) and the call fails with `rate_limited` — the envelope/router decides (pi's throw, goose's cap). R-RT-5 `pause_turn`, `empty_response` after retries, `invalid_response`, content-policy and account classes are terminal for the gateway; the control strategy's `retry`/`escalate` decision point (ADR-0016 `DecisionPoint`) or the router (C2, `model.rerouted`) opens a **new logical call** if it changes anything about the request — a request-changing "retry" is by definition a new `model_call_id` with `causes[] ∋ failed event`. R-RT-6 waiting on a connection slot is `queue_wait_ms` on the attempt (feeds `time.working_ms`).

### 6.5 Capability descriptor, discovery, drift and fingerprint

**Transport capability declaration** (per `WireDialect` × endpoint; tri-state `{supported, unsupported, unknown}`, declared → probed → `ConformanceRecord` with DRIFT, mirroring ADR-0013/ADR-0020): `streaming`, `usage_in_stream`, `usage_on_cancel`, `cache_semantics`, `cache_state_visible`, `count_tokens`, `deferred_requests`, `model_listing`, `snapshot_id_exposed`, `retry_after_honoured`, `seed_accepted`, `parallel_connections{max?}`, `websocket`. **Model capability declaration** stays in the Model Profile (ADR-0020: `context_window, max_output, image_input, native_function_calling, parallel_tool_calls, strict_schema_dialect, reasoning_replay, …`); this dossier adds two fields to propose to WS-C3 (sidecar): `seed_honoured` (tri-state; OQ-122) and `substitution_allowed` (whether served-model drift is tolerated for this binding). **Discovery** yields `ModelDiscoveryClaim{provider_model_id, context_window?, max_output?, modalities?, pricing?, snapshot_id?, provenance{origin = tool(endpoint), authority = external}}`; a profile *pins* values (authority `definition` at seal); at probe time `declared ≠ discovered` is DRIFT (experimental data, ADR-0004 semantics), and the precedence is **pinned wins** — goose's override→configured→canonical→default chain is replaced by "the sealed profile is the only runtime source; discovery is evidence". **Served-model drift**: `completed.served_model` ≠ `model_ref.provider_model_id` ⇒ `model.call.completed{served_model, substitution: provider_fallback | safety_routing | unknown}`; spend is derived at the served model (ADR-0039 `model_ref.serving_route`); the row is annotated for J3/J4 as a configuration-level drift (OQ-048: the model coordinate of that call is the served model). **Snapshot ids**: `ModelSnapshotRecord{provider, model_id, snapshot_id?, pinned, provenance = reported, observed_fingerprint?}` (WS-L4 ontology) is filled by the gateway from `served_model`/system-fingerprint fields where exposed. **Fingerprint probe** (OQ-111 proposal): a pre-registered prompt set P (|P| ≈ 8–16, short, deterministic-intent tasks), temperature 0, `seed_request` if `seed_accepted`, n ≥ 8 samples per prompt at experiment open and close (cadence per `Design`); record `{per_prompt_agreement_rate, multiset_hash, served_model, snapshot_id}` as a `ConformanceRecord` charged `instrument`; DRIFT when agreement or the modal output changes beyond the pre-registered band; policy: annotate every arm run between the probes, and split the arm at the drift boundary for reporting (never silently pool). Nondeterminism evidence (S-WS-C1-02) is why a single hash is inadmissible.

### 6.6 Usage, cost and timing emissions (ADR-0039/0043 obligations)

`model.call.completed/failed` payload (extending WS-B1 §6.3; CF sidecar): `{usage: UsageRecord{raw: opaque(owner = dialect), canonical: {tokens.input.uncached, tokens.input.cache_read, tokens.input.cache_write[ttl_class], tokens.output.visible, tokens.output.reasoning}, view: TokenVector (hh-inclusive/1), normalizer_ref (= the profile's `usage_mapping` version id, CF-106), available: bool, arrival}, cost?: Money{…, provenance ∈ {provider_reported, gateway_reported, estimated_from_pricing, unknown}, confidence, pricing_ref?}, timing: {latency_ms (request_sent→last_byte of the successful attempt), attempts, ttft_ms?, queue_wait_ms, measured_at = adapter}, stop_reason, stop_details?, served_model?, snapshot_id?, surface_ids{response_id}, rate_limit_snapshot?, error?}`. Rules: E-U1 the gateway normalises **once** and stamps `normalizer_ref` (OpenHands single-source precedent; ADR-0043 §5); E-U2 provider-reported cost (a `cost` field, a billed-units field) is `provider_reported` with `confidence = exact` only for the served model; a table price computed by the gateway is `estimated_from_pricing` with `pricing_ref` (ADR-0043 §4); E-U3 `usage.available = false` (cancelled streams on dialects with `usage_on_cancel = unsupported`, proxies that strip usage) ⇒ the L2 charge is `n/a`-shaped with `coverage` reduced, never `0`; E-U4 cache roles are emitted as the dialect delivers them; `cache_state` is `unknown` unless `cache_state_visible` (OQ-097 input to C4/J3); E-U5 attempt timing per M4; the logical `latency_ms` excludes failed attempts and `queue_wait_ms` (ADR-0043 §3); E-U6 every probe/discovery call is accounted with `charged_to = instrument`.

### 6.7 Acceptance criteria (the conformance suite; C0 unless marked)

- **AC-C1-1 Model-blind codec (T-LCD-01 analogue).** A static gate over the codec sources and the `WireDialect` documents finds no model identifier and no reference to profile fields; compiling the Stage-0 definition under the two minimal profiles (ADR-0020) produces two plans whose bytes differ only in profile-owned fields *and* the codec emits them without a branch (diff of codec inputs = diff of plans).
- **AC-C1-2 Golden streams.** For every C0 dialect, a fixture set of recorded wire transcripts (happy path; tool call with split JSON deltas; parallel calls; reasoning with signature; redacted reasoning; usage-only trailing chunk; proxy metadata frames; in-stream error frame; truncated tool call at max output; server-side substitution; cancellation mid-stream; zero-chunk stream; idle timeout) decodes to a canonical event sequence byte-identical to the expected document, and `collect(stream)` equals the fixture's expected `ModelMessage` in canonical form. Two independent codec implementations must agree (reproducible-builds discipline, ADR-0019 AC-1 style).
- **AC-C1-3 Grammar.** A property test over fixtures and fuzzed frame orderings never violates G1–G7; `completed` is reconstructible from `block.completed` events alone.
- **AC-C1-4 Error classification.** Every fixture error (status codes, `error.code`s, error texts per dialect) maps to exactly one `ModelErrorClass` with the expected `retry_class`; the `unknown` rate over the fixture set is 0; every `error_text_to_class` rule has a complete debt record or the dialect document fails to load (T-LCD-05).
- **AC-C1-5 Retries.** Under injected 429/5xx/idle-timeout sequences, attempts equal `min(failures+1, max_attempts)`, delays honour `retry-after` (seconds, ms, HTTP-date) within the cap, jitter stays within bounds, bytes are identical across attempts (hash equality), one `model.call.attempt.*` pair per attempt, one reservation for the logical call; a `permanent` 4xx is never retried; a delay above the cap yields `will_retry = false`.
- **AC-C1-6 Usage (shares AC-L2-1 / AC-I1-5).** Golden usage payloads in inclusive, exclusive, nested-details and flat shapes lower to the canonical decomposition with `input.total = uncached + cache_read + cache_write`, `normalizer_ref` stamped; cancelled and usage-stripped fixtures yield `available = false` and no zero charge.
- **AC-C1-7 Tool calls.** Split, out-of-order-index and interleaved argument deltas parse to the expected object; invalid JSON yields `Unparseable{invalid_json}` with the raw string preserved; truncation yields `Unparseable{truncated}` + `truncated = true`; provider ids appear only in `surface_ids`; `tool_call_id`s are allocated and nested under `model_call_id`; no case-folding or rewriting occurs.
- **AC-C1-8 Opaque round-trip.** Reasoning/thought/text signatures survive `decode → ledger → render` byte-for-byte with `owner` stamped; the gateway never emits an interpreted view of them.
- **AC-C1-9 Drift facts.** A substitution fixture yields `served_model ≠ requested`, cost priced at the served model, and a drift annotation; a discovery fixture contradicting a pinned profile value yields a `ConformanceRecord{verdict: DRIFT}` and no profile mutation.
- **AC-C1-10 Accounting completeness.** Projecting a Stage-3 run yields exactly one charge per `model.call.completed/failed` (AC-L2-2) and one attempt span per attempt (ADR-0043 AC); probes are `instrument`.
- **AC-C1-11 Out-of-process (T-LCD-12).** The recording/fake gateway variant binds in the same slot as the live variant and the acceptance suite is unchanged; the live variant can run as a separate process exchanging canonical documents (not the default binding).
- **AC-C1-12 Fingerprint probe (Stage 3).** On a fixed fake endpoint with injected output distributions, the probe reports agreement rates and flags DRIFT exactly when the injected distribution shifts beyond the band; cost is charged `instrument`.
- **AC-C1-13 Secrets and egress.** No credential material appears in any ledger blob or event; an endpoint outside the H4 allow-list is refused before any bytes leave.

### 6.8 Build-stage suggestion

- **Stage 0 (minimal baseline):** one wire dialect (the Stage-0 baseline's provider family), `open_call/stream/complete/cancel`, `native_fc` only, usage + `latency_ms` on `model.call.completed`, one hard-coded `AttemptPolicy`, no probes.
- **C0 / Stage 1:** the normalized event grammar and `ModelMessage`; closed `StopReason`/`ModelErrorClass`; `WireDialect/1` schema with debt records; `AttemptPolicy` as data; `model.call.attempt.*` and the §6.6 payload; `usage_mapping`/`normalizer_ref`; golden-stream suite for the first dialect (AC-C1-1…8, 10, 11, 13); recording/fake variant.
- **C0 / Stage 3 (evaluation-first):** a **second wire dialect** (recommended: choose ADR-0020's second minimal profile from a different provider family so T-LCD-04's two-profile compile also exercises two codecs), transport probes, discovery claims + DRIFT, served-model drift, fingerprint probe (AC-C1-9, 12), `estimate_tokens` for F2 reservations.
- **C1 / Stage 5:** deferred/background requests (`stop_reason = deferred`), websocket framing, connection adaptivity and `queue_wait_ms` tuning, count-tokens endpoints, dialect descriptor governance cadence (with C3/I6), OTel lowering with I1.
- **C2:** interposition variant for model-boundary interception (J6, OQ-038) reusing the same codec set and emitting the same events with `participant_class = hosted`; `freeform`/`shim`/`code_mode` wrappers (E2/C3).

### 6.9 Interposition and hosted participants (input to WS-J6; non-blocking)

The `InferenceRequest → ModelEventStream` pair is also the natural *interception schema*: an intercepting variant decodes a hosted participant's outbound provider request with the same dialect codec, emits the same events stamped `participant_class = hosted, observability_level ⊇ {model_io}`, and charges with `provenance = measured` (ADR-0039 §4 mechanism table) — the Inspect agent-bridge shape (S-136/S-137). Because interception yields no plan hash and no compiled identity, `context.artefact.delivered` cannot be emitted for such calls (closed-world rule applies to native calls only), which is exactly ADR-0013's "hosted stays hosted" ruling (OQ-048). No native contract changes for this (T-LCD-06).

### 6.10 Dependencies and reconciliation with upstream

- **WS-A4 / ADR-0019 / ADR-0021 (consumed):** the provider tool-API target artefact *is* the `ProviderRequestPlan` minus the transcript; the plan's dialect schema is the lowering target's schema; `relower` on model switch changes the plan and (if the family changes) the dialect — the gateway sees a new plan hash on the next call, nothing else. **OQ-072 closed:** consume as data; transport only.
- **WS-A4 / ADR-0020 (consumed; two additions proposed to WS-C3):** `usage_mapping` stays profile-owned (CF-106); propose `seed_honoured` and `substitution_allowed` capability fields; propose no new `ProfileRule.kind` — dialect-side rules live in `WireDialect` (sidecar CF).
- **WS-A3 (consumed):** `OpaqueLeaf` = `CompiledPayload`-class opaque with owner; provider explanations are `Text(authority = external)`; model output is `delegate` (ADR-0033).
- **WS-L2 / ADR-0039/0040 (consumed):** reservation before dispatch (`MissingReservation` refusal); charges idempotent on `(source_event, dimension)` so a crash between attempt and charge never double-charges; `instrument` attribution for probes; `n/a` never 0.
- **WS-I1 / ADR-0043 (consumed):** M3/M4 emitted here; `measured_at = adapter`; propose renaming the enum value `gateway` to `external_gateway` to avoid collision with this component's name (sidecar CF).
- **WS-B1 / ADR-0026/0027 (consumed; payload extension proposed):** `model.call.requested/completed/failed` payloads per §6.1/§6.6; `model.call.attempt.*` per CF-089; `model.stream.delta` remains ephemeral; `served_model` and `usage.available` added (sidecar CF).
- **WS-D1 (OQ-063):** agreed — D1 renders; the gateway receives rendered material and `context_label`.
- **WS-C2:** consumes `provider.notice{rate_limit_snapshot}`, `ModelError.retry_class`, `served_model`; owns `model.rerouted`.
- **WS-C4:** consumes cache roles and `cache_state`; owns markers policy (through the profile) and semantic caching.
- **WS-F2:** reserves and checks; consumes `estimate_tokens`; owns the exhaustion rule; opens new logical calls for request-changing retries.

## 10. Confidence

**High** for the contract shape (operations, plan-as-data, model-blind codec, event grammar, opaque leaves, terminal reconstructibility): each element is read directly in ≥3 production gateways at pinned commits and two protocol specifications, and it composes with the ratified ADR-0019/0020/0039/0043 obligations without amendment. **High** for the closed stop-reason/error-class cores and the identical-bytes retry rule (the same values recur across seven systems; the counter-patterns are documented failures in their own comments). **Medium** for the `WireDialect` descriptor as *data with debt records*: the precedent is partial (codex/goose keep transport config as data; nobody keeps textual classification as expirable data), so it is `novel as integrated`; the risk is governance overhead, mitigated by one rule per (dialect, class) and fixture-based removal tests. **Medium** for the fingerprint/drift design: the nondeterminism mechanism is solid (Tier B with a reproducible recipe, corroborated by a `provisional` preprint) but the probe's parameters are unvalidated (OQ-WS-C1-02). **Low** on any quantitative claim (nondeterminism rates, cache cost multipliers) — none is load-bearing. Reflexively: this dossier assumes providers keep exposing per-call usage and a served-model id; the `available`/`unknown` fields exist because that assumption fails for proxies and some cancellations.
