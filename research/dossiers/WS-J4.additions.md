| CF-337 | ADR-0045 (`interval_method` enum `{clt, clustered_clt(task), wilson, bootstrap, bayesian_beta}`) vs ADR-0158 | The ratified enum cannot express a paired bootstrap (BCa/percentile), a permutation or signed-rank test, a declared prior, or a labelled substitution; unclustered `clt` is inadmissible for task-level metrics with replicates and for heavy-tailed units, yet the enum lists it without a floor. | Dialect bump (additive): `interval_method ⊇ {bootstrap_paired{bca | percentile}, bayesian_beta{prior}}`; `ComparisonReport` gains `test{kind}`, `sign_profile`, `tail_effects`, `EstimatorSelection`, `outcome_bounds`, `multiplicity`; `clt` retained but admissible only via the selection rule (floors) and never for `unit ∈ {tokens, money, ms}`. ## Ontology terms

| term | definition | notes |
|---|---|---|
| analysis spec / analysis report / cell | `AnalysisSpec{kind, selection: ResultsQuery{watermark}, design_ref, pre_registration_ref?, estimator_policy, model_form?, resampling{draws, seed, plan}, label}` (content-addressed) → `AnalysisReport{report_id, generated_from{row_watermark, run_ids_hash, metric_registry_version, price_table_version, seed, draws}, cells[], diagnostics[], labels, provenance}`; a cell is one `(key, metric)` result with value or `n/a{reason}`, interval, test, bounds and label. | ADR-0157; ontology §4g "reports" column. Persisted by J5; rendered by K2. |
| estimator selection / interval substitution | `EstimatorSelection{declared, floors{T_clt, T_bca}, fallback_chain, substituted?: {from, to, reason}}` recorded on every interval; a substitution is a labelled report fact, never a warning. | ADR-0158. lm-eval `stderr_for_metric` made declarative. |
| contrast (difference-of-differences) interaction estimate | For factors F₁, F₂: the paired difference over tasks of two paired harness effects at matched budget (e.g. Δ_{h|m₁} − Δ_{h|m₂}) over fully crossed *probed* cells, cluster-bootstrapped by task; the default `model_form` and the T-LCD-09 canned analysis. | ADR-0158. Never interpolates categorical axes (ADR-0012). |
| sign profile | `{helped, hurt, unchanged}` task counts for a paired comparison. | ADR-0158. |
| tail effect | The paired effect on a quantile (P50, P95) or the max of a heavy-tailed metric, with a bootstrap interval; reported beside the mean effect for `unit ∈ {tokens, money, ms}`. | ADR-0158. |
| outcome-class sensitivity bounds (`robust` / `sensitive`) | `outcome_bounds{lower, upper, verdict}`: the paired effect recomputed with every excluded (`infrastructure_failure`, `oracle_failure`, `cancelled`) run of one arm set to failure and of the other to success, and vice versa (Manski bounds); `sensitive` is a report state naming cells to re-run, never a refusal. | ADR-0157; S-522. |
| confirmatory / exploratory / preview (report labels) | `confirmatory` requires a matching `PreRegistration` and Holm control on primaries; `exploratory` carries BH q-values; `preview` uses reduced draws and is never persisted as confirmatory. | ADR-0157. Readiness rule: unlabelled claims fail. |
| resample plan | `ResamplePlan{levels: [family?, task, replicate?], draws, seed, indices_ref}` — one per report, shared by every metric; hierarchical when `Design.blocking` nests. | ADR-0157/2; METR precedent. |
| frontier-membership probability | Fraction of task-resamples in which a configuration is non-dominated on a `(cost, capability)` frontier that includes the origin; a report field beside the deterministic `on_frontier`. | ADR-0159. |
| cost-of-pass | `E[cost per attempt] / P(success)` per configuration (task-averaged, bootstrap interval); `n/a{estimator_undefined}` when the success interval includes 0; frontier cost-of-pass = min over compared systems. | ADR-0159; S-509. |
| transfer ratio / sign stability | `transfer_ratio = Δ_held_out / Δ_in` (paired bootstrap interval; `n/a` when Δ_in's interval includes 0); `sign_stability` = fraction of held-out levels whose Δ shares Δ_in's sign with an interval excluding 0. Conditionality region (existing term) is reused unchanged. | ADR-0159; ADR-0012. |
| search baseline (`oracle_best_of_n`, `selected_best_of_n`) | The equal-search-budget baseline ADR-0046 decision 4 requires, synthesized from the baseline arm's replicates: pass@N (oracle; labelled upper bound) or the recorded selector's pick; `n/a` when replicates < N. | ADR-0159; S-235. |
| indistinguishable set / rank interval | `rank()` output: per-configuration rank intervals from task resampling and a partition into sets whose members' paired-Δ intervals overlap; leaderboards render sets. | ADR-0158; S-510. |
| known-answer dataset (KA) | A deterministic synthetic generator with recorded seed and known truth (effect, interaction, frontier, ties, expiry event) against which an estimator's coverage, bias and `n/a` behaviour are checked at a Stage gate. | WS-J4 dossier §6.7 (KA-1…13). |
| surface model form / surface status | `model_form ∈ {contrast, factorial_glmm, curve_on_ordered_axis}` declared on a `FittedSurfaceReport`; `status ∈ {active, expiring, expired}` driven by the report's assumption-debt expiry. | ADR-0160; amends ontology §4f (additive fields `unknown_cells`, `status`, `debt_record_ref`, `portability`). |
