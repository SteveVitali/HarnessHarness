## Ontology terms

| term | definition | notes |
|---|---|---|
| audit-grade event | A run-ledger event of a class in the closed audit-grade list: `durability = ledger` forced, `audit_fields` inline and content-free, producer restricted to kernel components, obligations declared. | ADR-0066; not a new event, a classification |
| audit field / content ref (content-free envelope rule) | The partition of an audit-grade payload into inline, canonical, non-redactable, non-offloadable fields (ids, hashes, closed enums, integers, `ContentAddress`es, provenance) and redactable `ContentAddress` references. | Rule C; precedent Codex `log_only`/`trace_safe` split (ADR-0044) |
| audit obligation / audit coverage | A declared rule `∀ e:Class ∃ e':Class' linked by field` over a run's durable prefix; coverage = the set of unmet obligations computed by `audit_view`. | Rule O; MUST-data in `AuditPolicy` |
| audit checkpoint (tree head, signed checkpoint) | `security.audit.checkpoint`: an RFC 6962 root over the run's leaf hashes `[0, tree_size)` plus `chain_hash`, previous-checkpoint link, cross-run anchors and one or more kernel signatures; kinds `periodic, effect_terminal, final, rotation, on_demand`. | Shape: C2SP/Rekor signed note; CloudTrail digest chaining; extends ADR-0029 decision 3 and ADR-0036's rotation checkpoint |
| inclusion proof / consistency proof | Logarithmic proofs that an event is under a checkpoint head / that a later head extends an earlier one; verified by pure functions. | RFC 6962; transparency-dev/merkle `proof/verify.go` |
| auditor (role) / audit receipt | A subscriber outside the run's writer that recomputes heads, compares them with signed checkpoints and stores `(run, checkpoint_ref, tree_size, tree_head, signatures)` in a place the writer cannot write (results store, bundle, parent run, lab audit index). | Crosby–Wallach auditor; Logos observer node; Schneier–Kelsey trusted verifier T |
| equivocation / split view | The presentation of two different heads for one `(run, tree_size)` to different auditors, or a rewritten fork/child prefix under an untouched parent; detected by auditor comparison and cross-run anchors. | `Tampered{fork_equivocation}`; C2SP split-view |
| cross-run anchor | A head hash recorded on a cross-run edge in both directions: `parent_head_at_spawn` on `control.subagent.spawned`, `parent_anchor` on the child's `lifecycle.run.created`, child `final` head on `result/cancelled`, `source_head_hash` on `lifecycle.run.forked`. | Extends ADR-0027 fork anchor to delegation |
| audit reference (`audit_ref`) | `{run_id, seq, hash, checkpoint_ref, inclusion_proof?}` — the verifiable citation form used by results rows, bundles, viewer links and metric `computed_from[]`. | Extends `EventRef` (ADR-0027) |
| tombstone (`redacted` / `gc`) | The two audit-grade records that must precede byte deletion of a blob: `lifecycle.ledger.redacted` (endorsed, with basis) and `lifecycle.ledger.gc` (retention policy); both carry the addresses as `content_fingerprints`. | ADR-0068; IETF draft `content_fingerprint`; ADR-0037 I3 |
| audit retention floor | The minimum retention of audit-grade envelopes, checkpoints and anchors (`AuditPolicy.retention.audit_envelope_floor`), ordered ≥ experiment/bundle retention ≥ blob tier policy. | Durations owned by WS-L6 (OQ-173) |
| kernel signer record | `KernelSignerRecord{key_id, public_key_ref, alg_ref, custodian, valid_from, valid_until, superseded_by?}` in the run manifest and `InstrumentRecord`; private key readable only by the kernel (`readers = {kernel}`). | Custody: OQ-170 with WS-H3 |
| witness cosignature (C2) | A timestamped signature by a party outside the host over the same checkpoint note, given only after verifying consistency with the largest head that witness has seen; quorum policy in `AuditPolicy.witness_policy`. | C2SP tlog-cosignature |
| receiver receipt (C2) | A receiver-signed record of an effect as observed by its target, lifted into the ledger as an `unverified`/`external` link on the effect; a capability-vector entry (`receipts`) for hosted participants and executors. | S-324; T-LCD-07 |
| audit policy | `AuditPolicy{cadence, signer_key_ids, witness_policy?, retention, obligations, redaction_authority}` — the MUST-data record referenced by the run manifest (`audit_policy_ref`) and pinned in the bundle. | ADR-0024 ladder: data |
| decision scope | `decision_scope ∈ {once, session, persisted}` on `security.permission.decided`: whether a decision applies to one effect, is cached for the session, or persists as a rule; scopes other than `once` require a `security.permission.granted`. | Codex `ReviewDecision` variants as fixture set |
| audit completeness (amended) | Component vector `{chain_ok, checkpoints_ok, scopes_closed, blobs_accounted, producers_ok, coverage_ok, cross_run_ok | n/a}` with `headline = ∧ applicable`; a `veto: true` security-dimension metric. | Amends the v1 term (ADR-0044) — ADR-0068 |
