## Ontology terms

| term | definition | notes |
|---|---|---|
| value-of-compute scheduler / compute policy (`compute_policy`) | Registered component class (home: control plane, cardinality `exactly-one`) invoked by the driver between `decide` and `envelope.check`; binds parameters a strategy left unbound, tightens bound ones, or advises model-owned points; never proposes, refuses, grants, widens or owns β. Null variant `static`. | WS-F4 ADR-0188. Distinct from *control strategy* (proposes), *control envelope* (checks) and the *experiment scheduler* (J3, instrument level). |
| compute option (`ComputeOption`) | Closed sum `{continue_as_configured, spawn_subagent, extend_search{additional_sample \| additional_branch \| retry_task \| continue_generation}, evaluator, effort_level, alternate_role, stop_now}`; extension by dialect bump. | Every option maps to a parameter of a ratified decision or record (ADR-0103/0107/0117/0121/0123/0134). |
| marginal-value estimate (`MarginalValueEstimate`) | `{delta_p_success{point, interval, source}, expected_cost: ResourceVector, expected_latency_ms, risk: RiskEstimate, oracle_conditionality, evidence_refs[]}`; `unknown` never ranks above `continue_as_configured`. | WS-F4 ADR-0189. |
| compute decision record / `control.compute.decided` | The ledger record of one bind: options considered with estimates or typed infeasibility, chosen binding, estimator ref, priors used, inputs digest, rationale, cost of estimation; linked to the `control.decision` it bound. | WS-F4 ADR-0188; CF-401. |
| bind step (bind / tighten / advise) | The monotone driver-loop step: bind unbound parameters, tighten bound ones (never widen, never change kind/point/owner), or emit `compute_advice`. | Amends ADR-0103 decision 4 (CF-400). |
| compute advice (`compute_advice`) | A typed `ContextItem` artifact kind rendered through the Model Profile for model-owned decision points; delivery/activation/following measured (T-LCD-13). | Never affects `bind`. |
| compute estimator (`compute_estimator`) | Registered class with `estimate/observe`; variants `rules` (C3 baseline, no model calls), `bandit` (windowed/discounted, drift-reset), `surface_prior` (read-only evidence refs), `predictor` (C4 via I5). | WS-F4 ADR-0189. |
| prior cell / prior reset | `PriorCell{key: (profile version_id, snapshot fingerprint, task_class, option), stats, window \| discount, valid_until}` — a kernel-derived materialized view; `control.compute.prior_reset` on drift or supersession marks a family `unknown` until `min_n`. | ADR-0078 view, not derived memory. |
| stability signal | Agreement rate / answer-set entropy over canonical output hashes or validator verdicts among samples produced so far; an estimator input ranked below validator verdicts; never computed over `Text`. | Adaptive-Consistency / Certaindex shape with the hedge-word regex rejected. |
| task value (`TaskValue`) | `{success_value, failure_cost \| from_reversibility, currency}` on the task contract; the unit of the scheduler's objective. | CF-405; OQ-419. |
| scheduling overhead (`harness_overhead.scheduling`) | Attribution bucket for every estimator model call and Lab-side allocator cost; `rules` is zero by construction; capped by `budget_share_cap`. | ADR-0043 `cost_view.by_attribution`. |
| oracle allocation | A hindsight row synthesized by J4 from a `uniform` arm's replicates (per task, the cheapest option set that succeeded); an upper bound, labelled as such; yields `scheduling.regret_vs_oracle`. | ADR-0159 `oracle_best_of_n` pattern. |
| value-of-information validation strategy (`voi_weighted`) | A `ValidationStrategy` variant choosing the next `(candidate, task, replicate)` cells inside `adaptive_search` by disagreement or expected information gain; search-only; rows `estimated`. | CF-402; S-082 mechanism. |
