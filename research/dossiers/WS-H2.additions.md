## Ontology terms

| term | definition | notes |
|---|---|---|
| **flow contract** | The declaration on a `ToolCapability` of its label *contribution* (taint tags added, readers restricted to), the resources it reads, its recipient and content parameters, whether it labels typed leaves, and how recipients are resolved; required at `seal` for open-world and egress capabilities. | WS-H2 / WS-E1; APPA `d_τ`, Fides τ(x), CaMeL `inner_sources`; C2 |
| **declared contribution** | The partial label `d_τ` a capability adds to any call's label regardless of arguments; the basis of the prospective post-call label. | WS-H2; APPA |
| **prospective post-call label** | `L⁺(p) = L(p) ⊔ d_τ`, the label a proposal will have after the tool runs; the C2 monitor checks flow and taint against it (reactive checking is unsound for composite tools). | WS-H2 / WS-H1; APPA necessity proposition |
| **admission** | The kernel's re-validation of a realized tool result against the capability's declared contribution before it enters context; realized-more-restrictive is admitted as realized, less-restrictive at the declared label (`AdmissionNarrowed`). | WS-H2 / WS-B1; APPA admission gate |
| **quarantine handle** / **quarantine slot** | A typed leaf `{handle_id, label, schema?, capacity_bits?, blob_ref}` standing for a value above the context label; its content is never rendered as `Text`; it joins into an argument's label when passed to a tool but never into the context label of later calls; a slot whose items are delivered as handles. | WS-H2 / WS-D1; Fides `Hide`, CaMeL variables, LIO labeled values; answers OQ-105 |
| **label branch** | A child process spawned with `isolation = label_branch`: seeded with the parent's context label (never top), bounded by the parent's clearance, exiting by `abandon`, `labeled_return` or `attested_return`; its approvals never transfer to the parent. | WS-H2 / WS-F3; APPA child trajectory; extends ADR-0034 P2 |
| **clearance** | The upper bound on a process's effective authority = the parent's effective authority at spawn (ADR-0034 P2's ceiling, named); LIO's current clearance. | WS-H2 / WS-F3 / WS-H1 |
| **remedy** / **recovery graph** | A typed, non-widening move the monitor offers with `ask`/`deny`: `approval(effect_id) \| sanitize \| shape_endorse \| branch \| substitute \| prerequisite`; the finite graph of such moves over `(Label, effect projection)`, enumerated deterministically by bounded search. | WS-H2 / WS-H1 / WS-H7; APPA Theorem 5; ACP `RequestPermission`, CaMeL Q-LLM refusal |
| **bounded sanitizer** | A deterministic Validator/Procedure registered in the sealed definition with `bounds{from, to, removes}` whose output is endorsed under the `policy_rule` basis; `SanitizerBoundExceeded` if the realized output exceeds `to`. | WS-H2 / WS-G1; APPA sanitizers; reconciles ADR-0034 P1 |
| **capacity-bounded schema** / **capacity_bits** | A schema with a finite value space (booleans, closed enums, bounded numerics/dates, fixed-shape records and bounded arrays of those) and `capacity_bits = ⌈log₂\|values\|⌉`; the only schemas eligible for shape endorsement, up to a per-definition `cap_max`. | WS-H2 / WS-G1; Fides type lattice, APPA attest-schema; answers OQ-106 |
| **flow policy** / **flow rule** | A `HarnessRule` action carrying rules `{selector, condition, decision ∈ {deny, allow, declassify, sanitize}}` in the closed predicate language over labels × canonical arguments × effect projection; evaluated deny → allow/declassify → Π default. | WS-H2 / WS-H1 / WS-A3; CaMeL/Fides policies, Cedar |
| **policy edit classification** | `classify_policy_edit(P, P′) → narrowing \| widening \| incomparable`, exact over the closed language; `delegate`-origin edits apply only when `narrowing`; otherwise a widening `HirDiff` (ADR-0017). | WS-H2 / WS-I5; Progent SMT check, Cedar analyzability |
| **enforcement class** | `deterministic \| advisory` on every check and decision input; advisory inputs may add rows to Π's inputs or propose remedies, never set a label or a decision class; an advisory lowering is a declassification. | WS-H2 / WS-H1 / WS-I2 |
| **robust declassification (D-ROBUST)** | The precondition that no input to an endorsement/declassification decision (recipient parameters, sanitizer selectors, approval subject) has `effective_authority ≤ external` or `taint ≠ ∅` unless shape-endorsed; violation `RobustnessViolated`. | WS-H2 / WS-H1 / WS-H7; Zdancewic–Myers; Fides `policy_no_untrusted_declassification` |
| **explicit secrecy** | The confidentiality guarantee the scheme claims: no value reaches a recipient outside its reader set through an explicit argument or declared contribution; implicit flows through effect sequences are not covered. | WS-H2; Fides |
| **effect projection** | `project(run, effects, until_seq)`: the finite set of committed `(EffectClass, args_canonical_hash, phase)` a flow rule's history predicates range over. | WS-H2 / WS-B1 / WS-B2; ADR-0026 views; APPA committed-effect projection |
