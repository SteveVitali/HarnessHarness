## Ontology terms

| term | definition | notes |
|---|---|---|
| **secret channel** / `SecretRef` | A named, versioned credential registration (`SecretChannel{channel_id, spec, revision, provenance}`) whose value exists only inside the credential broker; referenced everywhere else by the typed leaf `SecretRef{channel_id}`; identity is the logical name (value and placeholders excluded). | WS-H3; aligns ADR-0025 "channel names" and ADR-0026 "references only". |
| **credential broker** | The kernel MUST-code component (credential delivery point) that registers channels, binds them into environment handles as placeholders, mediates each use just-in-time, mints scoped tokens, revokes and rotates; never decides authority. | WS-H3; CB4A CDP; Codex `network-proxy` credential broker precedent. |
| **delivery mode** | `{proxy_injected, minted_scoped, wrapped_long_lived}` — how a bound channel becomes an authenticated action; declared per channel as an ordered allow-list; kernel preference A > B > C. | WS-H3; CB4A Models A/B/C. |
| **placeholder credential** | The random, recognisably prefixed value that stands in for a channel inside an environment handle, snapshot or fork; substituted only by `mediate`. | WS-H3; Codex dummy value; agent-vault placeholder. |
| **credential binding** | `CredentialBinding{binding_id, run_id, env_handle, channel_id, permission_id, mode, placeholder?, expires_at, revision, state}` — the run-scoped object that ties a channel to an environment under a `secret_access` `Permission`; lifetime ⊆ run. | WS-H3; allocated id (ADR-0036). |
| **secret fingerprint** | `SecretFingerprint{channel_id, revision, prefix}` — keyed, truncated, irreversible hash of a value used as the mask token and as the correlation key in ledger events and leak findings. | WS-H3; parameters OQ-WS-H3-04. |
| **redaction-at-source** | The deterministic (`kernel` deriver) masking of known secret values, placeholders' counterparts, patterns and canaries applied before an observation is model-visible, before a ledger append, on snapshots and on every export delivery. | WS-H3; distinct from `SinkPolicy.redaction` (content classes) and from `lifecycle.ledger.redacted` (post-hoc tombstone). |
| **secret-visibility invariant** (SV-n) | The closed list SV-1…SV-10 of surfaces that must be value-free and the enforcement for each. | WS-H3-adr-1. |
| **leak test** / `secret_leak` | An acceptance oracle from the battery LT-01…LT-12; `secret_leak` is the class-scoped `veto: true` metric family (`ledger`, `model_io`, `end_state` variants). | WS-H3-adr-3; ADR-0045/0047. |
| **canary channel** | A registered channel with `canary: true` that the broker never injects; any mediation attempt or destination observation of it is `security.secret.leak_detected`. | WS-H3; honeytoken precedent (S-WS-H3-07, CB4A TM-6). |
| **credential_supply** | The Hosting ABI capability-declaration field by which a hosted participant declares which channels and modes it can accept; undeclared = `unknown` = nothing bound. | WS-H3 → WS-J6; T-LCD-07. |
| **kernel-internal channel** | A secret channel with `bindable = false` that can never be bound into an environment handle and is used only by kernel components through `kernel_use(channel_id, purpose, caller)` — the ledger signer key (WS-H6-adr-2), the model-gateway credential (WS-C1, OQ-WS-H3-01), the vault credential; every use is audited with `destination = kernel:<component>`. | WS-H3; producer rule per WS-H6-adr-1. |
