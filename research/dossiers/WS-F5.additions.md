## Ontology terms

| term | definition | notes |
|---|---|---|
| coordination object / `CoordinationObjectKey` | A thing more than one AgentProcess could write: closed sum `ledger{run_id} \| workspace{env_handle_id, subtree} \| memory_scope{scope, store} \| artifact_name{name} \| resource{key} \| budget_node{budget_id}`. | WS-F5 ADR-1; dialect-closed |
| ownership record | `OwnershipRecord{object, owner: RunId, mode ∈ {exclusive, shared_read}, granted_by: EventRef, lease_ref, valid, on_owner_end ∈ {return_to_grantor, detach_to_owner}}`; at most one valid per `(object, seq)`; derived view `ownership_table`. | WS-F5 ADR-1 |
| one-writer-per-object rule | For every coordination object and `seq` exactly one AgentProcess may write it; ownership is conferred at spawn or by ledgered transfer, never discovered; writes are fenced by the owner's `lease_generation`. | Generalises ADR-0026 §5; Logos "every key has exactly one writer"; Symphony "one authority" |
| ownership transfer / return / escrow | `control.ownership.transferred{object, from, to, basis}`; return = transfer back in the child's terminal transaction; escrow = a `return_to_grantor` ownership held for a grantor run that has not yet restored. | WS-F5 ADR-1/3; OQ-WS-F5-05 |
| resource key | Canonical closed schema `{fs_path, host, port, tracker_item, vcs_ref, secret_ref, custom(ns, bytes)}` naming a shared resource for `resource(key)` leases (ADR-0130). | extends ADR-0087 scope binding `resource_key`; OQ-WS-F5-03 |
| merge policy | Closed sum `single_writer \| append{dedup_by} \| conflict_set \| three_way_text{base, tokenizer} \| validator_selected{validator_ref} \| parent_decides`; no value means "newest wins". | WS-F5 ADR-2; LangGraph reducer precedent |
| merge conflict / merge resolution | `MergeConflict{conflict_id, object, base_ref?, sides[], detector, resolution?, resolved_by?}`; `MergeResolution = choose \| supersede \| coexist \| escalate \| abandon`, each a ledgered `control.merge.resolved`. | WS-F5 ADR-2 |
| merge report | `MergeReport{merge_id, parent_run_id, children[], merged[], conflicts[], absent[], lost_write_count, provenance, derived_from}` — derived view cited by the parent's completion claim. | WS-F5 ADR-2 |
| merge proposal | A non-owner's proposed new version of an owned object, queued (`append`) for the owner; never applied without the owner's ledgered action. | WS-F5 ADR-1/2 |
| lost write / silent overwrite | Lost write: a child-committed, applied write absent from both `merged[].inputs` and `conflicts[].sides`. Silent overwrite: a merged output equal to one side of an unresolved single-writer/keyed conflict. Both are `veto: true` metrics. | WS-F5 ADR-2; AC-F5-01/-02 |
| child result / child outcome | `ChildResult{child_run_id, claims[], artifacts[], memories_written[], fs_changeset_ref?, effects_irreversible[], cost, child_head}`; `ChildOutcome = result \| cancelled \| budget_exhausted \| stop \| infrastructure_failure \| unknown \| refused_at_spawn` (closed). | WS-F5 ADR-3 |
| absent child | A child whose `ChildOutcome ≠ result`; contributes nothing to `merged[]`; blocks dependent completion claims under `on_absent_child = block_completion`. | WS-F5 ADR-2 G-5 |
| peer message / messaging policy | A `ContextItem{kind: peer_message}` delivered as a wakeup occurrence (`Trigger.peer_message{from}`) at a decision point, labelled `⊔(ctx(sender), delegate)`, never an endorsement or grant; `MessagingPolicy{parent_to_child, child_to_parent, sibling, broadcast, max_pending, coalesce}` is definition data. | WS-F5 ADR-1; Prime Agent/AutoGen shape |
| consistency level / consistency declaration | Closed sum `linearizable_single_writer \| snapshot_at_fork \| per_key_serializable \| causal_cross_run \| strong_eventual_union \| conflict_set_eventual`; `ConsistencyDeclaration{object \| kind, level, staleness_bound?, readers}` checked by the compiler against the ownership/`derive` mode and by the Stage-4 battery. | WS-F5 ADR-3; Jepsen hierarchy names |
| coordination policy | `CoordinationPolicy{messaging, merge_policies, declarations, default_isolation ∈ {fork_snapshot, scoped_subtree, share}, depth_cap, fan_out_cap, on_absent_child}` — MUST-data of the sealed definition; loosening diffs refused in evolution contexts. | WS-F5 ADR-3; CF-WS-F5-09 |
| failure domain (AgentProcess) | A child run's own ledger + writer lease + environment handle + budget node + attenuated handles + clearance + subscriptions; cross-domain edges are only spawn/terminal/message/ownership records. | WS-F5 ADR-3; doc 2 §5.7 |
