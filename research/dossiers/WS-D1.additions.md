## Ontology terms

| term | definition | notes |
|---|---|---|
| context builder | The `context_policy` component: a fixed **kernel admission** (operations `assemble`, `render`, `offload`, `emit` and invariants I-ID/I-RP/I-ORDER/I-LABEL/I-NOWIDEN/I-PAIR/I-ATOM/I-MEDIA/I-NOSYS/I-DET) plus a pluggable **selection policy** variant. | WS-D1 ADR-1. Distinct from AIOS's "context manager" (CF-WS-D1-05). |
| kernel admission | The non-pluggable step that decides which candidates may enter which slots, from records only (authority, validity, readers, identity, media), before any policy runs. | WS-D1 ADR-1 §3. |
| selection policy / context policy variant | A registered `ContextPolicy` variant with `select`, `priority`, `declare`; chooses membership among admitted candidates, admissible slot, within-slot order, eviction order, by-reference delivery and expansion requests; cannot touch authority, labels, validity, `required` or slot floors. | WS-D1 ADR-1 §1/§4; T-LCD-08/-12. |
| context candidate | `{candidate_id, context_item, kind, state ∈ {handle_only, expanded}, retention, estimate, source_event, slot_hint?, readers?}` — one thing the builder may deliver this call. | WS-D1 ADR-1 §2. |
| candidate kind | Closed sum (+ registered `ext`) `{kernel_notice, definition_instruction, principal_message, procedure_index, procedure_body, tool_surface, memory, observation, artifact_excerpt, transcript_item, budget_reminder, environment_state, subagent_result}`; never encodes a provider role. | Codex `content_kind` generalised. |
| retention class | `required` (never truncated or evicted; set only by the kernel or a `definition`-level rule) or `optional(PriorityClass)`. | WS-D1 ADR-2 §1. |
| priority class | Kernel-fixed closed eviction order `{commentary, observation_old, observation_recent, image, memory, procedure_body, transcript_tail}` + registered `ext`. | OQ-WS-D1-02. |
| slot / slot declaration | Profile-declared container `{slot_id, min_authority, admit_unknown_validity, admits, cardinality, cache_tier ∈ {static, dynamic, transcript}, diffable, budget_share?, order}`; the unit of role placement. | WS-D1 ADR-3 §2. |
| reserved slots | The six kernel-constant slots `kernel, definition, principal, transcript, external, unverified` with fixed `min_authority` equal to their name's class; every layout must declare them. | WS-D1 ADR-3 §1. |
| slot min-authority | The floor an item's authority must meet to enter a slot; `role_map(min_authority)` bounds the provider role the renderer may use. | ADR-0034 RP applied to slots. |
| layout | The ordered list of slot declarations compiled into `ModelSurface.layout` (profile-owned) plus the kernel's ordering rules. | ADR-0019/0020. |
| context plan | Content-addressed output of `assemble`: `{plan_id, model_call_id, derived_from, slots[SlotFill], omitted[], context_label, occupancy_estimate, legal_cut_points[], reserved}`; carries no provider role and no rendered text. | WS-D1 ADR-1 §2. |
| planned item | One admitted candidate in a slot with `delivery_id`, `authority`, `label`, `tokens`, `state`, `delivered_by_reference`. | — |
| omission record | `{candidate_id, reason ∈ {authority, validity, readers, budget, dedup, media_unsupported, cardinality, unidentified}, evidence}` listed in `context.assembled.omitted[]`. | Codex notice made data. |
| omission item | The kernel-authored `kernel`-slot item present whenever `omitted ≠ ∅`; names counts, never content; "omissions do not authorize actions". | WS-D1 ADR-2 §4. |
| delivered by reference (steady-state diff) | Delivery of a `diffable` slot section by pointing at an earlier `delivery_id` whose hash is unchanged; joins the label as if delivered; marked on `context.artefact.delivered.by_reference`. | Codex `WorldStateSection` precedent. |
| legal cut points | Indices of the plan/transcript at which deletion or summarisation preserves I-PAIR/I-ATOM; exported to WS-D2. | OpenHands `manipulation_indices`. |
| reserve-before-select | Kernel step reserving the tokens of kernel-mandated items (omission item, `advise` reminders, current-time, required framing) before the policy selects optional candidates. | Codex `input_budget.rs`. |
| offload handle | `{content_address, media_type, size, label, excerpt_report, read_capability}` — the addressable stand-in for a payload kept outside the window; carries the payload's label. | WS-D1 ADR-2 §5. |
| excerpt policy / excerpt report | `{max_lines, max_bytes, max_tokens?, mode ∈ {head, tail, head_tail}}` and `{truncated_by, total_lines, total_bytes, retained_range}`. | Pi `truncate.ts`. |
| tool-result clearing | Replacing an already-delivered observation by its offload handle (`derived_from = projection`, `deriver = kernel`); the cheapest compaction primitive. | S-038. |
| just-in-time context / progressive disclosure | Candidate state `handle_only` (index form) whose expansion is an observable effect producing an `expanded` candidate with a new `delivery_id` and a deterministic `context.artefact.activated`. | S-038, S-050, S-040. |
| quarantine slot | The reserved `external` slot: renders open-world and free-text content at ≤ `role_map(external)`; **joins** the context label (no label-exempt slot exists). | Answers OQ-105. |
| context window cap | The profile's declared context window as the cap of the `context.occupancy` gauge; exceeding it is `ContextWindowExceeded → CompactionRequired`, never a run stop. | ADR-0040 E5. |
| assembly error classes | `PolicyViolation`, `UndeliverableArtifact`, `ContextWindowExceeded`, `InvalidLayout`, `StaleView`, `EstimatorMismatch`, `MissingProvenance` — errors, never warnings. | — |
| rendered request | `{messages[], surfaces_revealed[], trace[(span → delivery_id)]}` — the builder's `render` output consumed by the C1 gateway as data. | Resolves OQ-063. |
