## Ontology terms

| term | definition | notes |
|---|---|---|
| execution alignment | The property that every claim a model makes about a run (observed / effected / verified / achieved / pending / progress) corresponds to what the runtime's authoritative handles show at the seq of evaluation; correspondence, not correctness (G1/G3) and not authority (H1). | S-062 definition adopted; doc 2 §5.3 "belief-state reconciliation" |
| claim | An `Observation{source: model_claim}` typed as `Claim{kind, subject, predicate, asserted, evidence_refs, extracted_by, extraction_confidence, provenance(authority = delegate), evidence_class = claimed}`; never evidence for a Validator by itself. | WS-G2 ADR-1 §1; ADR-0016 invariant |
| claim kind | Closed sum `observed \| effected \| verified \| achieved \| unachievable \| progress \| pending \| assumption`. | dialect-closed |
| claim surface | The compiled, profile-owned structured fields through which a model states claims (completion `finish{criteria_status, artifacts_claimed, open_items}`, progress artifact statuses, optional belief-probe fields); a conditioned rule with an assumption-debt record. | T-LCD-01/-05; precedents browser-use `is_done/success`, OpenHands task tracker |
| claim extraction channel | `structured` (surface field; confidence 1.0) · `parsed` (profile grammar over `Text`; capped confidence) · `judged` (G3 Validator of judge kind). | WS-G2 ADR-1 §2 |
| authoritative handle | A record at authority ≥ `environment` that can adjudicate a claim: `ledger_event`, `effect_state`, `validator_verdict`, `world_state`, `environment_probe`, `task_contract`, `progress_artifact_version`; never the model's own text. | WS-G2 ADR-1 §3 |
| reconciliation record | `{claim_id, agreement, divergence_class?, severity, detector, detector_ref, confidence, evidence_refs, probe_effect_ids, mode, charged_to, provenance}`; never mutates the claim; sets the claim's evidence class to `reconciled(agreement)` by projection. | WS-G2 ADR-1 §4 |
| agreement | Four-valued `agree \| diverge(class) \| unverifiable \| stale`; `unverifiable` never passes a required criterion. | runtime-verification impartiality (S-WS-G2-13) |
| divergence class | Closed sum D1 `phantom_observation`, D2 `phantom_effect`, D3 `unverified_verification`, D4 `stale_belief`, D5 `contract_gap`, D6 `open_effect_at_completion`, D7 `censored_evidence`, D8 `progress_regression`, D9 `evidence_inversion`, D10 `no_progress_loop`. | WS-G2 dossier §6.3 |
| completion gate / gate result / hold | `gate()` at `DecisionPoint.stop` → `{pass, hold{divergences, required_actions}, veto{invariant}}`; a hold consumes one unit of `reconciliation.holds`. | WS-G2 ADR-2 |
| reconciliation notice | Typed record `{record_ref, class, subject, expected, observed, suggested}` delivered as a D1 `kernel_notice` candidate at `kernel` authority; measured via the delivered/activated/followed chain. | never prose at elevated authority |
| censored evidence | Evidence a claim cites that the harness truncated, offloaded and never re-read, forgot in compaction, blocked (`refused`), or summarized at `delegate` authority; D7. | S-148, S-WS-G2-02 |
| false completion | An `achieved` claim whose gate verdict is `hold`/`veto` or that a deterministic oracle contradicts; veto-eligible metric `false_completion_rate`. | S-WS-G2-01 "false success" |
| honest failure | An `unachievable` claim reconciling to `agree`/`unverifiable`; passes the gate with `status = failed_honestly`; measured by `honest_failure_rate`. | S-WS-G2-01 HF |
| belief probe | A structured per-step elicitation of the model's beliefs (progress, risk, recoverability, constraints, failure mode, uncertainty, forecast, repair cost, next action) compared against handles and across harness views; C2 Lab instrument; `provisional`. | S-148 shape |
| reconciler (`execution_alignment` component class) | The component implementing `extract / bind / reconcile / gate / intervene / declare`; kernel floors exist without a bound variant; C2 variants add detectors, probes, notices, Γ tables. | WS-G2 ADR-3 §4 |
| severity record | `SeverityRecord{source_register ∈ {execution_alignment, security, effect}, level ∈ {info, low, medium, high, critical}, rule_ref}` — per-register ownership, shared shape. | OQ-125 answer |
