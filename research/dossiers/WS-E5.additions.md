## Ontology terms

| term | definition | notes |
|---|---|---|
| execution contract | The ordered per-effect stages `resolve → authorize → prepare → commit → execute → capture → observe`, kernel-owned, mapped onto the ADR-0030 lifecycle (`intended → authorized\|refused → prepared → committed → observed\|unknown`). | ADR-0100; refines the brief's five verbs (CF-216) |
| resolve (stage) | The pre-authorization stage: `SurfaceArgMap` → canonical params, pinned capability + executor binding, executor-registered deterministic assessors run by the kernel, `declared: EffectClass`, `resource_keys`, `deadline`. | inputs to WS-H1 `authorize` |
| execute (stage) | Dispatch of an `ExecutionRequest` to a bound executor through the helper boundary; exactly one per `(effect_id, attempt_no)`; gated by a `CommitToken` for non-`read_only` effects. | I-1 |
| capture (stage) | The concurrent stream of typed observed-effect signals from all sources, stamped by the kernel with effect identity and redacted before visibility. | ADR-0101 |
| tool executor | The registered component class that runs a bound `ToolCapability` version against an environment handle and *reports*; receives `(ModelProfile, ResourceAccount)`; never returns a permission, label, lower risk class or higher retryability. | ADR-0023 slot; outside the TCB (WS-H1 §6.5) |
| executor declaration | `ExecutorDeclaration{environment_class, isolation_min, capture_kinds, interrupt, partial_application, streaming, dedup_support, dedup_window?, probe_support, detached_processes, meters, on_kernel_loss, assessors[]}` — tri-state where applicable; validated at `bind`. | T-LCD-07 |
| execution request / execution id | The kernel-built dispatch record `{effect_id, attempt_no, execution_id, commit_token \| read_only_marker, capability_version, canonical_args, env_handle, containment_policy_ref, attribution_token, credential_bindings[], deadline, grace_ms, drain_ms, output_policy, resource_reservation_ref, idempotency_key, dedup_hint}`; `execution_id` is a kernel-chosen protocol key, never an OS pid. | Codex `process_id` precedent |
| commit token | The proof, derived from the durable `action.effect.committed` record, that a helper demands before executing a non-`read_only` request; absent/expired/forged ⇒ `NotCommitted`. | ADR-0030 barrier made verifiable at the boundary |
| attribution token | Opaque, kernel-minted, single-use-per-attempt token bound to `(run_id, effect_id, attempt_no, env_handle)`, delivered by the helper into the environment, resolved by mediators to an `effect_id`; unresolvable ⇒ refusal (net, credential) or `unattributed` (fs, process). Not a credential. | supersedes WS-H4's "executor-minted" wording (CF-213) |
| capture item (+ kinds) | `CaptureItem{structural ids, execution_id, seq, ts_mono, source, kind, payload, provenance}` with `kind ∈ {output_chunk, progress, fs_change, process, egress, credential_use, containment_violation, resource_usage, world_changed, structured_result, terminal}`. | closed sum; dialect bump to extend |
| capture source | `executor_reported \| helper_observed \| mediator_observed \| kernel_derived` — who produced a capture item; the kernel never upgrades an executor report to an observation of its own. | |
| effect capture manifest | The content-addressed record of an attempt's non-ephemeral capture items, `raw_output_ref`, `truncation`, `completeness`, `observers_present`, `residual_channels_ref`; referenced by `action.effect.observed.capture_manifest_ref`. | |
| capture completeness | `complete \| partial{reasons ⊆ {truncated, unobserved_channel(kind), drain_timeout, executor_unreported}} \| unknown` on every `observed`; `complete` only with every implied observer present and no residual channel for the domain. | never coerced (T-LCD-07) |
| error origin | `tool \| execution \| transport` — whether a failure came from the tool's own result, from the helper/kernel execution layer, or from the boundary; determines the lifecycle transition together with the effect risk class. | ADR-0102 |
| derived retryability | `retryable = f(ErrorClass, origin, effective_risk_class)` computed by the kernel; an executor `retryable_hint` may only lower it; retry *policy* is WS-F2's. | CF-061 |
| deadline hierarchy | `deadline = min(capability default, model-requested, budget remaining wall time, environment idle cap × ratio, turn deadline)` fixed at `prepare`, enforced locally by the helper (deadline dominance, I-6). | defaults MUST-data |
| grace / drain | `grace_ms` between graceful interrupt and kill; `drain_ms` to collect descendants' output after kill before `observe` proceeds. | Codex 50 ms / 2 000 ms precedent |
| two-phase interrupt | `interrupt(graceful)` → `grace_ms` → `interrupt(kill)` → `drain_ms`; the kill step is skipped before `deadline` for `compensable`/`irreversible` effects whose executor declares `interrupt ∉ {supported}`. | class-aware |
| detached child effect | A process reported `process{detached}` becomes an effect `{domain: spawn_process, parent_effect_id, state: committed}` owned by the environment handle; its output is captured under its own `effect_id`; terminated at `detach`/run terminal with an explicit `observed`. | answers OQ-090 |
| world-changed signal | Capture item `world_changed{scope ∈ {fs(paths), page(url), external(target)}, evidence_ref}`; re-validates queued sibling proposals' preconditions (`PreconditionViolated{stale_after}`). | browser-use `terminates_sequence` generalised |
| output policy / truncation record | `output_policy{retain_bytes_cap, model_view, offload_above, max_deltas}` and the typed `truncation{omitted_bytes, original_size, policy_ref}` on the observation and manifest; an omission is never silent. | |
| helper session | The persistent, resumable (`hello(resume_session_id)`) connection between the kernel and one sandbox helper per environment handle over which `attach/exec/read/signal/fs.*/egress.decision_request` run. | Codex exec-server precedent |
| sandbox helper boundary | The final OQ-045 placement: a separate helper binary behind a narrow, schema-versioned protocol through which the kernel drives OS isolation primitives; process handles are `execution_id`s. | ADR-0049 confirmed; ADR-0050 trigger 2 not fired |
