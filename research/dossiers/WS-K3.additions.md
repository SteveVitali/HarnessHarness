## Ontology terms

| term | definition | notes |
|---|---|---|
| exposure definition | A sealed Harness Definition (ADR-0023 `Assembly` grammar) whose `ToolCapability` entities wrap Lab operations by identity and whose `ExposurePolicy`, `CallerBinding`s, `Permission`s and `Budget`s govern an MCP-served surface; compiled through `compile` and served by `serve(bundle)`; the canonical one is `hh-lab/<n>`, pinned in the `InstrumentRecord`. | WS-K3; object-level document calling the instrument level (CF-366). |
| Lab catalogue | The MCP artefact (`DiscoverResult` + `ListToolsResult` [+ resources]) of an exposure definition's compiled bundle; byte-identical for every caller; listing is never authorization. | WS-K3; ADR-0097 statelessness applied. |
| supply surface | A harness bundle's compiled tool surfaces minus `hidden`, served over MCP to a hosted participant or external agent so that its calls are native effects in a HarnessHarness-owned run, mediated by the reference monitor with the caller as proposer. | WS-K3 / WS-J6 (`HostedRunSpec.supplies.tools`). |
| caller binding | The sealed MUST-data record `{binding_id, credential kind, principal_ref, caller_kind ∈ {agent, human_principal, provider_client, service}, authority_cap, permissions, budget_node, readers_identity, rate_policy?, expires_at?}` from which the kernel derives an external caller's `OpaqueProcess`, authority class and budget; identity comes from the transport binding (stdio launch record or H3-validated token), never from request content. | WS-K3; ADR-0053 D-4 hosted child at the boundary. |
| surface session | The `kind: surface` run opened per (server instance, caller binding) whose turns are the caller's `tools/call`s; the only state a K3 server has; the home of `charged_to = instrument` server work and of `measurement.export.delivered` for served pages; launched runs link back through `causes[]`. | WS-K3; WS-J3 "the experiment is a run" shape. |
| surface handle | A `surface_ids` alias of an allocated id (`run_handle`, `experiment_handle`, `session_handle`, `plan_handle`, cursor) returned by a Lab tool; a *name*, never a capability — authority to act on it is a kernel-held `AuthorityHandle` of the caller's process; opaque, bounded in lifetime, unknown/expired ⇒ tool execution error. | WS-K3; MCP "Stateful Tools" guidance restated on ADR-0051 terms. |
