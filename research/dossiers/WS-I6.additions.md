## Ontology terms

| term | definition | notes |
|---|---|---|
| debt home / `DebtHomes/1` | The closed inventory of record kinds that carry an `AssumptionDebtRecord`, each with its IR/registry binding, default `expiry_condition` and default `RemovalTest.kind`; a record on any other kind is `UnknownDebtHome`. | ADR-WS-I6-1 §1; seventeen homes; growth by dialect bump. |
| debt class | `model_conditioned \| provider_conditioned \| task_conditioned \| instrument_reflexive \| spec_decision` — what a conditioned rule is a hypothesis *about*. | Additive field on `AssumptionDebtRecord/1`. |
| deficiency class / `DeficiencyClass/1` | Closed enum naming the hypothesised beneficiary deficiency (`premature_stop`, `format_noncompliance`, `tool_shape_mismatch`, `name_misalignment`, `schema_dialect_gap`, `context_overflow_handling`, `loop_or_repetition`, `instruction_following_gap`, `claim_grounding_gap`, `reasoning_replay_incompatibility`, `latency_or_cost_profile`, `unknown{Text}`); paired with a `predicted_effect{metric_ref, direction}` that the removal test measures. | OQ-WS-I6-04 on closure at C0. |
| evidence grade | Derived, never stored: `hypothesized` (no instrument-produced evidence), `evidenced` (probe/compliance/conformance/calibration evidence), `confirmed` (a matched `comparison_report` with `artifact_benefit` on a scoped beneficiary). | Orthogonal to the ratified status (CF-WS-I6-02). |
| runway / probation | `runway`: minimum interval between a record's creation and its earliest time-based expiry (`InsufficientRunway` refusal); *probation*: the bounded age a `hypothesized`-grade record may reach before turning `expiring` (`DebtPolicy.hypothesized_max_age`). | OpenHands `_runway_error` precedent; OQ-WS-I6-01. |
| debt index / `DebtIndex` | Derived registry projection (`StaleIndex` family) listing every debt record with stored and current status, evidence grade, next expiry, removal-test executability and last verdict, uses, and `expired_used` run counts. | Served by registry `query`; never a store of record. |
| removal test / `RemovalTest` | Extends the ratified term: a closed sum `{retirement_experiment, critic_experiment, successor_chain_experiment, probe_pass, recalibrate, refit, zero_uses, null_profile_compile, remeasure, no_dead_weight_found, revalidation_review, profile_registered}`; every executable kind is an ordinary J3 experiment; every kind must instantiate at `seal`/`register` (`validate_removal_test`). | ADR-0126's removal test is the `retirement_experiment` verdict. |
| removal verdict / `RemovalVerdict` | Immutable record `{debt_ref, kind, verdict ∈ {pass, fail, inconclusive{reason}}, report_ref, settled_at}`; `fail` is evidence (grade `confirmed`), `pass` makes the rule eligible for retirement. | |
| retirement record / `RetirementRecord` | `{removal_test_report_ref, verdict_ref, decided_by: ProvenanceRecord{origin: human}, rationale: Text}` referenced by the superseding version that omits the rule (`supersedes{reason: expiry}`); the product meaning of "retired by ADR". | CF-WS-I6-05. |
| debt report / assumption-debt health | `DebtReport`: persisted, provenance-bearing projection per definition/profile/bundle/fleet with rows, counts, buckets `{overdue, imminent, scheduled, awaiting_seal}` and `AssumptionDebtHealth`; the latter is the `debt.*` `MetricDeclaration` family in the evolvability dimension. | Rendered identically by CLI and web (ADR-0170 §4). |
| debt policy / `DebtPolicy` | MUST-data document `{required_fields_by_home, min_runway, hypothesized_max_age, evidence_max_age, warn_within, grace_period, max_open_removal_tests, priority, notice_sinks, schedule, dead_weight_designs_allowed}` layered with `authority_cap`. | ADR-0024 pattern (as `RegistryPolicy`). |
| debt notice / `DebtNotice` | `{debt_ref, owner, bucket, reason, next_action, report_ref}` emitted to declared sinks; never a model context item. | litellm alert shape. |
| expired-used run | Any run compiled with an `expired` debt record of any home under a recorded `intent_ref`; excluded from headline reports unless the `Design` declares dead-weight purpose. | Generalises ADR-0126 §3's profile-only form. |
| spec-debt record / spec-debt register | An `AssumptionDebtRecord{debt_class: spec_decision}` per ratified ADR, generated from its (a)/(c)/(d) fields with revalidation triggers; `research/registers/spec-debt.md`. | ADR-WS-I6-2; RK-06. |
| dead weight | A conditioned rule that is valid and conformant but unfollowed by, or non-inferior on removal for, its scoped beneficiary — S-047's word, given a test. | The failure signature T-LCD-05 replaces with a removal test. |
