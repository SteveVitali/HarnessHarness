## Ontology terms

| term | definition | notes |
|---|---|---|
| **results row (`ResultsRow/1`)** | `project(run, results_row, until_seq, scoring)`: the canonical, content-addressed record of one run's coordinates (factor tuple with both configuration ids), outcome, total metric cell list (`value \| n/a{reason}` with `audit_ref` evidence), consumption with cost provenance, cache, lineage, ledger-derived annotations, audit head and scoring context; keyed `(configuration_version_id, run_id)`; never a display name. | WS-J5 / WS-B1 / WS-I2 / WS-L4. ADR-0026/0038/0045 realized. |
| **row version / row head** | A `ResultsRow` produced under one `ScoringContext`; re-scoring yields a new version with `supersedes` + `derived_from_reason ∈ {initial, regrade, validator_superseded, pricing_resnapshot, registry_bump, redaction}`; the head is the newest version whose scoring members are not revoked; versions are never deleted. | WS-J5 (CF-344). |
| **scoring context** | `{validator_set[], overlay_runs[], metric_registry_version, pricing_ref, view_policy_version}` — the pinned inputs a row projection depends on besides the run's own prefix. | WS-J5. |
| **overlay run** | An instrument run whose `verification.validator.verdict` events target another run by `audit_ref` (regrade, counterfactual scoring); never appends to the subject's ledger; named in the subject row's scoring context. | WS-J5 / WS-G1 / WS-I7. Precedent: Harbor regrade trial (`source_trial`). |
| **results annotation index** | Derived, rebuildable index over rows: `bundle_refs[]{bundle_id, kind, claimed_level, status, level_now, verifiable_by[]}`, `depends_on_revoked`, `bundle_retracted`, `excluded_by[]`, `leaderboard_memberships[]`, `analysis_refs[]`, `flags[]{kind, reason_ref}`; excluded from row bytes (CF-298). | WS-J5 / WS-I3 / WS-L4. |
| **cell table** | Derived table per design: `cell_id = (arm_id, configuration_id, task_id)` → included/excluded row heads with reasons and per-metric (c, n), values, outcome counts, veto count; the J4 aggregation input. | WS-J5 / WS-J4 / WS-I2. |
| **experiment run / experiment ledger** | A run with `run_kind = experiment` (charged `instrument`; no configuration, environment or cells) whose durable `measurement.experiment.*`, `measurement.analysis.*`, `measurement.leaderboard.*` events are the immutable record of what an experiment declared, bound, excluded, amended, analysed, closed, bundled and published. | WS-J5 / WS-J3 / WS-B1 (CF-343). |
| **analysis record** | `AnalysisRecord{analysis_id, kind, procedure, inputs (row versions or query + watermark set), registry/pricing versions, oracle ids, judge snapshots, report: ContentAddress, pre_registered, registered_analysis_ref?, post_amendment, provenance, cost}`; immutable; supersession only; `pre_registered` only when the plan matches by identity. | WS-J5 / WS-J4 / WS-I2. |
| **pre-registered vs exploratory analysis** | Label on an analysis record: pre-registered analyses match `PreRegistration.analysis_plan_ref`/`primary_metrics` by identity; all others are exploratory; both are recorded, neither is hidden. | WS-J5 / WS-I2. Precedent: none in OSS planes; motivated by S-523/-09. |
| **leaderboard definition** | Versioned, name-published record `{suite, split, scope, admission policy, columns[], rank_rule, strata[], disclosure_policy, readers, contamination_policy_ref}`; MUST-data except the projection. | WS-J5 / WS-J2. Precedent (grammar): Harbor Hub `columns[]`/`rank_by[]`; HELM schema. |
| **admission policy** | `{min_bundle_status, min_claimed_level, require_bundle_kind, min_replicates_per_task, required_match_spec_mode, eval_budget_equality_across_entries, cache_policy_required?, allow_outcome_classes, allow_veto_tripped, exclude_suite_retired = annotate, allow_hosted_observability}` — what a configuration needs before it may be a leaderboard entry. | WS-J5. `no-precedent / novel` as an enforced rule (partial: SWE-bench `checked`, Terminal-Bench 2.1 review). |
| **leaderboard snapshot / entry / unadmitted** | `LeaderboardSnapshot = project(definition, results store @ watermark_set)` with `snapshot_id = view_hash`; an entry is one `configuration_id` with strata, contributing row versions, bundle refs, headline distribution, columns, cost/Pareto, budget match, rank, `selection?`, disclosure and flags; `unadmitted[]` lists configurations with typed reasons; published snapshots are retained and never deleted; `diff_snapshots` reports no removals. | WS-J5 / WS-K2 / WS-K3. Precedent: HELM summarizer over immutable runs. |
| **disclosure record (`DisclosureSummary`)** | Per experiment/entry counts derived from the experiment ledger: arms registered / published / restricted, exclusions, analyses pre-registered / exploratory; an entry without an experiment is `undisclosed`. | WS-J5. Motivated by S-523 (mechanism), S-488 best@k disclosure, T-LCD-14. |
| **selection record** | `{n_candidates_registered, rule, search_budget_ref}` on an entry produced by choosing among registered arms (best-of-N); the leaderboard form of search-time vs artifact benefit. | WS-J5 / WS-I2 (ADR-0046). |
| **watermark set** | `[(run_id, seq)] + catalogue/registry watermarks` stamped on every results-store read and derived object; reads are byte-repeatable at a watermark set; `WatermarkAhead` when a requested seq is not yet durable. | WS-J5 / WS-B1 (generalizes ADR-0026 `derived_from`). |
| **reader-verifiable level (`level_now`, `verifiable_by`)** | Annotation on a row's bundle ref: the reproducibility level still supportable after GC/redaction (`level_now`) and, per reader set, the level a reader with that access can verify (`verifiable_by`); never raises `claimed_level`. | WS-J5 / WS-I3 / WS-L6 (OQ-374; OQ-331/OQ-112). |
| **results export** | `export_rows(QuerySpec, target, PublicationPolicy)` — a lowering with a typed loss report; only `ledger_native_rows` is lossless; `n/a{reason}` never lowers to 0 or empty. | WS-J5 / WS-I1 / WS-I3 (T-LCD-11). |
