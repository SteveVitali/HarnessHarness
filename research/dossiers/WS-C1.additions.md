**Positions on peer sidecar questions addressed to WS-C1 (not re-deciding their owners' turf):**
- **OQ-072 (closed here):** the gateway consumes the compiled `ProviderRequestPlan` as sealed data and owns transport only; a model-id branch in codec sources fails the AC-C1-1 static gate (ADR-0118).
- **OQ-063 (agreement):** D1 renders; the gateway receives rendered material plus `context_label` (CF-158 consistent).
- **OQ-111 (partial):** distributional fingerprint, `instrument`-charged, DRIFT annotates and splits arms (ADR-0120 decision 5); parameters → OQ-286.
- **OQ-122 (partial):** `seed_honoured` tri-state per model in the profile, probed, never inferred from the transport's `seed_accepted`; seed material recorded as `seed_request` on `model.call.requested`; by-replicate pairing admissibility remains I2's.
- **OQ-048 (input):** the model coordinate of a call whose `served_model ≠ requested` is the served model; the run-level representation (role table / realized set) is C2's CF-260.
- **OQ-097 (input):** `cache_state` is `unknown` unless `WireDialect.cache_state_visible`; no audited API exposes warm/cold state (negative result N1).
- **OQ-117 (proposal):** `normalizer_ref` → profile (`usage_mapping` version); `pricing_ref` → bundle; dialect documents → C1 registry (OQ-285).
- **OQ-297 (position):** a `failed` terminal closes the stream after any `block.completed` events already emitted (G4/G5), so a completed tool-call block before `stream_interrupted` is available to B2/F2 as a committed observation; continue-vs-restart is F2/B2's decision and rendering under a new profile is D1's (OQ-067); the gateway guarantees only that the partial is reconstructible and never re-sent by a transport attempt.
- **OQ-298 (position):** minimum `serving_route_reported` fields = `served_model`, `substitution`, `provider.notice{fallback_boundary}` where exposed, cost `provenance = gateway_reported`; candidates `unknown`; stratify rather than refuse unless the `Design` says otherwise (ADR-0120 decision 7).
- **OQ-195 (position):** provider-side compaction surfaces as `provider.notice{kind: other → propose `compaction_applied`}` plus `usage.iterations` in `usage.raw`; the gateway records the notice and the pre-call `view_hash`; the forgotten-set ledger entry and `harness_overhead.compaction` mapping are D2/L2's; `pause_after_compaction` is a decision-point guard (F1), not a gateway behaviour.
- **OQ-202 (position):** the embedder is a model binding with its own `ModelSnapshotRecord`; the same distributional probe applies; the index is annotated `depends_on_drifted`; rebuild/refuse is D3's.
- **OQ-206 (position):** the gateway is the publisher of the `model snapshot id` dependency stamp, sourced from `served_model`/`snapshot_id` claims (`authority = external`).
- **OQ-229 (position):** shim-interpreter model calls are ordinary `model.call.*` events with their own `model_call_id`; their tokens post under the same profile `usage_mapping` roles as any call and are attributed by `attribution` (E2 decides `subject` vs `harness_overhead`), not by a separate token role.
- **OQ-236 (position):** provider-hosted search results arrive as `ProviderOpaqueBlock{kind: provider_search_result, payload, owner}`; the gateway never lifts fields; the lifting to `DiscoveryResult` is a profile/E4 mapping over the ledger block.
- **OQ-148 (position):** the gateway uses a kernel-internal channel through `kernel_use(purpose = gateway_auth)`; `open_call` obtains a credential *handle* (`CredentialUnavailable` otherwise); no credential material enters any event or blob (AC-C1-13); a `credential_binding_id` on `model.call.requested` is acceptable and rotation is H3's `security.credential.rotated`.

## Ontology terms

| term | definition | notes |
|---|---|---|
| **model gateway** (alias: model adapter) | The boundary component (`home = model_boundary`, CF-026) through which every native model call leaves the kernel and every provider response re-enters it; model-blind and dialect-parameterised; consumes the `ProviderRequestPlan` as data and owns transport only (CF-044, OQ-072). | Registered component class; operations `open_call/stream/complete/cancel/estimate_tokens/discover/probe/describe`. Alias retained per ADR-0008. |
| **provider request plan** (`ProviderRequestPlan`) | The sealed, content-addressed data document (`plan_hash`) the gateway serialises without choosing: dialect ref, endpoint ref, rendered system/messages, lowered tool payloads, tool choice, sampling, reasoning options, cache-marker positions, response format, dialect-registered provider params, opaque metadata passthrough. Named by WS-A4; defined here. | CF-258 (naming vs D1 `RenderedRequest`). |
| **wire dialect** / **`WireDialect` descriptor** | A gateway-owned, versioned, content-addressed data document describing one provider API family's transport: framing, plan schema, envelope fields, auth kinds, usage arrival, cache semantics, capability declaration, retry-after sources/caps, idle timeout, and `DialectRule`s with assumption-debt records. Selected by `provider_api_family`. | The data home for dialect-conditioned knowledge that is not model-conditioned (WS-C1 F3). |
| **wire codec** | The pure function pair `serialize(dialect, plan) → frames` / `decode(dialect, frames) → ModelEvent*` for one wire dialect; contains no model identifier and no profile field (AC-C1-1). | One per dialect; two independent implementations must agree on golden streams. |
| **normalized model event** / **model-event grammar** | The closed kernel sum `ModelEvent` (attempt/message/block start-delta-completed, usage.updated, provider.notice, attempt.failed, completed, failed) with grammar invariants G1–G7; deltas are `ephemeral`; terminals are `durable`. | Lowering to Hosting-ABI `agent_message_chunk`/`usage_update` and to OTel GenAI with declared loss. |
| **normalized assistant message** (`ModelMessage`) | The settled output of one logical model call: typed blocks (text, reasoning, redacted reasoning, tool call, provider-opaque), stop reason and details, usage record, served model, snapshot id, surface ids, provenance (`authority = delegate`). Reconstructible from `block.completed` events alone. | Precedent: pi `AssistantMessage`; goose `Message` + `ProviderUsage`. |
| **provider notice** | A `ModelEvent` carrying provider-emitted, non-content information (`rate_limit_snapshot`, `served_model`, `fallback_boundary`, `safety_buffering`, `reasoning_included`, `verification_required`, `models_etag`, `other`) as an owner-stamped opaque payload; never changes classification or accounting by itself. | Precedent: codex `ResponseEvent::{ServerModel, SafetyBuffering, RateLimits, ModelVerifications}`. |
| **opaque leaf** (`OpaqueLeaf`) | WS-A3 `CompiledPayload`-class opaque bytes `{format_tag, bytes_hash, owner{provider, model}, provenance}` carried through decode → ledger → render byte-for-byte: reasoning/thought/text signatures, encrypted reasoning items, provider-opaque blocks. | The gateway never interprets one; D1 decides replay or drop (OQ-067). |
| **served model** / **served-model drift** | The provider-reported model identity that actually produced a response (`served_model`), and the fact `served_model ≠ model_ref.provider_model_id` with `substitution ∈ {none, provider_fallback, safety_routing, unknown}`; priced at the served model; a configuration-level drift, annotate + split. | OTel `gen_ai.response.model`; distinct from C2's `routing.deviation`. |
| **attempt** vs **logical model call** | An attempt is one transport send of identical bytes under one `model_call_id` (a `model.call.attempt.*` span, ADR-0043 M4); a logical model call is the unit with one plan hash, one reservation and one terminal. A request-changing "retry" is a new logical call. | Aligns with WS-I1 `model_attempt` and WS-C2 retry-vs-reroute. |
| **attempt policy** (`AttemptPolicy`) | The per-call data record `{max_attempts, base/max delay, jitter, honour_retry_after, retry_after_cap_ms, retry_on ⊆ {transient, rate_limit}, stream_idle/attempt/connect timeouts}` supplied by F2 and executed by the gateway. | CF-256 ownership split. |
| **retry class** | `ModelError.retry_class ∈ {transient, rate_limit, permanent, ambiguous}`; kernel-fixed default per `ModelErrorClass`; a dialect rule may only narrow transient → permanent. | Precedent: Inspect `RetryDecision.kind`. |
| **model error class** (`ModelErrorClass`) | The closed kernel sum of gateway-emitted failure classes grouped by attribution (transport, request, account, policy, response, control) plus `unknown`; extended only by dialect bump; `raw`/`provider_code` kept as surface aliases. | Consumed by C2's class → action table and F2; never message text. |
| **stop reason** (`StopReason`) | Closed kernel sum `{end_turn, tool_use, max_output, stop_sequence, content_filter, refusal, pause_turn, deferred, cancelled, error, unknown}` with `raw_stop_reason` alias and `StopDetails`. | Precedent: pi, Inspect, Anthropic, Responses `incomplete_details`. |
| **unparseable arguments** (`Unparseable{raw, reason}`) | The typed tool-call argument value when strict JSON parsing at `block.completed` fails (`invalid_json`, `truncated`, `empty`); preserved verbatim; never repaired by the gateway; handled by the control strategy at `act` and rendered to the model by E5 through the profile's `error_format`. | Negative precedents: opencode `experimental_repairToolCall`, pi `repairJson`. |
| **transport capability declaration** | The gateway-owned, tri-state (`supported | unsupported | unknown`) record per wire dialect × endpoint (streaming, usage in stream/on cancel, cache semantics/state visibility, count tokens, deferred requests, model listing, snapshot id exposure, retry-after honoured, seed accepted, parallel connections, websocket); declared → probed → `ConformanceRecord`; never intersected with model capabilities. | T-LCD-07 applied to transports. |
| **model discovery claim** (`ModelDiscoveryClaim`) | A value reported by a provider listing/metadata endpoint (`context_window`, `max_output`, modalities, pricing, snapshot id) with `provenance{origin = tool(endpoint), authority = external}`; evidence that surfaces DRIFT against the pinned profile; never a runtime source ("pinned wins"). | Replaces goose's override → configured → canonical → default chain. |
| **distributional fingerprint** | The `ConformanceRecord` from the fingerprint probe: per-prompt agreement rates and a multiset hash over n temperature-0 samples of a pre-registered prompt set, with served model and snapshot id; DRIFT when agreement or modal output leaves the pre-registered band; charged `instrument`; annotates and splits arms. | Mechanism: S-441 (single hashes flap under nondeterminism). |
| **queue wait** (`queue_wait_ms`) | Time an attempt spent waiting for a connection slot or rate-limit window before bytes were sent; recorded on the attempt span; feeds ADR-0039 `time.working_ms` so throttling never masquerades as harness latency. | Precedent: Inspect `max_connections` semaphore. |
