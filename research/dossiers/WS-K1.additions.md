## Ontology terms

| term | definition | notes |
|---|---|---|
| attendance declaration / attendance source | `AttendanceDeclaration{value ∈ {interactive, async, unattended}, source ∈ {declared, tty_inferred, forced}}` written by a surface into the run manifest before `open_run`; the value is ADR-0069's `attendance`, the source records how it was decided. | WS-K1 (extends WS-H7 `attendance`); manifest field. |
| presentation mode | A surface property `attended terminal \| headless \| serve \| acp` naming how one command set is presented; never a ledger fact except through the attendance declaration. | WS-K1; distinct from attendance (the precedents conflate them). |
| invocation record | `InvocationRecord{argv_canonical, cwd_ref, principal, attendance declaration, output_format, stdin_digest?, overrides_layer_id?, instrument_record, idempotency_key}`; appended as `lifecycle.surface.invoked` (durability per OQ-385). | WS-K1 / WS-B1. |
| exit class | The closed sum `ExitClass ∈ {ok, invocation_error, validation_error, refused_by_kernel, budget_exhausted, refused, cancelled, infrastructure_failure, oracle_failure, approval_denied_unattended, tampered}` derived totally from `outcome_class × StopReason` plus two pre-ledger classes; numerals are a convenience, the string in `ResultRecord` is authoritative. | WS-K1; no new sum for ledger facts (ADR-0048). |
| surface preset | `SurfacePreset{name, approval_mode, narrowing_leaves[], requires_containment}` (MUST-data): a precedent-style mode spelling that lowers to one `approval_mode` value plus Π narrowing leaves; the bypass preset requires `enforcement_evidence = enforced`. | WS-K1 / WS-H7 / WS-H1; presets are lowerings, the IR parameter is the identity (ontology "approval mode"). |
| cli stream view | `cli_stream_view` = the identity projection over a run's durable ledger events filtered by a `SinkPolicy{content_classes}`, emitted as JSONL and terminated by one `ResultRecord`; a `compact` view is a declared-lossy projection with a `LoweringLossReport`. | WS-K1 / WS-I1 / WS-K2. |
