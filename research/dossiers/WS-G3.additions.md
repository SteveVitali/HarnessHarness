## Ontology terms

| term | definition | notes |
|---|---|---|
| **critic** | A `Validator` component variant that renders a verdict about a run, effect, artifact or claim from a kernel-built evidence bundle: programmatic (deterministic oracle classes) or model-based (judge). A beneficiary prompt asking the model to check itself is a `HarnessRule`, not a critic. | WS-G3; ADR-0016/0047 |
| **critic kind** | `{programmatic, judge, agentic_judge (may probe read-only), emulated (ToolEmu-class scenario oracle; veto-only), monitor (veto over `claimed` evidence)}` | WS-G3; WS-E2 owns the emulated pre-check as a placement |
| **evidence bundle** / **evidence item** / **omission record** | The kernel's content-addressed projection of ledger views, end-state reads, artifacts and probe results supplied to a critic; each item carries `evidence_class`, provenance and label and is rendered under the role-placement invariant; omitted items are listed with a reason. | WS-G3; ADR-0026/0034 |
| **evidence class** (values) | Closed value set of the ratified term: `measured` (kernel/environment facts), `reconciled` (claims checked against state by WS-G2), `claimed` (any AgentProcess output). Orthogonal to authority class (CF-080). | WS-G3 completes WS-L3's term |
| **grounding (of a verdict)** | Derived: the strongest evidence class among the items a verdict cites; `ungrounded` ⇒ `oracle_failure`; headline and gate uses require `measured`/`reconciled`. | WS-G3 |
| **critic site** | `{instrument (Lab-invoked per run; charged_to = instrument), runtime (bound in the sealed definition at a decision point; charged_to = subject)}` | WS-G3; ADR-0045 §9; CF-114 |
| **critic use** / **gate critic** / **reporting critic** | `{report (verdict is a metric or detector), gate (verdict changes control flow)}`; a gate critic's verdict is never the reported success; gate judge calls inside search are `search_budget.judge_calls`. | WS-G3; ADR-0046 |
| **held-out critic** | The critic that produces an arm's `artifact_benefit`/`transfer`, required to be outside the `held_out_from` closure of every gate critic used in the search; violation `JudgeLeakedIntoArtifact`. | WS-G3; WS-I5 |
| **independence vector** | `{snapshot, context, capability, provenance, optimization, adversarial}` declared on every critic with per-use minimums; summarized on every verdict. | WS-G3-adr-2 |
| **admission mode** | `{principal_only, quarantined_external, all_labelled}` — which labelled evidence `build_evidence` admits to a critic's bundle; the verdict's label follows the join. | WS-G3; WS-H7 default `principal_only` |
| **calibration record** / **exploratory critic** | Content-addressed record of a critic's agreement with a deterministic or human reference on a pre-split labelled set, with error rates, position/self-consistency, evidence ablation and expiry as assumption debt; a judge without an active record is *exploratory* (`n/a{no_detector}` for gating). | WS-G3-adr-3; resolves OQ-123 shape |
| **position calibration** | Contract rule that comparative verdicts are evaluated in both orders and aggregated; `position_consistency` is a calibration field. | WS-G3; S-WS-G3-03 |
| **uncited finding** | A critic finding with no `evidence_ref` into the bundle; dropped and counted (`uncited_findings`), the operational form of hallucinated findings. | WS-G3; S-WS-G3-06 |
| **critic placement** / **critic gate rule** | `HarnessRule{kind: critic_gate}` with `{decision_point, trigger, max_iterations?, budget_share_cap, admission_mode}` and an assumption-debt record whose removal test is the critic experiment. | WS-G3; T-LCD-05 |
| **critic experiment** | The standard matched-budget recipe `{critic on, off} × placement × critic snapshot (× admission mode)` reporting Δ deterministic success, overhead, approvals and calibration error rates; WS-F4's input. | WS-G3; T-LCD-14 |
| **monitorability** | The property that a critic reading `claimed` evidence (reasoning, transcript) keeps detecting misbehaviour; lost when the beneficiary is optimized against that critic ("monitorability tax"). | WS-G3; S-WS-G3-05; OQ-WS-G3-02 |
